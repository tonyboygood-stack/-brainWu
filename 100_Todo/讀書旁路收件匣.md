# 讀書旁路收件匣

> 這裡只收閱讀中突然浮現、但**不屬於本篇知識收成**的靈感與待辦。它們留在原始頁面，這裡用標籤自動集中；不用複製、不用整理、不打斷閱讀。

## 靈感發想

```query
tag:#靈感發想
```

## 行動與待辦

```query
tag:#行動與待辦
```

## 使用方式

- 臨時想到要查、要買、要問、要做：直接在當前頁寫一句，末尾加 `#靈感發想` 或 `#行動與待辦`。
- `#靈感發想`：先捕捉，不要求變成任務。
- `#行動與待辦`：已可執行的下一步；在這裡找到後再排進週計畫或正式待辦。
- 這兩個標籤不會被「收成這一篇」處理，也不會變成臨床知識卡。
