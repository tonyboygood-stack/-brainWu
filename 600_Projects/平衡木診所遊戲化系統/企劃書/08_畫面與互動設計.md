# 08 畫面與互動設計

---

## 一、先講一個核心張力，它決定整節怎麼走

### 診所的視覺語言 vs 遊戲化的視覺語言，是衝突的

| [[600_Projects/東湖診所開業計畫/設計簡報\|設計簡報]]定的 | 一般遊戲化長的樣子 |
|---|---|
| 日式簡約、無印風 | 飽和色、圓角卡通 |
| 大地色系、暖米、淺木色 | 高對比、螢光強調色 |
| 留白、寧靜 | 彈跳、閃爍、粒子特效 |
| 「讓人放下戒備」 | 「刺激多巴胺」 |

**而且有個更實際的問題：診間平板與櫃台電腦，病人是看得到的。**

如果螢幕上跳出「+10 XP！🎉」，病人會看到。那會直接破壞設計簡報寫的「走進來的第一秒感受：安心、無壓力、溫暖」——病人會覺得「這家診所在玩遊戲」。

### 解法：**「安靜的遊戲化」**

不是把遊戲感藏起來，是**用不同的方式表達它**：

| ❌ 吵的遊戲化 | ✅ 安靜的遊戲化 |
|---|---|
| 音效、彈跳、粒子 | 靜音；動畫是「生長」與「浮現」，不是「爆炸」 |
| 飽和強調色 | 診所的大地色系，強調色極少 |
| 數字跳動、進度條爆滿 | 文字、印記、留下痕跡 |
| 「你得到了 10 分！」 | 「龜背芋留下了感激的淚水」 |

---

## 二、⭐ 最重要的判斷：這套系統的美術重心不在動畫，在**排版**

把整套系統的核心機制列出來看：

| 機制 | 本質 |
|---|---|
| 位階日誌 | **文字** |
| 交接備註 | **文字** |
| 老闆公告、每日一句、今日播報 | **文字** |
| 完成台詞 | **文字** |
| 每日診所日誌 | **文字** |
| 平衡木里程碑小故事 | **文字** |
| 今天值得記一筆 | **文字** |

**除了地圖和樹，這整套系統是文字驅動的。**

> 所以美術預算與心力不該花在「完成任務的爆炸特效」，該花在**字體、字級、行距、留白**。
> 一個排版講究的文字系統，比一堆動畫有質感得多，而且**完全符合日式簡約風**——這一次，品牌調性和功能需求是同一個方向，不用妥協。

### 視覺隱喻：不是一個遊戲，是**一本會長大的書**

- 每天寫一頁（每日日誌）
- 每個人有自己的筆記本（位階日誌）
- 牆上有一棵樹，樹上掛著這些年的紀事（平衡木）
- 完成一件事，是**在紙上留下一個印記**，不是「得到分數」

### 字體策略：用字體本身當設計語言

| 用途 | 字體 | 為什麼 |
|---|---|---|
| **敘事區**（日誌、編年史、每日一句、完成台詞） | **思源宋體 Noto Serif TC** | 溫暖、書卷氣、日式；讓人願意慢慢讀 |
| **功能區**（任務清單、按鈕、數字、備註） | **思源黑體 Noto Sans TC** | 清楚、好掃視 |

> **這個對比本身就是導航**：看到宋體就知道「這是故事」，看到黑體就知道「這是要做的事」。不用畫線分區，字體就分好了。

字級要偏大——診所可能光線不足，而且員工可能一手拿東西一手滑手機。

## 三、⚠️ 兩種螢幕，兩套視角

**病人看得到的螢幕，不能出現遊戲元素。**

| 螢幕 | 誰看得到 | 顯示什麼 |
|---|---|---|
| **櫃台電腦** | 病人可能瞄到 | **營運視角**：今日任務狀態、備註、今日播報、公告<br>❌ 不顯示角色、經驗、金幣、稱號、完成動畫 |
| **診間平板** | 病人在診間會看到 | 同上（可加：老吳的私人收件匣，需登入） |
| **員工手機**（PWA） | **只有她自己** | ✅ 完整遊戲感：角色、位階、金幣、稱號、完成回饋 |
| 老吳手機／電腦 | 只有他 | 全部 ＋ 後台 |

> **原則：遊戲化是員工的私人體驗，不是診所的公開展示。**
> 這同時解決兩件事：病人的觀感，以及員工的隱私（她的等級不該掛在牆上給人看）。

## 四、導航結構

### 手機（員工主要裝置，PWA 加到主畫面）

底部四個分頁 ＋ 一個常駐浮動按鈕：

```
┌────────────────────────────┐
│                            │
│         （內容區）           │
│                            │
│                     ┌────┐ │
│                     │ ✍️ │ │ ← 今天值得記一筆
│                     └────┘ │   （常駐，所有頁面都在）
├────────────────────────────┤
│  🗺️      📋      🌳      👤  │
│ 地圖    公佈欄   平衡木    我  │
└────────────────────────────┘
```

四個分頁的分工很乾淨：

| 分頁 | 回答什麼問題 |
|---|---|
| 🗺️ **地圖** | 我現在要做什麼？ |
| 📋 **公佈欄** | 診所現在怎麼樣？ |
| 🌳 **平衡木** | 我們走過什麼？ |
| 👤 **我** | 我變成什麼樣子了？ |

> 「今天值得記一筆」做成浮動按鈕而不是分頁，因為它是**隨手丟**的東西——要在任何頁面都按得到，而且不值得佔一個分頁。

## 五、地圖畫面

### 底圖

**第 1 期直接用成舍設計的 3D 俯視渲染圖 ＋ 可點擊熱區。** 現成資產、成本為零、格局最真實（員工一眼認得出哪裡是哪裡）。
第 2 期再考慮描成日式扁平插畫。

### ⭐ 任務圖示：**未完成是淡的，完成是實的**

這是我建議的最重要一個互動細節。

| 常見做法 ❌ | 建議做法 ✅ |
|---|---|
| 未完成 = 紅點／驚嘆號，完成 = 消失 | 未完成 = **淡色、半透明、緩慢呼吸的小點**<br>完成 = **變成一枚實心印記，留在原地** |

**為什麼這個差別很大：**

- 「未完成亮紅燈」= 一整天地圖都在對你叫，有壓迫感；而且病人瞄到會覺得「這家診所很多事沒做」
- 「完成就消失」= 做了一整天，地圖回到空白，**你的努力在畫面上不留痕跡**
- **「淡→實」= 一天結束時，地圖從淡淡的變成滿是印記**

> 心理感受完全不同：前者是**清空**（做完只是回到零），後者是**填滿**（做完是留下東西）。
> 這也呼應整套系統的核心哲學——**回饋來自「被記錄」，不是「被獎勵」**。

### ⭐ 角色站在她的守備區

地圖上，員工的小角色**站在她今天守備的區域**。

- 一個人守櫃台＋調劑室 → 角色站在兩區之間
- **週六雙人班 → 地圖上有兩個小人** → 一眼看到「今天不是一個人」

成本極低（一個小圖釘在座標上），但代入感很強，而且它讓「守備制度」變成看得見的東西，不用解釋。

## 六、完成任務的回饋

老吳要的：角色完成任務畫面 ＋ 一句話（「龜背芋留下了感激的淚水：『終於有人澆水了！』」）。

| 決定 | 建議 | 理由 |
|---|---|---|
| 全螢幕 vs 卡片 | **卡片**（從下方滑出） | 一天 4–6 次，全螢幕會煩 |
| 停留時間 | **2 秒自動收，可點掉** | 不要讓人等 |
| **音效** | **預設全靜音** | 設計簡報寫「寧靜」，任何提示音都會破壞候診區。可在設定開，但預設關 |
| 動畫 | 淡入 ＋ 輕微上浮，**不彈跳** | 安靜的遊戲化 |
| 內容 | Q 版角色圖 ＋ 台詞（宋體）＋ 金幣與經驗（小字） | 台詞是主角，數字是配角 |

> **數字要縮小、台詞要放大。** 這是老吳花心思寫的東西，也是回饋的真正來源。「+10 金幣」誰都給得起，「龜背芋留下了感激的淚水」只有這間診所有。

## 七、平衡木畫面

### 滾動方向就是時間方向

```
       ↑ 往上滑
     🌳 樹梢 — 最新的里程碑
        樹枝 — 依年份分枝
    ────地面────
        樹根 — 籌備期（2026 年 5 月起）
       ↓ 往下滑
```

**往上是未來，往下是過去。** 不需要任何說明，滑一下就懂。

### 互動

- 點一塊牌子 → 從下方滑出詳細卡片：小故事（宋體）· 參與者頭像 · 留言串
- 留言時區分「當年在場的人」與「後來的人」（不同底色或小標）
- 樹隨開業月數緩慢長大（第 1 期用最單純的觸發）

## 八、角色卡（「我」分頁）

由上而下：

```
      [ 頭像 ]
   ○○○　🏅櫃台熟手
   到職 312 天

── 我的守備 ──
櫃台     ●●●○○  熟手 → 專精者　還差 4 個月
調劑室   ●●○○○  熟手　　　　　還差 1 個月
診療區   ●○○○○  跟診菜鳥　　　還差 2 個月
        （熟練值：櫃台 486 診）

── 我的日誌 ──  [ 3 本 · 12 則 · 4 則已傳承 🌱 ]

── 我收到的感謝 ──
💌 一位病人說：「櫃台小姐很細心地跟我解釋…」（永久保留）
🤝 老吳：「謝謝你週三一個人撐下來」

── 我的稱號 ──  🌱綠手指　🔥救火隊長　☔風雨無阻

── 金幣 ──  238 　[ 逛逛商店 ]

── 我的衛教語錄 ──  已說出口 47 句
```

**兩個設計要點：**

1. **「還差 4 個月」要明確寫出來**，不要只給模糊的進度條。清楚的距離感才有推進力。
2. **病人感謝卡放在最上面、永久保留、不被新的洗掉** —— 那是她做這份工作最真實的意義來源。

## 九、實務細節（容易被漏掉但會決定好不好用）

| 項目 | 設計 | 為什麼 |
|---|---|---|
| **離線可用** | 任務完成先存本機，連上網再同步 | 診所 wifi 不穩時不能卡住工作 |
| **草稿 autosave** | 所有輸入框即時存本機 | 配合語音輸入（一口氣講很長，斷掉會很挫折） |
| **原生 `<textarea>`** | 不用富文本編輯器 | Typeless 等語音工具注入不進富文本 |
| **深色模式** | 第 2 期 | 晚診到 21:30，診間燈光暗 |
| **單手可操作** | 主要按鈕在螢幕下半部 | 她常常一手拿東西 |
| **免登入停留** | PWA 記住登入，不要每天重登 | 每天要重登的系統，兩週內必被放棄 |

## 十、視覺色票（承設計簡報）

| 用途 | 色 |
|---|---|
| 底 | 暖米白 |
| 文字 | 深灰褐（不用純黑） |
| 分區色 | 淺木色系，各區明度差一點就好 |
| **唯一的強調色** | 🔴 只用在「待處理·紅」的備註 |
| 完成印記 | 淺木色實心 |
| 樹 | 自然綠褐 |

> **強調色只留給一件事**（紅色待處理）。其他全部靠明度與留白分層。
> 這是無印風的核心手法，也讓那唯一的紅色真的有份量。
