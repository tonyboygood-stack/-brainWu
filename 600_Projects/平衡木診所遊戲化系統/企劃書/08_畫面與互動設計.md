# 08 畫面與互動設計

---

## 一、先講一個核心張力，它決定整節怎麼走

### 診所的視覺語言 vs 遊戲化的視覺語言，是衝突的

| [[600_Projects/東湖診所開業計畫/設計簡報\|設計簡報]]定的 | 一般遊戲化長的樣子 |
|---|---|
| 日式簡約、無印風 | 飽和色、圓角卡通 |
| 大地色系、暖米、淺木色 | 高對比、螢光強調色 |
| 留白、寧靜 | 彈跳、閃爍、粒子特效 |
| 「讓人放下戒備」 | 「刺激多巴胺」 |

**而且有個更實際的問題：診間平板與櫃台電腦，病人是看得到的。**

如果螢幕上跳出「+10 XP！🎉」，病人會看到。那會直接破壞設計簡報寫的「走進來的第一秒感受：安心、無壓力、溫暖」——病人會覺得「這家診所在玩遊戲」。

### 解法：**「安靜的遊戲化」**

不是把遊戲感藏起來，是**用不同的方式表達它**：

| ❌ 吵的遊戲化 | ✅ 安靜的遊戲化 |
|---|---|
| 音效、彈跳、粒子 | 靜音；動畫是「生長」與「浮現」，不是「爆炸」 |
| 飽和強調色 | 診所的大地色系，強調色極少 |
| 數字跳動、進度條爆滿 | 文字、印記、留下痕跡 |
| 「你得到了 10 分！」 | 「龜背芋留下了感激的淚水」 |

## 二、⭐ 最重要的判斷：這套系統的美術重心不在動畫，在**排版**

把整套系統的核心機制列出來看：

| 機制 | 本質 |
|---|---|
| 位階日誌 | **文字** |
| 交接備註 | **文字** |
| 老闆公告、每日一句、今日播報 | **文字** |
| 完成台詞 | **文字** |
| 每日診所日誌 | **文字** |
| 平衡木里程碑小故事 | **文字** |
| 今天值得記一筆 | **文字** |

**除了地圖和樹，這整套系統是文字驅動的。**

> 所以美術預算與心力不該花在「完成任務的爆炸特效」，該花在**字體、字級、行距、留白**。
> 一個排版講究的文字系統，比一堆動畫有質感得多，而且**完全符合日式簡約風**——這一次，品牌調性和功能需求是同一個方向，不用妥協。

### 視覺隱喻：不是一個遊戲，是**一本會長大的書**

- 每天寫一頁（每日日誌）
- 每個人有自己的筆記本（位階日誌）
- 牆上有一棵樹，樹上掛著這些年的紀事（平衡木）
- 完成一件事，是**在紙上留下一個印記**，不是「得到分數」

### 字體策略：用字體本身當設計語言

| 用途 | 字體 | 為什麼 |
|---|---|---|
| **敘事區**（日誌、編年史、每日一句、完成台詞） | **思源宋體 Noto Serif TC** | 溫暖、書卷氣、日式；讓人願意慢慢讀 |
| **功能區**（任務清單、按鈕、數字、備註） | **思源黑體 Noto Sans TC** | 清楚、好掃視 |

> **這個對比本身就是導航**：看到宋體就知道「這是故事」，看到黑體就知道「這是要做的事」。不用畫線分區，字體就分好了。

字級要偏大——診所可能光線不足，而且員工可能一手拿東西一手滑手機。

## 三、⭐⭐ 三種視角（2026-09-08 老吳定案，取代原本的「藏起來」方案）

我原本的方案是**減法**——病人看得到的螢幕就把遊戲元素藏掉。
老吳的方案是**加法**——做一個更值得看的預設畫面。**加法明顯更好**：病人看到的不是一個被閹割的介面，而是一個療癒的診所小世界，這反而變成候診區的加分項。

### 老吳的原始設計

> 預設營運視角（一般路過看到的畫面），主要顯示診所狀態，**診所畫面外圍要包含一點點街區 ＋ 天氣隨每天變化**更有感覺。診所狀態有**準備中**與**工作中**兩種自動切換：準備中時角色會在整個空間遊蕩，工作中角色會在各自的守備區遊蕩。角色頭上偶爾會浮出一小句話（例如：「我感覺我越來越熟練了！」）。
> **關鍵是療癒系畫風，看著畫面自己跑都讓人覺得愉快那種**，所以畫面要有一些小小巧思。
> 除了預設營運視角，可以點旁邊切換**任務模式**，一樣的診所圖但會跑出不同位置的任務點可以點選操作（給員工打卡完成與備註用），**預設 30 秒不動會自動切回營運視角**，這個模式下才有角色與完成動畫。

### ❌ 景觀模式否決（2026-09-08 老吳）

我原本建議在候診區電視播純景觀畫面。老吳否決，理由是實務的：

> 候診區電視同時具備**衛教影片**與**叫號系統**的功能，所以只能在下診後上診前開啟，一直手動切換三個東西也麻煩。

**這個判斷是對的。** 一個需要人記得切換的畫面，兩週內一定沒人切。

### ✅ 定案：兩種視角，兩個操作點

| 視角 | 顯示什麼 |
|---|---|
| **① 營運視角**（預設） | 診所小世界 ＋ **街區與天氣** ＋ 診所狀態 ＋ 今日播報。無任務點、無經驗金幣 |
| **② 任務模式** | 任務點、角色、完成動畫、備註入口。**30 秒不動自動切回 ①** |

**操作點（老吳指定）：**

| 位置 | 裝置 |
|---|---|
| 櫃台 | 櫃台電腦 |
| **診療區或走道牆上** | **壁掛平板** ← ⚠️ 見下 |
| 員工個人 | 手機 PWA（預設直接進 ② 任務模式） |

### ⚠️ 這帶出一個新的採購需求：走道／診療區壁掛平板

[[600_Projects/東湖診所開業計畫/診所設備清單|診所設備清單]]目前**沒有這一項**。原本規劃的螢幕只有：診間電腦、候診區壁掛電視、收銀 POS。

需要補進採購清單並跟設計師確認：

- [ ] **壁掛平板 ×1**（診療區或走道）——尺寸、掛點高度
- [ ] **該位置的電源** ← **這是關鍵，要在水電階段就決定**，事後拉線很醜也很貴
- [ ] 掛架形式（固定 or 可調角度）
- [ ] 位置要避開病人視線動線（它會顯示任務與備註）

> **電源這件事現在就要處理。** 裝修還在進行中，這種需求晚一步就變成明線。

## 三之二、診所狀態：建議做四種，不是兩種

老吳定的是「準備中／工作中」。我建議再加兩種——**成本為零（同一張圖不同狀態），但畫面豐富度差很多**：

| 狀態 | 觸發 | 畫面 |
|---|---|---|
| 🌅 **準備中** | 開診前 | 燈漸亮，角色在整個空間遊蕩 |
| ☀️ **看診中** | 看診時段內 | 角色在各自守備區遊蕩 |
| 🍵 **午休** | 週二四六 12:30–14:00 | 燈半亮，角色坐著，畫面安靜下來 |
| 🌙 **打烊** | 非營業時間 | 角色不在，燈暗，**樹在月光下** |

> **「打烊」這個狀態特別值得做。** 它讓「診所也會休息」變成畫面——老吳晚上在家滑開來看，看到的是一間安靜的、亮著小夜燈的診所。
> 而且週三、週日是固定休，那兩天整天都是這個畫面，反而成為一種節奏感。

**狀態切換依據**：排班表 ＋ 看診時段，系統自動判斷，不需要任何人操作。

## 三之三、⭐ 角色的閒置台詞：老吳的第四個創意空間

老吳已有三個創意空間：完成台詞、商店品項、今日播報那一句話。這是第四個。

### 關鍵設計：台詞由**系統狀態驅動**，不是隨機廢話

隨機的可愛台詞看三天就膩。但如果角色**真的知道今天發生什麼**，療癒感就成立了——那不是可愛，是「它在陪你」。

| 觸發條件 | 台詞範例 |
|---|---|
| 位階接近升級 | 「我感覺我越來越熟練了！」← 老吳原例 |
| 準備中 | 「今天會是好日子吧」 |
| 未完成任務多 | 「等一下…先把這個做完」 |
| 快收診 | 「今天也順利結束了」 |
| 下雨天 | 「傘桶好像不太夠」 |
| 剛收到感謝卡 | 「剛剛那位阿姨說謝謝耶」 |
| 週三 PT 單人班 | 「一個人也要好好守著」 |
| 節氣 | 「立冬了，記得提醒大家多穿一件」 |

### ⚠️ 但要有一條「對外安全」的白名單

**營運視角是預設畫面，病人可能瞄到。** 所以：

| ❌ 絕不出現 | ✅ 可以出現 |
|---|---|
| 抱怨、疲累（「好累喔」「今天病人好多」） | 期待、專注、小確幸 |
| 任何評論病人的內容 | 天氣、節氣、季節 |
| 任務名稱、備註內容 | 抽象的心情（「今天空氣很好」） |

> **任務模式（員工私人操作時）的台詞可以放鬆一點**，因為那個畫面 30 秒後就自動收起來了，而且是她主動打開的。

### 台詞庫：後台統一編輯 ＋ AI 每日補充（2026-09-08 老吳定案）

> 老吳：「除了 AI 每天依據角色近期資訊給出建議之外，**後台我也有統一編輯的地方**。」

**兩層架構：**

```
   ①【老吳的台詞庫】← 後台統一編輯，這是主體
        ↑
        │ 老吳挑選／修改後加入
        │
   ②【AI 每日候選箱】← AI 依近期資料產出 3–5 句新候選
```

**每天的流程**：AI 看近期狀態（升階進度、天氣、節氣、感謝卡、任務量）→ 產出幾句候選 → 進老吳的候選箱 → 他挑、改、丟掉，或加進台詞庫。

> 這跟提案機制、里程碑小故事是同一個原則：**AI 草擬，人確認。**
> 好處是台詞庫會越用越豐富，而且**每一句都是老吳審過的**——不會有 AI 自己生出來的怪句子在病人面前跑出來。

#### 台詞庫的欄位

| 欄位 | 說明 |
|---|---|
| `觸發條件` | 狀態（準備中／看診中／午休／打烊）· 事件（剛收到感謝卡）· 時段 · 天氣 · 節氣 · 個人進度（接近升階） |
| `台詞文字` | 一句話 |
| **`對外安全`** | 是／否 → 決定能不能在營運視角出現 |
| `角色限定` | 某個角色專屬 or 通用 |
| `出現權重` | 稀有台詞給低權重 |
| `啟用中` | 停用而不刪除 |

## 三之四、療癒感怎麼做出來（老吳說的「小巧思」）

**⚠️ 先講一個容易被低估的事實：候診區的病人平均會等 10–20 分鐘，他們會盯著看。**
短循環的重複動作一定會被看出破綻，然後畫面就從「療癒」變成「無聊的螢幕保護程式」。

| 手法 | 說明 |
|---|---|
| **角色路徑隨機**，不固定循環 | 這是耐看與否的關鍵 |
| **走走停停**（老吳補充）⭐ | 見下方閒置行為清單 |
| **低幀率手繪感** | 8–12fps 的逐格動畫**反而更有手繪溫度**——頓感是風格不是缺陷，而且省電 |
| **偶發彩蛋** | 見下方彩蛋清單 |
| **天氣連動** | 下雨時畫面在下雨、玻璃有水痕；晴天有光斑移動 |
| **時間連動** | 光線角度隨真實時間變化；晚診時外面街區的燈亮起來 |
| **季節連動** | 接節氣表——樹的顏色、街區的細節隨季節換 |

> **天氣資料本來就要接（今日播報用），現在一份資料兩處用，額外成本為零，但氛圍加成極大。**

### ⭐ 角色的閒置行為清單（老吳 2026-09-08 補充「走走停停」）

**「走走停停」比等速移動有生命感太多**，而且它還順便解決一個技術問題——見下方美術規格。

| 行為 | 說明 |
|---|---|
| **走走停停** | 隨機停 1–3 秒再繼續 |
| 停下來轉頭看一下 | 像在想事情 |
| 停在窗邊看外面 | 特別適合下雨天 |
| 蹲下整理東西 | 在櫃子、推車旁邊 |
| 伸個懶腰 | 低機率，午休狀態時多一點 |
| 經過樹旁邊時停下來看一下 | 呼應平衡木 |
| **兩人靠近時互相打招呼** ⭐ | **只有週六雙人班才看得到**——讓那天更特別 |

> 最後一條成本極低但意義很大：週三 PT 一個人、平日 FT 一個人，只有週六螢幕上會出現兩個小人互相點頭。**孤單與不孤單，變成畫面上看得到的事。**

### ⭐ 彩蛋清單（老吳：「你幫我記起來」）

**這是一份可持續增補的清單。** 彩蛋不需要一次做完，第 1 期挑 5–8 個，之後慢慢加——**而且「今天出現了新彩蛋」本身就是一個持續的小驚喜來源**。

| 類別 | 彩蛋 |
|---|---|
| **動物** | 貓經過窗外 · 鳥停在招牌上 · 有人牽狗經過 · 麻雀在樹上跳 |
| **自然** | 樹上掉一片葉子 · 風吹過樹梢 · 雨滴在玻璃上滑落 · 陽光光斑緩慢移動 · 起霧 |
| **街區** | 腳踏車騎過 · 機車停一下又走 · 送貨員經過 · 鄰居開門出來 · 路燈一盞一盞亮起來 |
| **診所內** | 藥茶煎煮筒冒白煙 · 飲水機冒氣泡 · 印表機吐出一張紙 · 候診區電視的微光閃動 · 空氣清淨機的燈變色 |
| **時節** | 中秋的月亮特別大 · 過年的紅色小元素 · 聖誕小燈 · 端午的艾草掛在門邊 · 立春第一片新葉 |
| **稀有** | 🌠 流星（夜晚極低機率）· 🌈 雨後彩虹 · 雙彩蛋（貓和鳥同時出現）· 樹開花 |
| **診所專屬** | 老吳的女兒偶爾出現在畫面裡 ⭐ |

> **最後一條是我最推薦的。** 這間診所是一個爸爸開的，那個小孩會在這裡長大。
> 如果畫面裡偶爾出現一個小小的身影，這個小世界就不只是一間店的模擬，而是一個家的樣子。
> （而且她會長大——畫面裡的她也可以跟著長大。這是這套系統唯一能做、別人做不出來的東西。）

### ⚠️ 效能：這個畫面會在平板上跑一整天

- 低幀率（同時也是風格選擇）
- CSS／SVG 動畫優先於 canvas 全幀重繪
- 候診區與櫃台的裝置要**插電**，不要靠電池
- 提供「省電模式」：無人操作 30 分鐘後降到極低幀率

## 四、導航結構

### 手機（員工主要裝置，PWA 加到主畫面）

底部四個分頁 ＋ 一個常駐浮動按鈕：

```
┌────────────────────────────┐
│                            │
│         （內容區）           │
│                            │
│                     ┌────┐ │
│                     │ ✍️ │ │ ← 今天值得記一筆
│                     └────┘ │   （常駐，所有頁面都在）
├────────────────────────────┤
│  🗺️      📋      🌳      👤  │
│ 地圖    公佈欄   平衡木    我  │
└────────────────────────────┘
```

四個分頁的分工很乾淨：

| 分頁 | 回答什麼問題 |
|---|---|
| 🗺️ **地圖** | 我現在要做什麼？ |
| 📋 **公佈欄** | 診所現在怎麼樣？ |
| 🌳 **平衡木** | 我們走過什麼？ |
| 👤 **我** | 我變成什麼樣子了？ |

> 「今天值得記一筆」做成浮動按鈕而不是分頁，因為它是**隨手丟**的東西——要在任何頁面都按得到，而且不值得佔一個分頁。

## 五、地圖畫面

### 底圖

**第 1 期直接用成舍設計的 3D 俯視渲染圖 ＋ 可點擊熱區。** 現成資產、成本為零、格局最真實（員工一眼認得出哪裡是哪裡）。
第 2 期再考慮描成日式扁平插畫。

### ⭐ 任務圖示：**未完成是淡的，完成是實的**

這是我建議的最重要一個互動細節。

| 常見做法 ❌ | 建議做法 ✅ |
|---|---|
| 未完成 = 紅點／驚嘆號，完成 = 消失 | 未完成 = **淡色、半透明、緩慢呼吸的小點**<br>完成 = **變成一枚實心印記，留在原地** |

**為什麼這個差別很大：**

- 「未完成亮紅燈」= 一整天地圖都在對你叫，有壓迫感；而且病人瞄到會覺得「這家診所很多事沒做」
- 「完成就消失」= 做了一整天，地圖回到空白，**你的努力在畫面上不留痕跡**
- **「淡→實」= 一天結束時，地圖從淡淡的變成滿是印記**

> 心理感受完全不同：前者是**清空**（做完只是回到零），後者是**填滿**（做完是留下東西）。
> 這也呼應整套系統的核心哲學——**回饋來自「被記錄」，不是「被獎勵」**。

### ⭐ 角色站在她的守備區

地圖上，員工的小角色**站在她今天守備的區域**。

- 一個人守櫃台＋調劑室 → 角色站在兩區之間
- **週六雙人班 → 地圖上有兩個小人** → 一眼看到「今天不是一個人」

成本極低（一個小圖釘在座標上），但代入感很強，而且它讓「守備制度」變成看得見的東西，不用解釋。

## 六、完成任務的回饋

老吳要的：角色完成任務畫面 ＋ 一句話（「龜背芋留下了感激的淚水：『終於有人澆水了！』」）。

| 決定 | 建議 | 理由 |
|---|---|---|
| 全螢幕 vs 卡片 | **卡片**（從下方滑出） | 一天 4–6 次，全螢幕會煩 |
| 停留時間 | **2 秒自動收，可點掉** | 不要讓人等 |
| **音效** | **預設全靜音** | 設計簡報寫「寧靜」，任何提示音都會破壞候診區。可在設定開，但預設關 |
| 動畫 | 淡入 ＋ 輕微上浮，**不彈跳** | 安靜的遊戲化 |
| 內容 | Q 版角色圖 ＋ 台詞（宋體）＋ 金幣與經驗（小字） | 台詞是主角，數字是配角 |

> **數字要縮小、台詞要放大。** 這是老吳花心思寫的東西，也是回饋的真正來源。「+10 金幣」誰都給得起，「龜背芋留下了感激的淚水」只有這間診所有。

## 十二、美術素材規格（老吳用 Gemini 等工具生成）

> 2026-09-08 定案：**直接走手繪小世界**。老吳用 Gemini 或其他工具生成圖片。
> ⚠️ **我無法生成圖片**，所以我的工作是：定規格、拆圖層、寫 prompt 方向、確保跑出來的圖真的能用。

### ⭐ 最重要的一件事：先跑「風格定錨圖」，再跑其他

AI 生圖最常見的失敗是**每張風格都不一樣**，拼起來像不同遊戲。做法：

1. 先反覆迭代，跑出**一張你完全滿意的診所全景圖**
2. 把它當**參考圖**（reference / style anchor）去跑所有其他素材
3. 所有後續素材都必須跟它放在一起看，不搭就重跑

> 這一張圖值得花最多時間。它定了整個小世界的樣子。

### 圖層拆分（因為要動，不能一張圖打死）

| # | 圖層 | 張數 | 說明 |
|---|---|---|---|
| 1 | **診所室內底圖** | 1 | 依成舍平面圖的真實格局（櫃台、調劑室、3 床診療區、候診區、廁所）。**空的，沒有人** |
| 2 | **街區外圍** | 1 | 一點點街景，可與 1 同一張出圖 |
| 3 | **角色** | 5–8 種外觀 × 2–3 幀 | 見下方 |
| 4 | **彩蛋物件** | 每個 1–2 幀 | 貓、鳥、腳踏車、落葉…（可陸續增補） |
| 5 | 任務點圖示 | — | **用 emoji 或免費圖示庫**（Lucide／Phosphor），不用出圖 |
| 6 | 天氣與光線 | **0 張** | ⬇️ 見下 |

### ⭐ 天氣與光線用 CSS 做，不要出圖

四種天氣 × 四種時段 = 16 張底圖，這是不必要的成本。

**改用一張底圖 ＋ CSS 濾鏡疊層**：
- 夜晚 → 疊深藍半透明 ＋ 降亮度
- 傍晚 → 疊暖橘
- 雨天 → 降飽和 ＋ 疊灰藍 ＋ **雨絲動畫圖層**（一張小的循環貼圖）
- 晴天 → 疊淡黃光斑

> 一張底圖就能變出十幾種氛圍，**成本從 16 張降到 1 張**，而且調色比重跑圖快一百倍。

### ⭐ 角色動畫：不要做逐幀走路，用「平移 ＋ 上下浮動」

完整走路動畫要 6–8 幀 × 4 個方向 × 8 種外觀 = 兩百多張圖，不切實際。

**省法：Q 版角色只要「平移 ＋ 輕微上下浮動（bobbing）」，看起來就會走路。**

而且——**老吳提的「走走停停」正好掩蓋了沒有走路幀這件事**。等速滑行會露餡，走走停停不會。這個提議在美感和技術上剛好都對。

每個角色只需要：

| 幀 | 用途 |
|---|---|
| **站立**（正面） | 主要狀態，加 bobbing 就是走路 |
| **側面** | 左右移動時用（水平翻轉即可得另一側） |
| 蹲下 | 選配，做閒置行為用 |

> **5–8 種外觀 × 2–3 幀 = 約 20 張圖**。這是可以做完的量。

### 風格關鍵詞（給 Gemini 的方向）

依[[600_Projects/東湖診所開業計畫/設計簡報|設計簡報]]定的調性：

**要：** 日式簡約 · 無印風 · 溫暖手繪 · 大地色系（暖米、淺木色、灰褐、淡沙）· 柔和線條 · 等距／俯視視角 · 療癒 · 留白 · 自然材質質感（木、藤、布）· 柔和光線

**不要：** 飽和鮮豔 · 賽璐璐動畫感 · 古色古香中醫元素（紅木、金色、龍鳳紋）· 冷硬醫療感（白色塑膠、螢光燈）· 過度細節 · 誇張表情

> 這份「不要」清單直接來自設計簡報的禁忌清單——**現實空間和虛擬空間用同一套禁忌，兩者才會像同一個地方。**

### 產出規格

| 項目 | 規格 |
|---|---|
| 格式 | PNG（角色與彩蛋要**透明背景**） |
| 底圖尺寸 | 至少 2560px 寬（要在櫃台電腦與平板上看，可縮不可放） |
| 角色尺寸 | 底圖的 1/15～1/20 高，透明背景 |
| 命名 | `bg_clinic.png` · `char_01_front.png` · `char_01_side.png` · `egg_cat.png` … |

### 給我圖之後我能做的

拿到圖之後我可以：切圖層、寫定位與動畫程式、做走走停停與隨機路徑、接天氣濾鏡、掛台詞氣泡、做任務點熱區。

**流程建議：先跑那一張風格定錨圖給我看，確認方向對了再跑其他二十幾張。** 不然可能白跑一輪。
