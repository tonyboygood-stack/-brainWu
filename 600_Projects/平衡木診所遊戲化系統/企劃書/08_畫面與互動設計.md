# 08 畫面與互動設計

---

## 一、先講一個核心張力，它決定整節怎麼走

### 診所的視覺語言 vs 遊戲化的視覺語言，是衝突的

| [[600_Projects/東湖診所開業計畫/設計簡報\|設計簡報]]定的 | 一般遊戲化長的樣子 |
|---|---|
| 日式簡約、無印風 | 飽和色、圓角卡通 |
| 大地色系、暖米、淺木色 | 高對比、螢光強調色 |
| 留白、寧靜 | 彈跳、閃爍、粒子特效 |
| 「讓人放下戒備」 | 「刺激多巴胺」 |

**而且有個更實際的問題：診間平板與櫃台電腦，病人是看得到的。**

如果螢幕上跳出「+10 XP！🎉」，病人會看到。那會直接破壞設計簡報寫的「走進來的第一秒感受：安心、無壓力、溫暖」——病人會覺得「這家診所在玩遊戲」。

### 解法：**「安靜的遊戲化」**

不是把遊戲感藏起來，是**用不同的方式表達它**：

| ❌ 吵的遊戲化 | ✅ 安靜的遊戲化 |
|---|---|
| 音效、彈跳、粒子 | 靜音；動畫是「生長」與「浮現」，不是「爆炸」 |
| 飽和強調色 | 診所的大地色系，強調色極少 |
| 數字跳動、進度條爆滿 | 文字、印記、留下痕跡 |
| 「你得到了 10 分！」 | 「龜背芋留下了感激的淚水」 |

## 二、⭐ 最重要的判斷：這套系統的美術重心不在動畫，在**排版**

把整套系統的核心機制列出來看：

| 機制 | 本質 |
|---|---|
| 位階日誌 | **文字** |
| 交接備註 | **文字** |
| 老闆公告、每日一句、今日播報 | **文字** |
| 完成台詞 | **文字** |
| 每日診所日誌 | **文字** |
| 平衡木里程碑小故事 | **文字** |
| 今天值得記一筆 | **文字** |

**除了地圖和樹，這整套系統是文字驅動的。**

> 所以美術預算與心力不該花在「完成任務的爆炸特效」，該花在**字體、字級、行距、留白**。
> 一個排版講究的文字系統，比一堆動畫有質感得多，而且**完全符合日式簡約風**——這一次，品牌調性和功能需求是同一個方向，不用妥協。

### 視覺隱喻：不是一個遊戲，是**一本會長大的書**

- 每天寫一頁（每日日誌）
- 每個人有自己的筆記本（位階日誌）
- 牆上有一棵樹，樹上掛著這些年的紀事（平衡木）
- 完成一件事，是**在紙上留下一個印記**，不是「得到分數」

### 字體策略：用字體本身當設計語言

| 用途 | 字體 | 為什麼 |
|---|---|---|
| **敘事區**（日誌、編年史、每日一句、完成台詞） | **思源宋體 Noto Serif TC** | 溫暖、書卷氣、日式；讓人願意慢慢讀 |
| **功能區**（任務清單、按鈕、數字、備註） | **思源黑體 Noto Sans TC** | 清楚、好掃視 |

> **這個對比本身就是導航**：看到宋體就知道「這是故事」，看到黑體就知道「這是要做的事」。不用畫線分區，字體就分好了。

字級要偏大——診所可能光線不足，而且員工可能一手拿東西一手滑手機。

## 三、⭐⭐ 三種視角（2026-09-08 老吳定案，取代原本的「藏起來」方案）

我原本的方案是**減法**——病人看得到的螢幕就把遊戲元素藏掉。
老吳的方案是**加法**——做一個更值得看的預設畫面。**加法明顯更好**：病人看到的不是一個被閹割的介面，而是一個療癒的診所小世界，這反而變成候診區的加分項。

### 老吳的原始設計

> 預設營運視角（一般路過看到的畫面），主要顯示診所狀態，**診所畫面外圍要包含一點點街區 ＋ 天氣隨每天變化**更有感覺。診所狀態有**準備中**與**工作中**兩種自動切換：準備中時角色會在整個空間遊蕩，工作中角色會在各自的守備區遊蕩。角色頭上偶爾會浮出一小句話（例如：「我感覺我越來越熟練了！」）。
> **關鍵是療癒系畫風，看著畫面自己跑都讓人覺得愉快那種**，所以畫面要有一些小小巧思。
> 除了預設營運視角，可以點旁邊切換**任務模式**，一樣的診所圖但會跑出不同位置的任務點可以點選操作（給員工打卡完成與備註用），**預設 30 秒不動會自動切回營運視角**，這個模式下才有角色與完成動畫。

### 我建議再拆出第三種：景觀模式

因為[[600_Projects/東湖診所開業計畫/診所設備清單|設備清單]]裡已經規劃了**候診區壁掛電視（TCL 50 吋）**——那台電視本來就要買。

| 視角 | 用在哪 | 顯示什麼 |
|---|---|---|
| **① 景觀模式** | **候診區電視** | 純畫面：診所小世界 ＋ 街區 ＋ 天氣 ＋ 樹。**零資訊、零任務點、零文字** |
| **② 營運視角**（預設） | 櫃台電腦、診間平板 | 小世界 ＋ 今日播報 ＋ 診所狀態。無任務點、無經驗金幣 |
| **③ 任務模式** | 員工操作時（**30 秒不動自動切回 ②**） | 任務點、角色、完成動畫、備註入口 |

> **候診區電視播這個畫面，比播衛教影片親切、比播新聞好，而且是獨一無二的。** 病人會拍照。
> 但這也代表景觀模式的內容審查要最嚴——**任何任務名稱、備註、員工狀態都不能出現**。

### 手機與大螢幕的預設相反

| 裝置 | 預設視角 | 為什麼 |
|---|---|---|
| **大螢幕**（櫃台、診間、候診區） | ② 營運 / ① 景觀 | 是給人看的 |
| **員工手機** | **③ 任務模式** | 手機是私人的、是用來做事的 |

## 三之二、診所狀態：建議做四種，不是兩種

老吳定的是「準備中／工作中」。我建議再加兩種——**成本為零（同一張圖不同狀態），但畫面豐富度差很多**：

| 狀態 | 觸發 | 畫面 |
|---|---|---|
| 🌅 **準備中** | 開診前 | 燈漸亮，角色在整個空間遊蕩 |
| ☀️ **看診中** | 看診時段內 | 角色在各自守備區遊蕩 |
| 🍵 **午休** | 週二四六 12:30–14:00 | 燈半亮，角色坐著，畫面安靜下來 |
| 🌙 **打烊** | 非營業時間 | 角色不在，燈暗，**樹在月光下** |

> **「打烊」這個狀態特別值得做。** 它讓「診所也會休息」變成畫面——老吳晚上在家滑開來看，看到的是一間安靜的、亮著小夜燈的診所。
> 而且週三、週日是固定休，那兩天整天都是這個畫面，反而成為一種節奏感。

**狀態切換依據**：排班表 ＋ 看診時段，系統自動判斷，不需要任何人操作。

## 三之三、⭐ 角色的閒置台詞：老吳的第四個創意空間

老吳已有三個創意空間：完成台詞、商店品項、今日播報那一句話。這是第四個。

### 關鍵設計：台詞由**系統狀態驅動**，不是隨機廢話

隨機的可愛台詞看三天就膩。但如果角色**真的知道今天發生什麼**，療癒感就成立了——那不是可愛，是「它在陪你」。

| 觸發條件 | 台詞範例 |
|---|---|
| 位階接近升級 | 「我感覺我越來越熟練了！」← 老吳原例 |
| 準備中 | 「今天會是好日子吧」 |
| 未完成任務多 | 「等一下…先把這個做完」 |
| 快收診 | 「今天也順利結束了」 |
| 下雨天 | 「傘桶好像不太夠」 |
| 剛收到感謝卡 | 「剛剛那位阿姨說謝謝耶」 |
| 週三 PT 單人班 | 「一個人也要好好守著」 |
| 節氣 | 「立冬了，記得提醒大家多穿一件」 |

### ⚠️ 但要有一條「對外安全」的白名單

**營運視角與景觀模式的台詞，病人看得到。** 所以那兩個模式下：

| ❌ 絕不出現 | ✅ 可以出現 |
|---|---|
| 抱怨、疲累（「好累喔」「今天病人好多」） | 期待、專注、小確幸 |
| 任何評論病人的內容 | 天氣、節氣、季節 |
| 任務名稱、備註內容 | 抽象的心情（「今天空氣很好」） |

> **任務模式（員工私人操作時）的台詞可以放鬆一點**，因為那個畫面 30 秒後就自動收起來了，而且是她主動打開的。

## 三之四、療癒感怎麼做出來（老吳說的「小巧思」）

**⚠️ 先講一個容易被低估的事實：候診區的病人平均會等 10–20 分鐘，他們會盯著看。**
短循環的重複動作一定會被看出破綻，然後畫面就從「療癒」變成「無聊的螢幕保護程式」。

| 手法 | 說明 |
|---|---|
| **角色路徑隨機**，不固定循環 | 這是耐看與否的關鍵 |
| **低幀率手繪感** | 8–12fps 的逐格動畫**反而更有手繪溫度**——頓感是風格不是缺陷，而且省電 |
| **偶發彩蛋** | 一隻貓經過 · 樹上掉一片葉子 · 外面有人騎腳踏車 · 有隻鳥停在招牌上 |
| **天氣連動** | 下雨時畫面在下雨、玻璃有水痕；晴天有光斑移動 |
| **時間連動** | 光線角度隨真實時間變化；晚診時外面街區的燈亮起來 |
| **季節連動** | 接節氣表——樹的顏色、街區的細節隨季節換 |

> **天氣資料本來就要接（今日播報用），現在一份資料兩處用，額外成本為零，但氛圍加成極大。**

### ⚠️ 效能：這個畫面會在平板上跑一整天

- 低幀率（同時也是風格選擇）
- CSS／SVG 動畫優先於 canvas 全幀重繪
- 候診區與櫃台的裝置要**插電**，不要靠電池
- 提供「省電模式」：無人操作 30 分鐘後降到極低幀率

## 四、導航結構

### 手機（員工主要裝置，PWA 加到主畫面）

底部四個分頁 ＋ 一個常駐浮動按鈕：

```
┌────────────────────────────┐
│                            │
│         （內容區）           │
│                            │
│                     ┌────┐ │
│                     │ ✍️ │ │ ← 今天值得記一筆
│                     └────┘ │   （常駐，所有頁面都在）
├────────────────────────────┤
│  🗺️      📋      🌳      👤  │
│ 地圖    公佈欄   平衡木    我  │
└────────────────────────────┘
```

四個分頁的分工很乾淨：

| 分頁 | 回答什麼問題 |
|---|---|
| 🗺️ **地圖** | 我現在要做什麼？ |
| 📋 **公佈欄** | 診所現在怎麼樣？ |
| 🌳 **平衡木** | 我們走過什麼？ |
| 👤 **我** | 我變成什麼樣子了？ |

> 「今天值得記一筆」做成浮動按鈕而不是分頁，因為它是**隨手丟**的東西——要在任何頁面都按得到，而且不值得佔一個分頁。

## 五、地圖畫面

### 底圖

**第 1 期直接用成舍設計的 3D 俯視渲染圖 ＋ 可點擊熱區。** 現成資產、成本為零、格局最真實（員工一眼認得出哪裡是哪裡）。
第 2 期再考慮描成日式扁平插畫。

### ⭐ 任務圖示：**未完成是淡的，完成是實的**

這是我建議的最重要一個互動細節。

| 常見做法 ❌ | 建議做法 ✅ |
|---|---|
| 未完成 = 紅點／驚嘆號，完成 = 消失 | 未完成 = **淡色、半透明、緩慢呼吸的小點**<br>完成 = **變成一枚實心印記，留在原地** |

**為什麼這個差別很大：**

- 「未完成亮紅燈」= 一整天地圖都在對你叫，有壓迫感；而且病人瞄到會覺得「這家診所很多事沒做」
- 「完成就消失」= 做了一整天，地圖回到空白，**你的努力在畫面上不留痕跡**
- **「淡→實」= 一天結束時，地圖從淡淡的變成滿是印記**

> 心理感受完全不同：前者是**清空**（做完只是回到零），後者是**填滿**（做完是留下東西）。
> 這也呼應整套系統的核心哲學——**回饋來自「被記錄」，不是「被獎勵」**。

### ⭐ 角色站在她的守備區

地圖上，員工的小角色**站在她今天守備的區域**。

- 一個人守櫃台＋調劑室 → 角色站在兩區之間
- **週六雙人班 → 地圖上有兩個小人** → 一眼看到「今天不是一個人」

成本極低（一個小圖釘在座標上），但代入感很強，而且它讓「守備制度」變成看得見的東西，不用解釋。

## 六、完成任務的回饋

老吳要的：角色完成任務畫面 ＋ 一句話（「龜背芋留下了感激的淚水：『終於有人澆水了！』」）。

| 決定 | 建議 | 理由 |
|---|---|---|
| 全螢幕 vs 卡片 | **卡片**（從下方滑出） | 一天 4–6 次，全螢幕會煩 |
| 停留時間 | **2 秒自動收，可點掉** | 不要讓人等 |
| **音效** | **預設全靜音** | 設計簡報寫「寧靜」，任何提示音都會破壞候診區。可在設定開，但預設關 |
| 動畫 | 淡入 ＋ 輕微上浮，**不彈跳** | 安靜的遊戲化 |
| 內容 | Q 版角色圖 ＋ 台詞（宋體）＋ 金幣與經驗（小字） | 台詞是主角，數字是配角 |

> **數字要縮小、台詞要放大。** 這是老吳花心思寫的東西，也是回饋的真正來源。「+10 金幣」誰都給得起，「龜背芋留下了感激的淚水」只有這間診所有。

## 七、平衡木畫面

### 滾動方向就是時間方向

```
       ↑ 往上滑
     🌳 樹梢 — 最新的里程碑
        樹枝 — 依年份分枝
    ────地面────
        樹根 — 籌備期（2026 年 5 月起）
       ↓ 往下滑
```

**往上是未來，往下是過去。** 不需要任何說明，滑一下就懂。

### 互動

- 點一塊牌子 → 從下方滑出詳細卡片：小故事（宋體）· 參與者頭像 · 留言串
- 留言時區分「當年在場的人」與「後來的人」（不同底色或小標）
- 樹隨開業月數緩慢長大（第 1 期用最單純的觸發）

## 八、角色卡（「我」分頁）

由上而下：

```
      [ 頭像 ]
   ○○○　🏅櫃台熟手
   到職 312 天

── 我的守備 ──
櫃台     ●●●○○  熟手 → 專精者　還差 4 個月
調劑室   ●●○○○  熟手　　　　　還差 1 個月
診療區   ●○○○○  跟診菜鳥　　　還差 2 個月
        （熟練值：櫃台 486 診）

── 我的日誌 ──  [ 3 本 · 12 則 · 4 則已傳承 🌱 ]

── 我收到的感謝 ──
💌 一位病人說：「櫃台小姐很細心地跟我解釋…」（永久保留）
🤝 老吳：「謝謝你週三一個人撐下來」

── 我的稱號 ──  🌱綠手指　🔥救火隊長　☔風雨無阻

── 金幣 ──  238 　[ 逛逛商店 ]

── 我的衛教語錄 ──  已說出口 47 句
```

**兩個設計要點：**

1. **「還差 4 個月」要明確寫出來**，不要只給模糊的進度條。清楚的距離感才有推進力。
2. **病人感謝卡放在最上面、永久保留、不被新的洗掉** —— 那是她做這份工作最真實的意義來源。

## 九、實務細節（容易被漏掉但會決定好不好用）

| 項目 | 設計 | 為什麼 |
|---|---|---|
| **離線可用** | 任務完成先存本機，連上網再同步 | 診所 wifi 不穩時不能卡住工作 |
| **草稿 autosave** | 所有輸入框即時存本機 | 配合語音輸入（一口氣講很長，斷掉會很挫折） |
| **原生 `<textarea>`** | 不用富文本編輯器 | Typeless 等語音工具注入不進富文本 |
| **深色模式** | 第 2 期 | 晚診到 21:30，診間燈光暗 |
| **單手可操作** | 主要按鈕在螢幕下半部 | 她常常一手拿東西 |
| **免登入停留** | PWA 記住登入，不要每天重登 | 每天要重登的系統，兩週內必被放棄 |

## 十、視覺色票（承設計簡報）

| 用途 | 色 |
|---|---|
| 底 | 暖米白 |
| 文字 | 深灰褐（不用純黑） |
| 分區色 | 淺木色系，各區明度差一點就好 |
| **唯一的強調色** | 🔴 只用在「待處理·紅」的備註 |
| 完成印記 | 淺木色實心 |
| 樹 | 自然綠褐 |

> **強調色只留給一件事**（紅色待處理）。其他全部靠明度與留白分層。
> 這是無印風的核心手法，也讓那唯一的紅色真的有份量。

### ⚠️ 第 4 題的變化：美術成本上升了，要重新評估

原本我建議「第 1 期直接貼成舍的 3D 渲染圖 ＋ 熱區」，因為那是現成資產、成本為零。

**但營運視角要求的是一個會動的、有街區、有天氣、有角色遊蕩的療癒系小世界——這用 3D 渲染圖做不出來。** 它需要一張手繪風格的插畫底圖，加上可獨立動的圖層（角色、天氣、光線、街區）。

| 路線 | 成本 | 說明 |
|---|---|---|
| **A. 第 1 期先用 3D 圖 ＋ 靜態任務點，第 2 期再做小世界** | 低 | 先能用，療癒感延後 |
| **B. 第 1 期就做手繪小世界** | 中 | AI 生成底圖 ＋ 分圖層，估 NT$3,000–10,000 或大量 AI 生成迭代的時間 |

> 我的建議偏 **A**——因為[[600_Projects/平衡木診所遊戲化系統/企劃書/00_總企劃|總企劃]]的第 0 期還沒跑，任務清單都還沒穩定。**先確認這套系統真的有人用，再投資美術。**
> 但這一題你可能有不同看法：療癒的畫面本身可能就是「讓人願意用」的主要原因，那它就不是加分項而是必要條件。這要你判斷。
