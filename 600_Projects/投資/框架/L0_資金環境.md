# L0 資金環境｜錢從哪來、往哪去？

> [!important] 這一層決定「現在該不該重倉」
> 全庫術語統計中，**美元出現 223 次、利率 174 次**，是總經面的兩大主軸——比通膨（77）、GDP（48）都高出許多。這反映他的總經判斷是以**資金成本與美元流向**為核心，而不是傳統的景氣指標。

## 這一層在整套框架中的位置

L0 不直接給進出場訊號，它決定**其他層訊號的可信度與力度**：

```
利率往下 + 美元偏弱  →  資金願意冒險，高估值撐得住
                        L2 的籌碼訊號較容易兌現
                        
利率往上 + 美元轉強  →  資金重新評估風險，估值收縮
                        再好的籌碼訊號也要打折
```

他在第 82 期講得很直接：幾個月前大家覺得利率會繼續降，估值高的資產撐得住，為了未來的夢想願意多掏點錢；氣氛一變，該注意的就是**資金重新評估的風險**。

## 他的幾個總經判斷習慣

**1. 因衰退而降息，不是好事**
一般直覺認為降息利多股市，但他在第 29 期明確指出：**因為經濟衰退而出現的降息，反而更需要考慮減碼或賣出。**

**2. 用匯率交叉驗證外資意圖**
台股下殺但台幣沒有持續貶值、甚至由貶轉升，可能代表外資資金只是暫時躲起來，而非真正撤離。→ [[外資期貨先行指標]]

**3. 領先指標優先於當期數據**
他關注 LEI 領先經濟指標（領先實際景氣約 3–6 個月）、M2 貨幣供給、消費者信心指數，而非等 GDP 公布。→ [[賣出訊號系統]]

**4. 台灣的位置要放在全球資金鏈裡看**
熱錢進新興市場來得快去得也快；人民幣是台幣在出口市場的頭號競爭對手。
