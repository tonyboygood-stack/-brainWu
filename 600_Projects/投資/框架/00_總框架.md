# 宏爺股市分析總框架

> 59 期會員專題教學的骨架圖。**要回答任何股市問題，先讀這一份**，需要細節再往下鑽到各層 MOC 與知識卡。

## 一、先講結論：他的權重不是教科書式的

全庫術語統計（26.3 萬字）揭露了真實比重：

| 面向 | 出現次數 | 在他方法中的角色 |
| :--- | ---: | :--- |
| **籌碼面** | **1,107** | **判方向**——整套方法的核心 |
| 總經面 | 841 | 定調性（美元 223、利率 174 為兩大主軸） |
| 技術面 | 834 | 抓時機 |
| 策略 | 599 | 執行與部位 |
| 基本面 | 286 | 當篩選器，不當進場理由 |
| 心理紀律 | 244 | 貫穿全程 |

基本面只有籌碼面的四分之一。**用「基本面選股、技術面進場」去理解他會完全走偏**——他是先看誰在買，再看價格結構，基本面只用來排除地雷。

## 二、核心決策鏈

第 70 期他把整套方法濃縮成十個字：**「價平、量平，大戶持續加碼」**。展開成完整流程：

```
  L0 資金環境定調  ──── 美元往哪走？利率在升還降？
          │
  L1 確認市場位階  ──── 基期高低？乖離多大？週期哪一段？
          │
  L2 籌碼判方向 ★  ──── 均線糾結（價平量平）+ 大戶／法人連續加碼
          │
      ┌───┴───┐
      │ 口袋名單 │   ← 條件成立但還不進場，先觀察
      └───┬───┘
          │
  L3 體質篩選     ──── 產業是「過去沒有、現在開始、未來很多」嗎？
          │              股息歷年增加？董監持股高？營收往上？
          │
     利空不跌      ──── 壞消息出現卻撐住 = 籌碼被鎖住，訊號加強
          │
  L4 長紅突破      ──── 帶量突破關鍵壓力 → 進場
          │              但乖離過大則不追
          │
  L5 部位與退場    ──── 事先想好錯了怎麼辦、對了何時走
```

**這條鏈是整個知識庫的主幹。** 其餘 58 期都是在補充某個環節的細節。

## 三、六層架構

每層有一個記憶問句。遇到問題時依序自問，就是完整的判讀流程。

### [[L0_資金環境]]｜錢從哪來、往哪去？
大環境的水位與流向。美元強弱、利率方向、通膨壓力、地緣政治。這層決定**現在該不該重倉**。

涵蓋 12 期：18、39、52、53、54、60、65、74、78、80、82、84

### [[L1_市場位階]]｜現在在週期的哪一段？
不是預測方向，是確認**目前站在哪裡**。基期高低、乖離程度、市場情緒溫度。位階錯了，再好的股票也會套。

涵蓋 5 期：8、27、56、64、83

### [[L2_籌碼意圖]] ★｜誰在買、誰在賣？
**核心層。** 三大法人屬性差異、大戶持股流向、籌碼集中度、買賣家數差、外資成本線、分點追蹤。散戶只看漲跌會追高殺低，看穿資金意圖才能先一步。

涵蓋 5 期：15、25、36、70、76

### [[L3_標的體質]]｜這家公司撐得住嗎？
兩個子區：**基本面判讀**（財報三大表、成長股、十倍股、股息）與**產業趨勢**（他對特定產業的看法）。產業那批時效性強，價值在於看懂他**怎麼思考產業**，而非結論本身。

涵蓋 13 期：13、41、62、81 + 產業 59、63、66、68、69、71、75、77、85

### [[L4_進出時機]]｜什麼時候動手？
型態學、關鍵K線、多K定生死、箱型理論、週K月K、大漲的訊號。技術面在他的體系裡是**確認工具**，用來確認籌碼判斷、抓進場點，不是預測方向的水晶球。

涵蓋 7 期：10、11、24、34、40、49、67

### [[L5_部位與風控]]｜錯了怎麼辦？
資產配置、賣股的藝術、避險放空、個股期、期權、套利、美股ETF。**他花在「怎麼退場」的篇幅不比「怎麼進場」少。**

涵蓋 8 期：12、17、22、28、29、37、50、79

### [[貫穿層_心理紀律]]｜我在騙自己嗎？
股市心理學、他自己的修練之路、以及四本經典書籍的拆解（超級績效、金融煉金術、洞見趨勢、日本股神）。這層不分階段，全程都在作用。

涵蓋 7 期：16、43、45、46、58、61、72

### [[工具層]]｜用什麼看？
第 32 期（壓箱寶）與第 73 期（AI 戰情室）。實際的網站、選股策略、看盤設定。→ 詳見 [[數據來源清單]]

## 四、幾個貫穿全庫的原則

從多期反覆出現的態度整理：

1. **天上不會掉餡餅**——四處打聽名牌得到的可能是「真的名牌」（會套牢的那種）。好股票要靠長期觀察。
2. **流向重於水位**——大戶持股高低不如大戶正在買還是正在賣重要。買正在被買的，賣正在被賣的。
3. **利空不跌比利多大漲可靠**——壞消息測得出籌碼的真實強度。
4. **市場波動是機會不是災難**——大家哀鴻遍野時，正是觀察大戶偷偷佈局的好時機。
5. **條件要自己調**——他一再強調不要照抄他的參數，要找到適合自己風格且能長期獲利的方法。
