# L5 部位與風控｜錯了怎麼辦？對了何時走？

> [!important] 他花在退場的篇幅不比進場少
> 第 29 期開宗明義：很多人談如何選股、什麼時候買入，但一個同等重要卻常被忽視的問題是**什麼時候賣出**。賣出的時機往往決定賺賠，甚至影響整體報酬率。
>
> 他的核心態度：**很難賣在最高點，但要盡量賣在相對高點。**

## 核心觀念一：避險不是放空

第 12 期他用戰爭比喻分清楚兩件常被混為一談的事：

| | 避險 | 放空 |
| :--- | :--- | :--- |
| 角色 | **騎兵**（機動防守） | **正規軍**（順勢作戰） |
| 目的 | 規避風險、保障既有收益 | 賺取下跌價差 |
| 心態 | 買保險，「看到黑影就開槍」 | 全面確認條件才進場 |
| 條件 | **不含基本面**——等基本面出問題才避險就太慢了 | 技術＋籌碼＋資金三面俱到 |

> [!tip] 一個有意思的轉換
> 大多時候**成功的避險單會轉向反向的放空部位**——先買保險，確認趨勢真的轉了，保險就變成主動攻擊。

## 核心觀念二：工具有階梯，槓桿要控制

風險由低到高：現金存款 → 債券／債券基金 → 股票／股票基金 → 期貨與個股期 → 選擇權與權證 →（他的玩笑）樂透。

> [!warning] 他對槓桿的具體立場
> 個股期保證金約 13.5%，理論槓桿可達 7.4 倍。但他認為**4 倍左右較恰當**——槓桿是可以自己控制的，投入更多保證金就能降到 1 倍。
>
> 對選擇權的警告更直接：**用人性操作期貨與選擇權，再多錢都不夠賠。** 原則只有順勢操作與風險控管。

→ [[個股期運用]]

## 核心觀念三：進場條件消失時就出場

這句話貫穿放空與做多。他舉例：放空後若大盤反彈站回 20 週均線，就重返多方格局，該退場了。

**不是等停損價被打到才走，而是當初讓你進場的理由不見了就走。**

## 貫穿這一層的原則

**1. 多要攻、空要防**
多頭市場初中期保持積極樂觀，**末段時不要急著進場**——他強調「不作為比有作為更重要」；空頭市場則採防禦性組合。

**2. 散戶最大的誤解是以為資產配置是有錢人的事**
結果在多頭末段過度積極投入（從成交量或融資餘額可以判斷），下跌時手足無措，最後恐慌砍在低點。

**3. 技術訊號要拿籌碼當濾網**
他明講所有技術分析最好再參考大戶籌碼，才能避免被雜訊或主力甩轎出場。

**4. 沒有最佳解，只有適宜解**
資產配置「沒有最佳解，只能找到適宜的」；停損停利參數「並非標準答案」。重點在**進出有據、嚴守紀律**。
