# 外資期貨先行指標

> [!abstract] 一句話
> 外資通常一手現貨、一手期貨同步操作，所以期貨與選擇權的部位比現貨買賣超更早透露方向。

## 為什麼看期貨比看現貨早

外資持有台股約四成比例，資金雄厚、資訊領先。他們的典型操作是**現貨與期貨同步**：現貨買進的同時期貨持有多單，上漲時雙重獲利；反之現貨賣出加期貨空單，下跌時同樣雙重獲利。

期貨具價格發現功能，因此部位變化往往先於現貨表態。

但也有**不同步**的情形——現貨持有大量部位時，在期貨放空以對沖風險。這種情況下不能單看期貨方向下結論。

## 警戒數字

宏爺在第 36 期給出具體門檻：

| 指標 | 警戒值 |
| :--- | :--- |
| 外資期貨整體部位 | 超過 **3 萬口**以上特別小心 |
| 前五大交易人 | 接近 **1 萬口**是警訊 |
| 前十大交易人 | 接近 **2 萬口**是警訊 |

> [!important] 流向重於存量
> 這是他反覆強調的原則。假設外資期貨空單高達 5 萬口，但每天持續減少，可能代表危機正在解除。**絕對數字不如變化方向重要。**

## 為什麼要看前五大、前十大

早年只看外資期貨部位就夠了。但近年不少大戶到外資券商開戶，形成**假外資**，也出現外資操作短線的跡象。因此必須進一步拆解到前五大與前十大交易人的留倉情況，才能過濾雜訊。

## 需要追蹤的資料項目

第 36 期他示範用 Excel 從證交所、期交所網站自動匯入，建立以下分頁：

- 成交量（均量分析、量價關係、異常波動）
- 三大法人買賣超
- 外資期貨大台＋小台（換算：小台四口 = 一口大台，故取 大台 + 小台 × 1.4 ⚠️ 見下方存疑）
- 前五大／前十大交易人留倉（買方所有契約 − 賣方所有契約）
- 選擇權 Put/Call ratio
- 外資選擇權部位（Buy Call − Sell Call − Buy Put + Sell Put）
- 未平倉量

> [!warning] 一處存疑
> 逐字稿記載換算係數為「×1.4」，但小台為大台的四分之一，換算通常應為 ÷4 或 ×0.25。這裡可能是聽寫錯誤或有其他脈絡。**引用前務必回原片第 36 期確認**（`逐字稿/_srt/r-H5dqcnPcg.srt`）。

## 佐證工具：匯率

外資資金進出速度快。宏爺會用**台幣匯率**交叉驗證：台股持續下殺但匯率沒有持續貶值、甚至由貶轉升，可能代表外資資金只是暫時躲起來等待機會，而非真正撤離。

## 注意假動作

外資會用假動作迷惑市場，例如殺低進貨、拉高出貨。因此需綜合多種指標判斷，不能單押任一數字。
