# 缺口判讀

> [!abstract] 一句話
> 缺口分四種，位置決定意義——出現在起漲點是機會，出現在末段是警訊。

缺口通常來自國際或台灣突如其來的利多利空，造成隔日開盤的跳空。

## 四種缺口

### 1. 普通缺口
出現在**區間整理**之中。**較不重要**，參考價值低。

### 2. 突破缺口（最關鍵）
出現在盤整結束、趨勢啟動處。

- **向上突破**：需要明顯的**大量配合**，且成交量需持續增加。配合大量的向上跳空**通常不會回補**
- 缺口越大，漲勢力道越強，通常是可以果斷追進的訊號
- **向下突破則不一定需要量**——有量沒量都會跌，此時要當機立斷退出或反手放空

> [!warning] 假突破的判準
> 如果突破缺口在**三天內跌回起漲點**，就是假突破。

> [!important] 多空的不對稱性
> 向上突破必須有量，向下跌破不需要量。這個不對稱貫穿他整套技術判讀——多頭需要資金推動，空頭靠自身重量就會下滑。

### 3. 逃逸缺口
出現在趨勢中段，成交量**不必特別大**。上升趨勢中出現逃逸缺口是市場強勢的表態。

- **留意**：收盤價若跌破缺口下緣，代表上升趨勢將轉弱

### 4. 竭盡缺口
出現在一波狂升或狂跌的**後段**。此時投資人一窩蜂追高搶進，或極度悲觀殺出，造成跳空。

代表多方或空方的力道都只剩最後一口氣，**是另一波反向操作的好機會**——靜待行情轉折即可。

## 判讀順序

```
先問：這個缺口出現在哪個位置？
   ├─ 區間整理中  → 普通缺口，忽略
   ├─ 盤整末段    → 突破缺口，看量能決定是否追
   ├─ 趨勢中段    → 逃逸缺口，守住下緣即可
   └─ 狂升狂跌後段 → 竭盡缺口，準備反向
```

**位置比形狀重要**——這與 [[關鍵K線與位階]] 的邏輯完全一致。
