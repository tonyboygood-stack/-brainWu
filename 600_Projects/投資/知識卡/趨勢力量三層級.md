# 趨勢力量三層級

> [!abstract] 一句話
> 面 > 線 > 點。形態的趨勢力量大於均線，均線大於單根 K 線。

這是宏爺技術分析的公理，在第 10、24、34、67 期反覆出現。

## 三個層級

| 層級 | 是什麼 | 例子 |
| :--- | :--- | :--- |
| **面** | 形態學 | M頭、W底、箱型整理、三角收斂、旗形 |
| **線** | 均線 | 20週均線、6MA、12MA、60MA |
| **點** | 單根 K 線 | 日K圖，含關鍵K線 |

## 生成關係

這三者不是並列，而是層層堆疊出來的：

```
價格  →  形成當日 K 線（點）
        ↓
多日 K 線  →  形成均線（線）
        ↓
K 線在均線上下波動  →  形成形態（面）
        ↓
形態的趨勢力量  →  決定多空市場
```

## 三個實用推論

**推論一：單根 K 線權重最低**
除非是伴隨巨大量能的明確關鍵 K 線，否則難以用單日 K 線判斷趨勢的持續或轉折。這是他不愛做短線的技術面理由。

**推論二：週期越長，趨勢力量越強**
所以整理時間越久，突破的爆發力越強勁——這直接支撐了 [[大漲的訊號]] 中「整理最好一年以上」的修正，也支撐了 [[箱型理論]] 中「橫盤越久累積能量越大」。

**推論三：趨勢不容易形成，形成也不容易改變**
這句話他反覆講。含義是：既然趨勢難以形成，那麼一旦確立就值得跟隨；也因為難以改變，所以想用單根 K 棒扭轉乾坤有很大困難度。

## 實務含義

判讀順序應該由大到小：**先看形態（月K/週K的大結構）→ 再看均線（趨勢方向與斜率）→ 最後才看 K 線（進出場的精確時點）**。

反過來做——盯著日K找訊號卻不看大結構——就是他說的「越貼近盤面越賺不到錢」。
