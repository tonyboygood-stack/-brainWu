# 週K線判讀

> [!abstract] 一句話
> 日K雜訊太多、月K反應太慢，週K濾掉短線雜訊又不會錯過買點，是宏爺認定的最佳平衡。

## 為什麼是週K

| 週期 | 問題 |
| :--- | :--- |
| 日K | 一天一根 K 棒雜訊多、波動大，容易被主力騙進騙出 |
| 月K | 能掌握長線走勢，但變化太慢，等確認買點時好時機可能已錯過 |
| **週K** | 濾掉日K雜訊，補足月K遲滯，還能清楚顯示基期與位階 |

另一個理由是**機構的操作節奏**：法人主力通常以週為單位佈局或調整倉位，所以週K更能反映他們的方向。

## 量價關係：量先價行

技術分析的重要觀念——**價格是結果，成交量是原因**。週K的量能變化比日K更具參考價值，因為濾掉了短線雜訊，剩下的是法人主力的中期意圖。

| 型態 | 含義 |
| :--- | :--- |
| 價漲量增 | 買盤積極、資金湧入，趨勢延續 |
| 價跌量縮 | 賣壓減弱，可能是底部築成 |
| **價漲量縮** | **空頭背離**——漲勢可能無法繼續 |
| **價跌量增** | 恐慌性賣壓，趨勢持續轉弱 |

> [!important] 背離的口訣
> **背離就容易有轉折、後繼無力。** 如果在相對高位階出現量價背離，尤其是週K級別，後果可能不堪設想。

> [!warning] 個股要同步追蹤籌碼
> 因為籌碼若被主力鎖定，**無量也能飆漲**——這種情況下純看量價會誤判。

## 有效突破的條件

週K出現放量長紅時，用這幾點判斷是否為真突破：

1. 突破前波平台整理區的高點
2. 站穩關鍵均線（如 **20 週均線**）
3. 成交量明顯放大，**週量比前一週增長至少 30%**
4. 突破後連續**二到三週**維持高檔不快速回落

**假突破的警訊**：長紅但量能未顯著增加（無量上漲容易拉回）、突破後隨即拉回形成長上影線、衝高後快速回跌。

## 洗盤還是真轉空？

多頭股價在週K出現大跌，可能只是主力洗盤。分辨方式：

| | 可能是洗盤 | 真的趨勢轉空 |
| :--- | :--- | :--- |
| 均線 | 回測 20 週均線，**短暫**跌破 | 跌破 20 週均線且站不回 |
| 量能 | **沒有**明顯放大，代表賣壓有限 | 量能**放大** |
| 隔週 | 出現帶下影線的紅K，站回均線 | 長黑貫破平台整理區，資金出逃 |

> [!tip] 記憶法
> 無論長紅突破或長黑貫破，**只要帶量，是真突破的機率就很高；無量突破容易再拉回**。至於無量跌破，危險性雖比帶量跌破小，但跌破了重要支撐仍然後果堪憂。

## 突破後會漲到哪裡

他從老前輩學到的量價觀念：如果是主力**長時間吸納籌碼後的爆量上漲**，根據量先價行原理，**底部天量有機會挑戰歷史更大套牢量的高點**。量能不夠的話，突破幅度恐怕有限。

## 週均量搭配籌碼

| 週均量 | 法人 | 判讀 |
| :--- | :--- | :--- |
| 穩定放大 | 連續買超 | 大戶進場，股價有望走強 |
| 持續萎縮 | 轉為賣超 | 資金撤退，可能進入整理 |
| 放大但股價漲不上去 | 大戶籌碼分散 | 可能是**出貨**訊號 |
| 量能增溫 | 大戶籌碼集中 | 主力可能正在吸籌 |

## 買賣點訊號

**買點（多頭確認）**：週K收長紅＋量能放大突破中期均線或盤整區 → 股價突破 20 週均線 → 法人大戶連續買超、籌碼集中。

**賣點（空頭確認）**：高檔週K放量長黑跌破中期均線或盤整區 → 量價背離（股價漲但量沒跟上）→ 相對高位階出現巨量長黑，趨勢翻空機率高。

經驗法則：**漲一倍或整數關卡爆大量**，容易引來壓力修正。

> [!important] 核心口訣
> **窒息量找買點，天量找賣點。**

## KD 的有限使用

他一般不太參考 KD 值（短期雜訊過多），但**週期較大時會用來輔助確認**：KD 靠近 80 可能過度樂觀，靠近 20 可能過度恐慌。

但他不會單看 KD 就買賣，仍要參考均線、籌碼、基本面綜合判斷。
