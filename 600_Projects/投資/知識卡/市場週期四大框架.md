# 市場週期四大框架

> [!abstract] 一句話
> 用四種不同尺度的經濟週期理解「現在在哪一段」——資本支出、庫存、技術革命、信用槓桿各有各的節奏，有時共振放大，有時互相抵消。

第 83 期的核心句：**自古以來，累積大量財富的，通常是掌握週期的人。**

## 為什麼週期比選股重要

他舉了幾個歷史案例說明同一個道理：

- 美國 10 年期公債殖利率 1981 年一度高達 15.84%，之後隨通膨與利率下降，債券進入數十年多頭
- 銅價從 2003 年每磅約 0.8 美元漲到 2006 年 5 月約 3.7 美元，背後是中國建設需求擴張
- 疫情前航運運力供過於求、業者持續減艙，疫情後需求爆發，上海貨櫃運價指數從 2019 年底約 898 點升到 2021 年底接近 5000 點
- 反過來，黃金在 1980 年約每盎司 760 美元的高點，一直到 2007 年才回到成本附近——**等了 27 年**

> [!important] 結論
> **公司挑得再好，進入週期末段之後，市場一旦預期需求降溫、供給增加，股價通常領先財報與景氣提前修正。**

---

## 四大週期框架

### 1. 朱格拉週期｜資本支出（約 7–11 年）

**機制**：景氣與獲利改善 → 銀行授信轉寬 → 企業擴廠買設備 → 新增產能開出 → 若需求增速放慢，價格、產能利用率與投資報酬率轉弱 → 企業削減資本支出。

**追蹤指標**：資本支出增速、設備訂單、折舊。

> [!warning] 關鍵是**增速**而非金額
> 資本支出從年增 30% 降到 10%，金額仍在成長，但**市場可能已先修正評價**。設備股通常領先財報。

### 2. 基欽週期｜庫存（約 40 個月，3–4 年）

**機制**：核心是市場資訊與企業決策的**時間差**。終端需求回升 → 下游補貨與重複下單 → 上游高估需求 → 商品交付時庫存已超過銷售速度 → 企業砍單、降價、減產。

**適用**：半導體與消費電子。

> [!important] 他特別強調這個週期
> **營收創新高時，更要追蹤庫存天數、產品價格與產能利用率**——這些指標可能已經轉弱。他說「這週期觀念相當相當重要，大家記得多花點時間好好研究」。

### 3. 康波週期｜技術革命（約 45–60 年）

**機制**：跨世代大型基礎建設與技術的興衰。經濟長期低迷、舊產能淘汰、利率偏低時，資金投入新技術；這種技術不是單一熱門產品，而是能帶動**整套基建、就業與商業模式**的全面升級。隨著基建普及與市場飽和、債務擴張，投資報酬率下降，企業削減投資、消化過剩產能，進入長期調整，直到下一輪新技術接棒。

**六次技術革命**：

| 起點 | 主導技術 |
| :--- | :--- |
| 1771 | 機械化紡織、工廠與運河 |
| 1829 | 蒸汽、煤炭與鐵路 |
| 1875 | 鋼鐵、電力、化工與重型工程 |
| 1908 | 石油、汽車、石化與規模化生產 |
| 1971 | 半導體與網際網路 |
| 約 2020 年代 | **人工智慧與能源轉型** |

### 4. 明斯基循環｜信用槓桿（無固定週期）

**機制**：平穩越久，銀行與借款人越容易增加槓桿。三個階段遞進：

1. 現金流足以支付本金與利息
2. 只能支付利息，本金必須展延
3. 連利息都仰賴再融資或資產上漲

當利率升高、現金流轉弱、或銀行停止續借 → 借款人被迫賣出資產 → 價格下跌 → 壓低抵押品價值 → 形成更多賣壓。

**追蹤指標**：利息保障倍數、放款標準、違約率、信用成長。

### 補充：庫茲涅茨週期
適合解釋營建業、都更題材與房市循環。

## 週期會共振也會抵消

景氣波動往往伴隨經濟中多項活動同步擴張與收縮，所以**不同週期會同時存在**——有時彼此共振放大，有時互相抵消。這是為什麼不能只用單一週期理論判斷。

---

## 鐘擺效應：股價為何領先景氣

他引霍華・馬克斯的觀點：市場情緒像鐘擺，總在樂觀與悲觀、衝動與保守之間擺盪，**很少停在正中間**。

- **景氣大好時**：樂觀推升估值，只要公司獲利成長放緩，股價就可能提前修正
- **景氣低迷時**：若股價已反映多數壞消息、獲利下修開始緩和，股價有機會築底甚至提前反彈

> **景氣循環看基本面，鐘擺效應看市場願意出多少錢。**

實務上搭配過去的估值位階、獲利上修加速度、信用利差來觀察。

---

## 判斷週期位置的實務組合

他個人同時關注：**價格位階、估值區間、成交量與籌碼集中度**，基本面則留意**獲利預期有沒有跟著上修**。

> [!warning] 兩種誤判
> - 單看媒體一片樂觀就隨意抓頭 → 容易**錯失主升段**
> - 只看股價強勢而忽略估值與獲利上修速度 → 可能在**宴會快散場時才慢半拍進門**
