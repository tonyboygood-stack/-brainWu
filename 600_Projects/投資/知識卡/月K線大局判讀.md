# 月K線大局判讀

> [!abstract] 一句話
> 月K不是拿來猜下週漲跌的，是拿來看未來五年十年處於多頭的夏天還是空頭的冬天。

## 週期的分工

宏爺的比喻很清楚：

> **日K看戰技，週K看戰術，月K看戰略。**

月K形態通常要花好幾年才走得出來，背後代表的不只是市場群體心理的巨大轉變，更是**大週期的質變**。他說真正的高手通常先看月K圖。

> [!tip] 個股要看還原月K
> 除了大盤之外，個股習慣看**還原月K圖**，以避免除權息造成的價格失真。

## 第一步：看形態（看長相）

| 形態 | 含義 |
| :--- | :--- |
| **M頭**（雙重頂） | 跌破中間頸線，長期多空結構可能被破壞，由盤整轉趨空頭 |
| **W底**（雙重底） | 沒信心的人已經走了，籌碼逐漸集中於固執型的長線投資人手中 |
| **箱型整理** | 見 [[箱型理論]] |
| **多年打底後的低位階長紅突破** | **他最喜歡的型態**，通常進可攻退可守 |
| **三角收斂** | 月K級別一旦表態，無論向上突破或向下灌殺，爆發能量通常非常驚人 |

> [!warning] 形態學不是萬能公式
> 月K型態容易出現假突破或鈍化，**絕對不能只看形狀就下重注**，必須搭配下面三個工具。

## 第二步：看氣色（三大工具）

### 工具一：切線

月K的切線不是看三五個月，而是**連接好幾年的關鍵低點**畫出長期上升趨勢線，或連接好幾年關鍵高點畫出長期下降壓力線。

- 這條線是靜態的，代表**這個世代的多空底線或天花板**
- 只要價格沒有有效跌破長期上升切線，大格局多頭結構通常沒被破壞
- 長期下降壓力線被正式突破，可能是一個空頭時代的結束

**趨勢來自於突破。** 多頭突破後，下一階空方可能的防守區怎麼找？往前找前波套牢區——這用到的是套牢解套互換的觀念。

> [!tip] 迷茫時的做法
> 對股價走勢感到迷茫時，切換成還原月K圖，觀察多空防守區，心理會相對踏實。

### 工具二：長期均線

這是一條**動態**的趨勢線。月K上通常看 6MA（半年）、12MA（一年）、60MA（五年平均成本）。

| 情境 | 結構 | 含義 |
| :--- | :--- | :--- |
| 半年線往上、價格在 6MA 之上 | 健康多頭 | 過去半年進場的人平均都賺錢，拉回是良性整理，下方有層層獲利籌碼支撐 |
| 半年線往下、價格在 6MA 之下 | 空頭結構 | 過去半年進場的人平均都套牢，上方有層層解套賣壓，**任何反彈都可能只是逃命波** |

### 工具三：量能

- **連續上漲＋成交量暴增＋乖離過大** → 情緒已超過基本面，媒體狂放送利多、散戶與投機資金全衝進來，通常是**天量賣點的前兆**
- **低檔盤整＋窒息量** → 想賣的人都賣光了，籌碼相對安定，只要一點火苗就容易星火燎原，是**窒息量買點**

## 第三步：看籌碼（誰在台上跳舞）

日K籌碼很凌亂（有隔日沖），但月K的籌碼通常是真正大戶的方向。

1. **外資與主力**：不看今天買賣，看這個**月或季**是淨買入還是淨賣出。月K層級的連續買超代表這個市場、這個產業長線有沒有被認同。
   - 三種需注意的短期干擾：假外資、熱錢效應、被動型基金調節
   - **如果外資大賣都殺不下來，要思考背後是不是有比外資更強大的主力在控盤**
2. **融資變化**（散戶熱度）：長期打底後融資緩步增加是健康的；**高檔融資持續暴增、跟著指數噴出，顯示散戶陷入瘋狂，是非常危險的訊號**
3. **KD 值**：他一般不參考 KD（短期雜訊多），但**月K週期相對具參考價值**，特別留意超過 80 或低於 20

## 市場的四季循環

把以上工具組合起來，看出市場處於哪個階段：

| 局勢 | 形態 | 量價均線 | 籌碼 |
| :--- | :--- | :--- | :--- |
| **一、長期主升段**（多頭的夏天） | 趨勢明確，紅K多黑K少，低點不斷墊高 | 價在 6MA 上，短均帶動長均翻揚，價漲量增溫和放大 | 長線大戶連續買超 |
| **二、多頭末升段**（瘋狂的秋天） | 角度極度陡峭，連續巨量長紅 | 偏離 12MA、乖離過大，成交量失控暴增出現歷史天量（**這不是健康量，是出貨量**） | 大戶籌碼鬆動，**融資餘額瘋狂膨脹**，KD 高檔鈍化 |
| **三、高檔盤頭**（開始入冬） | M頭雛形或三角收斂末端，高檔常留長上影線或長黑 | 守不住 12 月均線，均線走平甚至下彎，量價背離 | — |
| **四、空頭**（冬天） | — | 價在均線下，反彈為逃命波 | — |

> [!note] 他的一個實戰觀察
> 末升段最迷人也最危險。他提過當時遇到**從不交易股市的朋友**看到新聞報導來請教該產業展望，他心裡想的是「糟糕，不妙了」。這是很典型的散戶進場訊號。
