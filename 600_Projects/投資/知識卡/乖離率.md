# 乖離率

> [!abstract] 一句話
> 乖離率不是預測工具，是一面照出市場集體情緒是否瀕臨極限的鏡子——衡量「物極必反」程度的儀表板。

宏爺在這一集開場點出一個核心觀察：許多投資人以為自己在跟股價對賭，其實是在跟「物極必反」這個鐵律對賭。看到別人狂歡才急忙進場，往往不是判斷錯誤，而是**進場者的情緒剛好抵達了市場反轉的極端點**。

## 計算方式

```
乖離率(%) = (當日收盤價 − N日移動平均價) ÷ N日移動平均價 × 100%
```

意義是**現價相對於過去 N 天平均成本是貴還是便宜**。

- 收盤 110、月線 100 → 正乖離 10%，代表這個月平均買入者帳上獲利 10%
- 收盤 85、月線 100 → 負乖離 15%，代表平均買入者虧損 15%

## 正負乖離的含義

| | 含義 | 極端時 |
| :--- | :--- | :--- |
| **正乖離** | 股價在均線之上，多頭氛圍，短期獲利者較多 | 擴到最大意味**獲利了結賣壓**累積，隨時可能回檔 |
| **負乖離** | 股價在均線之下，空頭氛圍，多數人虧損 | 擴到最大通常意味**超跌、空方力竭**，隨時可能反彈 |

## 零軸是多空分水嶺

乖離率在零軸附近徘徊代表股價緊貼均線，未脫離平均成本，處於盤整或緩漲緩跌。此時**乖離本身參考價值較低**——真正要看的是長紅或長黑 K 向上或向下突破後的方向。

## 週期要配合策略

這是他特別強調的一點：**指標週期必須配合自身策略**。做短線卻看 60 日乖離沒有幫助；著眼長期卻看 5 日乖離也沒有意義。

| 策略 | 週期 |
| :--- | :--- |
| 短線／當沖 | 3 日或 5 日 |
| 波段／長線 | 60 日（季線），或**他喜歡用的 100 日／20 週均線** |

## 參考門檻

**短線**（3 日均線乖離）：
- 正乖離超過 **+5%** → 不宜追高
- 負乖離超過 **−5%** → 不宜追空

**大盤長線**：通常在 **±15%** 左右；達到 **±20%** 要提高警覺。

> [!warning] 這些是經驗值，不是鐵律
> 不同股本大小、產業、波動性的股票，合理乖離區間都不同。**活潑的科技股或中小型飆股經常超過 ±15%，甚至更高。**
>
> 強勢多頭市場中的龍頭股，正乖離可能維持在 20% 以上很長一段時間。

## 極端乖離的操作確認

**負乖離極端（找買點）**
1. 股價急跌，短天期負乖離達極端值
2. K 線出現止跌訊號：守前低、長下影線、十字線或紅 K
3. 成交量萎縮，代表賣壓減輕

→ 可考慮**試探性**建立部位，但**必須嚴格設停損**。

**正乖離極端（找賣點）**
1. 股價急漲，短天期正乖離達極端值
2. K 線出現反轉訊號：長上影線、烏雲罩頂
3. 量能出現價創新高但量萎縮，或高檔爆量、巨量收長黑（主力出貨訊號）

→ 已持有多單可分批停利；**空手者切勿追高**。

## 用多週期乖離判斷趨勢

這是這一集最實用的框架：

**多頭確立的訊號**
1. 股價不再破前低，並開始突破下降壓力線
2. 短、中、長期乖離率**依序由負轉正**
3. **所有週期的乖離率都重新站回零軸之上**

**多頭中的健康回檔**
短天期乖離可能暫時回到零軸甚至轉負，但只要**中長天期（季線、20 週均線）的乖離堅守在零軸之上**，趨勢就沒變。

**空頭中的反彈機會**
長天期乖離已摜破零軸，此時股價短線反彈導致短天期正乖離過大、但**尚未突破零軸**——這是空單加碼或多單逃命的機會。

**趨勢力竭的警告**
長期上漲後，乖離率在末段急劇拉升達到歷史性極端高峰，隨後後繼無力——用他的話說，這是股價在喊「我累了」。

接著股價從高檔回落、跌破 20 週均線，導致中期乖離由正轉負——**看到這個訊號要特別小心**，代表趨勢可能已反轉，或至少進入中期整理。

## 核心心法：散戶的循環

他描述的迴圈很傳神：

```
空頭賠錢 → 恐懼驅使，只想反彈逃命
        ↓
持續修正到主力大戶見機介入
        ↓
趨勢反轉，大漲三天 → 散戶不請自來
        ↓
貪婪驅使，只想拉回加碼
        ↓
主力高檔出貨 → 再度轉為空頭市場
        ↓
       循環不已
```

> [!important] 主力會刻意操作乖離率
> 這是這張卡最重要的一點——乖離率不只是被動的溫度計，**它是主力的工具**：
>
> - **正乖離持續擴大**時，主力透過媒體釋放利多，在投資人帳上獲利的情況下**誘使更多散戶追高，以便倒貨**
> - **負乖離極大**時，主力**製造恐慌洗出浮額**，以利吸納籌碼
>
> 這是主力發動長短線攻擊前的過渡操盤，**本質是心理博弈**。
