# 科斯托蘭尼公式

> [!abstract] 一句話
> 短期趨勢 = 貨幣 + 心理因素。而這兩者的權重，會隨著時間尺度而翻轉。

宏爺引用德國投資人科斯托蘭尼的框架來解釋行情的生成。

## 公式

```
短期趨勢 = 貨幣因素 + 心理因素
```

**貨幣像氧氣**：供給充足就有機會帶動股市上漲，供給不足則讓股市下跌。這就是他常說的「資金活水」。

**但單靠貨幣不能決定行情**，還要看投資大眾的心態。如果大眾悲觀、沒人想買股票，錢會流向房地產、儲蓄或債券去賺更高利息。

**當貨幣與心理兩個因素都往負向發展時，就容易走跌。**

## 權重會隨時間尺度翻轉

這是這個框架最有價值的部分：

| 時間尺度 | 主導因素 |
| :--- | :--- |
| **短期** | **大眾心態造就 90% 的行情** |
| **中期** | **貨幣因素比大眾心態更具影響力** |

> [!important] 短期看情緒，中期看利率
> 這解釋了兩件事：
>
> 1. 為什麼短線那麼難做——90% 是情緒，而情緒無法預測。就算訓練有素的專家也容易被群眾情緒感染，在希望與恐懼之間擺盪。
> 2. **為什麼利率如此重要**——中期是貨幣說了算。

## 資金傳導有時間差

他點出一個很實用的機制：

> 如果有多餘的資金停在金融機構裡，**最晚 9 到 12 個月之後**，這些流動資金會有一部分進入股票市場。

傳導路徑是：

```
資金充裕（但大多數投資人仍悲觀）
        ↓
低檔進場的資金拉抬指數
        ↓
上漲行情讓大眾增加對股票的興趣
        ↓
逐漸進場，心態轉向更樂觀
```

**這說明了為什麼行情常在最悲觀時啟動**——貨幣因素先到位，心理因素才慢慢跟上。

## 情緒如何造成過度

- 市場預期上漲 → 參與者越來越貪婪 → 股價**飆漲過高** → 在高點被套牢
- 市場預期下跌 → 引發恐慌 → 紛紛拋售 → 股價**超跌**

這正是 [[乖離率]] 要度量的「物極必反」，也是主力刻意操作的對象。

## 怎麼用這張卡

判斷行情時分兩個問題問：

1. **貨幣面**：資金是充裕還是緊縮？利率往哪走？（→ [[L0_資金環境]]）
2. **心理面**：大眾現在是貪婪還是恐懼？（→ [[乖離率]]、[[逃命波與假反彈]]）

兩者同向時，趨勢的可信度最高；背離時，要看時間尺度——**短期跟情緒走，中期跟資金走**。
