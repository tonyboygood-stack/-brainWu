# 量價關係與背離

> [!abstract] 一句話
> 價格是結果，成交量是原因——量先價行，所以量能的變化比價格更早透露方向。

## 核心觀念：量先價行

價格漲跌的關鍵來自市場買賣的力量，而成交量正是這股力量的直接度量。

**週期越長，量能訊號越乾淨**。週K的量能變化比日K更具參考價值，因為濾掉了短線雜訊，剩下的是法人主力的中期意圖。

## 四種基本組合

| 組合 | 含義 | 方向 |
| :--- | :--- | :--- |
| 價漲量增 | 買盤積極、資金湧入 | 趨勢延續（健康） |
| 價跌量縮 | 賣壓減弱 | 可能底部築成 |
| **價漲量縮** | **空頭背離**——量能無法同步放大 | 漲勢可能無以為繼 |
| **價跌量增** | 恐慌性賣壓 | 趨勢持續轉弱 |

> [!important] 背離口訣
> **背離就容易有轉折、後繼無力。**
>
> 若在相對高位階出現量價背離，尤其週K級別，後果可能不堪設想。

## 兩個極端量的口訣

> **窒息量找買點，天量找賣點。**

**窒息量**：低檔盤整、成交量萎縮到幾乎沒人想交易，代表想賣的人都賣光了，籌碼相對安定。此時只要一點火苗（利多消息或大戶進場拉抬），就容易星火燎原。

**天量**：連續上漲、成交量暴增、同時乖離過大，代表情緒已經超過基本面。媒體狂放送利多，短線投機資金與散戶全衝進來——**這不是健康量，通常是出貨量**，是天量賣點的前兆。

經驗法則：**漲一倍或碰到整數關卡時爆大量**，容易引來壓力修正。

## 突破時的量能門檻

**週K有效突破**：週量比前一週增長**至少 30%**。

**日K大漲訊號**：巨量通常是日均量的 **2–3 倍以上**——這個巨量等於主力宣告吃貨完成。→ [[大漲的訊號]]

**突破後能漲多遠**：如果是主力長時間吸納籌碼後的爆量上漲，根據量先價行原理，**底部天量有機會挑戰歷史更大套牢量的高點**。量能不夠則突破幅度有限。

## 多空的不對稱性

這一點貫穿他整套技術判讀：

- **向上突破必須有量**——無量上漲容易拉回
- **向下跌破不需要量**——有量沒量都會跌

無量跌破的危險性雖比帶量跌破小，但既然跌破了重要支撐，後果仍然堪憂。

## 一個重要例外

> [!warning] 籌碼被鎖定時，無量也能飆漲
> 個股若籌碼被主力鎖住，純看量價會誤判。所以**個股必須同步追蹤籌碼**。
>
> → [[籌碼集中度]]、[[大戶持股流向判讀]]

## 量能配合籌碼的四種情境

| 週均量 | 籌碼狀態 | 判讀 |
| :--- | :--- | :--- |
| 穩定放大 | 法人連續買超 | 大戶進場，股價有望走強 |
| 持續萎縮 | 法人轉賣超 | 資金撤退，可能進入整理 |
| 放大但股價漲不上去 | 大戶籌碼分散 | **出貨**訊號 |
| 增溫 | 大戶籌碼集中 | 主力可能正在吸籌 |
