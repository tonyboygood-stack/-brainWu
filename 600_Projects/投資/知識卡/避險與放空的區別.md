# 避險與放空的區別

> [!abstract] 一句話
> 避險是買保險、防止趨勢突然反轉；放空是順勢作戰、主動賺取下跌利潤。兩者的進場條件與心態完全不同。

## 用戰爭比喻

| | 避險 | 放空 |
| :--- | :--- | :--- |
| 兵種 | **騎兵**（機動防守） | **正規軍**（正面作戰） |
| 目的 | 規避風險、保障既有收益 | 賺取下跌價差 |
| 心態 | 「有點看到黑影就開槍的味道」 | 必須全面確認條件才進場 |
| 是否看基本面 | **不看**——等基本面出問題才避險就太慢了 | 技術＋籌碼＋資金三面確認 |

避險的本質是**為現有部位買保險**：透過高槓桿工具，在真正遇到風險時部分彌補現股損失。

> [!tip] 避險常演變成放空
> 大多時候**成功的避險單會轉向反向的放空部位**——保險確認需要理賠時，就變成主動攻擊。

## 避險的進場條件

| | 多頭避險 | 空頭避險 |
| :--- | :--- | :--- |
| 情境 | 趨勢偏空但可能有反彈，要規避反彈 | 多頭格局中偶有回檔，要規避回檔 |
| 技術面 | 站回月均線 | 跌破 20 週均線 |
| 籌碼面 | 外資先行指標由空單轉多單 | 外資先行指標由多單轉空單 |

**反向暫毀或跌破避險單則須迅速處理**——避險單本身也要有退場紀律。

## 放空三不碰

> [!warning] 這三種絕對不要空
> **1. 漲太多、看它不爽就空**
> 趨勢通常強者恆強，隨意放空強勢股容易被軋空到天邊去。（就像看到跌很多就想搶反彈一樣危險）
>
> **2. 量少股**
> 無量則無價。
>
> **3. 盤整股**
> 多空雙方仍在蓄積能量，等方向出來再動作會相對安全。

## 放空的完整條件

三個面向都要成立：

**技術面**
- 大盤跌破 **20 週均線**（設定為 100MA）
- 大盤**月 KD 值高檔死亡交叉**

**籌碼面**
- 外資先行指標**連續進空單**期貨部位
- 法人**連續減碼**台股

**資金面**
- 新台幣呈現**貶值**趨勢

> [!important] 他特別強調的兩項
> 20 週均線與外資期貨部位的判斷最為關鍵。

## 出場原則

> **進場條件消失時出場。**

與做多相同的邏輯。例如放空後大盤反彈站回 20 週均線，就重返多方格局，該退場了。

**不是等停損被打到才走，而是當初讓你進場的理由不見了就走。**

## 可用的做空工具

由低風險到高風險：

- **融券**——限制較多
- **反向 ETF**——⚠️ 他明確警告不要長期持有。反向 ETF 可說是「上市即巔峰」，一路買進的投資人怎麼買怎麼虧，因為股市長期是緩步向上的
- **放空期貨或個股期**——他偏好的方式，限制比融券少很多 → [[個股期運用]]
- **選擇權**——空頭避險或放空常用 Buy Put（看大跌）或 Sell Call（看不漲）

> [!note] 他為什麼偏好用期貨放空
> 第 40 期他提過：個人偏好期貨才放空，主要是因為股票放空限制太多。
