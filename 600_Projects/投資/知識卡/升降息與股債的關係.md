# 升降息與股債的關係

> [!abstract] 一句話
> 升息對股債都不利但債券利息變高，降息對股債都有利但債券利息變少——方向相反的是「價格」與「利息」。

## 核心對照

| | 升息 | 降息 |
| :--- | :--- | :--- |
| 央行目的 | 把市場流動資金收回、抑制通膨 | 鼓勵資金投入市場 |
| 股市 | 可能變得悲觀 | 可能變得活絡 |
| 通膨 | 受到抑制 | 可能死灰復燃 |
| 債券**利息** | 增加 | 減少 |
| 債券**價格** | **下跌**（不利） | **上漲**（有利） |

**為什麼升息時舊債券價格下跌**：新發行的債券有更高的利息收益，使得舊有債券相對不吸引人。

> [!important] 一個重要的補充判斷
> 他在 [[賣出訊號系統]] 中指出：**因為經濟衰退而出現的降息，反而更需要考慮減碼或賣出。**
>
> 也就是說「降息利多」有前提——要看降息的**原因**是為了刺激成長，還是為了救火。

## 債券的本質

債券是一種借貸契約。買債券等於把錢借給發行機構，機構按約定利率支付利息，到期歸還本金。

**要看的基本要素**：債券種類（國債、公司債、市政債）、發行期限與到期日、面額、票面利率（固定或浮動）、還本方式、計息複息方式。

## 三大風險

**1. 利率風險**
市場利率變化直接影響債券價格（見上表）。

**2. 通膨侵蝕**
```
實質利率 = 名目利率 − 通貨膨脹率
```
票面利率 5%、通膨 4%，實質利率只剩 1%。**債券最大的敵人就是通膨**——因為通膨會導致升息。

**3. 信用風險（違約風險）**
發行機構若財務出問題，可能無法按時付息或還本，債券價格會大幅下降。

> [!note] 債券的一個優勢
> 我們是**債權人**，不像股票要公司賺錢才分紅——就算對方虧損，仍有還錢的義務。

**存續期間越長，風險越高**，因為這段期間營運、通膨、價格變動的機率都更大。

## 高利率不等於好

> [!warning] 高利率必然伴隨高風險
> 條件越糟糕、風險越大的發行單位，才需要開出更高的利率來吸引投資人。
>
> 他舉例：非投資等級（BBB 以下）殖利率約 15%；若看到 20% 的，違約機率非常高，「幾乎快要達到詐騙等級」。

**信用利差**（相對於美國公債這個無風險利率）：

| 等級 | 利差 |
| :--- | :--- |
| AAA | 不到 1% |
| BBB（投資等級） | 約 1.71% |
| CCC（非投資等級） | 超過 10% |

**三大國際信評公司**：穆迪、標準普爾、惠譽。

> [!important] 他的選擇原則
> **盡量選 BBB 投資等級以上，不要挑非投資等級。**

## 為什麼要配置債券

即使股票是他最愛的工具，債券仍有三個作用：

1. 相對股票**穩定、風險較低**
2. 利率通常比銀行定存高，**定期收到利息**——對需要固定現金流的人是好選擇
3. 納入組合可**分散風險**，減少過度暴險於單一工具

> [!tip] 他對定存的看法
> 通膨猖狂的年代，定存利率極低（他提到郵局一年期定存僅 1.6%，超過 500 萬部分利息更少）。**不要讓自己的錢越放越少**——這呼應他在 [[資產配置金字塔]] 中的立場：除非市場極度過熱，否則長期持有現金定存並不明智。

## 選債券 ETF 的三步驟

1. 確認自己的投資目標與風險承受能力
2. 研究產品特性——持有的債券類型、信用評等、預期收益
3. 持續關注市場動態（利率、經濟狀況都會影響價格）
