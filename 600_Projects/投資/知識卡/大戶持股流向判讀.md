# 大戶持股流向判讀

> [!abstract] 一句話
> 用集保股權分散表看各張數級距的持有人數變化，判斷籌碼是往大戶集中還是往散戶擴散。

## 核心原則：流向重於水位

這是宏爺在籌碼判讀上最強調的一點。

> 大戶與董監持股的**高低**固然要看，但**流向的重要性更高於持股水位**。

他的大原則直白得近乎粗暴：**買正在被買入的股票，賣正在被賣出的股票。**

## 怎麼讀股權分散表

集保結算所的資料會列出各張數級距的持有人數。判讀邏輯是看人數如何遷移：

| 現象 | 含義 |
| :--- | :--- |
| 大戶減碼 | 籌碼往上面（張數較少的級距）跑，該區人數變多 |
| 小級距持有人數**增加** | 籌碼越趨凌亂，通常**不利** |
| 籌碼往大戶集中 | 通常**較優** |

實務上是逐週比對同一檔股票的級距分布，觀察人數的位移方向，而不是看單一時點的絕對數字。

## 為什麼內部人特別重要

內部人（董監、大股東）通常比散戶更早知道公司的營運狀況。因此董監持股的水位與流向，在他的判讀中權重很高。

追蹤路徑：公開資訊觀測站 → 個股頁面下方「內部人股權異動」→ 右下角 more，可看上個月內部人買賣情況。

## 他的實務招數：直接打電話

第 70 期他示範了一個非典型動作——發現大戶異常出脫時，**直接電訪公司財務主管或發言人**詢問是否有重大利空。

他自己也承認對方未必說實話（「有的話可能也不會講」），但這個動作仍有價值：其中一個案例中，打完電話後該分點就沒有再出現減碼跡象。

> [!tip] 他給觀眾的建議
> 持股有疑慮時，試著打電話問公司財務發言人，看能否問出一些蛛絲馬跡。
