# 三大財報判讀

> [!abstract] 一句話
> 財報是落後指標，但它是唯一能驗證「這家公司到底有沒有真的賺到錢」的東西。

## 財報在他體系中的定位

技術與籌碼是**即時指標**——跌破均線、誰買誰賣，一兩天內就知道結果。
財報是**落後指標**——但能清楚呈現公司基本面的輪廓。

股價出現較大波動，多半發生在財報公布之後（月營收、季報、年報）。**股價終需回歸基本面。**

## 閱讀順序

```
1. 綜合損益表   ← 賺了多少（動態，一段期間）
2. 資產負債表   ← 家底有多厚（靜態，某個時點）
3. 現金流量表   ← 錢是真的還是帳上的（動態）
```

---

## 一、綜合損益表：公司賺不賺錢

反映一段期間的營運表現。

**獲利成長的四個來源**：營收大成長、成本下降、毛利提高、業外收入。

> [!warning] EPS 可能被業外損益扭曲
> 他舉的案例很有教育性：某公司**本業獲利成長、費用也沒特別拉高，但 EPS 反而不如去年**。
>
> 追查後發現原因是去年業外收入高，今年業外收入大幅減少。
>
> **所以看到 EPS 下滑不要直接下結論，要拆開本業與業外。**

**反過來的案例**：某廠營收其實是**衰退**的，股價卻大幅飆升——原因是銷售毛利較高的 AI 伺服器產品出貨帶動**毛利率走升**。

> [!important] 兩個推論
> 1. **營收與獲利可以背離**——高毛利產品組合的轉變比營收數字更關鍵
> 2. **高毛利往往來自急單需求爆發，最終回歸正常價格的機率很高**——要有「撐得住壞消息」的心理準備

**匯率的影響不可忽視**：台灣以電子產業居多，台幣貶值對出口導向電子廠幫助很大（業外匯兌收入）。反過來，低毛利時代碰上台幣升值，電子廠會非常辛苦。→ [[台幣升值的衝擊鏈]]

## 二、資產負債表：錢從哪來、花到哪去

```
資產 = 負債 + 股東權益
```

左邊（資產）＝錢花到哪裡去；右邊（負債＋權益）＝錢是怎麼來的。

呈現的是**某個特定時點**（季底、年底）的財務畫面。

**看什麼**：

- **負債比例** → 判斷違約風險，也能看出公司對獲利的自信程度
- **資產項目** → 公司把錢花在哪？買新廠房設備？投資？還是用來生產更多產品創造價值？

> [!tip] 資本支出是前瞻訊號
> **公司對未來營運展望看好，才會有擴廠計畫。** 觀察「不動產、廠房及設備」項目的成長，可以看出公司是否投入未來成長。
>
> 投資人對公司規劃掌握越詳細，越能先知先覺。

**兩個效率指標**：

| 指標 | 公式 | 意義 |
| :--- | :--- | :--- |
| ROA 資產報酬率 | 稅後淨利 ÷ 平均資產 | 每一元資產能產生多少利潤 |
| ROE 股東權益報酬率 | 稅後淨利 ÷ 股東權益 × 100% | 拿股東的錢去賺錢的能力 |

> [!warning] 不是越高越好
> 他特別提醒：**財務指標不要單看一個，要綜合分析**，否則容易被誤導。

## 三、現金流量表：最不容易造假的地方

三類現金流：營業活動、投資活動、融資活動。三者加總得出本期現金增減數，再加上期初現金餘額，得到期末現金餘額——這個數字會對應回資產負債表的現金項目。

> [!important] 自由現金流是重點
> **自由現金流是公司真正可以自由運用的資金，也是比較不容易作假的部分。**
>
> **如果長期呈現負數**，要留意這家企業在營運上是否過度燒錢——容易導致資金壓力越來越重，在資金週轉不靈的情況下甚至可能出現財務危機。
