# 台幣升值的衝擊鏈

> [!abstract] 一句話
> 貨幣升值一般被解讀為資金湧入的好消息，但對出口導向的台灣，急升是直接砍在企業獲利上的一刀。

## 三個推升力量

**1. 美元信心動搖**（主因）
→ [[貨幣競貶與金融壓抑]]

**2. 壽險業的美元部位對沖潮**
這是一股較少被注意的力量。台灣長年靠貿易順差累積美元，早期放在央行，再透過壽險業發行台幣保單去買美債。

> [!warning] 結構性的錯配風險
> - **台幣計價的負債** vs **美元計價的資產**——美元大跌時，美債市值大幅縮水
> - 通膨高漲時債券價格受影響
> - 若一次性賣出大量美債，恐在全球債市引發劇烈動盪
>
> 關鍵數字：壽險業海外資產龐大、多為美國公債，但**避險比率不到四成**。台幣強升時，壽險業面臨巨額匯損，只能匆忙補避險——而補避險的動作本身又推升台幣，形成**恐慌的正回饋**。

**3. 羊群效應**
民眾追漲殺跌搶換匯（他提到某日網銀 APP 大塞車的現象）。

## 衝擊鏈：誰會受傷

### 壽險業
匯率急升如同財務地雷，**升值越快，帳面損失如雪球般滾大**。他舉了歷史案例：某年台幣全年升值 8%，壽險業避險前匯兌損失達數千億元規模。

### 出口產業（直接壓縮獲利）

台灣企業營收多以美元計價、成本卻以台幣計價，所以升值是「快刀割肉」：

| 敏感度 | 影響 |
| :--- | :--- |
| 台幣每升值 **1%** | 上市櫃整體稅前獲利減少約 **0.5%** |
| 台幣每升值 **1%** | 台積電營業利益率下滑約 **0.4%** |
| 台幣每升值 **10%** | 本業毛利率下滑 4–5%，業外匯損 2–2.5%，**總獲利衝擊約 6–7.5%** |

> [!note] 但不必過度悲觀
> 他提醒：過去匯率波動後，大多數出口商會依合約情況**調整價格、重新談合約**。衝擊主要在於「出貨的是舊價格，現在台幣升，毛利馬上縮水」的時間差。

### 房地產（處境微妙）

一般認為升值吸引熱錢、利多房市，短期確實可能推升房價，台灣房價也常與台幣強弱相關。

> [!warning] 但歷史有反例
> 1988 年熱錢湧入、台幣大幅升值，房價拉高近三倍；但隨後**出口受創、產業外移，房市泡沫破裂**，台北市房價從高點修正，進入長達十年的低迷期。
>
> 判準是：如果台幣持續強勢，同時**出口與就業出現明顯衰退**，可能成為壓垮房市的催化劑。

## 與日本廣場協議的對比

這波急升讓不少人聯想到日本泡沫年代。但他做了關鍵區分：

| | 日本當年 | 這次台幣 |
| :--- | :--- | :--- |
| 節奏 | 熱錢**慢慢滲透**，資產價格逐步堆高，最後才引爆 | **恐慌性急升** |
| 資金基礎 | 紮實 | 可能並不紮實 |

**結論**：台灣產業陷入「失落 20 年」的機率小之又小。差別就在「急升」這兩個字。

## 區域競爭：人民幣是頭號對手

台灣與中國在科技、機械、紡織等領域出口競爭激烈。當台幣狂升而人民幣幾乎不動時，這樣的差距在出口市場上刀刀見骨。

而台灣不像中國有內需市場可以緩衝波動——這是結構性的脆弱點。

## 使用方式

看到台幣大幅波動時的檢查順序：

1. 是**急升**還是**緩升**？（決定資金基礎是否紮實）
2. 推力來自基本面還是**避險補倉的恐慌回饋**？
3. 出口與就業數據有沒有同步惡化？（決定房市與內需的連鎖風險）
4. 相對於人民幣的升貶差距有多大？（決定出口競爭力的傷害）

> [!warning] 數字會過期
> 本卡的敏感度係數（每升 1% 影響 0.5%）是當時法人的估算，結構可能隨產業組成改變。引用前回原片確認，並對照最新的法人估算。
