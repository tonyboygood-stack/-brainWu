## 公司本質

47 年的電路保護元件廠，1979 年高雄設廠、2000 年上市。10 個產品類別、8 個生產據點、25 國服務據點、4,200 名員工。

**三大功能群**：過電壓防護（壓敏電阻、氣體放電管、ESD、TVS）、過電流保護（PTC／PPTC／NTC ICL）、過溫度偵測（PTC、EV 溫度感測器、家電溫度感測器、溫壓整合感測器）。

**產品線演進**（法說會簡報）：

```
1989 NTC熱敏電阻 → 1997 壓敏電阻/PTC → 2002 PPTC → 2008 ESD
→ 2010 氣體放電管 → 2016 TVS二極體
→ 2018 電動車溫度傳感器（電池、馬達）   ← 轉折
→ 2024 壓敏電阻與氣體放電管複合型保護元件  ← 產品整合
```

**廠區擴張**：2019–2023 擴廠（高雄、宜昌），**2025 年中山廠落成**，簡報寫「持續擴建中」。

董事長與總經理均為**隋台中**（一人兼任）。資本額 12.81 億＝128,113 張。**董監質押 0%**，內部人結構乾淨（新查證，來源：TWSE 官方董監持股與質押資料）。
