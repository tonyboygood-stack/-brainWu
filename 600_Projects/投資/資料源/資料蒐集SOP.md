# 資料蒐集 SOP

分析一檔股票時，資料分兩類：**能自動抓的**（跑一行指令）與**需要人工的**（有驗證碼或要登入）。這份文件把兩邊都寫清楚。

---

## 第一步：跑自動抓取

```bash
python 000_Agent/scripts/stock-fetch.py 1786
```

約 60–90 秒跑完，產出 `600_Projects/投資/個股/_data/1786.md`。

**參數**

| 參數 | 說明 |
| :--- | :--- |
| `--days 30` | 三大法人抓幾個交易日（預設 20） |
| `--months 14` | 股價抓幾個月（預設 14，夠算 20 週均線） |
| `--no-cache` | 強制重新下載（同一天重跑會用快取） |

**自動涵蓋的六項**

| 資料 | 來源 | 對應框架層 |
| :--- | :--- | :--- |
| 公司基本資料、發言人電話 | TWSE OpenAPI | — |
| 月營收（含 YoY、MoM） | TWSE OpenAPI | [[L3_標的體質]] |
| 綜合損益表、資產負債表、營益分析 | TWSE OpenAPI | [[三大財報判讀]] |
| 日成交（開高低收量）＋ 🔴 20 週均線與乖離 | TWSE RWD API | [[L1_市場位階]]、[[L4_進出時機]] |
| 三大法人買賣超 | TWSE RWD API | [[三大法人屬性差異]] |
| 集保股權分散表（>400張／>1000張大戶） | TDCC Open Data | [[大戶持股流向判讀]] |

> [!note] 只支援上市股票
> 腳本目前走 TWSE 的 API。**上櫃（櫃買）股票**要另外從 [TPEx](https://www.tpex.org.tw/zh-tw/index.html) 取得，腳本尚未支援。

> [!warning] 集保是單週快照
> TDCC 開放資料只有**最新一週**。宏爺強調「流向重於水位」——要看趨勢，得用 [神秘金字塔](https://norway.twsthr.info/StockHolders.aspx?stock=1786)（把網址最後的代號換掉），它有數年的週資料。

## 第二步：人工補四項

以下四項**沒辦法自動化**，原因與做法逐一說明。

### ① 分點進出明細｜有圖形驗證碼（唯一真正要動手的）

**為什麼不能自動**：證交所買賣日報表每次查詢都要輸入圖形驗證碼。我不會、也不應該去破解驗證碼——這是我的界線，不是技術問題。

**操作步驟**

1. 開 [證交所買賣日報表](https://bsr.twse.com.tw/bshtm/bsMenu.aspx)
2. 「股票代號」欄輸入代號（例如 `1786`）
3. **輸入圖片上的驗證碼**（只有這一步非你不可）
4. 按「查詢」
5. 結果頁右上角有「**另存 CSV**」，存下來
6. 檔案丟給我，或把前十大買超／賣超券商貼給我

**拿到之後怎麼用**（依 [[大戶持股流向判讀]]）

| 看什麼 | 判準 |
| :--- | :--- |
| 前幾大買超券商是誰 | 重點是**同一家是否連續多日買超**——單日沒有意義 |
| 有沒有**地緣券商** | 公司所在地附近的分點在吃貨，通常是內部人或熟悉公司的資金 |
| 賣超方的結構 | 分散的散戶 vs 特定大戶，含義完全不同 |

**順便可以算出籌碼集中度**

```
籌碼集中度(%) = (前15大買超張數 − 前15大賣超張數) ÷ 區間總成交量
```

門檻依 [[籌碼集中度]]：60 日 > 5%（強者 10%）、120 日 > 3%；**負值代表主力在倒貨**。

> [!warning] 兩個限制
> 1. 這個網站**只有當日資料**，沒有歷史。要看連續性得每天存一份。
> 2. 也因為只有當日，要算 60 日集中度得累積 60 天的檔案——實務上不太可行。若真要這個指標，付費工具比較實際。

### ② 法說會｜✅ 已自動化

> [!important] 修正：這項原本被判定為不可自動化，是錯的
> MOPS **新版**確實會把查詢轉導到舊系統、網址帶加密參數，看起來沒救。
> 但**舊版的查詢表單可以直接 POST**，繞過整個新版前端就拿得到完整歷年清單。
> 連 PDF 下載也是單純的表單 POST。

腳本已涵蓋：列出歷年場次、各年度次數、最近 5 場的簡報檔名、以及影音連結。

**技術細節**

| 用途 | 方法 |
| :--- | :--- |
| 取清單 | POST `mopsov.twse.com.tw/mops/web/ajax_t100sb02_1`，帶 `step=0, firstin=true, TYPEK=sii, co_id=<代號>` |
| 下載 PDF | POST `mopsov.twse.com.tw/server-java/FileDownLoad`，帶 `step=9, filePath=/home/html/nas/STR/, fileName=<檔名>, functionName=t100sb02_1` |
| 檔名規則 | `<代號><西元年月日><M中文\|E英文>001.pdf` |

**下載某一場簡報**

```bash
python -c "import importlib.util as u; s=u.spec_from_file_location('sf','000_Agent/scripts/stock-fetch.py'); m=u.module_from_spec(s); s.loader.exec_module(m); print(m.download_conference_pdf('178620251216M001.pdf','.'))"
```

**要看什麼**（依 [[法說會判讀技巧]]）
- 管理層對**未來的展望**——財報這個落後指標缺少的前瞻資訊
- 🔑 **簡報的用心程度與美感**。宏爺的判準是：敷衍了事的公司他看了就興致缺缺，因為從小細節能看出公司的用人態度與文化
- **開會頻率本身也是訊號**——中斷或變少，代表與市場溝通的意願下降

> [!tip] 法說會如果有錄影，可以直接轉逐字稿
> 清單會附影音連結（多為 YouTube）。丟給 [[yt-transcribe.py]] 就能得到全文，比看簡報更完整。
>
> ```bash
> python 000_Agent/scripts/yt-transcribe.py "<法說會影音網址>"
> ```

**順便看的**：同一個網站可查「內部人股權異動」（個股頁面下方 → 右下角 more），能看到上個月董監大股東的買賣。

### ③ 主力買賣超與買賣家數差｜✅ 已自動化，不需登入

> [!important] 這一項原本以為要登入，實測後發現不用
> 拿有登入的 cookie 和完全匿名去打同一個 API，**回傳結果一模一樣**。
> 所以腳本已經涵蓋這兩項，你的 CMoney 帳號在這條管道上用不到。

**技術細節**（供日後網站改版時除錯）

API 在 `www.cmoney.tw/finance/ashx/MainPage.ashx`，兩個 action：

| action | 回傳 |
| :--- | :--- |
| `mainforceoverbuy` | `{Date, OverBuy}` — 主力買賣超（張） |
| `tradersum` | `{Date, BuyerCount, SellerCount, TraderSum}` — `TraderSum` 即**買賣家數差**（已驗證＝買方家數−賣方家數） |

要一把 `cmkey`，而那把金鑰**短效、幾分鐘就換**，且只嵌在籌碼K線頁面的 HTML 裡（一頁約 21 把，不在 JS 檔中）。腳本的做法是：載入 `/finance/<代號>/stockmainkline` → 抽出所有候選金鑰 → 逐一試到通為止。頁面載入時設下的 session cookie 也要沿用。

**判讀門檻**（依 [[買賣家數差]]）

| 型態 | 含義 |
| :--- | :--- |
| 主力買超為正 **+ 家數差為負** | **主力吃貨**——少數人吸收多數人的貨 |
| 主力賣超 + 家數差為大正值 | 偏**出貨**——少數賣方把貨分散給很多買方 |

### ③-2 籌碼集中度與外資成本線｜免費頁面沒有

實際檢查過 CMoney 的籌碼K線頁面，**這兩個指標完全沒有出現**——不是要登入，是免費版根本不提供，應該屬於付費的理財寶產品。

免費頁面實際有的是：主力買賣超（當日與**累計**）、買賣家數差、買家數、賣家數——這些腳本都抓了。

**替代做法**

| 指標 | 怎麼取得 |
| :--- | :--- |
| **籌碼集中度** | 公式是 (前15大買超張數 − 前15大賣超張數) ÷ 區間總成交量。分子要從**分點資料**算，所以卡在下面第 ③ 項的驗證碼 |
| **外資成本線** | 需付費工具。替代方案是用外資買賣超與對應日收盤價自行估算加權平均成本——但那是估算，不是官方數字，用的時候要標明 |

> [!tip] 有個免費的替代訊號
> 腳本抓的**主力累計買賣超**其實能回答同一個問題：籌碼在集中還是分散。搭配買賣家數差一起看，判讀力道不會差太多。

### ④ Goodinfo 與 M平方｜擋自動請求

**為什麼不能自動**：兩站都回 HTTP 403 擋掉程式請求，Goodinfo 還會跳出機器人驗證頁。**用瀏覽器開得起來**，只是抓不到。

**怎麼做**：直接用瀏覽器開，需要的數字自己看或複製給我。

- [Goodinfo 個股頁](https://goodinfo.tw/tw/StockDetail.asp?STOCK_ID=1786)（換代號）——個股綜合資料、財報選股篩選
- [M平方](https://www.macromicro.me/)——總經數據，對應 [[L0_資金環境]]
