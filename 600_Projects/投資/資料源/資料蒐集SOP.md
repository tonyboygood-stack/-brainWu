# 資料蒐集 SOP

目前提供「資料蒐集＋品質檢查＋待確認清單」。報告產生不代表完成宏爺六層評估。

## 一次蒐集個股與補充資料

```powershell
python 000_Agent/scripts/stock-fetch.py 1786
```

預設取得72個月未還原行情、20日法人與融資資料，再收集總經、期權、歷季財報與官方公告。若終端找不到 Python，可用工作區執行檔 `更新投資資料.ps1`。

產出：`個股/_data/<代號>.md`、`<代號>_supplement.json`。JSON保留補充來源的原始資料列、來源網址、擷取時間與錯誤狀態。

參數：`--days 30` 調整法人／融資日數，`--months 72` 調整行情月數，`--no-cache` 強制刷新，`--no-supplement` 明確略過補充資料。

只更新補充資料：

```powershell
python 000_Agent/scripts/stock_supplement.py 2330
python 000_Agent/scripts/stock_supplement.py 6488 --market otc
```

## 已接入的來源

| 資料 | 取得方式 | 限制 |
| :--- | :--- | :--- |
| 公司資料、當期財報、月營收 | TWSE／TPEx OpenAPI | 快照不等於完整歷史；金融業表格可能不同 |
| 歷史日行情、週月K、均線 | FinMind批次；失敗時有限次查交易所 | 未還原權息，週月K包含未收完期間 |
| 上市法人／融資 | 交易所逐日查詢；融資不足時FinMind備援 | 逐項檢查取得日數；不是盤中即時資料 |
| 上櫃法人／融資融券 | TPEx官方逐日查詢 | 日期、表格欄位與法人合計皆驗證 |
| 董監持股／質押、內部人轉讓申報 | TWSE／TPEx官方 | 申報不等於實際成交；資料年月與擷取日不同 |
| 重大訊息 | TWSE／TPEx當日公告 | 查無當日資料不代表沒有歷史事件 |
| 歷季損益、資產負債、現金流、歷年月營收 | FinMind個股查詢 | 原始列保留；不直接跨季累加EPS或未確認期間的現金流 |
| 除權息事件 | FinMind | 不等於已還原行情；減資／分割仍需核對 |
| 大戶集保 | TDCC官方快照＋按來源週次累積 | 同一週不重算新週；不足兩週不判流向 |
| 集保歷史補抓 | FinMind歷史端點 | 本次匿名查詢被會員權限拒絕，明列未取得；可使用自行提供的FINMIND_TOKEN環境變數 |
| 外資期貨／選擇權／買權賣權分計 | 期交所OpenAPI | 各契約分開列示，不直接合加大台小台口數 |
| 美元、台幣、利率、美債、CPI、M2、失業率 | FRED公開CSV、期交所匯率 | 各序列發布頻率不同；廣義美元指數不是DXY |
| 加權指數 | TWSE當月日資料 | 尚未建立多年大盤技術序列 |
| 法說會 | MOPS清單＋PDF下載函式＋影音連結 | 清單取得不等於已閱讀或解讀內容 |
| 主力買賣超／家數差 | CMoney公開頁面 | 可能因改版或短效金鑰失效；未取得要明列缺口 |

## 必須遵守的品質門檻

1. 買賣超與成交量必須是完全相同、無重複、完整的日期區間；缺一天就停算該區間占量比。
2. 「主力淨買超占量比」只是代理指標。沒有確認區間分點排名算法與來源定義前，不稱為宏爺集中度，也不套用5%、3%門檻。
3. 不足完整一年，不給52週位階；五年月均線不足60個月就不計算。官方逐月抓取失敗時停用相關技術結論。
4. 快取有期限，預設一小時；不把同日盤前抓到的資料永遠當成當日收盤。
5. 缺資料、過期、未驗證、無符合公告，均不得轉成零、中性、通過或「沒有風險」。
6. 選股結果為初步候選；代理籌碼沒有驗證前，不因代理值正負加分或判主力倒貨。
7. 原始行情尚未還原。除權息或分割附近的突破、乖離、長期均線需另行確認。

## 還需要的證據

- 多週集保持股歷史、連續分點、經驗證的區間集中度與外資成本線。
- 法說內容、歷史重大訊息、產業競爭及管理層展望的閱讀與比對。
- 本人的持股、成本、現金、借款、利率及風險預算；不能從公開股市資料猜出。
- 宏爺缺期與未整理內容，以及逐字稿數字回原片核對。

分點資料可由使用者合法取得的券商匯出檔補入；目前沒有自動假造或破解登入流程。

資料就緒後仍依 [[判讀SOP]] 逐層判讀。參見 [[系統補強紀錄_2026-09-09]]。
