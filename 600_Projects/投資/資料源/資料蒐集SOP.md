# 資料蒐集 SOP

分析一檔股票時，資料分兩類：**能自動抓的**（跑一行指令）與**需要人工的**（有驗證碼或要登入）。這份文件把兩邊都寫清楚。

---

## 第一步：跑自動抓取

```bash
python 000_Agent/scripts/stock-fetch.py 1786
```

約 60–90 秒跑完，產出 `600_Projects/投資/個股/_data/1786.md`。

**參數**

| 參數 | 說明 |
| :--- | :--- |
| `--days 30` | 三大法人抓幾個交易日（預設 20） |
| `--months 14` | 股價抓幾個月（預設 14，夠算 20 週均線） |
| `--no-cache` | 強制重新下載（同一天重跑會用快取） |

**自動涵蓋的六項**

| 資料 | 來源 | 對應框架層 |
| :--- | :--- | :--- |
| 公司基本資料、發言人電話 | TWSE OpenAPI | — |
| 月營收（含 YoY、MoM） | TWSE OpenAPI | [[L3_標的體質]] |
| 綜合損益表、資產負債表、營益分析 | TWSE OpenAPI | [[三大財報判讀]] |
| 日成交（開高低收量）＋ 🔴 20 週均線與乖離 | TWSE RWD API | [[L1_市場位階]]、[[L4_進出時機]] |
| 三大法人買賣超 | TWSE RWD API | [[三大法人屬性差異]] |
| 集保股權分散表（>400張／>1000張大戶） | TDCC Open Data | [[大戶持股流向判讀]] |

> [!note] 只支援上市股票
> 腳本目前走 TWSE 的 API。**上櫃（櫃買）股票**要另外從 [TPEx](https://www.tpex.org.tw/zh-tw/index.html) 取得，腳本尚未支援。

> [!warning] 集保是單週快照
> TDCC 開放資料只有**最新一週**。宏爺強調「流向重於水位」——要看趨勢，得用 [神秘金字塔](https://norway.twsthr.info/StockHolders.aspx?stock=1786)（把網址最後的代號換掉），它有數年的週資料。

## 第二步：人工補四項

以下四項**沒辦法自動化**，原因與做法逐一說明。

### ① 分點進出明細｜有圖形驗證碼

**為什麼不能自動**：證交所買賣日報表每次查詢都要輸入圖形驗證碼。我不會、也不應該去破解驗證碼。

**怎麼做**

1. 開 [證交所買賣日報表](https://bsr.twse.com.tw/bshtm/bsMenu.aspx)
2. 輸入股票代號
3. **輸入畫面上的驗證碼**（這一步只能你自己做）
4. 按「查詢」→ 頁面會列出當日每家券商的買進賣出張數
5. 右上角可以「另存 CSV」

**要看什麼**（依 [[大戶持股流向判讀]]）
- 前幾大買超券商是誰？是不是**同一家連續多日買超**
- 有沒有地緣券商（公司所在地附近的分點）在吃貨
- 賣超方是分散的散戶，還是特定大戶

> [!tip] 一個限制
> 這個網站**只有當日資料**，沒有歷史。要追蹤連續性，得每天存一份。

---

### ② 法說會簡報｜查詢參數是加密字串

**為什麼不能自動**：MOPS 新版網站把法說會查詢轉導到舊系統，網址帶的是一長串加密參數，無法用程式組出來。

**怎麼做**

1. 開 [公開資訊觀測站](https://mops.twse.com.tw/mops/#/web/t100sb02_1)
2. 市場別選「上市」，輸入公司代號與民國年（例如 `1786`、`115`）
3. 按「查詢」
4. 清單會列出歷次法說會，點檔案下載 PDF（通常有中英文版）

**要看什麼**（依 [[法說會判讀技巧]]）
- 管理層對**未來的展望**——這是財報這個落後指標缺少的前瞻資訊
- 🔑 **簡報的用心程度與美感**。宏爺的判準是：敷衍了事的公司他看了就興致缺缺，因為從小細節能看出公司的用人態度與文化

**順便看的**：同一個網站可查「內部人股權異動」（個股頁面下方 →右下角 more），能看到上個月董監大股東的買賣。

---

### ③ 籌碼集中度／買賣家數差／外資成本線｜需註冊登入

**為什麼不能自動**：CMoney 這幾個指標要登入才看得到。

**怎麼做**

1. 到 [CMoney](https://www.cmoney.tw/) 註冊帳號（宏爺說**免費版就夠用**）
2. 搜尋股票代號 → 進入「籌碼K線」
3. 記下三個數字

**判讀門檻**（依 [[籌碼集中度]]、[[買賣家數差]]、[[外資成本線]]）

| 指標 | 判準 |
| :--- | :--- |
| 籌碼集中度 | 60 日 > 5%（強者 10%）；120 日 > 3%。**負值代表主力在倒貨** |
| 買賣家數差 | **負值** + 主力買超為正 ＝ 少數人吸收多數人的貨，主力吃貨 |
| 外資成本線 | 多頭回檔至此易獲支撐；帶量突破且外資連買，可能是波段起點 |

> [!warning] 註冊請你自己來
> 我不會幫你註冊帳號或輸入密碼。

---

### ④ Goodinfo 與 M平方｜擋自動請求

**為什麼不能自動**：兩站都回 HTTP 403 擋掉程式請求，Goodinfo 還會跳出機器人驗證頁。**用瀏覽器開得起來**，只是抓不到。

**怎麼做**：直接用瀏覽器開，需要的數字自己看或複製給我。

- [Goodinfo 個股頁](https://goodinfo.tw/tw/StockDetail.asp?STOCK_ID=1786)（換代號）——個股綜合資料、財報選股篩選
- [M平方](https://www.macromicro.me/)——總經數據，對應 [[L0_資金環境]]

## 一頁速查

| 資料 | 自動？ | 卡在哪 | 怎麼辦 |
| :--- | :---: | :--- | :--- |
| 基本資料／財報／月營收 | ✅ | — | 跑腳本 |
| 股價／均線／乖離 | ✅ | — | 跑腳本 |
| 三大法人 | ✅ | — | 跑腳本 |
| 集保大戶（單週） | ✅ | — | 跑腳本 |
| 集保大戶（歷史趨勢） | 🟡 | 開放資料只有最新一週 | 開神秘金字塔看 |
| 除權息／股利歷史 | 🟡 | 腳本尚未納入 | 神秘金字塔的「股利股息」分頁 |
| **分點進出** | ❌ | **圖形驗證碼** | 你自己輸驗證碼 |
| **法說會** | ❌ | **加密參數** | MOPS 手動查詢下載 |
| **籌碼集中度等** | ❌ | **需登入** | 註冊 CMoney 免費版 |
| **Goodinfo／M平方** | ❌ | **擋機器人** | 瀏覽器自己開 |
| 上櫃股票 | ❌ | 腳本只支援上市 | 待補 TPEx 支援 |
