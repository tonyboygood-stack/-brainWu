# 數據來源清單

判斷來源是否可用，以本次實際回應及報告日期為準，不以「網站開得起來」代表資料完整。

| 來源 | 用途 | 入口 |
| :--- | :--- | :--- |
| TWSE OpenAPI | 公司、董監、質押、公告 | https://openapi.twse.com.tw/ |
| TPEx OpenAPI | 上櫃公司、公告、法人與融資 | https://www.tpex.org.tw/openapi/ |
| TPEx逐日查詢 | 上櫃法人歷史、融資歷史 | https://www.tpex.org.tw/www/zh-tw/insti/dailyTrade |
| 期交所OpenAPI | 各契約法人期權、匯率 | https://openapi.taifex.com.tw/ |
| TDCC | 股權分散官方單週快照 | https://opendata.tdcc.com.tw/getOD.ashx?id=1-5 |
| FinMind | 歷史行情、歷季財報、現金流、營收、除權息 | https://finmind.github.io/tutor/TaiwanMarket/Fundamental/ |
| FRED | 利率、殖利率、美元、台幣、CPI、M2、失業率 | https://fred.stlouisfed.org/ |
| MOPS | 法說清單、PDF下載與影音連結 | https://mopsov.twse.com.tw/mops/web/t100sb02_1 |
| CMoney | 主力買賣超、家數差（易受改版影響） | https://www.cmoney.tw/ |
| 神秘金字塔 | 股利／EPS與人工歷史查詢 | https://norway.twsthr.info/ |
| 產業價值鏈資訊平台 | 產業閱讀（尚未自動整合） | https://ic.tpex.org.tw/ |

2026-09-09 實測：FinMind個股行情與財報匿名可取得；集保歷史匿名回HTTP400要求提升會員等級。未自動購買或建立任何付費訂閱。權限可能變動，抓取失敗會保留錯誤狀態。

Goodinfo與M平方不是必要的唯一資料管道；目前由官方及FRED／FinMind補足部分用途，但不能宣稱等同兩站全部功能。

完整操作、快取與品質規則見 [[資料蒐集SOP]]。每次補充報告保留實際資料來源網址、時間與資料列，非只列網站名稱。
