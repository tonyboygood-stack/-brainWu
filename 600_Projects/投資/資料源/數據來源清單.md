# 數據來源清單

出處是第 32 期「價值連城工具：宏爺壓箱寶」——那集他把自己的工具箱整個攤開講。以下每個連結都在 2026-09-08 實測過連線狀態。

> [!tip] 要實際抓資料，看 [[資料蒐集SOP]]
> 那份文件寫了哪些能一行指令抓完（`stock-fetch.py`）、哪些卡在驗證碼或登入、以及每一項的手動操作步驟。這份清單則是「有哪些來源、各自能給什麼」。

依照分析框架的層次排列，你在哪一層卡住就查哪一區。

## L2 籌碼面（最重要，宏爺的核心）

| 用途 | 來源 | 狀態 | 怎麼用 |
| :--- | :--- | :---: | :--- |
| 千張／四百張大戶持股流向 | [神秘金字塔](https://norway.twsthr.info/) | ✅ | 宏爺判讀大戶籌碼的主力工具。看**流向比看水位更重要** |
| 集保股權分散表 | [集保結算所](https://www.tdcc.com.tw/portal/zh/smWeb/qryStock) | ✅ | 輸入代號查各張數級距持有人數。大戶減碼時人數會往小張數區跑 |
| 分點進出明細（上市） | [證交所買賣日報表](https://bsr.twse.com.tw/bshtm/bsMenu.aspx) | ✅ | 查當日該股每家券商買賣量。需先知道哪些是主力分點 |
| 分點進出明細（上櫃） | [櫃買中心](https://www.tpex.org.tw/zh-tw/index.html) | ✅ | 上櫃股票要在這邊查，不在證交所 |
| 籌碼集中度／買賣家數差／外資成本線 | [CMoney 籌碼K線](https://www.cmoney.tw/) | ✅ | 宏爺說免費版就夠用 |
| 三大法人買賣超 | [證交所](https://www.twse.com.tw/zh/) | ✅ | 官方原始數據 |

> [!tip] 籌碼判讀的三個關鍵數字（第 70 期）
> - **籌碼集中度** = (前15大買超張數 − 前15大賣超張數) ÷ 區間總成交量
>   高度集中：60日 > 5%（甚至 10%）、120日 > 3%。負值代表主力在倒貨
> - **買賣家數差為負** = 買家少、賣家多，少數人在吸收多數人的籌碼，通常是主力吃貨
> - **外資成本線**：多頭時回檔至此易獲支撐；帶量突破且外資連買，可能是波段起點

## 選股工具

宏爺用凱基「隨身e策略」App 的自訂選股，第 32 期分享了五個策略邏輯。**策略邏輯可以移植到任何券商 App**，重點在條件組合而非特定平台：

| 策略 | 條件組合 | 適用 |
| :--- | :--- | :--- |
| 外資籌碼選股 | 外資連續買超 + 短線走強 + 基期低 + 現金殖利率穩定 | 他個人最偏好：**均線走平＋外資連買** |
| 平均股息存股 | 穩定現金殖利率 + 趨勢向上 + 董監持股高 | 系統最低只能設 30%，條件偏嚴 |
| 長紅突破選股 | 均線糾結 + 成交量激增 + 突破關鍵壓力 | 需留意當天是否隔日沖大戶攪局 |
| 關鍵券商 | 特定分點默默買超 + 中期均線向上 | 邏輯同外資籌碼選股，主力換成關鍵券商 |
| 趨勢偏空股 | 跌破中長期均線或盤整區 + 低破前低、高不過前高 | 避開法人回補股；大盤破中期均線才適用 |

> [!warning] 他自己的提醒
> 回測數據看看就好，不同天數算出來的結果不同。條件請自行調整成貼近自己的風格，不要照抄。

## 兩個抓不到的來源

M平方和 Goodinfo 回 HTTP 403，是擋自動請求，**不是網站掛掉**——你用瀏覽器開得起來。如果之後需要程式化定期取得這兩家的數據，得另外找 API 或改用瀏覽器自動化，屆時再處理。
