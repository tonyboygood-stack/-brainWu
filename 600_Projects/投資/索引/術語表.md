# 術語表：逐字稿錯字對照與專有名詞

## 這份表在解決什麼問題

`逐字稿/會員專題/` 是 Whisper 機器聽寫的，專有名詞有系統性誤判。最極端的例子是**「宏爺」這兩個字在 26 萬字裡一次都沒被正確聽出來**——642 次全部是錯的。

後果很實際：直接在庫裡搜尋「長紅突破」會漏掉一半來源，搜尋「買賣家數差」則一筆都找不到。

**原則：逐字稿原文一律不動**，保留機器聽寫的原始狀態當作證據層。這份表是檢索時的翻譯層，也是寫知識卡時的校正依據。

## 需要看上下文判斷（不可盲目取代）

這些變體在中文裡是真實存在的詞，機械式取代會製造新的錯誤。

| 可能正確 | 逐字稿疑似變體（次數） | 為什麼要小心 |
| :--- | :--- | :--- |
| 基期（基期位階、基期低） | 激起 20 | 「激起」本身是常用動詞 |
| 程式（程式交易、選股程式） | 城市 14 | 「城市」是真實名詞 |
| 倒貨（主力倒貨給散戶） | 到貨 3 | 「到貨」是真實用語 |
| 配息 | 佩喜 5 | 「佩喜」非常用詞，但仍建議看前後文 |

判斷方式：看該句是否在談籌碼／股價。談主力行為時的「到貨」幾乎必然是「倒貨」；談庫存供應鏈時則可能是真的到貨。

## 使用方式

- **檢索時**：先把查詢詞翻成變體一起搜。例如找宏爺對某主題的看法，要同時搜「紅野」「洪野」「洪爺」。
- **寫知識卡時**：一律用正確寫法，並在 `source_quote` 欄位標註原文可能長什麼樣。
- **引用具體數字或術語前**：回原片確認。`逐字稿/_srt/` 有時間軸檔可快速定位。
