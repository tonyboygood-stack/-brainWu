## 稅務規劃（2026-05-13 整理）

### 診所收入結構

- **健保：約 70–80%**（113 年新制費用率已約 80%，本身課稅所得低）
- **自費：約 20–30%**（費用率僅認定 20%，設帳可扣實際費用 50–60%）
- 經營形態：**獨資**

### 報稅方式策略

| 階段 | 建議方式 | 原因 |
|------|---------|------|
| 開業第 1 年 | **設帳** | 裝修設備費龐大，很可能報虧損，合法不繳稅 |
| 之後每年 | **讓會計師兩種都試算，選有利的** | 健保比例高時差距縮小，但自費那塊設帳仍較優 |

> 從設帳切回費用率每年皆可選擇，不需現在決定，讓數字說話。

### 設帳的核心邏輯：把費用做足

課稅所得 = 收入 − 費用。費用列得越完整，繳稅越少。  
**重點不是少報收入，而是把每一筆真實花出去的錢都有憑有據。**

| 費用項目 | 注意事項 | 年估金額 |
|---------|---------|---------|
| 租金 | 租約清楚即可列 | 54 萬 |
| 裝修折舊 | 超過 8 萬分 7 年攤（預期續租用 7 年，不續約剩餘可一次認列）| 依裝修總額 |
| 醫療設備折舊 | 超過 8 萬分 7 年攤 | 依設備總額 |
| 藥材耗材 | 占收入 15–25% 為合理區間，超過 40% 被列異常 | — |
| 員工薪資 | 需開扣繳憑單 | — |
| 員工福利旅遊 | 全體員工可參加者免扣繳 | — |
| 進修差旅費 | 需與出入境記錄吻合 | — |
| 車輛 | 過戶至診所名下：牌照稅、燃料稅、保險、油費、維修全可列 | — |

### 裝修折舊說明

- 法定年數 7 年，租約 6 年（預期續租）→ **用 7 年折舊**
- 若未續約提前離開 → 剩餘帳面價值**一次認列損失**，不會白損

### 113 年新制重點

- 健保收入與自費收入**分開計算**費用率
- 每年 4 月 20 日後到健保局下載「醫療項目分類表」重新計算
- 案例：舊制算出 86 萬所得 → 新制 16 萬（差 70 萬）

### 稽查風險警示

- 私人消費與帳面所得要平衡：若未來購置不動產，所得規模需能支撐
- 現金收入存入帳戶時備注「診所自費收入」
- 所有裝修設備發票統一開立至診所（確認正確開法請會計師說明）
- 藥材進貨量可被反推看診量，申報須與進貨紀錄相符

## 診所核心理念（2026-05-26 確立）

### 自費針灸為主的經營方向

**核心理由：**
- 現在的診所病人太多、等待太久，治療品質被稀釋
- 自費制度讓病人在來之前先做一個**主動選擇**
- 這個選擇本身就篩掉「反正免費不來可惜」的搭便車心態
- 留下的是真正想被治好的人，時間才能給需要的人

**治療品質 > 看診人數**

> 空間的品質是療癒的一部分。
> 每個病人值得被完整對待，而不是流水線的一格。

**待規劃（未來建立定價結構時的依據）：**
- [ ] 設計自費針灸定價結構（初診 / 複診 / 療程）
- [ ] 研究同類型自費中醫診所的定價參考
- [ ] 評估健保是否保留（或以純自費為主）

## 需加入契約的額外條款

#### 1. 稅務條款
```
本租金每月新台幣 45,000 元整，係指甲方（房東）之實收淨額。本租賃所得依法應由乙方（醫師）辦理扣繳。甲方同意上述租金款項外，由乙方另行負擔並代為繳納依稅法規定計算之租賃所得稅款（10%）及二代健保補充保費（2.11%）。乙方每月支付予甲方之金額為新台幣 45,000 元，並另向稅務及健保機關辦理申報繳納扣繳稅款及補充保費。甲方應配合提供身分證影本、銀行帳戶資訊及相關必要文件，供乙方辦理稅務申報使用。
```

#### 2. 裝修免租期條款
```
自民國 115 年 X 月 X 日起至 115 年 X 月 X 日止，計 30 天為裝修免租期。期間免收租金，承租人僅需負擔使用期間之水電費及管理費。正式起租日為 115 年 X 月 X 日，租金支付亦自該日起算。
```

#### 3. 診所用途聲明條款
```
乙方承租甲方之房屋作為中醫診所使用，並將依照政府相關規定完成必要之房屋使用申請及變更程序，以符合一切診所使用之規定，甲方已清楚了解且無異議。
```

#### 4. 開業執照保障條款（爭取，若無法則放棄）
```
本契約之履行，以乙方取得該址之「中醫診所開業執照」為必要條件。若因房屋土地使用分區、路寬限制、防火避難規定或既有違建問題，致主管機關無法核發執照，乙方得提前通知甲方解除契約，甲方應於通知後 7 日內退還已繳納之押金及預付租金。
```

#### 5. 租金遞增條款（6 年總期）
```
本租賃契約總租期共計 6 年。租金調整方式：
- 第 1–2 年：每月 45,000 元
- 第 3–4 年：每月 47,000 元
- 第 5–6 年：每月 49,000 元
（以上皆為房東實拿淨額）
期滿後，乙方享有優先續租權。
第 3 年起需補繳押金差額 4,000 元。
```
