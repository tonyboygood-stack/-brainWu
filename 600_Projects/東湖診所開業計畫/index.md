## 稅務規劃（2026-05-13 整理）

### 報稅方式：設帳 vs 費用率

| 比較項目 | 設帳（查帳） | 費用率（推計） |
|----------|------------|--------------|
| 邏輯 | 收入 - 實際成本 = 課稅所得 | 收入 × (1 - 費用率) = 課稅所得 |
| 文件要求 | 需保存所有支出發票與憑證 | 不需提供憑證，直接套財政部比例 |
| 自費收入 | 需如實記錄 | 往往因自費申報偏低而選用 |
| 虧損時 | 可照實報虧，不繳稅 | 仍需按費用率繳稅 |

**結論：開業首年建議設帳。** 原因：
1. 開業初期裝修設備費用大，設帳可能直接報虧損、合法不繳稅
2. 費用率標準自民國 70 年代幾乎沒更新，自費費用率僅認定 20%（即認定淨利 80%），遠低於現代診所實際成本
3. 國稅局現已用 AI 大數據反推真實收入，設帳才有底氣面對稽查

### 可列費用項目（設帳時最大化）

- 藥材耗材：有發票，占收入 **15–25%** 為合理區間
- 固定資產折舊：超過 8 萬元的設備與裝修，**7 年折舊**
- 員工薪資、福利、旅遊
- 進修差旅費（需與出入境紀錄吻合）
- 車輛（過戶診所名下）：牌照稅、燃料稅、保險、維修、油費
- 租金

### 稽查風險警示

- **私人消費 vs 帳面所得要平衡**：買 5,000 萬房子但診所報表淨利只有 30 萬 → 國稅局最愛的查稅案源
- 金流記錄清楚，現金收入存入帳戶時備注「診所自費收入」
- 所有設備裝潢統一發票須開到**診所統編**

### 113 年新制重點

- 健保收入與自費收入**分開計算**費用率
- 每年 4 月 20 日後到健保局下載「醫療項目分類表」，重新計算所得
- 案例：舊制 86 萬所得 → 新制 16 萬（差 70 萬）

## 需加入契約的額外條款

#### 1. 稅務條款
```
本租金每月新台幣 45,000 元整，係指甲方（房東）之實收淨額。本租賃所得依法應由乙方（醫師）辦理扣繳。甲方同意上述租金款項外，由乙方另行負擔並代為繳納依稅法規定計算之租賃所得稅款（10%）及二代健保補充保費（2.11%）。乙方每月支付予甲方之金額為新台幣 45,000 元，並另向稅務及健保機關辦理申報繳納扣繳稅款及補充保費。甲方應配合提供身分證影本、銀行帳戶資訊及相關必要文件，供乙方辦理稅務申報使用。
```

#### 2. 裝修免租期條款
```
自民國 115 年 X 月 X 日起至 115 年 X 月 X 日止，計 30 天為裝修免租期。期間免收租金，承租人僅需負擔使用期間之水電費及管理費。正式起租日為 115 年 X 月 X 日，租金支付亦自該日起算。
```

#### 3. 診所用途聲明條款
```
乙方承租甲方之房屋作為中醫診所使用，並將依照政府相關規定完成必要之房屋使用申請及變更程序，以符合一切診所使用之規定，甲方已清楚了解且無異議。
```

#### 4. 開業執照保障條款（爭取，若無法則放棄）
```
本契約之履行，以乙方取得該址之「中醫診所開業執照」為必要條件。若因房屋土地使用分區、路寬限制、防火避難規定或既有違建問題，致主管機關無法核發執照，乙方得提前通知甲方解除契約，甲方應於通知後 7 日內退還已繳納之押金及預付租金。
```

#### 5. 租金遞增條款（6 年總期）
```
本租賃契約總租期共計 6 年。租金調整方式：
- 第 1–2 年：每月 45,000 元
- 第 3–4 年：每月 47,000 元
- 第 5–6 年：每月 49,000 元
（以上皆為房東實拿淨額）
期滿後，乙方享有優先續租權。
第 3 年起需補繳押金差額 4,000 元。
```
