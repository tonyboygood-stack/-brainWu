# 職缺說明書：醫療行政助理

> 2026-08-24：已正式於104刊登（3個月方案）。本檔案整理自實際貼文內容＋內部完整版獎金制度。

## 診所簡介

平衡木中醫診所（台北市內湖區東湖路16巷20號1樓，籌備中，目標2026-10-25開業）。由吳宗城中醫師主持，裡面只有吳醫師看診，環境相對單純。父親經營中藥房退休後，兒子中醫師回來開設這間診所，目前已在裝修籌備階段尾聲，目標打造一個舒適有溫度的看診空間，希望能找到未來能長期合作的工作夥伴。

## 職稱

醫療行政助理

## 工作內容

1. 櫃檯行政與接待：協助患者掛號、預約管理、診所電話諮詢及親切接待
2. 診間環境整潔與消毒作業
3. 協助藥局作業、藥品庫存管理
4. 在醫師指導下協助診務工作
5. 簡單診所行政和臨時性之物品採購、相關交辦事務、醫療資訊文書整理
6. 【未來視營運規模增加】針灸/傷科治療輔助、拔針作業——需完成中醫師公會相關課程取得執行資格，診所會協助安排受訓（見下方獎金制度之技能晉升加給）

## 應徵條件

- 學歷：高中職以上，醫護相關科系尤佳，非必要條件
- 經歷：診所或醫療院所行政/櫃檯經驗者優先，無相關經驗可培訓，有心學習即可
- 特質：細心、認真負責、主動積極——診所新創，流程細節仍有調整空間，希望找到願意一起切磋改進的夥伴
- 能獨立作業：草創初期同時段最多1-2人，需能扛下多項工作
- 基本 Word、Excel 操作
- 重視病患隱私與消毒衛生規範
- 期待長期合作，非短期性質

## 工作地點

台北市內湖區東湖路16巷20號1樓

## 上班時段（2026-08-24 對齊實際刊登版本）

**週一、五（午晚診）**：13:30–21:30，中間30分鐘休息，實際工時7.5小時

**週二、四、六（早午診）**：09:00–12:30、14:00–17:30，中間1.5小時午休不計薪，實際工時7小時；週六與PT同班，雙人力支援診所最忙的一天（見同資料夾 `職缺說明書_PT週三週六助理.md`）

**週三、週日固定休**（週三由PT獨自支援）

週工時：7.5×2 ＋ 7×3 = **36小時/週**，低於法定40小時上限，不需變形工時、不需加班費。超過排定時段之工作另計加班費。

> 30分鐘休息為刻意設計：只有一位人力，下午診到五點容易delay（尤其需要她包藥時），30分鐘是預留的緩衝下限，實際沒delay時可以更長，不delay就是給她多的休息時間。

## 休假制度

週三、週日固定休；依勞基法規定另有國定假日、特休（到職滿6個月起3天，滿1年起7天）；週休二日

**臨時請假/特休代班**：可請PT視情況支援平日班（需PT配合意願，非保證班），並以家人支援作為第二層備援。

## 內部完整版獎金制度（2026-08-24 老吳定案，面試／簽約時具體說明用）

**原則**：獎勵穩定出勤與留任、能力成長，不綁看診量／業績，避免與「治療品質優先」理念衝突。對外貼文的「視營運狀況調薪」「績優獎金依表現評核」是簡化用語，面試/簽約時換成以下具體版本說明：

| 項目 | 金額 | 條件 |
|---|---|---|
| 底薪 | 34,000元起 | 面議，依經驗核薪 |
| 全勤獎金 | 2,000元/月 | 當月無遲到、無故缺勤（小診所人力只有1位，全勤影響大，故金額拉高） |
| 技能晉升加給－拔針 | +1,000元/月 | 完成公會拔針受訓，取得執行資格 |
| 技能晉升加給－藥務聯繫 | +1,000元/月 | 承接科學中藥、水藥與耗材之聯繫採購作業 |
| 服務品質獎金 | 待定 | 老吳規劃中，尚未定案 |
| 年資調薪 | 滿1年＋1,000–2,000元/月；滿2年再＋1,000–2,000元/月（永久調升底薪，非一次性） | 到職滿1年／滿2年仍在職 |
| 三節禮金／年終獎金／特休 | 依福利制度 | 細節留到面試/簽約時說明 |

> 技能晉升加給兩項可疊加，全數到位後底薪實質等於34,000＋2,000（含在全勤內另計）＋2,000（雙技能）＝理論上限約38,000＋，加上年資調薪逐年墊高。服務品質獎金金額與條件待老吳確認後補上。
