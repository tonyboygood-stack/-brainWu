# 員工到職／簽約準備清單

> 2026-08-30 整理，適用FT/PT及未來新人，之後招募可重複使用

## 員工需準備（簽約/報到當天攜帶）

1. **身分證正反面影本** — 核對身分、辦理勞健保加保
2. **薪資轉帳存摺影本** — 先決定診所發薪銀行，請員工準備該行存摺，省跨行手續費
3. **一般體格檢查報告**（3年內有效即可，依40-65歲每3年一次的級距認定；未滿40歲為5年、65歲以上為每年）— 沒有近期報告者需另外安排體檢
4. **大頭照** — 建立人事檔案/識別證用
5. **緊急聯絡人資訊**（姓名、關係、電話）
6. **印章或簽名** — 簽約及相關表單用
7. **目前投保單位資訊**（前公司／職業工會／眷屬等）— 用於確認她現在的勞健保掛在哪裡，銜接加保/退保時間，並評估過渡期是否能先維持原狀不轉出

## 診所端（雇主）需準備好

- 正式勞動合約一式兩份（雙方用印/簽名，各執一份）
- 獎金制度書面說明（底薪34,000起＋全勤2,000＋技能晉升加給拆兩項＋年資調薪，不能只是口頭講）
- 個人資料蒐集告知同意書（依個資法，蒐集身分證、體檢等個資需告知用途並取得同意；體檢報告屬健康資料，是特種個資，存放要注意保密）

## 目前卡關中的行政前置（尚未解決，見index.md人員招募區塊）

- 雇主戶/統編尚未成立，員工已提前到職訓練 → 過渡期方案：問她能否維持原投保單位不轉出＋幫她投保雇主意外責任險
- 統編下來後立即辦理加保，並嘗試主張回溯到職日生效（不保證成功）
