# 藥材供應商評估

> 診所核心理念之一：提供安全、可溯源的中藥材。
> 每找到一家就補入下方，評估欄位慢慢填，開業前統整比較。

---

## 評估維度說明

| 維度 | 說明 |
|------|------|
| **溯源能力** | 能否追蹤到產地、農民、種植過程 |
| **檢驗標準** | 重金屬、農藥殘留、微生物等項目 |
| **認證** | GMP、ISO、政府核可等 |
| **供貨型態** | 飲片、科學中藥、粉末、原料等 |
| **服務診所** | 是否有診所供貨經驗 |
| **價格** | 相對市場水準 |
| **信任感** | 學術合作、公會認證、口碑等 |

## 供應商一覽

### 德利泰興業有限公司

**網站**：https://www.derleetai.com.tw
**Facebook**：https://www.facebook.com/derleetai
**狀態**：考慮中

#### 溯源管理

採收方式分三種：
- **基地採收**：自有基地，控制最完整
- **契作採收**：與農民簽約，指定種植規範
- **區域採收**：特定產區就源採收

採收流程：
1. 依藥材生長屬性選擇合適產地
2. 種植前：土壤檢測 + 水質檢測
3. 生長期間：隨機採樣檢測
4. 採收後入廠前：再次檢驗，合格才進入加工

#### 檢測機制

- ✅ 四大重金屬含量檢測
- ✅ 農藥殘留檢測
- ✅ 食品 411 項檢測

#### 學術與組織

- 中華民國中藥商業同業公會全國聯合會 **會員**
- 經貿協會 **會員**
- 與**中國醫藥研究所**、**中國醫藥大學**保持學術交流

#### 初步印象

溯源管理做得扎實，三層採收 + 三段檢測流程，且有學術背景背書。理念和診所「提供安全中藥」的核心方向高度吻合。值得進一步聯繫。

### 金記寶安（JIN JIH BAO AN）

**網站**：https://www.jjba.com.tw
**狀態**：考慮中

#### 基本背景

- 創立於**清光緒五年（西元 1879 年）**，迄今逾 **147 年**
- 七代林家子孫傳承經營
- 目前為國內**最大規模中藥材批發商之一**
- 百年後依古例加「記」字，改名金記寶安
- 理念：**誠信至上**，嚴格把關進口中藥材與食品

#### 業務範圍

- 專職：中藥材及食品**進出口貿易**
- 服務對象：**中醫藥體系**、食品、生技製藥等相關業者（✅ 有服務診所經驗）

#### 待確認

- [ ] 診所供貨流程（飲片 / 科學中藥 / 原料？）
- [ ] 最低訂購量與價格
- [ ] 藥材檢驗標準（重金屬、農藥殘留等項目）
- [ ] 是否有溯源資訊可查
- [ ] 聯絡方式（業務或直接電話）

#### 初步印象

老字號、規模大、明確服務中醫診所，是市場上信譽穩固的批發通路。但進出口為主，溯源透明度相對德利泰資訊較少，需進一步確認品質管控細節。
