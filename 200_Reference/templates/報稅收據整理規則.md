# 報稅收據整理規則（醫療及生育費用）

> 每次處理收據時依此規則擷取資訊、判斷可列報性、標記問題。

---

## 擷取欄位

| 欄位 | 說明 |
| ---- | ---- |
| 日期 | 收據上的就診/交易日期 |
| 院所／來源 | 醫療機構名稱或藥局名稱 |
| 項目 | 診療項目、手術、藥品等 |
| 受益人 | 老吳本人 / 老婆 / 寶寶 / 父母 |
| 掛號費（元） | 每次就診自付掛號費 |
| 自費金額（元） | 非健保給付的自費項目 |
| 健保點值（元） | 健保給付部分（若收據有列，填入；不可列報） |
| 保險理賠（元） | 商業醫療險理賠金額（若有，填入；需從可列報中扣除） |
| 可列報金額（元） | = 掛號費 + 自費金額 − 保險理賠 |
| 備註 | 問題標記或說明 |

---

## 可列報 vs 不可列報

| 類型 | 可列報？ | 說明 |
| ---- | -------- | ---- |
| 掛號費 | ✅ | 每次就診自付部分 |
| 自費診療項目 | ✅ | 非健保給付，有正式收據 |
| 有處方箋的藥費 | ✅ | 醫師開立處方後領藥 |
| 醫院/診所附設月子中心 | ✅ | 需確認是醫療機構附設 |
| 新生兒醫療費 | ✅ | 可列入扶養親屬醫療費 |
| 健保點值給付部分 | ❌ | 健保已給付，患者未自費 |
| 商業保險理賠部分 | ❌ | 已獲補償，不可重複列報 |
| 獨立月子中心（非醫療機構） | ❌ | 非醫療院所，不可列 |
| 無處方箋藥品/保健食品 | ❌ | 自行購買，非醫師指示 |
| 純美容/整形手術 | ❌ | 非醫療必要性 |
| 手寫白條（非正式收據） | ⚠️ | 可能不被接受，需確認 |

---

## 自動標記規則（處理收據時逐條檢查）

處理每張收據時，若符合以下任一條件，在備註欄標記 `⚠️` 並提醒：

1. **無抬頭或無姓名** → `⚠️ 收據無抬頭，可能無法列報`
2. **月子中心** → `⚠️ 請確認是否為醫療機構附設月子中心`
3. **藥局收據** → `⚠️ 請確認是否有醫師處方箋`
4. **保險理賠欄空白** → `⚠️ 請確認商業保險是否有理賠此筆`
5. **手寫或非正式收據** → `⚠️ 非正式收據，建議補正式單據`
6. **美容/整形相關字眼** → `⚠️ 疑似美容項目，請確認是否具醫療必要性`
7. **保健食品/維他命/營養品** → `⚠️ 保健食品不可列報`
8. **可列報金額為 0** → `⚠️ 此張收據無可列報金額，確認是否需要保留`

---

## 彙總計算方式

```
總可列報金額 = Σ（掛號費 + 自費金額 − 保險理賠）
```

- 無金額上限，全額列報
- 最終填入申報書「醫療及生育費用」欄
