# 古典脈診整合入口

> 脈診不是「看哪一部像哪個臟腑」而已。它同時讀取**位置（哪個通道）、高度（陽氣／排邪能力）、寬度（媒介容量）、質地（病邪性質）與向量（臟腑是否真的互相支持）**。

## 先走這個順序

1. **校準**：姿勢、三指同時在脈、患者狀態與季節時間；沒有可讀脈時才考慮生脈法。
2. **先排經筋**：1–6 豆見浮緊，先確認是否有津液寬度與向上壓力能排邪；若沒有，不能直接深治。
3. **定位層次**：以深度判定衛／營／元及經絡系統，而非把浮沉直接等同寒熱。
4. **讀五參數**：高度、寬度、長度、節律、質地必須合參。
5. **查向量與阻滯**：先確認上游是否供應，再判某臟腑是真虛還是假虛。
6. **才判補充經絡**：動脈、伏脈或特定深度表現才進一步查經別／奇經；絡脈主要仍靠視診。
7. **以脈追蹤治療**：治療前、中、後都回來看預期方向是否出現。

## 與病生理總圖的對接

| 總圖問題          | 脈診可提供的證據               |
| ------------- | ---------------------- |
| 病勢是排邪、伏邪還是顯露？ | 經筋浮緊、左右手差異、三焦脈、伏脈、動脈   |
| 還有何種媒介？       | 表層津、中層血、深層液與腎精的脈寬      |
| 停在哪個系統？       | 深度＋經絡脈位置＋循行、視診與病史的交集   |
| 真虛還是假虛？       | 定向脈是否顯示上游供應或三焦間阻滯      |
| 治療是否有效？       | 目標脈的方向、節律、質地與寬度是否按預期轉變 |

## 硬規則

- 單一脈象不能指定單一經絡或病名。
- 緊脈可能是阻滯，也可能是身體在固攝津、血或腎精；必須先判媒介與向量。
- 絡脈不能只靠脈診確診，必須合參可見絡脈、結節與情緒／病史。
- 深層病理與臟腑病理不能由表中層脈單獨推定。
