## 操作方式

**中焦中氣＝現金流。** 每日飲食產生，是保證下焦元氣不被耗損的前提。

> 🟢「**大多數的臨床治療，多是在調理中焦胃氣的層次展開**，也就是『現金流』層面。」

### 虛與鬱滯兩型

| | 中焦**虛** | 中焦**鬱滯**（實／有火） |
|---|---|---|
| 食慾 | 食慾不佳 | 食慾過盛、貪食冷物 |
| 二便 | 大便稀溏或腹瀉 | 便秘、排氣過多或異味 |
| 其他 | 不能食寒飲冷、肌肉不足或鬆弛、皮膚光澤度下降 | 口腔或咽喉發炎、口臭、面部長痘 |
| 舌 | 初起可無異常；長期則舌體胖大或鬆弛、舌苔白厚或不乾淨；中焦溼滯者**舌邊齒痕** | 舌苔黃、膩 |
| 脈 | **關部虛脈**，嚴重時細而緊 | — |

## 判讀標準

⚠️ **不可點對點推論**：

> 🟢「臨床常常會有腹脹、便秘、腹瀉、口腔潰瘍等的主訴，這種情況**不管是虛證還是實證都有可能出現**，一定要避免『點對點』、由症狀推導結論的錯誤思路。」

> 🟢「不管面對任何情況或已有的診斷、化驗結果，我們**首先要評估下焦、中焦的虛實**。」

### 脾主四肢：外圍佐證

除虛實外，還要看**四末之寒溫、肌肉之有無、排汗是否正常**，以確認脾胃之氣是否暢達於外。

⚠️ **手足冷的三種可能**：下焦元氣虛衰／中焦中氣不足／體表經脈阻塞。
鑑別法：看**左手尺部脈象**。若精不足（脈緊、細、弱），**不能猛烈開表**。

## 臨床意義（用藥法則）

**中焦用藥的核心規則：辛則開，苦則降，但要「微」不要「強」。**

> 🟢「用『**微**』而非『**強**』，是保證藥性既不過於向外開散，也不過於向下降洩，這兩者都可能導致『**藥過其位、過於開洩而傷正氣**』。」

> 🟢「用來調治中焦氣分層次的湯藥，通常**不會是顏色很深、味道很重、稠厚而帶有強烈氣味的**。」

| 情況 | 用藥 |
|---|---|
| 中氣不足 | 白朮、茯苓、陳皮 |
| 很虛弱 | 黨參、黃芪、蓮子 |
| 有寒 | 乾薑、熟附子 |
| 便溏 | 蓮子、扁豆 |
| **鬱滯**：便秘 | 大腹皮、厚朴 |
| **鬱滯**：舌苔厚膩有口臭 | 大黃 |
| **鬱滯**：氣分有熱 | 石膏或滑石 |

以上補益者，傳統稱**「建中之品」**。

> 🟢「有人以為這類藥（石膏、滑石）會傷胃氣，**事實並非如此**。大部分金石藥沒有味道，酌量『取其氣』，不會損害脾胃。」

### 非藥物途徑

> 🟢「艾灸、熱敷、內功按摩、靜坐和良好的睡眠可以整體提升人體的真氣，中氣也會同步充足。」
