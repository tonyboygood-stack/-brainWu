## 操作方式

**下焦元氣＝原始資本／固定資產。** 與腎氣、水代謝、生殖功能以及**收闔的能力**有關。

> 🟢「下焦充足，可以保證神氣的開闔有度。」
> 🟢「一般**不存在過剩的狀態**，多以『虛』或『不足』呈現。」

### 五維度省察

| 維度 | 不足之象 |
|---|---|
| **主觀症狀** | 下腹空虛或寒冷、皮膚乾燥不潤、頭髮稀少、視力下降、腰部寒冷或疼痛、夜尿頻、水腫；女性白帶過多／月經量少／行經時間短；男性性功能下降 |
| **闔固下降的表現** | 入睡困難、眼眶水腫發暗、常有清稀鼻涕 |
| **神** | 記憶力／專注力下降、過度敏感、容易激惹、煩躁不安 |
| **觸診** | 小腹寒冷或虛軟無力、內部張力不足；**兩側腳踝內側、手上大魚際與小魚際**肌肉虛軟或局部凹陷 |
| **望診** | 眼神不足或空洞、飄忽不定、神散或驚恐；面無光彩；皮膚沉滯晦澀 |
| **舌** | 偏瘦、蒼白、柔弱，或胖大水滑；伸出口腔時顯得無力。⚠️ 單純下焦精氣不足，**舌苔也可能沒有特別異常** |
| **脈** | 偏緊、沉、細或弱；甚者虛浮無根 |

## 判讀標準

### 元氣不足 vs 精虛：兩個深度層級

| | 元氣不足 | 精虛 |
|---|---|---|
| 深度 | 輕度／下焦**表層**虛損 | **更深層次**的虛損 |
| 取法 | 取其**氣** | 取其**味** |
| 氣味 | 甘溫、甘平、辛溫、辛熱 | 輕者甘、酸；虛甚者鹹、苦 |
| 藥例 | 人參、灶心土、附子、肉桂、淫羊藿 | 輕：五味子、巴戟天、杜仲、菟絲子、肉蓯蓉<br>甚：龜甲、阿膠、鹿茸、龍骨（動物類） |
| 藥勢 | 偏動、略升浮 | 偏靜、沉降 |

> ⚠️ 🟢「（溫陽化氣之藥）可補元氣一時之不濟，但其中的某些藥味**不宜久服**，否則會傷精耗氣。因為**下焦主闔，靜才是真養**。」

### 下焦用藥的形質特徵

> 🟢「滋補下焦的藥物我們多**取其味**，需要**久煮**，藥物的質地相對其他層次會**更重**，多偏於**種子或根莖**，藥湯的顏色會更深，味道會偏厚一些，藥勢偏靜、沉降。」

### 下焦虛滯

元氣虛損到嚴重程度時，邪氣會進入較深的層次 → **「下焦虛滯」**。

## 臨床意義

**這一步設定了整個治療的力度上限。**

> 🟢「如果精不足（脈緊、細、弱），用藥時，**不能猛烈地開表，以免進一步耗傷元氣**。」

書中醫案有違反此規則的實例與後果，見 [[醫案_A先生_口腔潰瘍四年（李辛）]]。
