# 脈診與飲食整合：食物是媒介與方向的支持，不是脈象處方

## 三層脈寬先決定食療的目標

| 脈寬所在深度 | 本書對應的媒介 | 飲食思考的方向 |
|---|---|---|
| 衛氣層 | 津 | 先問胃陰、補水與消化能否承受；目標是支持外排而非盲目發散 |
| 營氣層 | 血 | 先問血的化生、運行與固攝是否能同步進行 |
| 元氣層 | 液、腎精 | 先問能否固攝與承受；目標是支持元氣，而非把深層病邪倉促推動 |

## 脈象如何進入食療判斷

| 脈上發現 | 飲食問題應優先問什麼 |
|---|---|
| 滑或長 | 是否濕、飲食不規律、糖／乳製品／酒精等加重脾負擔？ |
| 數 | 是否有熱性食物、晚食、情緒性進食、阻滯化熱？ |
| 遲 | 是否寒濕、生冷與消化動力不足？ |
| 緊 | 是病理性寒／阻滯，還是正在固攝津、血、腎精？ |
| 細、弱、空 | 是哪一層媒介不足，且消化能否承受補益？ |
| 伏脈／經別脈 | 飲食是要支持伏邪、重建媒介，還是配合已確認的外清策略？ |

## 與四層補充經絡的對接

| 系統 | 食療的角色 |
|---|---|
| 經筋 | 支持津液與衛氣，並依病勢決定是否協助外散 |
| 絡脈 | 支持血分、活血與固血的平衡；仍要先完成絡脈的視診／觸診判讀 |
| 經別 | 最先判定是深—淺—深的伏邪支持，還是淺—深—淺的外清；兩者飲食方向不可混用 |
| 奇經八脈 | 支持元氣與固攝，並依先天／生命史層問題決定是否激發氣機 |

## 個體化問診清單

先由脈與舌建立工作假說，再問：寒熱是否並存、穀物与糖／乳製品／酒精的影響、津液與濕痰來源、脾胃升降、氣血是否足、肝的疏泄、下焦排泄與荷爾蒙、情緒與進食的交織。最後才討論穀物、蔬菜、動物性食物、乳製品、香料與烹調方式。

> 本書明確反對「因為你有某脈，所以必須吃某食物」的固定配對。食物建議必須服從病勢、媒介、消化能力、偏好、敏感性與文化背景，並以後續脈象與症狀追蹤校正。
