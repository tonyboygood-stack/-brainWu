# 舌診的三層讀取與觀察條件

## 三層不是三種獨立疾病

| 可見面 | 原書的主要讀值 | 要問的問題 |
|---|---|---|
| 舌苔 | 衛氣與津（外分泌液） | 還有沒有防禦、宣散、排邪所需的濕潤與輸布？ |
| 舌體 | 營氣：血與津液 | 媒介是充盈、耗損、阻滯，還是被用來固攝病邪？ |
| 舌下靜脈 | 元氣／先天之氣 | 長期病理是否壓到下焦、血分與元氣層？ |

脾正經連舌本，關乎張力與血的送達；腎正經連舌本並啟動動作；心絡脈使舌表達情緒與言語。這些是**可檢查的假說來源**，不能由單一舌態直接確診。

## 觀察條件先於判讀

- 清晨厚苔可能是睡眠時陰液化生；清晨舌尖／邊紅可能是陽氣、運動或匆忙造成的暫時外現。
- 飲食、草藥、近期活動、月經與伸舌太久都會改變苔、色澤和姿態。
- 先讓患者自然張口；強力伸舌、緊夾舌或維持姿勢過久，本身既改變舌象，也可能帶來動作／張力資訊。
- 拍照可作追蹤，但要先取得同意、只拍舌、不拍臉，並盡量固定光線、時間與伸舌方式。

## 與四診的工作分工

舌診提供第一眼的可見反應；問診校正時段、飲食、排泄與情志；脈診追查深層伏邪、媒介與向量。原書特別指出：舌不必直接呈現被成功伏藏的病理，因此「看起來平靜」不等於沒有伏邪。

## 最小記錄格式

`條件 → 舌態／濕潤 → 苔 → 舌體 → 舌下 → 位置 → 脈／病史校正 → 病勢假說`

此格式使照片和面診可在後續同條件下比較，而不把一次性的視覺印象寫成定論。
