# 舌診與補充經絡

> 本章的價值是把舌象接到「補充經絡如何容邪／何時失守」。它不是舌象對經絡的一對一字典；原書本身也要求同時有症狀、脈象與系統指徵。

## 奇經八脈：原書提供的辨認方向

| 通道 | 可見方向（節錄） | 回到總圖的問題 |
|---|---|---|
| 衝脈 | 前 2/3 近前正中線兩側條索／伏梁，常伴紫或淡紫 | 中焦升降與生命史相關的固攝是否阻滯？ |
| 任脈 | 薄／收縮與局部腫、結節、地圖苔並見 | 陰虛與陰滯是否同時存在？ |
| 督脈 | 實可見紅、吐弄、顫；虛可見痿軟、根部塌陷；繫帶張力可作線索 | 陽氣的上升、運動、防禦是否失衡？ |
| 陰／陽維脈 | 上焦緊或紅；或胖大厚苔後轉痿軟等 | 記憶、表裡陽氣交換與濕熱的關係？ |
| 陰／陽蹻脈 | 短腫淡紫；或兩側緊、長紅 | 結構排列、內外側張力與風／陽氣？ |
| 帶脈 | 中後部／根腫、阻滯線、芒刺、沉積、厚苔 | 下焦容納、排泄與中下焦界面是否受阻？ |

## 絡脈、經別、經筋：何時才在舌上顯露

- **絡脈**成功容邪時，舌可以沒有病理。失去伏邪後，邊緣半透明、淡白／淡紫、紫或捏緊，小刺／粗糙才成為線索；要沿相關絡脈再尋蜘蛛網靜脈或結節。
- **經別**維持伏邪時也可能無症狀。媒介耗損後可見腫、蒼白、萎縮；病邪顯露可見大熱、凸出物、兩側明顯不同或偏斜。根部乾裂／萎縮是其陰液緩衝不足的重要警訊。
- **經筋**與衛氣的體表防禦相連。外緣紅可能是衛氣正在動員，不可直接讀成病熱；需看是否能排出、是否困於表，並以脈與皮部／運動證據校正。

## 不可省略的限制

舌主要顯示「表達出來」的病理；成功伏邪可能無舌象。因此要判某補充系統，至少需舌象加另一類證據（脈、循行／觸診、可見絡脈、病史或動作）。
