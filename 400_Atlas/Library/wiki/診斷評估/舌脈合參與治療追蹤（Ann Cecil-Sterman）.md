# 舌脈合參與治療追蹤

## 為何同一厚苔可走向相反策略

原書的代表分岔：厚膩苔加遲滑脈，較支持濕本身成為病理；同樣厚苔若見紅絳舌與深層數脈，可能是身體用濕制約伏熱。前者可能以處理濕為先，後者若先祛濕，可能撤掉原本的代償。此處的價值不在固定處方，而在阻止「看到厚苔就祛濕」的捷徑。

## 對照表

| 舌所提出的問題 | 脈／其他資料負責校正 |
|---|---|
| 外周紅是衛氣排邪或病理熱？ | 浮層或深中層的數脈、近期外感／運動史 |
| 濕、腫、厚苔是否該排？ | 深層數與滑、舌體色、二便與病程 |
| 無苔／乾裂能否承擔排邪？ | 津液寬度、三焦與深層媒介、排泄出口 |
| 兩側差異、偏斜是否涉及補充經絡？ | 循行、動作、觸診、可見絡脈、病史 |
| 舌下警訊是否已及元氣層？ | 深層脈、下焦症狀與完整評估 |

## 追蹤方式

1. 固定觀察條件並描述，不只拍照。
2. 寫出介入前的病勢假說與目標：助排、維持伏邪、重建媒介、處理顯露或保護資源。
3. 同時記錄目標脈的深度、寬度、數／滑與向量變化。
4. 看舌象是否朝預期轉變，也看患者是否有安全、通暢的排邪反應。
5. 若舌象轉差，先回問：它是病邪加深，還是身體正在顯露／排出？不可只根據照片加重同一策略。
