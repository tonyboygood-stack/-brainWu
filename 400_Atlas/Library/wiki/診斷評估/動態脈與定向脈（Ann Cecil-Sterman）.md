# 動態脈與定向脈：讀「有沒有真的在運作」

## 四種脈診語言

| 類型 | 手指如何操作 | 它回答什麼 |
|---|---|---|
| 靜態脈 | 停在既定深度，不移動 | 該點的質地、寬度、長度、節律 |
| 探查動態脈 | 改變單一手指在單一脈位的深度 | 該臟腑在不同層次能否展現其功能 |
| 定向脈 | 三指維持壓力，以傾斜或釋壓誘發反應 | 兩個臟腑是否真正傳遞氣血物質 |
| 經絡脈 | 帶著明確意圖讀取特定經絡類別 | 病邪主要由何種經絡系統承接 |

探查脈讀「這個臟腑能不能做事」；定向脈讀「它有沒有把該給的東西送到下一站」。兩者不能互相取代。

## 定向脈的兩個動作

- **釋壓**：極慢放鬆某一脈位，讓手指跟隨脈氣。若脈能依預期上行或在應停的位置停住，表示其功能可行。
- **傾斜**：在維持三部壓力下，微下壓供應端，同時微釋放接收端；下一搏接收端若有「彈跳感」，表示向量存在。

## 核心氣機向量

| 檢查 | 成功的脈上反應 | 缺失時先問 |
|---|---|---|
| 肺宣發 | 釋壓後肺脈可跟隨上達衛分 | 肺本身不宣，或脾未上輸？ |
| 脾氣上輸肺 | 壓脾／腎、釋肺，肺有彈跳 | 脾濕、脾虛或橫膈阻滯？ |
| 胃氣下行 | 壓脾、釋腎，腎有彈跳 | 胃是否逆、帶脈或下焦是否阻？ |
| 肺氣下納腎 | 壓肺／脾、釋腎，腎有彈跳 | 肺不降，還是胃／中焦不作使者？ |
| 腎陽資助衛氣 | 壓腎→脾、釋肺，肺有彈跳 | 腎陽、脾陽或中焦傳遞何者失效？ |
| 心氣宣散 | 釋壓後心脈上達衛分 | 心血是否足以載神與宣散？ |
| 肝血上行心 | 壓肝、釋心，心有彈跳 | 肝血不足，或脾未能上輸？ |
| 肝血下滋腎 | 壓肝、釋腎，腎有彈跳 | 肝血是否能下達腎陰？ |
| 心腎相交 | 依序壓心／肝、釋腎，腎有彈跳 | 橫膈、肝作使者或心腎本身？ |

書中另述「腎向心」的探查，但明言此涉及個體命運與自主性的倫理邊界，不應當作常規判讀。

## 使用原則

- 三指必須持續同時接觸；只抽離一、兩指會失去全身關係的背景。
- 向量缺失不等於接收端「虛」。先找供應不足、通道阻滯、格拒或拒納。
- 診脈本身是互動；若意念能使表現迅速改變，較傾向經絡功能層問題。若不能改變，才更要謹慎考慮臟腑本身的病理。
