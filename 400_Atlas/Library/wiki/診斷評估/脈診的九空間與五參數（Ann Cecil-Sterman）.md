# 九空間與五參數

## 九空間：先確定你在讀哪裡

寸、關、尺各分表、中、深，構成 3×3 的九空間：表層讀衛氣，中層讀營氣，深層讀元氣。它不是九個互不相干的格子；同一深度可換不同透鏡，讀氣、媒介、三焦、臟腑或經絡系統。

## 五參數：再判斷那裡發生什麼

| 參數 | 在此系統中主要讀取 | 不可省略的合參問題 |
|---|---|---|
| **高度／深度** | 陽氣能否上達、排邪或維持伏邪的能力 | 是正常生理深度，還是陽虛、外脫、寒濕收引、情志退縮？ |
| **寬度** | 物質媒介容量：表層津、中層血、深層液與腎精 | 脈細是物質不足，還是受緊縮／阻滯而暫時變窄？ |
| **長度** | 陰陽是否安位、臟腑是否互通或超出負荷 | 延長是溝通、媒介溢出、氣過亢，還是風邪？ |
| **節律** | 寒熱與病勢速度 | 數或遲是否有同時的高度、寬度與質地佐證？ |
| **質地** | 病邪與身體反應的性質 | 緊、弦、滑、澀等是病邪本身，或是在保護某媒介？ |

## 讀值的三個警戒

1. **緊不必然是阻滯。** 肝可為藏血而緊、脾胃可為留津而緊、腎可為固精而緊；若把保護性緊直接瀉掉，可能反而加重耗損。
2. **浮不必然只是表邪。** 表層浮緊可指經筋排邪；尺位浮越則要考慮腎陽外脫或三焦脈，意義完全不同。
3. **脈形不是病名。** 質地必須與所在脈位、深度、媒介寬度、病史與其他診法合參。

## 常用質地的系統定位

| 質地／組合 | 本書提供的優先判讀方向 | 還要再查什麼 |
|---|---|---|
| 浮、緊（1–6 豆） | 經筋正在防禦或排邪 | 下方是否有足夠津液寬度與向上衛氣壓力？ |
| 緊且空／弱／細 | 可能是媒介不足下的固攝反應 | 津、血、液或腎精屬哪一層不足？ |
| 滑 | 常與濕相關 | 脾胃運化、脈寬、是否覆蓋真實深度？ |
| 數 | 熱或氣機加速 | 是局部反應、熱邪轉移，還是右尺三焦脈？ |
| 遲 | 寒；若合併經筋緊，提示病邪更深內傳 | 陰經經筋與資源能否繼續排邪？ |
| 弦 | 常指阻滯，尤其關部時要查橫膈與募穴 | 是否其實是寒邪或保護性緊？ |
| 細／狹窄 | 對應深度的媒介不足 | 表＝津、中＝血、深＝液／腎精 |
| 散、伏、動 | 不宜僅以質地定義 | 進一步檢查經別／奇經脈與病勢狀態 |

## 出處

Ann Cecil-Sterman《脈診的藝術》第 1–2 章，特別是〈九個空間、五個參數與多種脈象質地〉。
