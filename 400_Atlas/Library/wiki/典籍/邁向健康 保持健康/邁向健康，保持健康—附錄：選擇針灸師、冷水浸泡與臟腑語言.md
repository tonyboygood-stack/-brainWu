# 附錄：選擇針灸師、冷水浸泡與臟腑語言

> 附錄不是可忽略的宣傳頁。它很清楚地說出作者希望臨床如何發生：以個人化問診、脈診、完整經絡系統、溫暖的說明與耐心為核心；同時也包含遠距經絡、石頭療癒、反對電針，以及將冷水浸泡直接寫成伏寒與自體免疫病因等高主張。資料庫要完整保存這份立場，也要讓使用者一眼看見哪些是「作者世界觀」、哪些是可檢核的安全實務。

## 附錄一．選擇針灸師：把作者的好問題留下來

作者不希望病人只看頭銜，而希望看見臨床者是否善良、專注、不評判、能傾聽並依個人情境追問。她特別重視面對面脈診、每次重新辨證，以及是否懂得經筋、絡脈、經別、奇經八脈與正經的整體系統。

這可轉為病人真正能使用的選擇清單：

- 是否具有所在地要求的合法執業資格、清楚說明受訓背景與治療範圍？
- 是否先問主要困擾、病史、用藥、紅旗與就醫狀態，而不是一開始就承諾能治癒所有病？
- 是否能以可理解的語言說明「這次會做什麼、可能的感受與風險、何時需要轉介」？
- 是否取得知情同意、維護隱私、使用單次拋棄式針具並採取感染控制？
- 若病況沒有改善、惡化或超出範圍，是否願意與其他醫療／心理專業協作或轉介？

作者認為針灸能處理很廣泛的疾病、慢性退化與嚴重心理情緒困難；這反映她的臨床信念，不能當成通用療效保證。對中風、發炎性腸病、感染、癌症、自體免疫疾病、嚴重精神症狀等，針灸若使用，應是整體照護中的輔助，不能延誤標準診治。

### 作者的治療偏好，與資料庫的處理

| 原書立場 | 本資料庫如何保存 |
|---|---|
| 以全經絡系統而非只處理痛點 | 作為古典系統的臨床思路，連回經筋、絡脈、經別與奇經卡 |
| 反對電針，認為它不夠個人化 | 標記為作者偏好；不把它擴寫成所有情境皆禁用的安全結論 |
| 指壓、精油、石頭及遠距激發經絡 | 記為作者／經絡實踐者的主張；不可取代面對面評估、急症處理或實證治療 |
| 疼痛後應立刻好轉、72 小時大幅改善 | 可作回訪觀察，不能當成療效承諾；疼痛惡化或有紅旗要重新評估 |

## 附錄二．冷水浸泡：作者病例要保留，但不可變成恐嚇或醫囑

作者以一位反覆冷水浸泡、全身關節痛的男性為主線，從緊脈、畏冷、腹脹、頭痛和關節晨痛推論「深層伏寒」。她以艾灸、溫熱熟食、停止冷水浸泡與日後疼痛改善，展示她的病生理框架：寒邪入體，衛氣無法排出，經別暫將其安置於關節，最後侵入結構。

這是一則能幫助讀者理解作者如何把**外在刺激 → 排邪／伏邪 → 資源與媒介 → 經別 → 關節症狀**串起來的完整病例，因此不能刪掉；但其將冷水浸泡直接造成自體免疫病、關節炎或早逝的結論不採用，也不能要求有關節痛者一概停止運動、冷療或自行施灸。

更安全的結論是：冷水浸泡並非無風險的萬靈解方，突然冷水接觸會產生冷休克反應，並有低體溫與心血管壓力等風險；特別是心血管病史、暈厥、心律問題、未受評估的疾病、酒精／藥物影響或獨自進行時，應先與醫療人員討論。它是否適合某人，不能由「感到振奮」或「關節暫時麻掉」來判定。突然胸痛、心悸、呼吸困難、意識混亂、無法停止發抖或失去協調時，需立即停止、保暖並尋求醫療協助。

作者在病例末尾提醒治療者衛教應不責備、不優越，這點非常值得保留。病人若選擇冷水浸泡，好的對話不是「你做錯了」，而是：「你想得到什麼效果？實際帶來什麼反應？有哪些已知風險？有沒有比較適合你目前身體狀態的恢復方法？」

## 附錄三．臟腑不是西醫器官清單

作者最後重申，本書的肺、心、脾／胰、肝、腎主要是「經絡與功能網絡」的語言，不等同於解剖學器官。這是本資料庫很重要的閱讀鑰匙：

| 臟腑語言 | 作者在本書賦予的功能 | 使用時的界線 |
|---|---|---|
| 肺 | 氣的下行與外宣、津液滋潤、情緒釋放 | 不等同肺功能檢查或呼吸疾病診斷 |
| 心 | 神、喜悅、舌與血脈 | 不等同心臟病因或心理疾病診斷 |
| 脾／胰 | 運化、肌肉四肢、上升、思慮與統血 | 不等同胰臟或消化系統的單一解剖功能 |
| 肝 | 疏泄、藏血、肌肉眼睛與規劃 | 不等同肝功能數值、肝炎或肝病診斷 |
| 腎 | 生長生殖、骨、水液、志與溫煦推動 | 不等同腎絲球功能、腎衰竭或荷爾蒙診斷 |

因此，若病人有黃疸、胸痛、呼吸急促、持續出血、嚴重腹痛、排尿明顯改變、神經症狀或精神危機，不能因為在經絡語言中「理解成肝、肺、心或腎」而跳過正式醫療評估。

## 石頭與圖像：保留為象徵與閱讀入口

書中的石頭圖像和註釋（如孔雀石的放鬆、黃鐵礦的疼痛轉移、紫水晶的情緒安撫）可保留為作者的象徵性語言、攝影與空間氛圍的一部分。它們不應被標記為可以治療疾病的物質療法。圖片本身仍保留在原書掃描，使用時從 [[健康衛教圖像與短章索引（Ann Cecil-Sterman）]] 回看，避免把影像和作者原來的頁面脈絡切散。
