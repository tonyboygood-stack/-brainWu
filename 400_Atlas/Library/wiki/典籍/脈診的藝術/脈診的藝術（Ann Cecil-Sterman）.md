# 《脈診的藝術》大目錄

> **本書解決的問題**：不是把單一脈象對到單一疾病，而是回答：身體正在排邪、伏邪、耗損或顯露？哪種媒介不足？哪一條通道失去聯繫？治療是否真的讓病勢改變？
>
> **與《高階針灸臨床手冊》的關係**：前書建立補充經絡的病生理與針灸方案；本書提供診斷接口。脈診在此是「病勢—媒介—通道」的動態讀取法，不能脫離舌、病史、觸診與循行指徵單獨定論。

**第二輪閱讀順序**：[[脈診的藝術—第一章：觸脈不是讀表，而是建立可被信任的觀察]] → [[脈診的藝術—第二章：九個空間與五個參數，先看脈在做什麼]] → [[脈診的藝術—第三章：探查脈，把臟腑功能放回整體壓力中]] → [[脈診的藝術—第四章：定向脈分辨堵住、退回與無法接住]] → [[脈診的藝術—第五章：五類經絡脈，讀病邪被哪一層承接]] → [[脈診的藝術—第六章：由簡到繁，讓讀脈有可回頭的次序]] → [[脈診的藝術—第七章：先證明來源，再談補瀉與治療方向]] → [[脈診的藝術—第八章：把食物放進脈的資源與方向，而非食物處方]] → [[脈診的藝術—第九章：病例的價值是展示推理，不是複製處方]] → [[脈診的藝術—第十章：小兒觀察、發育節奏與證據邊界]] → [[脈診的藝術—第十一章：治療前中後都要回來看脈]]。

## 收錄規則

- 保留可重複使用的**診斷方法、判讀規則、系統轉折與追蹤指標**。
- 31 種質地、病例與大量問答不逐條改寫為孤立規則；第二輪已將其放回章節敘事、圖像與病例的推理順序，再由五參數、經絡脈與治療追蹤頁提供快速查詢。小兒章中與疫苗、自閉症／神經發展障礙之因果連結屬作者主張，已明確標為不採用的醫療資訊。
- 書中涉及針刺的例子只收錄為「由脈決定治療意圖」的示範；具體方案仍以 [[高階針灸臨床手冊]] 的系統卡為準。
