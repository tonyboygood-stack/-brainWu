# 附錄二：經別交會穴與開放穴的作者功能

> 作者說，經別治療中最重要的是交會穴：它向身體表明正在作經別治療，並體現治療原則。以下不是正經穴性，而是作者指定以「經別手法」針刺時的功能；循行穴則可保留較接近正經的功能。

| 經別 | 交會穴的作者功能 | 開放穴的作者功能 |
| --- | --- | --- |
| 膀胱／腎 | BL-40 舒筋、化未解邪的熱濕、風性神經病、腰與腑濕熱、血痰熱、排泄與泌尿；BL-10 舒筋絡、祛外風寒熱，調頭腦過陽。 | KI-10 處谷氣受阻而成的濁津、濕痰水腫與關節腫、下焦出血帶下陽痿、濕眩步態，並利下焦、調津。 |
| 膽／肝 | CV-2 藏血固精、溫腎、調月經下焦、化濁濕與活血；GB-1 改變看世界方式、明目開上竅、反省放過去、疏風。 | GB-30 舒筋、開臀強腰、護精、祛風濕／關節邪；LR-5 至生殖與 CV-2，清「三蟲」、處關節痹與氣逆、安神，導血護精。 |
| 胃／脾 | ST-30 鬆宗筋與經筋、調氣血／月經胞宮、轉腎精病邪、處完穀與奔豚；BL-1 疏風熱、激 ST-42／衝脈、平衡荷爾蒙水液、明目。 | SP-12 利濕化痰清熱、處下焦濕／疝、行氣活血與乳汁；作者特別用它處胸不開的緊弦寸脈、羞恥內疚與霍亂。 |
| 小腸／心 | GB-22 舒筋衛、調向舌之血、寬胸、激胞脈通腎、連先天並處神志；BL-1 入腦／垂體、平衡腺體與眼周緊痛。 | SI-10 舒筋、清血熱活血祛風、散胸喉腹與九竅結聚、開上肢；HT-1 處九心痛與生命挑戰、寬胸、通心腎，處腋／淋巴結。 |
| 三焦／心包 | TH-16 祛速蔓風與痰、利濕散腫清失控熱、開喉與頭面九竅；CV-12 泌別清濁、和脾胃化濕，使氣下膀胱小腸並處執念／九心痛。 | GV-20 抑逆熄風、潛陽安神、升陷開頭竅；PC-1 使人和解挑戰、寬胸理愧、宣肺止壓力咳，清血熱散乳房結。 |
| 大腸／肺 | LI-18 調氣血逆、行氣防滯、利咽暴瘖；ST-12 活血宣肺、清胸熱降氣、鬆頸肩，原書也列亡陽、危重、神經病／痿。 | LI-15 化風痰濕、利尿疏風、調血與關節邪；LU-1 宣降肺氣、化中焦痰濕、清熱疏風、開頸並處奔豚。 |
