# 高階針灸臨床手冊：經別的脈診、環路與治療選擇

## 作者如何在脈上找經別

作者將奇經八脈與經別都放在伏脈中辨認。奇經有隱蔽震顫；經別則在隱蔽特徵旁常帶一點浮。她所說「隱蔽」不是找不到，而是先以壓向骨頭阻斷橈動脈，略放鬆後辨是哪個脈推手指，再壓回去看該脈是否消失；在稍放鬆時出現、壓回骨位時消失者，被她讀為經別脈，表示該位置仍有維持伏邪的能力。

經別脈位如下：

| 脈位 | 經別 |
| --- | --- |
| 左寸 | 小腸／心 |
| 右寸 | 大腸／肺 |
| 左關 | 膽／肝 |
| 右關 | 胃／脾 |
| 左尺 | 膀胱／腎 |
| 右尺 | 三焦／心包 |

## 選 SDS 或 DSD：作者先問「媒介還在不在」

作者的選擇不取決於症狀看起來多嚴重，而取決於該合口還有沒有承運病邪的媒介。脈在肌肉中層的寬度比脈力重要，因經別仰賴津液。腎、肝、脾、心脈在中層寬，表示相應經別仍有資源承接。

她用可用資源依次選合：資源皆足用第一合；有血用第二合；血不足但津足用第三合；血津皆不足而液足用第四合；若全媒介皆失，轉第五或第六合。某脈浮而緊、向上推手指時，作者讀為身體正推病邪往經筋，該合適用 SDS。

若該合媒介太少，作者建議先用前一合建立資源，或選 DSD 並加原穴。例如血虛時可用膽肝經別加原穴鞏固血，也可用胃脾 DSD 先支持津，減輕膽肝壓力。脈弱、細的合口儘量不用；若仍用，採 DSD 並加原穴。所有脈都浮數、陰液不足時，書中選三焦／心包。

## 七類診斷材料

作者將經別診斷放在以下材料的交會：

1. 合口資源與中層脈寬。
2. 浮緊脈是否把病邪推向經筋。
3. 某臟腑在特定層次是否仍強，可支援相鄰合口。
4. 哪種媒介不足，因而無法維持伏邪。
5. 慢性、單側、間歇性問題所在的循行部位。
6. 病情是否依腎精、血、津、液、氣、陽逐步耗損。
7. 單一經別的循行、衛氣、配對陽經媒介動員、配對陰經媒介耗損等指徵。

作者提醒，症狀是用來選哪個合口，不是決定 SDS／DSD；後者仍只依媒介。病人不必具備所有指徵，病程愈進展才愈多。

## 《素問》第六十三篇在本書中保留的經別線索

作者摘出的重點包括：膀胱經別的頸肩痛、突發背痙攣放肋與 BL-67／對側 BL-63、華佗夾脊「三次」；腎經別的心痛腹脹膈滿、KI-2 刺血與 KI-1；膽經別的呼吸難、自汗咳、胸脅痛與 GB-44、髖痛 GB-30；肝經別的突發生殖器痛與 LR-1；胃經別的噴嚏流涕鼻衄上齒冷與 ST-45／ST-44；脾經別的腰痛腹鼓、抬頭呼吸難；小腸的少腹痛放腰／生殖器與便秘泄瀉；心經別的胸脅痛、心悸、平臥氣急、睡眠與眩暈；三焦的咽痛緊、口乾、煩躁、舌縮、抬頭／舉臂難與 TH-1、對側 TH-2；心包的腕痛、掌熱與 PC-1 周圍；大腸的胸脅滿、胸熱、呼吸難、耳聾與對側 LI-1、PC-9；肺的胸悶、咳喘、煩躁、咯血痰、掌熱。

## 十二經別核心要訣

作者將經別的個性濃縮為：

- 膀胱：在表部骨關節找伏邪處，腎精耗則病邪露。
- 腎：陰轉陽的活動，並作帶脈緩衝，防病邪入元氣。
- 膽：移氣導邪入伏，需要血載氣。
- 肝：以血支持腎精，偏安靜、深層的補血經別。
- 胃：津移動以支持血。
- 脾：津液耗竭而風氣內動。
- 小腸：動員液支持津，衛氣內化至胸。
- 心：液失則伏邪失，陽不能錨於腰，衛氣萎縮。
- 三焦：伏邪完全失，氣在流失。
- 心包：津液與血分嚴重失。
- 大腸：終末期，陽幾乎盡。
- 肺：衛氣與正經、臟腑會合，病邪由 LU-1 入臟腑。

她允許有的臨床家脈優先、有的症優先；有人治有症的合，有人改治其他合以鞏固資源；有人只 SDS 加原合穴，有人資源不足前只 DSD。也可只用一對中的一經：陽經別提供移邪動力，陰經別提供伏邪媒介。

## 高級加穴的五個方向

作者把相鄰六合加穴收為幾個治療意圖：舒筋（BL-40、BL-36、BL-10、GB-25、GB-22、SI-10、ST-30）；固本（CV-4、CV-3、GV-4、BL-28、BL-23、KI-16、CV-12、ST-42 等）；利上、下竅；調氣血、理氣、寬胸、宣肺；清熱祛濕、風寒、痰、血熱與風。她說這些只是精細調整，仍偏好先讓單一經別的方案聚焦、簡單。

書中還要求治前喝常溫白水，使身體知道有津液可供轉化，並鼓勵日常、尤其早餐前充分補水。

## DSD 完整順序

DSD 的進針是：交會穴 → 開放穴 → 所選循行穴。交會穴通常由上至下；開放穴可雙側或首針同側；最後才加循行穴。DSD 不刺井穴，因作者的意圖是回伏、建媒介而非排邪；頸上背緊時先刮痧放衛氣。拔針則反向：額外元氣穴 → 循行穴 → 開放穴 → 上、下交會穴。

## SDS 環路與井穴

SDS 的四交會穴要形成環：一側下合 → 同側上合 → 對側上合 → 對側下合；常加正中交叉穴 GV-20，淺刺不手法，讓病勢轉到井穴所在、力量較強的一側。環的起點依損傷最初發生側，而井穴留在原始傷側；例如現在右膝痛但二十年前左膝重傷，從右側起環，左側刺井穴，把病勢引回左側排出。新鮮右側傷而無左側歷史，從左側起環，右側刺井穴。慢性單側痛則常推定源在對側無痛側。

SDS 的完整順序是：皮部／緊處先刮痧或走罐 → 交會穴環與交叉穴 → 開放穴 → 精選循行穴 → 與最後交會穴同側的井穴。作者說井穴的壓力感是衛氣「敲門」，可立即拔針，穴位可能出血。拔針依額外元氣穴、循行、開放、非井穴側交會與交叉、井穴側交會、最後井穴進行。

## 滯塞、好轉與作者的疑難排解

作者把頸、骨盆、夾脊、肩胛、胸鎖乳突、斜方、腹直、乳周、肋架、臀、腓腸列為常見滯塞／五柱；在任何 SDS、DSD 前以刮痧或拔罐鬆開，才可移衛氣。好轉反應則是壓抑、潛伏、未解病勢再現、逐層剝離阻塞的過程。

SDS 後仍痛僵時，她回看皮部刮痧、飲食寒涼與冰敷；DSD 中突痛時，在痛處衛分進針、向離前正中線轉一百八十度後立刻出針、不閉孔，仍痛則刺相應經筋井穴。深淺不能得氣時查針的金屬與針柄；治療失敗時查伏邪是否需先在胸鎖乳突、膈、髂腰、腹、夾脊、臀、胸骨、骶等刮痧釋放。

她也把類固醇、免疫系統亢進而血檢無病邪、三治三停的意義、各大關節或單膝的經別判讀、以及「要伏多久」放在問答中。她認為伏邪直到脈示津液與氣足以排出才釋放，可能數日、數週、數月；若生活方式不變，經別 DSD 便成為長期保護臟腑的策略。
