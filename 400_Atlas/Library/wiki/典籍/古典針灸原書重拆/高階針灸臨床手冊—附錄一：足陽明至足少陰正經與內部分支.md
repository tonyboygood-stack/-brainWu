# 附錄一：胃、脾、膀胱、腎正經與內部分支

## 胃正經與五支

正經由 LI-20 上印堂，沿鼻外側下行、繞口至 CV-24，上耳前 ST-8，終 GV-24；原書另註主線由 LI-20 至 BL-1、ST-1。

1. ST-5 下至 ST-9、ST-12 入體，過膈，終胃脾。
2. 胃至 ST-30。
3. ST-12 內行至 ST-30 出體表，經 ST-32、膝，終 ST-45。
4. ST-36 至 ST-42，終中趾。
5. ST-42 至 SP-1。

## 脾正經

正經由 SP-1 上至 SP-12，入胃脾，過膈、咽，終舌本。

- 分支：胃的 CV-12 至心的 CV-14。

## 膀胱正經與四支

正經由 BL-1 至眼腦交界、GV-24、GB-15，終 GV-20。

1. GV-20 至耳尖上方。
2. GV-20 過腦，自 GV-16 出，下至腰，終腎 BL-23、膀胱 CV-3；構成內側背俞線。
3. BL-23 至 BL-35，終 BL-40。
4. GV-17 至 GV-14，循外側背俞線下臀、BL-40，終小趾 BL-67。

## 腎正經與三支

正經由小趾下肉墊至 KI-2、KI-10、GV-1、GV-4，終腎 BL-23、膀胱 CV-3。

1. 腎至生殖，向上過膈至肺、喉，終舌本。
2. 肺 LU-1 至心，散胸中。
3. KI-2 至 SP-8。
