# 高階針灸臨床手冊：經筋治療的完整操作敘事

> 閱讀入口：[[古典針灸原書重拆 MOC]]

## 先確定「現在是哪一條經筋受傷」

作者將經筋治療的目的寫成兩件事：驅逐滯留的病邪、疏通受阻的衛氣，因而緩解疼痛、恢復氣血運行與關節活動度。她認為成功有兩個先決條件：**透過動作評估**，以及**先治療底層虛損**。

她特別提醒，疼痛出現的位置不必然就是原始受傷處。症狀可能已轉到另一條經筋，但原始損傷還留在原處；也可能是損傷真的已傳到別條經筋，而原處仍殘留部分腫痛。讓病人做動作，才能讀到當下真正要處理的路徑。

## 先從脈中找四種底層虛損

作者把經筋易受傷歸到「氣虛，身體無法擋住或迅速清除病邪」。她的工具箱先從以下脈象檢查開始：

1. **腎陽**：腎陽脈是否有足夠強度？
2. **胃之津液**：中取時脾脈的寬度如何？
3. **肝氣條達**：肝脈是否弦緊，使衛氣難以順行？
4. **肺氣宣發**：慢慢抬起手指時，肺脈的氣是否隨之浮到體表，肺能否把衛氣布散出去？
5. **經筋脈定位**：哪一處脈呈現緊而浮？

她要求先處理診出的腎陽、胃津、肝氣或肺氣問題，再進行經筋治療；若沒有先處理，經筋方案的效果會受損，並且應回到脈上確認虛損已經充分處理。

## 以困難的動作辨別六經筋

作者把「哪一種動作最困難」當成經筋診斷最重要的一問。

| 最困難的動作／狀態 | 作者所屬經筋 |
| --- | --- |
| 伸展；包含手臂側展、向前伸展、行走、駕駛時的運動痛 | 太陽 |
| 旋轉；轉頭、轉軀幹、旋髖、旋臂，或頭部側屈 | 少陽 |
| 停頓、承重；抓握持物（尤其手臂伸直）、髖前屈、靜止站立 | 陽明 |
| 將手、膝、足往身體方向收回 | 太陰 |
| 屈肢時旋轉；如坐姿把外踝放上對側大腿、倒茶 | 少陰 |
| 持續疼痛或完全失去運動能力 | 厥陰 |

她另外辨別太陽與陽明的伸展痛：太陽的痛在運動過程發生；陽明則在身體靜止、承住該姿勢時發生。

## 工具箱：交會區、阿是穴、結聚點與井穴

作者把十二經筋收束到四個交會區：足陽在顴骨、足陰在恥骨上方、手陽在太陽穴、手陰在腋下。交會區要找最緊的點。

接著找阿是穴。她既收患者主觀說「對，就是那裡」的痛點，也收施術者摸到的弛緩、緊張、冰冷、發熱、疼痛處。沿經筋圖看各大關節、枕骨、面部與踝部的深色結聚點；作者把它們稱為經筋與骨、韌帶相連的「經筋之果」，寒邪與緊張易聚於此。

井穴是每條經筋唯一的針灸穴，也是釋放病邪的門戶。作者強調它不是一個死點，而是月牙形的潛在區。她的取法是：用食指承住病人遠端指／趾間關節，拇指放在指甲角遠端，上下泵動指甲數次；指甲床周圍會發紅的位置，才是當下真正的井穴。以 LU-11 為例，它可在內側、外側，甚至指甲床基部正中。

## 經筋的兩種針刺法

**鑱刺法**：只入針管所容許的極淺深度，肘與腕完全伸直，以肩帶動極小提插；在衛氣層持續提插至得氣後立刻出針，不留針。

**捻轉替代法**：同樣只進淺層，但把針往離前正中線的方向轉到微微抓住皮膚，再直接拔出，使針周出現帳篷狀皮膚拉起。作者說這是她最常用的法，效果強但可能疼痛，病人覺得太不舒服時不採用；鑱刺法侵入性較小。

## 作者的經筋治療方案

1. 診脈，記錄腎陽、胃津、肝、肺與經筋脈等發現。
2. 記錄疼痛或可見損傷的位置。
3. 問疼痛性質：劇痛為寒、鈍痛為濕、放射痛為熱、遊走痛為風；作者稱風為各種外邪的載體。
4. 問哪一個動作最困難。
5. 把脈上出現、動作判讀、疼痛位置所指的經筋全部記下；三者可以相同、部分相同或完全不同。
6. 依脈診先處理一項或多項底層虛損：溫補腎陽、滋養胃津、疏肝、宣肺氣。
7. 先治最內層經筋，再向表：**PC → LR → HT → KI → LU → SP → LI → TH → SI → ST → GB → BL**。
8. 在相對交會區取最緊點，平補平瀉：足陽摸顴骨；足陰摸恥骨上約一寸；手陽摸太陽、ST-8、GB-13 周圍；手陰摸腋下至 GB-22 周圍。
9. 從疼或緊的最近端，沿經筋向井穴觸診，找主觀與客觀阿是穴。
10. 用鑱刺或捻轉處理這些阿是穴。
11. 遇結聚點，以同樣手法鬆解。
12. 必要時用拔罐或走罐疏通氣血鬱滯。
13. 不留針；作者說此時處理的是風邪。
14. 緊、冷、鬆弛處可在途中或全線針完後施灸；先針阿是穴，再在該進針處灸。
15. 到終點時，針該經筋井穴、針尖朝遠端，立刻出針以釋放病邪；井穴不做鑱刺或捻轉。
16. 若不只一條經筋受累，依傳變順序逆向治療；例如從太陽傳到陽明，先治陽明、最後治太陽。
17. 用剩餘時間回看已灸處是否仍溫熱，不足則繼續施灸。

## 補經筋：結構鬆弛而非邪實時

作者將反覆脫位、結構完整性差等經筋弛緩情況，另列為補經筋的情境。她的次序是：先針交會區；再針井穴，針尖朝經絡近端；從井穴往近端觸診，找弛緩處，以鑱刺立刻出針，再用滑動按壓把針孔完全閉住，沿全經向上操作。若其中某處仍呈寒、濕、熱實證，則回到前述瀉法方案處理。

## 頻率、處方與精油

作者說損傷常在第一次就有顯著改善；一週一次也能做成，但時間較長。她列的古典處方是連續三天、每日最多三次；在現代門診，則較常需要數次每週治療。

她給病人的後續方向是保暖、避生冷、避免冰／冷敷，以及使用瀉鹽或海鹽浴。經筋範圍寬而每條只有一個穴位，精油以外用藥膏方式使用；作者說理想上應依風寒、風熱、風濕及底層虛損、氣機方向、麻木、疼痛、血分受累來調配。她列出以 1%–5% 濃度混基礎油的六經用油：

| 經筋層次 | 作者列舉精油 |
| --- | --- |
| 太陽 | 雲杉、羅勒 |
| 少陽 | 迷迭香、芹菜、檸檬 |
| 陽明 | 苦橙、苦橙葉 |
| 太陰 | 史密斯尤加利／薄荷尤加利、白松香 |
| 少陰 | 安息香、鼠尾草 |
| 厥陰 | 快樂鼠尾草、德國洋甘菊 |

她另建議在安全的高溫熱水中加入大量瀉鹽或海鹽，浸泡至少二十分鐘；原書特別提到高血壓者須謹慎。

## 好轉反應、疑難排解與常見問答

作者認為經筋損傷會傳到相鄰經筋，漏掉交會穴時尤其容易。她的疑難排解依序是：

- **治療沒有效**：先查是否漏治底層虛損，這是她說最常見的原因。
- **治後再做動態評估，活動度或疼痛無改善**：視為有瘀血指徵，需要處理。
- **痛轉移卻沒有排出**：通常漏了交會穴、井穴，或沒有由最內層向最外層治。
- **已有改善但劇痛仍在**：查緊痛處是否漏灸；加艾灸、走罐，並釋放井穴。
- **淺層提插或轉針無法得氣**：檢查針的種類。

問答裡，她為四種底層虛損各補一個做法：腎陽不足時灸或刮痧 GV-4、GV-14；胃津不足時補 ST-42、TH-2，準備溫水與彎吸管讓病人吸飲；肝脈難疏時可雙側刺、灸華佗夾脊位置的 BL-17，取針後瀉 LR-14，或瀉 LR-6、LU-6；肺氣不宣時在 LU-7 用飛針。她也解釋經筋釋放術是極精微、無針的徒手技術，可在針前放鬆頸部 GV-14 與 GV-4，但按本方案治療並不以它為必要。

## 作者的腳踝病例

一名男子跨過排水溝上人行道時在冰上滑倒，扭傷腳踝。他洗完澡後趕公車而出汗，BL-59 至 BL-62 外側小腿與足部腫脹，劇烈刺痛，旋轉最困難。

作者診為「風寒襲於膽與膀胱經筋」：膀胱經筋有肉眼可見損傷；旋轉痛表示損傷已入少陽，膽經筋也受影響。她的治療依傳變反向進行：先在 SI-18 附近取最緊阿是穴；沿膽經找阿是穴、以鑱刺或捻轉處理，隨時灸冷、緊、腫處，針 GB-44 後出針；再沿膀胱經處理腫脹處、灸、針 BL-67 後出針，最後確認灸處仍保持溫熱。她個人的習慣是在針交會穴後立即針井穴，結束時再針一次，讓交會穴與井穴同時留針，以凸顯正在啟動經筋。
