# 維脈：編織生命的織錦

> 作者以織錦比喻維脈：陰維記錄人生事件在身心結構留下的改變，陽維記錄造成這些改變的行動；蹻脈則是這幅織錦的當下快照。GB-29、SI-10 像織機的梭與踏板，在此刻連起維與蹻。

## 陰維脈：回望過去所造成的結聚

作者說維脈平衡時人活在當下；陰維失衡時執著於過去，陽維失衡時恐未來。意象須由營分與氣支持，久而耗竭，身體便讓物質滯留；血瘀使神不流，氣滯成痛。陰維維持結構完整、防陰失，並在 CV-22、23 令後天陰回補先天陰。

經典主症為心痛、心悸、煩躁、神志擾與「飛陽」──恐懼抑鬱伴腰痛，BL-58 可觸飛脈；亦可眩暈、猝昏強直、胸脅痛。脈細澀數。作者列五積、固定或遊移的積聚／癥瘕、疝與泌尿生殖症狀、腰沉痛、阿茲海默與記憶減、心律與二尖瓣問題、臟腑乾燥及月經性血虛頭痛。心理面是過去創傷、遺憾、罪疚、羞恥、反覆「如果……」、抗老、衰老焦慮、壓抑記憶與九種心痛。

**路徑**：KI-9、SP-13、SP-15、SP-16、LR-14、CV-22、CV-23，入腦，敘事上由腎的自我、脾的社會、肝的體表／世界，回到任脈。開穴 PC-6；郄 KI-9 可強瀉作急救止急性心痛，也可震顫以處不能釋懷的人生停滯。

作者的標誌穴語意包括：KI-9 以「客旅」使人退後看自己、轉化執念；SP-13 使事件下行釋放、解腹部積與依附；SP-15 處變化混亂與同化；SP-16 處悲傷、哀怨與創傷僵直；LR-14 使時間週期圓滿、理氣並放記憶；CV-22 讓表達從胸升起；CV-23 恢復真實聲音與身份。

治則為安神、養血、調氣；無陰性液滯時補陰，氣／情緒滯時亦補陰；有陰性液滯則作者改用任或衝。流程為 PC-6（女右男左，可選）→ KI-9 → SP-15、CV-22、CV-23 等由下上標誌穴 → 餘穴 → 震顫、觀想、深層脈診 → 40 分留針 → 脈診、先拔開穴、靜臥五分。PC-6 取微屈腕後兩筋最深凹，筋太近時由尺側筋下穿。

## 陽維脈：面向未來的行動與衛氣

陽維協調腎陽到體表成衛氣的運動；協調失敗形成少陽寒熱、高熱或惡寒。它記錄求學、青春、大學、職業與轉折、婚離、子女、更年期、失親、成敗、退休等大事件，並在 GV-16／15 把外在活動記到腦。它可回收過多陽至督脈，也可把陽集中在急需處（如受風時 GB-20）；於 GB-20 入小腦，記錄身體、社交技能與協調。作者把它寫成在過去未來間留下「新未來」空間的脈。

經典為寒熱往來、惡寒或高熱的少陽病，脈浮滑數而深層常弱。原書列昏厥僵直、腦霧、腰腫痛、黃疸、吸收不良、耳病、慢性呼吸／經筋／皮病、痿症、各種頭風與神經病、單側偏頭痛、皮膚耳鼻喉問題、低熱皰疹、陽亢與創傷記憶軀體化。心理面是過度承諾、不能排序、面對轉換困難、未來恐懼與驚恐、失方向／動力、未竟夢想的失望，也包括終末期不能接納死亡。

**路徑**：李時珍線為 BL-63、GB-35、GB-29、LI-14、TH-13／14／15、GB-21、SI-10、GB-20 至 GB-13；原書另列數條替代線，皆以 GB-29／SI-10 的維蹻交會為關鍵。開穴 TH-5；郄 GB-35 是原書所列亡陽、昏厥、心跳／呼吸停止時強刺激的急救穴。治則召陽、宣陽、化濕、清化濕熱。

作者的標誌穴包含 BL-63（安神舒筋、開竅）、GB-35（清混亂、決斷、寒熱與單側痛）、GB-29（維蹻交會、記憶影響姿態）、LI-14（積極行動）、SI-10（手臂向外延伸）、GB-21、GB-20（風與九竅）、GB-13（安神、改變心意）。創傷軀體化時，作者特別要在 GB-29／SI-10 拔罐，可側臥，必要時加入更多蹻脈穴。

流程 TH-5（女右男左，可選）→ BL-63 → GB-29、LI-14、GB-21、SI-10、GB-20、GB-13 等由下上取標誌穴 → 餘穴 → 震顫、觀想、深層脈診 → 40 分留針 → 脈診、先拔開穴、靜臥五分。TH-5 取伸腕後、肌腱結聚的教科書定位附近；作者寫患者可能微汗。

→ 接續：陰蹻與陽蹻脈。
