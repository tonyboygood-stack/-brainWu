# 高階針灸臨床手冊：橫絡如何把病勢帶到元氣層

> 閱讀入口：[[古典針灸原書重拆 MOC]]

## 橫絡不是可見血管，而是從絡穴向內的可能路徑

作者將橫絡定義為由絡穴通往臟腑的路徑，因為它接引五行的元氣層。它不可見、不可觸，通常畫成一條經的絡穴接到表裡配對經的原穴，例如 ST-40 接 SP-3；但作者認為其實際版圖遠比圖上短線寬廣。

橫絡的重要性在於：它能釋放多餘熱邪、釋放元氣層、恢復正經的氣血力量。它不是一個獨立於縱絡的概念，而是縱絡容量失去後，病勢從營分向內的下一道可能走向。

## 橫絡第一段與第二段

橫絡開始活躍的前提是：縱絡已排空回正經，而正經再也不能用腫脹、囊腫、結節等病理陰液容納病邪。作者把此時的橫絡症狀看成臟腑即將受到病邪波及的警訊，不一定表示病邪已正式進入橫絡。

若未處理，第一段從功能衰退經的絡穴走到表裡配對經的原穴。該原穴理想上暫時固定病邪，直到來源絡脈重新騰出空間、接回病邪；或由該原穴轉到自身絡穴再安置。作者以脾縱絡失守為例：SP-4 的病勢傳至 ST-42。她認為配對經可能仍較強，而原穴的氣稠密緩慢、位置偏遠端，故可維持伏邪數小時到數十年。

病勢移入橫絡時，長期縱絡滯留帶來的陽氣與熱會同時移動。若配對原穴也飽和，病勢進入第二段：從配對原穴到該經絡穴，該絡穴再滿再空後，經原絡連結回原始經原穴；或病邪直接由配對原穴向內走。作者說此時可進入三焦、正經內部分支，最後影響臟腑。她把募穴放在圖上作臟腑代表，並以三焦從命門、沿華佗夾脊分布元氣的機制，解釋病邪何以更容易深入臟腑。

## 病勢接近臟腑時，身體仍試圖攔截

作者將橫絡第二段描述為緩衝近乎耗盡、熱入裡、先見臟腑膜的炎性改變而後及臟腑本身的時刻。她列胸膜炎、胃炎、結腸炎、腸炎、膽囊炎、膀胱炎、胰腺炎、肝炎、心包炎、腎盂腎炎、心肌炎及各臟腑熱證作為對照，並以元氣層數脈表示脈上的讀法。

但她也說，經別與奇經八脈很可能在第一與第二段之間截擊病邪，重新建立伏邪；病勢也可被送到「終點」，嘗試由感官九竅、頭、胸、腹、陽經井穴排出。她的核心敘事始終是身體會用盡不同通路，避免病邪真正進臟腑。

## 橫絡指徵與作者的理論順序

作者將疼痛沿正經內外循行線、臟腑相關熱象當成橫絡線索。肺內支從 CV-12 經 ST-25、CV-13 到 LU-1，是她用來說明「內部路徑的疼痛」的例子。她列出一個理論次序，並說實際順序仍隨個人的虛實體質改變：

| 橫絡 | 作者列出的主要指徵／症狀 |
| --- | --- |
| 肺 | 胸滿、咳嗽、喘息 |
| 胃 | 發熱汗出、脘腹脹熱、痰、沿線痛；高熱、大汗、大渴、脈洪大、煩躁易怒 |
| 大腸 | 唇乾、口乾、舌津受損、咽乾 |
| 三焦 | 汗出、發熱、沿線痛 |
| 小腸 | 耳疾、耳鳴耳聾、頜下與唾液腺腫、慢性顳顎問題 |
| 膽 | 汗出、發熱、關節痛與酸痛 |
| 膀胱 | 眼疾、目黃、青光眼、流淚分泌物、枕痛、慢性頸痛、痔瘡、腸道問題 |

## 橫絡的治療意圖與診斷

作者主張在橫絡指徵明顯時才做橫絡治療；若沒有相應指徵，治療可能促成伏邪釋放而出現好轉反應。其意圖是保護或溫補元氣，刺血清絡穴，把病邪由元氣層拉回營分；若源頭在原穴，則瀉原穴，把病勢推出，再在陰陽配對經的絡穴刺血與艾灸清理。

她的診斷先由症狀定受累橫絡，再在相應臟腑脈位尋元氣層數脈，並查相關正經是否殘留結節。表裡兩經皆受影響時，需判來源和虛實：

- 來源經實：瀉來源原穴；先刺血、後灸配對經絡穴。
- 來源經虛：灸來源原穴；刺血配對經絡穴。
- 對絡穴做的操作，原穴做相反操作。

重症而來源難辨時，她建議比兩條表裡配對脈，找較虛者，灸其原穴、刺另一經絡穴；例如灸 LI-4、刺 LU-7、LU-4 和血，或灸 LU-9、刺 LI-6、LI-12 和血。

## 原書的三個橫絡例子

- 長期胃腸脹滿、此刻發熱汗出、脘腹脹熱、煩躁、脾脈弱：作者取 SP-3 補或灸、ST-40 刺血。
- 感冒後牙痛、肺脈弱：肺未能禦邪於外，作者取 LU-9 補或灸、LI-6 刺血。
- 未解病邪已成全身酸痛（膽）與頭痛（膀胱）：作者溫灸 LR-3、KI-3，再刺 GB-37、BL-58。

## 演變的排列組合與先天體質

作者提醒，病邪也可能直接沉到原始經原穴，不先跨表裡；也可能由第二經的原穴轉入其絡穴，形成第二條縱絡，例如 SP-4 → ST-42 → ST-40，再回到 SP-3。血分不足而無法形成實質絡脈時，病邪可不經原絡充盈就直接入配對原穴。她將原穴飽和而無法轉移，視為橫絡成立的關鍵。

她再把停留在原穴的病邪放進先天體質：可進任督絡，經衝脈修改下一世和下一代；可進蹻脈，陰絡到陰維、陽絡到陽維，於是情緒歷史顯在姿勢與步態；真正入臟腑時，經別也可能啟動，把病邪送到關節以保護臟腑。

## 橫絡的其他四種用法與兩個敘事例

作者也將絡穴—原穴用成平衡表裡能量的聯絡通道：例如胃火盛、脾虛，可針 SP-3、ST-40，如天平般把多的氣傾向不足的一側。她列四個不同傳承：兩穴皆補的陰陽虛損法；瀉肝原、補膽絡並另補脾原瀉胃絡的能量轉移法；以原穴作「主」瀉、絡穴作「客」補的敘事模型；以及內熱時刺血絡穴、補原穴的內外連結法。

她用兩個炸雞例子凸顯「主」必須看事件順序：若週五吃大量炸雞、翌晨右腹劇痛、苔黃厚，膽為主，瀉 GB-40、補 LR-5；若先與老闆爭吵、因怒吃炸雞、翌晨同樣痛與黃苔，肝為主，瀉 LR-3、補 GB-37。

她還列以單一絡穴處理氣逆的簡法：LU-7 對頻欠伸與頻尿，LI-6 對頻便腸鳴多氣，SP-4 對腸痛腹脹，ST-40 對噁吐，HT-5 對心悸心速心律不整，SI-7 對反流，BL-58 對小便不通，KI-4 對喘，PC-6 對心悸，TH-5 對往來寒熱，GB-37 對上下交替症狀，LR-5 對眩暈頭痛。

## 簡單三層情緒絡脈模型

這個較簡化的模型不分實空。作者先判病理情緒的位置：

- **心境（gan）**在衛氣層：環境能量滲入、急性、沒有特定對象，如「我生氣但不知為何」。
- **情緒（qing）**在營分／血：可說出具體對象，如「我對老闆生氣」。
- **性情衍生情緒（xing）**在元氣：出生即有的傾向，加上生命前七、八年形成的改變；病人常否認或無法意識它。

三層都處理未被經歷與釋懷、反而被強迫性維持的情緒；目標不是改變性情，而是讓人能成為真實的自己。衛氣由肺與肝主，營分由脾與心主，元氣由腎與三焦主。

診斷時先判層次，再標出悲傷、憂思、焦慮／過度興奮、恐懼、憤怒等主導情緒。方案是：在脈象對側刺血層次對應的兩個絡穴——衛氣用 LU-7、LR-5；營分用 SP-4、PC-6；元氣用 KI-4、TH-5。再在對側刺一個陽絡穴：LI-6 對悲傷、ST-40 對憂思、SI-7 對焦慮／過度興奮、BL-58 對恐懼、GB-37 對憤怒，最後補其陰經配對原穴；例如刺 LI-6 後補 LU-9。
