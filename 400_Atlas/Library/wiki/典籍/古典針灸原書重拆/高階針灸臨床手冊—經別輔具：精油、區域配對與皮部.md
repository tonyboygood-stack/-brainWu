# 經別輔具：精油、區域配對與皮部

> 在六組經別之後，作者補上三個使方案變得可操作的層次：精油如何只作極微量的穴位刺激、六組區域配對如何處理急性多部位表現，以及皮部如何作為衛氣層面的區域。

## 精油：只在交會穴使用「微量」

作者的簡易原則是：精油只塗交會穴，用牙籤尖端沾取極少量，依序輕觸所有穴位，中途不再沾取；皮膚不應留下油亮感。他的理由是：微量給予最大刺激，過量會使神經受器過載而關閉；BL-1 若油量多可能隨皮脂移向眼睛；許多精油浸濕皮膚會造成灼傷。

若患者容易塗多，作者的處方是：SDS 精油稀釋在 caulophyllum oil 至 10%；DSD 稀釋於芝麻油或荷荷芭油。

| 經別 | SDS 簡易用油 | DSD 簡易用油 |
| --- | --- | --- |
| 膀胱／腎 | 薄荷或松針 | 茴香 |
| 膽／肝 | 檸檬 | 迷迭香 |
| 胃／脾 | 生薑或艾草 | 苦橙葉 |
| 小腸／心 | 依蘭依蘭 | 乳香 |
| 三焦／心包 | 德國洋甘菊／藍甘菊或沒藥 | 花梨木或芳樟 |
| 大腸／肺 | 尤加利或絲柏 | 松針 |

作者另列複方，並說不必然優於簡易版；選擇取決於診斷和對各香調比例的理解。SDS 時，較高的前／中調比例通常為較低後調的兩倍；DSD 則反過來。

| 經別 | SDS 複方 | DSD 複方 |
| --- | --- | --- |
| 膀胱／腎 | 茉莉（後）＋松針（前） | 芹菜籽（中）＋羅勒（前） |
| 膽／肝 | 德國洋甘菊（中）＋香檸檬（前） | 歐當歸籽（後）＋冷杉（中） |
| 胃／脾 | 芫荽籽（中）＋丁香（前） | 胡蘿蔔籽（中）＋絲柏（後） |
| 小腸／心 | 沒藥（後）＋橘（前） | 葛縷子（中）＋松針（前） |
| 三焦／心包 | 乳香（後）＋薄荷（前） | 甘松（後） |
| 大腸／肺 | 欖香脂（後）＋薄荷（前） | 肉桂皮（後）＋安息香（後） |

## 區域經別：按六經區域把兩條經別接起來

作者將區域對應寫成：太陽為膀胱／小腸，少陽為膽／三焦，陽明為胃／大腸，太陰為脾／肺，少陰為心／腎，厥陰為肝／心包。它的用途是釋放肌肉骨骼或皮膚病症；慢性症狀通常偏向五行經別治療，急性且涉及多部位時可選區域治療。作者非常概略地以三週內作為急性參考，但要求依個案判斷。

區域方案的三步是：

1. 在相應皮部刮痧或走罐。
2. 走標準 SDS 經別流程，並加入兩條區域配對經別的井穴，例如膀胱／小腸取 BL-67 與 SI-1。
3. 在井穴所屬經筋路徑的阿是穴作針刺釋放，不留針。

若有助於治療意圖，作者會加經筋交會穴以防病邪傳入下一區域；例如 BL／SI 治療加 SI-18，以免轉至少陽交會處。

## 皮部：不是點，而是較寬的衛氣區域

作者先區別歷史上如「盾牌」覆蓋全身的廣義皮部：它用於釋放尚未阻礙運動的外感病邪，只需井穴與經上阿是穴，不像經筋依動態評估。與經別合用的皮部則較小、較複雜，是早期廣大皮部的子集；它們與經筋一樣傳導衛氣，並把區域配對經別連在一起。

- **太陽皮部**：胸部環帶，GB-22 經 CV-17、BL-44、BL-15、GV-11 繞胸一周回 GB-22。
- **少陽皮部**：乳突周圍 GB-12、TH-16（有時至 TH-18／19）；季肋 LR-13、GB-25；有時另有 GB-25 至 CV-2／3 的帶狀區。
- **陽明皮部**：衣領環帶，GV-14 經 GB-21、SI-12、ST-12、CV-22 回 GV-14。
- **太陰皮部**：喉部環帶，圍繞 ST-9、LI-18、SI-16。
- **少陰皮部**：CV-23 郵票大小區域。
- **厥陰皮部**：PC-1 郵票大小區域。

作者強調標示穴位只用來引導定位，皮部本身不是穴位。刮痧最好在坐位先做，較易出痧；不能坐者可先刮前側再翻身，若只能俯臥，則至少刮後半環帶並確實處理雙側 GB-22。若無痧，作者讀為氣血兩虛，要求減少針數以免耗竭；區域方案後仍痛時，書中建議強瀉 BL-63。
