# 帶脈、大包與胞脈：固攝、宣洩與胸腹血路

## 帶脈的兩個方向：固與瀉

作者將帶脈區分為「固帶」與「瀉帶」。固帶用於阻腎精、血或津液漏泄，並整合衝任督的上行；瀉帶排由脾在中焦產生並下沉的濕，為帶脈騰出再次容邪的空間。開穴都是 GB-41（足臨泣），採鉤針法：自第五蹠骨外側入，向內跨足背、鉤過第五肌腱下；成功時作者寫骨盆有滲透溫熱、腹有微向下牽拉。

**固帶**用於先天精漏、前列腺及生殖婦科漏泄、慢性脾不培氣血、第一個七／八期的神志不安及先天根源的氣血虛。穴為 LR-13、GV-4、BL-23、BL-52、GB-26、SP-15、ST-25、KI-16、CV-8（不針），多補；側臥、從脊向前淺透連穴，KI-16 可透至 CV-8 下。流程 GB-41（女右男左）→ 依性別側由 GV-4、BL-23、BL-52、GB-26、SP-15、ST-25、KI-16 前行（若欲激腎陽則由 KI-16 向後）→ 震顫、觀想、脈診、40 分留針、收針靜臥。

**瀉帶**在作者筆下是下焦寒濕／濕熱：經典為腰以下冷痛如浸冷水、赤白帶下、突腰痛、提重痛與不能前後彎。脈中焦滑、近肌腱滑數。其身體畫面含黏液便、泌尿生殖與遺精早洩、帶下與點滴、腹水腫／重冷／肥胖、脊不能伸、腿癱與靜脈炎、不孕；心理面是不能放過去、怨、執、孤立與深創傷。穴 LR-13、GB-26、GB-27、GB-28；LR-13 平補平瀉，膽穴瀉。濕熱選 GB-27，寒濕選 GB-28；必要時可雙取。上焦九竅已受影響或上熱下寒加 BL-60，臍痛加 LR-2，月經亂兼偏頭痛加 LR-3。

作者要求瀉帶前先釋放五柱／祖系軸：胸鎖乳突、膈、髂腰、夾脊與臀肌，可刮痧、拔罐、走罐或各自釋放；GB-27 會激發五柱。瀉帶流程為五柱釋放 → GB-41 鉤針 → LR-13、GB-26、GB-27（濕熱）或 GB-28（寒濕）依降序 → 震顫、觀想、脈沉、40 分留針、先拔開穴、靜臥。書中也寫極深創傷下的濕可如安全毯，先固帶建立安全感後再瀉。

## 大包與胞脈：把胸中血下送帶脈

作者說大包與胞脈不是奇經，但經由奇經上的原絡穴把血接到元氣層。大包是環胸、以脾大絡為核心的管理血結構；在 CV-15 接胞脈，再與 GV-1 相連。胞脈把脾所化的血與胸中情緒滯留下送腎与帶；帶滿時，作者列肌瘤、內膜異位、痛經、PMS、前列腺問題及神志不安等下焦血失調。

瀉大包是 GB-22（腋下三寸）→ CV-15 → 對側 GB-22，用於移胸鬱且常聯胞脈；固大包是 SP-21（腋下六寸）→ CV-15 → 對側 SP-21，用於固胸中氣血津，通常不聯胞脈。胞脈是 CV-15、GV-9、GV-1 的縱線，著重心腎向下溝通；衝脈第二路則是腎心向上。

作者給的典型選穴是 GB-22、GV-9、CV-15、GB-26、GV-1（或以 BL-57 開 GV-1）；若病理情緒偏陽如怒焦，加 GB-27，偏陰如悲恐過思，加 GB-28。大包—胞脈—帶脈方案為：先釋放五柱 → GB-22、CV-15 點刺 → 可加 GV-9 → GV-1 點刺或 GV-4／BL-57 → GB-26 → GB-41 鉤針 → 震顫、觀想、脈診、40 分留針 → 由上向下拔針且 GB-41 最後 → 靜臥五分。原書另註，即使不對絡穴點刺，此方案仍有效。
