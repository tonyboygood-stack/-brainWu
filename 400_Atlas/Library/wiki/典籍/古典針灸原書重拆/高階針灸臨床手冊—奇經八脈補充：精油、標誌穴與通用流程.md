# 奇經八脈補充：精油、標誌穴與通用流程

作者指定精油只用極微量：牙籤沾一次後觸所有開穴／必要循行穴，皮膚無油光；原因是過量使受器過載、BL-1 可能移油入眼，而微量刺激最大。

| 經脈／開穴 | 作者列的精油 |
| --- | --- |
| 衝 SP-4 | 廣藿香；第一、四路冬香草，第二路紫羅蘭且 PC-6 用快樂鼠尾草，第三路雪松，第五路廣藿。 |
| 任 LU-7 | 橡苔，或橙花＋生薑。 |
| 督 SI-3 | 雪松＋迷迭香，或雪松＋肉桂葉；配 BL-62 時茴香＋肉桂葉＋艾草。 |
| 陰維 PC-6 | 快樂鼠尾草；或岩蘭草＋乳香＋香草；或玫瑰＋香蜂草。 |
| 陽維 TH-5 | 澳洲茶樹＋迷迭香，或迷迭香＋香茅。 |
| 陰蹻 KI-6 | 茉莉或水仙；或水仙＋茉莉＋杜松。 |
| 陽蹻 BL-62 | 肉桂葉，或肉桂葉＋羅勒。 |
| 帶 GB-41 | 寒濕艾草；濕熱鼠尾草＋羅馬洋甘菊＋羅勒，或艾草＋綠花白千層＋檀香。 |

作者把精油每日塗開穴 100 天；若以針為主，循行穴可選擇性微量加用。

通用奇經流程為：開穴（可省，震顫／搖針／聽針）→ 第一循行穴 → 標誌穴 → 其餘循行穴 → 必要的元氣層加穴；若合兩經，再刺對側第二經循行與開穴；勸患者安靜內省；第一針起留 40 分；反序拔針，休息數分。標誌穴是關節、孔竅或骨隆起附近、能勾出經脈輪廓並強化意圖的穴。

原書的參考表已分散放入各經卡；核心開穴／起點為衝 SP-4／CV-2、任 LU-7／CV-2、督 SI-3／GV-1、陰維 PC-6／KI-9、陽維 TH-5／BL-63、陰蹻 KI-6／KI-6、陽蹻 BL-62／BL-62、帶 GB-41／LR-13。

問答中作者特別說：單針開穴不構成奇經治療，可能給未處理病邪直入先天的通道；必須走循行穴。胸部腎俞在中線旁半寸、肋間凹緣，橫刺。治療時感寒是腎精被動員的正常反應，除非原有病理寒正外宣。PC-6 只配衝脈第二路；即使不用開穴，震顫／搖針仍可讓身體辨識奇經意圖。
