# 奇經八脈工具箱：開穴、脈診、手法與療程

## 開穴不是處方本身，而是接引元氣的信號

作者說開放穴源於十一世紀徐鳳，並非古典必需，功能只是「探測元氣層次」、調氣而不治正經。為讓身體辨認出這是奇經治療，開穴必須以震顫、搖針或聽針進入；單純針絡穴會被理解為正經絡穴，刺血則會被理解為絡脈治療。

| 奇經 | 開穴 |
| --- | --- |
| 衝 | SP-4 公孫 |
| 任 | LU-7 列缺 |
| 督 | SI-3 後溪 |
| 陰維 | PC-6 內關 |
| 陽維 | TH-5 外關 |
| 陰蹻 | KI-6 照海 |
| 陽蹻 | BL-62 申脈 |
| 帶 | GB-41 足臨泣 |

第二、三祖系中，作者指定女性右側、男性左側單側開穴；任一律左、督一律右。衝若補後天，女右男左；若補先天，女左男右。另一條原則是跟隨發現奇經脈象的一側。

作者稱循行穴才是實際治療奇經的穴位。配對穴通常是另一奇經的開穴，最後才刺，僅在其功能未被既有穴覆蓋時加入。書中列明代常用配對 SP-4／PC-6、LU-7／KI-6、BL-62／SI-3、GB-41／TH-5，但強調任何奇經可依穴性相配，古典使用不必然有配對。

## 手法、留針與療程

- **震顫**：一手持針，另一手以 PC-8 震顫針柄，或拇食指震顫針身；正確時全身有極細嗡感。作者要求施術者安靜、沉潛並能感到自身重量。
- **搖針**：弧度較大，較容易但較弱。
- **聽針**：先在深層提插，再提至中層；用於同為絡穴的開穴。
- **瀉／補**：快速震顫為瀉，慢速震顫為補；陰經開穴取最大凹陷／縫隙，陽經開穴取皮膚與筋膜最結聚處。

作者指定自第一針起留針 40 分鐘。常規療程先每週一次，出現轉變後拉長為兩週、三週，總長三個月或一百天；急救時可連治三天、停三天，反覆至預期轉變。

他偏好單側針刺：李時珍主張依脈象側單刺，孫思邈僅雙側皆見脈象才雙刺。作者以身體追求對稱來解釋其臨床經驗：刺激一側，另一側會產生相應反應，病人常在未針側感到同樣甚至更強的感覺。

若合用兩條奇經，順序是：核心經開穴 → 同側核心循行穴 → 對側第二經循行穴 → 第二經同側開穴。加穴原則則限於元氣層的原、合、募、俞、會、三焦、腎、任督、經別交會與絡穴；作者認為與元氣無關的穴會分散意圖。艾灸通常每穴三壯，任七壯、督一壯。

## 以「14／15 顆綠豆壓力」辨奇經脈

作者要求每次評一側手腕：三部同時壓至橈動脈血流止（15 顆綠豆壓力），微放至僅少量血流能過（14 顆），記錄向指上推的脈位；再壓回 15。若脈在 15 仍留在原位，為奇經脈；若消失，為經別脈。

| 脈所在處 | 作者對應經脈 |
| --- | --- |
| 僅寸 | 陽蹻 |
| 僅尺 | 陰蹻 |
| 僅關 | 帶 |
| 寸＋關 | 陽維 |
| 關＋尺 | 陰維 |
| 寸並延至大魚際 | 陽維 |
| 尺並向近端延伸 | 陰維 |
| 寸關尺皆有，並浮至衛分 | 督 |
| 寸關尺皆有，並浮至營分 | 衝 |
| 寸關尺皆有，但不浮 | 任 |

若三部皆有，再極慢放壓：一路跟至表層為督；跟至中層停止為衝；只在深層、未到中深交界即停或不跟，為任。寸、尺同見，作者寫為蹻脈間的互動。

作者另列強連結：督／蹻／維連腦髓；衝／任／督／帶連胞宮；帶與陽維連膽；任／督／蹻連骨；衝與陰維連脈（血管）。
