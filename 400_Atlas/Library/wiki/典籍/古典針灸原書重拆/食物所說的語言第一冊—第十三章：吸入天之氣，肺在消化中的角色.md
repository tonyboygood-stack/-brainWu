# 第十三章：吸入天之氣，肺在消化中的角色

> 在作者的圖像裡，食物是地的獻禮，呼吸是天的獻禮。腹中吸收出的精微要上達胸，在肺中與新鮮吸氣相會，再由心無私輸布到全身；所以消化不只在肚子完成，也要有能下行、能開展的呼吸。

## 三朵火與肺的兩個任務

空氣從上進來，下行到腹部，扇動腎陽的命門火；命門火維持胃火。這是第一個風箱意象。第二個意象在胸：食物精微過腸壁入血、上輸肺，與吸入之氣混合，才準備交心輸布。作者說若此過程順暢，人得地之氣與天之氣，會有精力與靈感；不好時，即使吃得好也疲乏。

他把肺的關鍵寫為兩面：**肺氣下行**（呼吸進腹、膈肌放鬆、扇動命門火）與**宣發**（清氣、營養、血在胸中完成轉化並外送）。這也讓代謝不被留給抽象名詞：每個細胞的「小爐子」需要氧與營養，不能只靠刺激物或流行代謝法。

## 不把胃填滿：為呼吸保留上方三分之一

作者引用藏傳飲食教導：胃只放三分之二，最上三分之一留給呼吸。這不是解剖上的胃被空氣填滿，而是簡單的飲食姿態——太飽會直接妨礙呼吸，也讓食物精微的吸收、升提和轉化不高效。選適合自己消化的好食物、勿暴食，再取升提宣散的綠菜、芽菜、發芽穀、發酵食物、芳香香料，使已消化的清氣能上達胸。

作者不建議用刺激食物追求代謝；少製造濕、少傷消化，加入運動、呼吸，反而是支持代謝的根本。

## 一段可直接練的「開放式空虛停頓」

1. 舒適坐，脊椎與頸放鬆但對齊。
2. 呼氣後，在呼吸道仍開放、但空虛的狀態停一下。
3. 等溫和清楚的吸氣衝動出現，順著讓氣湧入；觀察是否更深、更開。
4. 第二輪停時，放鬆所有呼吸肌；以不費力、不評價的方式做約 9–10 次。
5. 每天練幾回，不把停頓拉長到造成負擔。

作者說練的是呼氣後自然發生的吸氣，而不是逼吸氣更深。

## 肺的餐桌：潤、降、宣與鬆膈

| 目標 | 實際食物／做法 |
|---|---|
| 潤肺、助下行 | 蘋果、梨、沙梨；杏仁是主要肺堅果，配核桃等其他堅果以油脂纖維通腸；松子承接松林的肺象。 |
| 溫中、清宣 | 鮮薑可天天用；薄荷、芫荽、蒔蘿、迷迭香等芳香食材。 |
| 根菜下降 | 白蘿蔔的溫和辛味，作者用來使肺氣下行。 |
| 鬆膈、開胸 | 柑橘皮，尤其乾燥成熟橘皮／陳皮；用果皮與白橘絡，不用果肉。 |
| 適度濕潤 | 蒸小米或小米粥；對乾咳、嗆咳，作者以小米潤肺。 |
| 痰濕重時 | 生薑、小蔥、柑橘皮、孜然、豆蔻、天堂椒、茴香籽、葛縷子、芥末籽、肉桂、奧勒岡、迷迭香。穀物與香料先乾炒／乾焙可加陽與清肺性。 |

### 作者的乾柑橘皮做法

買有機橘／柑，洗外皮，果肉吃完留皮。可在暖陽下攤乾，讓周圍通風；或最低溫烤箱、門微開，烘 1–2 小時至輕且硬挺；食物烘乾機亦可。之後再敞放 1–2 日，完全乾再密封，否則會腐。用時掰約一兩平方英寸的小片；味濃，調味後可撈掉，切極細則可留在菜裡。

## 什麼會讓肺的食物路徑卡住

作者列四個要先移走的阻力：冰飲讓肺受冷而咳、呼吸上逆；暴食沒有呼吸空間；食積使食糜、營養精微遲遲不能升胸，午餐後昏沉是線索；慢性便秘使下行反轉，食慾減、疲乏，也可把胃火往上擠成逆流。故清便秘也在幫肺和胃。

最後他把最不需要任何購買成本的兩項工具放在一起：**充分咀嚼、深呼吸**。咀嚼使食物碎、消化液進入、唾液分泌，並藉下頜活動激發胃經；呼吸入腹、開胸，則即使飲食不變也會改變消化與滋養的品質。作者的總結是：物質、火、呼吸——健康吃、勿飽滿、以呼吸點燃命門並在胸完成轉化，讓心把它循行全身。
