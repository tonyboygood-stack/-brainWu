# 高階針灸臨床手冊：經別如何把病邪留在關節或帶回表層

> 閱讀入口：[[古典針灸原書重拆 MOC]]

## 經別在作者筆下的功能

作者以《靈樞》第十一篇、《素問》第六十三篇和《甲乙經》為文獻起點。她把經別視為正經的分支：當病邪可能危及臟腑時，經別把它送往各大關節——外部解剖最深處——讓它進入伏邪狀態。因此，經別是衛氣層與元氣層的溝通系統：病邪由衛氣侵入、由元氣容納；它會一直被維持，直到身體有能力清除，或資源不足以再壓制。

這也是作者的「疾病剋星」敘事在經別章中的具體版本：較慢、較輕的慢性病勢，是身體避免更重臟腑病變的自然策略；經別只在病理存在時被動員。

## 原書案例：十年前胃流感後的關節炎與胃病

一名四十六歲女性過勞、少睡，左髖、左肘、左拇指劇烈關節痛，胃食道逆流、胃炎漸加重。她十年前曾因「胃流感」臥床數日、嘔吐且排綠色液體；脈上雙側關部肌肉中層細，皆不浮，舌乾、有正中裂紋。

作者診為胃津不足、衛氣滯關節成痹：早年胃部病毒在臟腑處被經別攔截，移到髖、肩等大關節；十年裡仍能伏住，後因過勞少睡耗資源而失去壓制，病邪回到胃，形成現有胃症。她選胃／脾經別第三合 DSD，連做三天、休息並喝營養湯。第四天原症全消，作者讀為病邪已回關節；其後腰痛、鼻竇感染出現，表示退至第一合，再以膀胱／腎經別完成排出。她報告最後關節炎與胃問題皆消失。

## 經別如何形成：資源、正經水道與區域配對

經別被作者稱為「孫絡」：病勢自衛氣層未被經筋處理，先嘗試進入絡脈；絡脈無法圍堵，就經橫絡到原穴的元氣層，再由元氣到關節。她說有時血與津液不足，便會跳過絡脈，直接從衛氣進入元氣。

另一種讀法是正經作為水道，本來應以陽分、發汗把病邪驅出；經別被啟動，表示正經已不堪負荷。例如太陽膀胱經不能以汗排邪，病勢越過絡穴走到 BL-40 合穴、接觸元氣，身體便用經別把它轉成伏邪。BL-40 也是經別連續體第一個穴位。

經別亦可藉區域配對轉移病勢：如太陽的膀胱與小腸經別彼此連，皮部作體表橋梁，需用刮痧釋放。作者舉例：骶骨緊（足太陽）的人，肩部（手太陽）也可能突然痛，表示病勢已轉到區域配對。

病邪固定於關節後，是否仍能伏住，完全依賴腎精。腎精被耗後，作者依序列出動用血、津、液、氣、陽支援；經別的技藝就是辨資源耗損、病邪所在，決定建立資源以維持伏邪，或建立足夠資源以排除病邪。

## 六合：六組配對與疾病進退次序

十二經別分六個「合」，每對共享四個交會穴。作者把正向次序視為疾病進展，反向次序視為疾病退回與痊癒：

1. 膀胱／腎
2. 膽／肝
3. 胃／脾
4. 小腸／心
5. 三焦／心包
6. 大腸／肺

## DSD 與 SDS：作者所設定的兩種方向

經別治療先選身體該「根除」還是「重新建立伏邪」。兩種手法都在衛氣與元氣兩端接引，再帶到相反端後回返。

- **DSD（深—淺—深）**：先在元氣層接氣，提到衛氣，再推回元氣。作者稱它為鞏固：把陽帶回內部，套住病邪並護送到元氣，以媒介把它「砌磚封鎖」在關節／伏邪。
- **SDS（淺—深—淺）**：先開衛分，再深刺接引和病邪同困元氣的衛氣，最後提回衛分。作者用它釋放被衛氣困住的病邪，使其準備向表排出。

DSD 的具體操作是深刺、深層小提插或震顫、提至衛分小提插或圓周、再推深層重做；SDS 則淺入針管深度、衛分小提插或圓周、深刺元氣得氣、提回極淺衛分並留針。使用圓周與震顫時，SDS 動作快、DSD 動作慢；每一層都要得氣，失氣則回原點重新接引。作者也容許熟練後，依個別穴位意圖，在同一方案中混用相反手法或單純淺／深刺。

經別的適應指徵被作者概括為：慢性、間歇性、單側，或左右交替的症狀與體徵。

## 經別治療工具箱

**交會穴**必不可少；它們是運送點，移動衛氣，四個穴合用即向身體表明正在做經別治療。除非某穴被障礙物遮擋，均以 SDS／DSD 針刺。書中也列其上、下合穴：胃／脾為 BL-1、ST-30；膀胱／腎為 BL-1、ST-30；小腸／心為 BL-1、GB-22；三焦／心包為 SJ-16、CV-12；大腸／肺為 LI-18、ST-12。

**交叉穴**只用於 SDS：前正中線單穴，常取 GV-20，淺刺不手法、針尖指向要有井穴的一側，以引衛氣跨過去。

**開放穴**用來區分一合中的兩經別：BL-40、KI-10、GB-30、LR-5、ST-30、SP-12、SI-10、HT-1、GV-20、GB-22、LI-15、LU-1，依序對應十二經別。

**循行穴**只從路徑中挑少量、最能闡明意圖者；作者反對全部針刺，以免訊息過多、反降效。可隨脈或臟腑單側取穴。**阿是穴**可先刮痧、入全部經別針後再觸診；仍痛才以經別方式處理，SDS 不留、DSD 留深。**井穴**雖不在經別路線，但 SDS 必加，用以啟動經筋並留出排邪出口；皮部可在所有方案中刮痧，讓衛氣可內引或外導。

另可加入俞穴、元氣層穴、合穴、會穴、募穴、郄穴。排泄也屬準備：作者要求問便秘或顆粒便，因衛氣若在腸道不暢，排邪無出口；腸道不佳時加入 ST-25。疤痕亦需先鬆解，才不阻衛氣。

## 留針、療程與清晰度

作者列 DSD 自所有交會穴完成起留四十分鐘；SDS 自井穴進針起留二十分鐘，若得氣很強，最後一針後即可起針。脈出現預期變化時，也可結束。

經別經典療程是「治三天、停三天」共三輪，至第十八日再評估；需要可再開下一輪。若只能一週一次，作者讓病人自按交會穴或用精油鞏固。她強調先熟練單一經別，體驗各經別的個性，再探索同時治多條或加入相鄰經別穴。

## 六合的媒介與兩種方向

DSD 在各合把病邪帶入關節；SDS 把病邪帶到衛氣，讓井穴啟動的經筋排出。作者安排的支援媒介為：

| 六合 | 維持伏邪／移動病勢的媒介 |
| --- | --- |
| 膀胱／腎 | 腎精 |
| 膽／肝 | 血 |
| 胃／脾 | 津（外分泌液） |
| 小腸／心 | 液（內分泌液） |
| 三焦／心包 | 氣 |
| 大腸／肺 | 陽 |

她說到第四合為止，血、津、液已耗盡；第五、六合往往犧牲氣與陽以求伏邪。第二合另連眼耳，第三合連所有感官九竅。第五、六合的 SDS 特別描述用於慢性、單側、間歇的相關經筋風邪；資源足時，亦可把心包、肺或大腸的急性感染引向表層。

## 三種診斷視角與生命時鐘

作者最常從「媒介動員」看六合：第一合較輕、第六合較重，治療意圖是養媒介以控制病邪，或養媒介讓病邪向外退；隨脈與症狀變化逐合後退，末段可出現像疾病初起的好轉反應，常是有大量痰的感冒樣症狀，數日後消退。

她也允許非循序地單獨使用某一合來處理肌肉骨骼、循行路線上的慢性症、急性臟腑感染，或持續表現某合症狀的先天易感者。最後她給出一個隱喻生命時鐘：BL/KI 的混沌水生 GB/LR 的生發，再生 ST/SP 的形體；形體隨時間被 TH/PC 的欲望消耗而由 HT/SI 衰敗，欲望再與 LI/LU 的世界衝突。經別映照元氣如何接納衛氣所遇世界，也映照身體為保臟腑而逐步犧牲資源的過程。
