# 第二章：九個空間、五個參數與深度

> 作者把三部、三層的脈看成九個空間：手指在其中「釣」到脈，意念再以五參數「撒網」並取回訊息。這是她從感覺走向判讀的基本框架。

## 九個空間與五參數

表層三空間反映衛氣，中層三空間反映營氣，深層三空間反映元氣。五參數為高度／深度、寬度、長度、節律（至數）與質地。作者說高度是陽氣可否向上外行；寬度是體液容量；長度呈陰陽交互、臟腑溝通、急慢與超限；節律讀氣行是否順；質地讀病邪性質。

## 高度：陽氣軸與十五豆的分層

高度量衛氣與陽氣的活力，以及它能否把邪推外，或在資源不足時帶邪入元氣層伏藏。極端浮脈是陽上衛分（腎位可成浮陽／陽外脫）；虛脈是陽不足以推動脈氣。

| 壓力 | 作者在此層所讀 |
| --- | --- |
| 1–3 豆 | 衛氣在陽經經筋、腠理皮毛與肌腱韌帶。 |
| 3–6 豆 | 衛氣在陰經經筋，涉及平滑肌：腸、心、胞宮、血管。 |
| 6–9 豆 | 六豆讀表裡與衛營平衡、消化支援免疫；亦可感絡脈。 |
| 9–11 豆 | 營分的血與津、正經；約十一豆可見陽腑與表裡—先天連結。 |
| 12 豆 | 陰臟與元氣交界、深筋膜神經與臟周筋膜，亦見正經內外路徑轉折。 |
| 15 豆 | 元氣、腎精與骨；奇經、經別、奇恆之腑。 |

作者提醒病邪存在時，衛氣走經別、營氣走絡脈。若病理只在衛／營層，可說與經絡相關；深層才見臟病變。陽腑是陰臟的陽性外出路，陽腑病變未必嚴重，陰臟病變則是作者最重視的層次。

## 三種讀法：媒介、三焦、臟腑—經絡

津走皮膚與九竅，血走經絡，液與腎精走奇恆之腑及臟腑。三焦讀法則將寸表看橫膈上、關中看橫膈與帶脈間、尺看帶脈下。

| 右手 | 左手 |
| --- | --- |
| 寸：表大腸經／中肺經與大腸腑／深肺臟 | 寸：表小腸經／中心經與小腸腑／深心臟 |
| 關：表胃經／中脾經與胃腑／深脾臟 | 關：表膽經／中肝經與膽腑／深肝臟 |
| 尺：表三焦經／中心包與三焦病變／深腎陽 | 尺：表膀胱經／中腎經與膀胱腑／深腎陰 |

古早簡化法僅留右肺脾腎陽、左心肝腎陰。

## 高度的時間、月經與遮蔽因素

春夏脈較高、冬較沉；晨寸應比傍晚高，運動也能升脈；睡著時寸不應浮。作者將肺脈連月經：經期偏浮、經後浮緊，排卵期肺在肌中最強以送血胞宮，月經前肺在深層推血於腎精層。

抑鬱、強隱私／秘密、創傷、寒與濕都可能令脈整體下移：前四為退縮或防衛，寒兼緊／遲，濕兼滑；厚濕重肌肉也可遮住脈頂。她的「廣義深度」是寸應浮、關應中、尺應沉。

## 寬度、長度與至數

寬度是陰／媒介軸：表寬看津、中寬看血、深寬看液與腎精；不是武斷說太大太小，而問脈「是否想變大」。長脈可為臟腑溝通、血／濕／氣／風溢出；三部連成極長時，作者讀為多餘物正借奇經溝渠。短脈則氣或媒介不足、陰受約束。

節律按患者一息脈幾至而非時鐘；一息四至為正常。寸通常比尺稍數。數多讀陽性熱／風熱，常先看腑；遲、澀多讀寒濕，常先看臟。作者要求每一部、每一深度都可比較至數；她的具體量法是觀患者吸氣頂峰、連續三息數脈並取平均。
