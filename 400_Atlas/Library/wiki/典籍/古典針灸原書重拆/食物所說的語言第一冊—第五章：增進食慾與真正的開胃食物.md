# 第五章：增進食慾與真正的開胃食物

> 作者的「開胃」不是餐前填肚子，而是讓唾液、胃火、下行與食積清理為正餐做好準備。這張卡保留了可直接用在餐桌的食物名單與不適合作開胃的項目。

## 真正開胃的四個工作

開胃小食要刺激唾液、清前餐食積、幫胃氣下行、溫和升胃火以準備蛋白消化與愉快饑餓。作者認為傳統前菜常有此智慧，但也有例外。

- **苦味小點**：橄欖、雅枝竹。
- **鹽水漬／醋漬**：鹽水橄欖、雅枝竹；醋漬甜菜、胡蘿蔔、青番茄、小黃瓜。蒔蘿幫膽汁等消化液分泌。
- **根菜與脆口物**：胡蘿蔔、紅蘿蔔、白蘿蔔、豆薯使氣下；消化強者可生或微燙，咀嚼震動下頜又激發胃經。胡蘿蔔甜脆助胃脾，蘿蔔辛能處理脂肪／起司造成的滯。
- **天然發酵少量**：酸菜、味噌湯／味噌、克菲爾、泡菜、康普茶；作者說可醒肝膽、助分泌、消食、胃氣下。

酒的例外是可安全飲者餐前極少量：梅酒或雪莉約 1–1.5 盎司；其甜可提食慾、準備脾分泌、調肝膽，但多飲加重負擔又易增重。不能喝或兒童可用葡萄酒／米酒入菜，讓酒精大致蒸散而留食療效果。

## 如何用食物讓唾液與食慾回來

作者列苦菜（苦苣、紅菊苣、廣葉菊苣、巴西里）、胡蘿蔔芹菜等脆口物、蘋果梨水梨、少量柑橘。香料都能行津，尤其生薑、茴香籽、八角、豆蔻、葛縷子；可入菜、泡茶、餐前／後嚼。家用比例是每杯熱水一小撮散裝香草；鮮薑每杯三片、八角每人一顆。綠茶或薄荷、洋甘菊、菊花、紫蘇、生薑茶亦可。

他說若健康飲食沒有可咀嚼脆食，人常在傍晚渴望洋芋片等不理想食物並暴食。

## 看似前菜，卻不是開胃

| 項目 | 作者的理由 |
| --- | --- |
| 冰物、冰水 | 消化需全然溫暖。 |
| 寒涼／生食 | 削弱胃火，使消化更難。 |
| 麵包 | 過調胰脾、沒有下行性、易飽又乾；宜作一餐的穀，而不是正餐前。 |
| 起司 | 慢消、方向不清；若吃，較宜兩餐間點心。 |
| 餐中大量水 | 稀釋胃酸與分泌；水提前約 20 分鐘喝。 |

消化弱者、或大餐油重餐前更需要真開胃；作者邀讀者下次節慶餐先給這類前菜，親自比較它與起司、麵包、炸點、奶油沾醬開場的差異。
