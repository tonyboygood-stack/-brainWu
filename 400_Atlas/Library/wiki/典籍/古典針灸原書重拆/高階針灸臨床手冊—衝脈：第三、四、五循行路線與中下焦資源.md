# 衝脈第三、四、五循行：活血、結構與水穀

## 第三路：把陽氣升到督脈起點以活血

作者說第三路由衝經帶脈連督，將陽氣升至督脈起點；血瘀或血虛而痛時，用陽活血。它從血會兼膈俞 BL-17 的背俞系統受影響，並處理寒或血虛所致肝鬱與平滑肌、尤其子宮氣機不暢。

**主治**：難治痹與關節痛、九竅閉塞、腰僵與椎間盤突出、骨折、血瘀、下陷與孔竅漏泄、腸漏、克隆氏症／腸躁、膀胱大腸濕熱、小產與帶下等不能固攝的婦科問題、念珠菌、肌瘤、內膜異位、PMS、泌尿生殖問題、前列腺炎、失禁、下焦刺痛與愛迪生氏病；心理面則以陽維持秩序、血儲記憶，故作者列阿茲海默、失智與記憶提取困難。

**穴位與治則**：CV-2、ST-30、GB-26、GV-1 或 GV-4、BL-17；振陽以祛血瘀痹。例為 SP-4、GB-26（瀉）、GV-4（補）、BL-17（補）；可加 BL-11 處血瘀痹，必要時 SI-3 助陽行或 GB-41 鬆宗筋。處下焦時，作者要求以 GB-22 或 LU-1 開胸。流程為側臥、SP-4（女右男左）→ 標誌穴 → 其餘路徑穴 → 逐針震顫／觀想／深層脈診 → 40 分留針 → 脈診、先拔開穴、靜臥五分。

## 第四路：向下支持姿勢與骨骼

第四路是衝脈第一條下行路，作者說它化生蹻脈，將腎精送足背以支撐結構與骨骼，協助腎支持姿勢，升托資源流失而虛陷的組織，也把陽送給脾。

作者列姿勢受陽失影響、氣喘、血瘀型陽虛、腸胃問題、發育遲緩、矮小與侏儒；心理面為當下自我感差與心神失衡，也記錄孩童急於走路或兩歲未走路，並寫行走不應強教，而待肌骨與陽氣化育成熟。

穴位為 KI-11、KI-10、BL-40，經 KI-6、KI-3 至「Kidney Prime（腎為本，KI-1 後方，見圖）」，全可灸；非必要配 KI-6。治則是以腎陽升脾氣來支持姿勢。流程 SP-4（女右男左）→ KI-10、BL-40、腎為本 → 細震顫 → 所有循行穴安全灸至熱入 → 觀想連結、深層脈診、40 分留針及同樣收針靜臥程序。作者對腎為本的描述是一寸針、重壓針管、緩慢盡深推入，越深常越溫和。

## 第五路：水穀之海、肝血與肌肉營養

第五路健脾、養肝血，讓後天氣支持腎陰而不耗血；肝血不足加重脾負荷。作者以 ST-30、ST-36 為水穀之海的上下輸送點，讓四海獲得食物營養，並到脾肝起點以平衡脾虛、肝木乘脾。此路把營養送到肌肉。

作者列脾虛、食積、噁吐、腹瀉、腸風、潰瘍性結腸炎、乳糜瀉、GERD、痔瘡、腸鳴、臍痛、濕熱發酵，以及由飲食、酒、房勞、邊緣系統黃疸引發的五疸。穴位為 ST-30、ST-36、ST-37、ST-39、ST-42、LR-1、SP-1；ST-37、39 輸血，ST-30、36 輸水穀，ST-42 升胃清陽並送營養至肌肉。肝木乘脾取 LR-1 與 SP-1；神志不安或血熱出血取 SP-1；血瘀調氣血津液取 LR-1。

治則為補脾氣滋胃陰，並把胃清陽／津液上送九竅。SP-4（女右男左）後取標誌穴如 ST-30、ST-36、ST-42，再順路取餘穴；所有穴震顫，確認細微震感與穴間連結，深層脈診，40 分留針，之後脈診、先拔開穴、靜臥五分。作者若要加入另一條經，要求選元氣層穴位。

→ 接續：任脈治療。
