# 診斷窗口：脈、舌、觸診、症狀與生活史如何讀同一個身體

> 整合入口：[[古典針灸系統整合 MOC]]  
> 前一張：[[古典針灸系統—資源動力：衛氣、津液、血、精、氣與陰陽如何決定病勢]]

## 整合命題：沒有任何一扇窗能單獨代表整個身體

八書給出的不是五套互相競爭的診斷法，而是同一個身體的多面觀測。脈使人觸到深度、質地、方向、資源與經絡層；舌使人看見身體已在表面留下的濕潤、顏色、運動、苔、裂與舌下痕跡；觸診與動作使人接觸經筋、皮部、疤痕、關節與可見絡脈；症狀與病史則把這些訊號放回時間、季節、飲食、睡眠、情緒、創傷與人生階段。

整合診斷的工作不是「找哪一項最準」，而是問：這些窗口是否正在講同一個方向？若不一致，差異本身可能表示層次不同、病勢正在移動，或部分資源與部分功能正呈現不同步的狀態。

## 五扇窗讀同一條病勢

| 窗口 | 它最擅長告訴你的事 | 它不能單獨決定的事 |
| --- | --- | --- |
| 脈 | 當下的深度、位置、質地、速度、規律、方向與治療後變化；可主動探查經絡層。 | 不能脫離病史就把一個脈象固定成唯一診斷。 |
| 舌 | 已可見的表面反應：苔、舌質、色澤、濕潤、形態、裂紋、舌下、區域與動態。 | 一張照片或單一顏色不足以代替整個人的時間脈絡。 |
| 觸診／動作／皮部 | 張力、痛、拘急、腫、疤痕、關節、單側或交替的空間位置。 | 不能只把局部痛點等同於病勢的全部路徑。 |
| 症狀與功能 | 消化、食慾、排便、睡眠、呼吸、月經、生殖、感官、疲勞及情緒如何實際運作。 | 症狀名稱本身不會指出是哪個經絡層在處理它。 |
| 生活史與餐桌 | 發作前後的外感、創傷、壓力、作息、飲食、生熟溫涼、季節、關係與人生需求。 | 不可把單一生活習慣抽離身體當下資源，直接當成原因。 |

## 脈診在整合中的位置：問身體正在動用哪個層次

《脈診的藝術》讓脈不只對應臟腑。從表層的經筋緊脈、絡脈的血分／伏邪、經別的淺深與關節性伏脈，到奇經八脈的更深手感，脈可被用來探查系統正動用哪種保護策略。它還讓左右、位置、深度與方向具有意義：不是「脈名＝病名」，而是身體正在向外釋放、向內保存、還是資源正難以維持的即時問題。

因此整合卡會把脈視為**動態提問工具**：初診摸到什麼，治療或生活調整後是否改變，往往比第一次為它下定義更重要。

## 舌診在整合中的位置：看身體把什麼留在表面

《舌診》使可見的舌不只是臟腑地圖。舌苔可連衛氣、津液與熱反應；舌體的姿勢、厚薄、色澤、乾濕、裂紋、齒痕與芒刺，讓人看見不同介質與不同反應；舌下靜脈、舌根與特定區域又把讀法帶入絡脈、經別、奇經、三焦及下焦／先天的語境。

整合上，舌特別適合回答「資源和病勢在一段時間內留下了什麼形態」。與脈相比，它通常呈現的是較可見、較具累積性的痕跡；兩者合讀，才能同時看見正在發生的動態與已形成的表現。

## 觸診、動作與空間：讓圖譜回到身體

經筋圖譜提供寬度、重疊與結聚點；絡脈圖譜提供羽狀展開、縱橫連結與可見脈的位置；經別與奇經圖譜把關節、胸腹、頭面、脊柱與骨盆放到同一張空間地圖。觸診、動作、疤痕、皮部與左右差異使這些圖不只是背誦路線。

整合診斷要問的不是「此處是哪一穴」，而是：哪個區域正在緊、痛、空、腫、敏感或失去動作？它與脈、舌、臟腑功能及時間史是否相互呼應？這使局部身體訊息可以回到系統層，而非被孤立為骨科或情緒問題。

## 從生活史建立時間維度

作者在病例、飲食與生活書裡不斷追問：什麼時候開始？此前有外感、胃腸事件、受傷、關係改變、少睡、過勞、飲食改變、月經／生殖階段或季節切換嗎？這些問題不是附加閒聊；它們讓目前的脈舌訊號有前因、有資源帳，也有可能的出口。

尤其飲食史不只問「吃得健康嗎」：是生或熟、冷或溫、乾或濕、補或瀉、餐食如何組合、吃的時間與身體食慾如何？生活史亦不只問壓力大不大，而是睡眠、排便、活動、休息、環境光、新聞、關係與可照顧自己的時間是否真正允許資源恢復。

## 一個整合的閱讀順序

```text
1. 先聽時間與主訴：這段變化從何時、何種條件開始？
2. 看功能與資源：消化、排泄、睡眠、濕潤、能量、週期仍如何運作？
3. 看舌與身體：留下哪些表面、形態、空間與動作痕跡？
4. 摸脈：此刻哪個深度、方向、資源層與經絡層最突出？
5. 再回到全體：各訊號是同一策略的不同面向，還是顯示病勢正在轉換？
6. 處理後復看：脈、舌、觸感、症狀、睡眠、排泄與食慾往哪裡變？
```

這是編者整合後的閱讀流程；它的要點不是每次都做滿所有步驟，而是避免以單一症狀、單張舌照或一次脈診，取代身體整體的故事。
