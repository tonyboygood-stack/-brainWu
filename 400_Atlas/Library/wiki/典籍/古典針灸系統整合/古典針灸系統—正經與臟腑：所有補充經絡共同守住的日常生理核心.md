# 正經與臟腑：所有補充經絡共同守住的日常生理核心

> 整合入口：[[古典針灸系統整合 MOC]]  
> 前一層：[[古典針灸系統—奇經八脈：當病勢觸及先天、生命軸線與深層容納]]

## 整合命題：正經不是「最表面」也不是「最後一站」

在補充經絡的敘事強烈時，很容易忘記正經與臟腑才是整個系統必須持續守護的中心。它們每分每秒完成消化、呼吸、循環、排泄、感官、睡眠、運動、生殖與情緒相關功能。經筋、絡脈、經別、奇經八脈之所以要阻擋、容納、轉移或保存病勢，正是為了讓這些功能不致立即失守。

因此，正經不該被安排在病勢圖的最深或最末，而要畫在中央；同時它又跨衛、營、元三個資源場。它可接收表層、參與營分輸布，也可在深層與元氣／經別相連。整合系統不是「補充經絡 versus 正經」，而是**補充經絡為日常正經生理創造生存條件**。

## 功能不是器官孤島：十二正經是一張持續運作的網

圖譜書將十二正經的主線、內部分支和相關穴位放在同頁，使臟腑功能不再是單一器官的位置，而是有外在經路、胸腹聯繫、頭面分支、感官與四肢的網絡。這提供了整合上最重要的提醒：

- 消化不是只有胃；它連到脾、肝膽、小腸、大腸、津液、氣機、餐序與排便。
- 呼吸不是只有肺；它連到鼻喉、皮毛、衛氣、胸、痰、悲傷、皮部與大腸的出口。
- 心與小腸不只在胸；它們連到液、血、睡眠、腦、感受與上下之間的分配。
- 腎與膀胱不只在下背；它們連到精、骨、腦、下焦水道、生殖、恐懼、恢復與長期容納。

這些不是要把所有現象歸進某一臟腑，而是讓功能樞紐頁可以同時容納經路、資源、症狀、脈舌、食物與生活條件。

## 三焦：把「臟腑功能」連回資源與方向的總介面

食物第一冊用上焦、中焦、下焦安排食物策略；舌診用舌的區域與氣機向量重新觀看三焦；脈診與經別又讓三焦成為氣化、濕熱、資源與深層調度的節點。整合後，三焦是跨書最有用的介面之一：

| 焦 | 它在整合上幫我們連起的內容 |
| --- | --- |
| 上焦 | 呼吸、胸、頭面、感官、衛氣分布、與外界相遇。 |
| 中焦 | 食慾、消化、轉化、血津化生、餐序、溫煦與運輸。 |
| 下焦 | 排泄、水道、骨盆、生殖、腎精、固攝、帶脈與長期容納。 |

三焦不是把人切成三段，而是讓「吃進去的東西如何被化生、分布、使用與排出」和「病勢在哪個空間被處理」可以放在同一幅圖上。

## 為什麼食物與生活在正經核心，而非外圍

食物書的補瀉、溫涼、升降、五味、烹調與餐序，本質上是在調整正經與臟腑每天獲得的材料、溫度、濕潤度與負荷。第二冊的食譜進一步把這變成真正的一餐；生活書用睡眠、排便、節律、活動與環境確保功能有恢復時段。受孕力書則放大顯示：當身體要建造與固攝一個新生命，消化、血津、溫煦、下焦與休息如何成為不可分的正經生理條件。

所以「飲食衛教」不該放在針灸後的最後一欄；它是正經能否維持、衛營元能否化生、補充經絡是否還有餘裕的基礎條件。相反地，食物也不能被視為脫離辨證的萬用答案：每一道料理都要受當下病勢、資源、消化力、季節與人生階段調整。

## 功能樞紐將如何展開

下一階段不會為十二臟腑各做孤立百科，而會建立幾個有「雙向交通」的樞紐：

| 功能樞紐 | 將整合的核心題目 |
| --- | --- |
| 脾胃／中焦 | 化生、食慾、津液、餐序、濕、升降、肌肉與資源入口。 |
| 肝膽／少陽 | 流動、血、方向、側身、感官、決斷、食積與向外展開。 |
| 心小腸／少陰 | 血與液、胸與腦、睡眠、接納與分別、內在分配。 |
| 肺大腸／太陰陽明 | 呼吸、皮毛、外界、乾濕、排出、悲傷與末端出口。 |
| 腎膀胱／下焦 | 精、水道、骨、腦、生殖、恐懼、深層恢復與關節伏邪。 |
| 生殖、胞宮與帶脈 | 建造、血、津液、溫煦、固攝、週期、妊娠與產後。 |

每一樞紐都會從正經功能出發，再接上經筋、絡脈、經別、奇經的相關段落，並放入脈舌、食物、生活與病例入口。這樣「脾胃」或「肝膽」才不會又變成省略太多、無法和病人溝通的器官標籤。
