# 寒熱濕燥與食物方向：讓食材、烹調與病勢放在同一張圖

## 整合命題：食物的作用在於改變身體的方向與條件，而非套上固定屬性

寒熱濕燥、升降出入、補瀉、五味與烹法，是八書把抽象病生理轉譯到餐桌的共同語言。它們不能被用成「某食物永遠治某器官」的標籤；作者更在意的是：這個人此刻偏冷還是偏熱？介質偏乾、偏濕還是被卡住？需要上提、下降、宣散、收斂、滋養或清出空間？同一食材在生食、蒸、炒、煮湯、烤、加香料後，可能回答不同的問題。

## 四個不是對立的讀法

| 語言 | 整合上的含義 |
| --- | --- |
| 寒／熱 | 問溫煦與反應強度是否足夠、過度，或已使介質改變。 |
| 濕／燥 | 問身體是否有可用的潤澤與介質，還是停滯、黏滯、耗傷。 |
| 升／降／宣／收 | 問氣機與食物方向是否幫助所需的輸布、排出、表達或固攝。 |
| 生／熟與烹法 | 問食物是否真正能被此刻的消化與資源狀態利用。 |

這四組可同時成立。例如一個人可能既有乾燥與熱耗，又有中焦寒滯；也可能在需要恢復濕潤時，仍有一部分積滯需要出口。整合卡保留這些並存，而不是替人硬選唯一屬性。

## 從病勢到餐桌的翻譯順序

1. 先由脈、舌、功能與病史確認當下偏向及資源條件。
2. 再決定餐食主要意圖：溫煦、潤養、化生、宣散、下降、收澀或清瀉。
3. 以烹法、食材組合、香料、湯與餐序完成意圖。
4. 持續觀察食慾、排便、睡眠、口乾、痰濕、舌苔與脈舌變化，調整方向。

此順序使食物不只是「配合針灸」，而和針灸一樣參與改變病勢可以停留、移動或釋放的條件。
