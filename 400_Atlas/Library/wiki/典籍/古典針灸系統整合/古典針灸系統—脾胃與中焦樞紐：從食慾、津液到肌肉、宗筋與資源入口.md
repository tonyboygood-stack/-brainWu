# 脾胃與中焦樞紐：從食慾、津液到肌肉、宗筋與資源入口

> 整合入口：[[古典針灸系統整合 MOC]]  
> 資源底圖：[[古典針灸系統—消化與中焦：所有資源化生、餐食判讀與氣機升降的起點]]

## 整合命題

脾胃是全系統的入口與轉運站：食物能否被接納、煮熟、轉化並送往全身，決定衛氣、血津與可用氣能否持續化生。它因此同時出現在飲食、脈舌、經筋、絡脈與經別的敘事裡。胃脾第三合以「津」作媒介，又使中焦問題不只停在腹脹或食慾，而可牽到宗筋、感官與關節伏邪的資源條件。

## 從不同窗口讀同一個樞紐

| 窗口 | 可讀的脾胃／中焦面向 |
| --- | --- |
| 功能與生活 | 食慾、餐後感受、排便、餐序、早餐、熟生溫涼與疲勞。 |
| 舌 | 舌中央、苔、濕潤、厚薄、裂紋與中焦熱／濕／津液。 |
| 脈 | 關位、脾胃動態、食物與資源能否被運輸。 |
| 經絡 | 胃脾經筋與肌肉、胃脾絡脈的營分、胃脾經別的津與宗筋。 |

## 整合後的實用閱讀

面對中焦問題，先別急著問「該補脾還是清胃」。先問：這個人是否能吃、能消化、能形成津液、能向下排出、又能把資源上輸？然後才以食物的補瀉與方向、烹法、作息，以及經絡層的脈舌觸診，決定目前是要讓系統有材料、騰空、溫煦，或恢復下降出口。
