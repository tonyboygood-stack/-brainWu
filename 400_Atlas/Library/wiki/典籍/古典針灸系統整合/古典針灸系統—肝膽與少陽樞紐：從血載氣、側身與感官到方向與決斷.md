# 肝膽與少陽樞紐：從血載氣、側身與感官到方向與決斷

> 整合入口：[[古典針灸系統整合 MOC]]  
> 前一張：[[古典針灸系統—脾胃與中焦樞紐：從食慾、津液到肌肉、宗筋與資源入口]]

## 整合命題

肝膽／少陽在八書中是「讓資源能移動、讓人能朝一個方向展開」的樞紐。它同時接血、氣、側身與頭面感官，也接食積、壓力、情緒、眼耳、膽絡與第二合經別的下焦伏邪。故它不能被簡化成情緒或肝火；核心問題是：血能否承載氣、氣能否使生活與身體仍有方向、以及這份流動是否在付出過多資源。

## 五扇窗

| 窗口 | 肝膽／少陽可讀的面向 |
| --- | --- |
| 功能與生活 | 壓力下的方向感、決斷、飲食積滯、睡眠與恢復。 |
| 舌 | 兩側、色澤、邊緣與肝氣鬱結演變。 |
| 脈 | 關位的肝脾動態、血與氣的質地、方向性。 |
| 經絡 | 側身、頭面、眼耳、膽／肝絡脈與第二合。 |
| 食物 | 綠葉、芽菜、果實、香料及其宣散、收斂、下降的方向。 |

## 整合後的閱讀

肝膽問題要同時看「流不流」與「有沒有可流的血津」。一味推動可能耗損血與津；一味滋養而沒有出口又可使積滯更明顯。少陽因此是最適合用脈舌、側身觸診、時間史與餐食方向交叉確認的樞紐：先辨病勢是被卡、被熱耗、被濕困，還是資源不足而無法順暢，才回到對應原書。
