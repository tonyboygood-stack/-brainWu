# 第五至六章：讓胃準備好，而不是用禁忌壓住它

> 作者在這兩章所做的事很細緻：他不把「開胃菜」當裝飾，也不把胃只當成酸的容器。他想讓一餐從食慾、唾液、咀嚼與下行開始，然後由濕潤、溫和甘味、適度苦味與可消化的份量把食物接住。這套說法可以成為很好的餐桌觀察，前提是不把它擴張成胃病自行治療。

## 第五章：真正的開胃，是讓下一餐有地方可去

作者認為開胃食物有四個工作：刺激唾液、幫前一餐向下移動、讓胃準備接納食物、在不過度刺激下帶來愉快的飢餓感。他推薦的不是一大籃麵包或濃起司盤，而是小份、能讓口腔和胃開始工作的食物：

- **橄欖、雅枝竹**等苦味或鹽水漬小點；
- **醋漬甜菜、胡蘿蔔、青番茄、小黃瓜**；
- 消化力允許時的**胡蘿蔔、白蘿蔔、豆薯、芹菜**等脆口根菜；
- 少量發酵食品，如**酸菜、味噌湯、克菲爾、泡菜、康普茶**；
- **蘋果、梨、水梨、少量柑橘**；
- 餐前或餐後的**薑、茴香籽、八角、豆蔻、葛縷子**熱飲，及綠茶、薄荷、洋甘菊、菊花、紫蘇茶。

這張清單不是「前菜處方」。有胃灼熱、胃潰瘍、食物過敏、腸胃敏感或正在做低鈉／低酸等醫療飲食的人，醃漬、醋、發酵與辛香料可能並不合適。最實用的做法是從一樣、少量、熟悉的食物試起，觀察飢餓感、逆流、腹脹與排便，而不是在一餐塞進五種新食材。

### 酒不是開胃治療

原書列出梅酒、雪莉、米酒或葡萄酒作為少量開胃選項，也說不能安全飲酒者應避免。資料庫的界線更明確：不建議為了食慾、消化或健康開始飲酒。若不飲酒、未成年、孕期、正服用會與酒精交互作用的藥物、有肝病、酒精使用困擾或其他風險，完全不飲是正確選擇。食慾的準備可用湯、香草熱飲、少量可耐受的食物、規律餐次與休息完成。

## 不必把麵包、起司和水妖魔化

作者批評冰冷食物、大量餐中飲水、麵包與起司當作「自動前菜」，因為它們可能太快讓人飽、太乾或較慢消化。這份提醒可用來問：「吃主餐前已經很撐了嗎？是不是常以麵包、炸物或濃沾醬代替正餐？」但它不代表麵包、起司或喝水本身有害。

一個實際修正是：若主餐前常吃到飽，改為小份前菜或直接減少等待時的零食；水分仍應分散在整天補足，不需要刻意脫水。若醫師建議隨餐喝水、需要吞藥或有特定水分限制，應以醫囑為先。

## 第六章：胃喜歡什麼？把作者的答案放回一碗飯裡

作者說胃喜「濕潤、溫和甘味、降氣與舒緩」，胰—脾則協助轉化、輸布與向上。他以「胃陰」比喻保護性的黏膜與津液，以「胃火」比喻消化活動。這是古典功能語言，不等同胃酸檢測值、胃黏膜檢查或胰臟／脾臟的西醫診斷。

他給出的食物與料理非常具體：

| 想支持的餐食特徵 | 作者列出的實際食物／做法 |
|---|---|
| 濕潤、較容易入口 | **米、小米、玉米、大麥、櫛瓜、南瓜、地瓜**；蒸、煮、燉；湯、燉菜、粥、燕麥粥、濕潤砂鍋菜 |
| 溫和甘味與中焦主食 | **米、燕麥、蕎麥、藜麥、莧菜、高粱、畫眉草**；地瓜、奶油南瓜、其他南瓜 |
| 帶來苦味或下行感 | **橄欖、雅枝竹、苦苣、紅菊苣、蒲公英葉、西蘭花筍、苦瓜**；胡蘿蔔、防風草、白蘿蔔 |
| 香料與草藥 | **薑、薑黃、孜然、小豆蔻、芫荽籽、茴香籽、葛縷子、八角、肉桂、迷迭香、奧勒岡、羅勒、百里香、蒔蘿、巴西里、芫荽葉、蔥** |
| 堅果、種子與蛋白 | **榛果、夏威夷豆、南瓜子、葵花子、雞肉**（均視耐受、份量與整體餐食調整） |

作者特別重視雞湯：雞、胡蘿蔔等根菜、芹菜、巴西里、月桂葉、迷迭香、百里香、龍蒿與適量調味，經長時間熬煮後成為病後或疲憊時的滋養料理。這是一個很好的家常湯模板；但發燒、感染、慢性病、鈉限制、食物過敏或食慾嚴重下降時，該怎麼吃仍需依個別情況處理，不把雞湯視為免疫治療。

## 胃食道逆流：保留作者的問法，不能採用他的自行調酸法

作者將逆流主要讀成「胃氣上逆」，並列舉打嗝、噁心、便祕、咳嗽、胸口灼痛等可以一起觀察的現象。他提醒食物、份量、晚吃、壓力、便祕與吃飯匆忙可能有關，這些都是值得在病史中問的條件。

但原書將許多逆流歸於胃酸太低，並暗示用醋、肉類或食療增減胃火，這不適合作為自我處理準則；也不可因而自行停用 PPI、制酸劑或其他處方藥。逆流的成因和治療需要由臨床人員評估。胸痛、吞嚥疼痛或卡住、嘔血／黑便、持續嘔吐、明顯體重減輕、貧血、夜間症狀惡化或新發嚴重症狀，需優先就醫。

可在不改藥的前提下做生活記錄：晚餐與睡眠相距多久？是否吃得特別油、辣、酸、甜或過量？酒精、咖啡因、壓力和便祕是否同時出現？一次只改一項，例如把晚餐提早、縮小份量、改一部分烹調方式，再和治療者討論結果。

## 這兩章可直接變成的衛教對話

> 「我們先不決定你有哪一種體質。先看：你餓的感覺是舒服的，還是常噁心、過飽、脹或逆流？你吃飯前是不是已經靠零食把自己吃飽？有沒有一種簡單、溫和、你願意連續吃兩週的餐，讓我們看看身體怎麼回應？」

這保留了作者的「胃要被好好迎接」的精神，也讓病人從真實的早餐、前菜、湯與晚餐開始，而不是被一串胃部禁忌淹沒。
