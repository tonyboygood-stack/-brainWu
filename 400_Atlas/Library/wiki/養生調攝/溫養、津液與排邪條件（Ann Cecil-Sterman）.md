# 溫養、津液與排邪條件

## 三個衛教目標

原書以溫水、溫熱／熟食、保暖、休息與規律二便來說明一件事：身體若要把病邪向外／向下處理，需要**溫煦的推動、可用津液與通暢出口**。這與 [[舌苔、衛氣與津液（Ann Cecil-Sterman）]] 的「衛氣需要津」是一個接口。

| 要保留的條件 | 原書中的日常入口               | 總圖中的意義               |
| ------ | ---------------------- | -------------------- |
| 津液載體   | 溫和補水、滋潤性飲食、避免過度脫水與極端排毒 | 有條件排尿、排便、汗出，也有條件維持伏邪 |
| 溫煦與衛氣  | 防寒、頸／下腰／下腹保暖、避開不當冷刺激   | 讓經筋與衛氣維持防禦及外出方向      |
| 排泄出口   | 規律排便、辨認腸道阻滯、休息支持排邪     | 避免病邪在媒介不足時被迫轉深或停滯    |

## 兩個不可混淆點

1. **排出不等於越多越好。** 原書反覆警告，長期強烈「排毒」、腹瀉、過度出汗或利尿而未補媒介，可能使氣與津液更少；此時不應把更多排泄預設為好轉。
2. **表現為發熱、鼻涕、噴嚏、腫脹或皮疹時，不可只靠日常規則判讀。** 它們可能與排邪／反應有關，也可能需要醫療評估。衛教的任務是提供病史與追蹤資訊，不是鼓勵延誤照護。

## 舌脈接點

乾、無苔、細弱／資源不足時，優先檢查是否仍有足夠津液與氣承擔排邪；濕、腫、厚苔時，需先與紅絳、深層數脈及病史區分「濕為病理」或「濕在制約熱」。不以保暖／補水作為全體通用處方。
