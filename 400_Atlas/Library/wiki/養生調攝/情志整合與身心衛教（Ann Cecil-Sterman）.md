# 情志整合與身心衛教

## 不是把情緒變成病因指控

原書把壓力、過度刺激、未整合事件、環境負荷與身體緊縮連到肝、心、心腎與維脈／任脈的語言。資料庫保留的是一個衛教原則：**承認負荷、提供可做的記錄／休息／界線選項，並不以責備要求人「想開一點」。**

## 三個可接到病生理的支持面

| 日常支持      | 原書的功能語言                   | 系統位置                         |
| --------- | ------------------------- | ---------------------------- |
| 降低刺激與環境負荷 | 新聞、螢幕、雜物、工作與睡眠界線          | 減少肝氣／心神持續緊繃及陽氣耗損的誘因          |
| 專注與感恩     | 用餐、面對面連結、休息與身體覺察          | 支援脾胃接納、心神安定與行為改變             |
| 承認與記錄生命事件 | 書寫、語音記錄、在可信空間分享；必要時尋求專業支持 | 為未整合經驗建立外在記錄，避免把它只留在身體作為「證據」 |

## 重要邊界

創傷、焦慮、憂鬱、自傷風險或功能顯著受限，需要合格心理健康與醫療專業的評估。書寫／按摩／調攝可作支持，但不應被資料庫表述為其替代治療。

## 與補充經絡的接點

這頁只支持「情志與生命史可能影響容邪／媒介與緊縮」的假說；要判絡脈、陰維脈或任脈，仍需回到 [[舌診與補充經絡（Ann Cecil-Sterman）]]、脈、身體指徵與完整病史。
