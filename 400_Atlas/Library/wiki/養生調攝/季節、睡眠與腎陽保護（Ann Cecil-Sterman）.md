# 季節、睡眠與腎陽保護

## 本書的共同主張

原書將「反覆以刺激硬撐」視為耗傷腎陽／元氣的生活模式：過亮夜間光線、忽略睡意、過勞、過度冷／熱刺激、將疲勞誤作需要更多刺激。它所要保護的不是抽象的養生分數，而是身體在排邪、溫煦、活動與恢復之間切換的餘裕。

## 可交付的行為方向

| 場景    | 來源主張的衛教方向                    | 系統用途             |
| ----- | ---------------------------- | ---------------- |
| 季節與夜晚 | 光線、活動與睡眠隨季節／日落收斂；冬季特別重視儲藏與安靜 | 降低不必要的陽氣動員       |
| 起床與白天 | 溫和醒來、早餐與規律日間活動，不用驚嚇式刺激啟動     | 讓後天之氣而非深層儲備支援日用  |
| 睡意與疲勞 | 辨識「瞌睡穴」、提早結束進食與螢幕刺激、在疲勞時休息   | 保護腎陽、恢復睡眠與消化的空間  |
| 運動與刺激 | 問清活動後是穩定恢復或靠亢奮硬撐；以個別狀態選強度    | 不把腎上腺式亢奮誤作真正資源充足 |

## 進入病勢總圖的問題

當人持續疲勞、夜間亢奮、靠咖啡因／刺激維持或睡後未復，先問「現有媒介還剩多少」而非直接提高排邪強度。此卡主要支持**重建媒介與保護資源**；它不能單憑作息描述指定某一經絡或替代脈診。

## 追蹤

以可感知、可重複的指標追蹤：入睡與醒來、日間疲勞波動、食慾、耐受活動、手足冷暖、舌的濕潤與目標脈。若出現明顯惡化或新的急性症狀，停止把它當作單純調養問題，回到臨床評估。
