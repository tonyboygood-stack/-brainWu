# 食療衛教建議單模板

> 用於把診療判斷轉成可執行、可回看的飲食支持；不是通用菜單，也不取代疾病治療、過敏／藥物評估或營養治療。每次先用 [[病勢—媒介—食物與烹調矩陣（Andrew Sterman）]] 選方向，再用 [[食療食材群索引（Andrew Sterman）]] 寫出實際食物。

## 1. 此次判讀錨點

- **病勢工作假說**：`排邪中／維持伏邪／容量超載／病邪顯露／待釐清`
- **媒介與中焦承接狀態**：`津液／血／氣／陽氣／腎精／元氣；食慾、餐後反應`
- **證據（至少兩項）**：`舌：`　`脈：`　`問診／病史：`
- **本次飲食意圖**：`保留津液／減少刺激／守中易消化／漸進增加纖維／支持下降／其他：`
- **已知限制**：`過敏、文化／素食、孕哺、糖尿病、腎／心／肝腸疾病、吞嚥問題、用藥、營養風險：`

## 2. 一至兩週的最小調整

| 欄位               | 本次內容                                         |
| ---------------- | -------------------------------------------- |
| 保留或增加的 2–3 個食物組件 | `例：小米粥；熟胡蘿蔔與白蘿蔔；菇類湯。請依本次判讀改寫。`               |
| 一道可重複的烹調模板       | `例：穀物／粥 + 熟根菜或綠葉菜 + 個人可承接的蛋／魚／豆類；蒸、燉或煮湯。`    |
| 暫時回查的一個誘因        | `例：晚間咖啡、酒、強烈辛辣、冰冷生食、過量糖或一種明顯不耐食物；不做無目的全面禁食。` |
| 份量與節律            | `規律餐次；以吃後舒適為上限。避免在疲乏、無苔或排泄不暢時激烈清瀉／斷食。`       |
| 不適即停的項目          | `本次新增食物若引發明顯腹痛、嘔吐、過敏、嚴重腹瀉／便秘或原症惡化，即停止並尋求評估。` |

- **回看日期**：`＿＿＿＿`
- **維持／替換／停止的條件**：`＿＿＿＿`
- **轉介門檻**：持續或加劇的疼痛、發燒、嘔吐、出血、無法進食或排泄、快速體重變化、過敏反應，或任何急性／嚴重症狀，均不以此表自行處理。

## 寫法範例（示範格式，不是對個人的建議）

`判讀：厚膩苔 + 餐後困重，但寒熱與脈象尚待合參。意圖：先讓餐食更容易被承接，不先全面祛濕。最小調整：一週內以薑蔥蒸熟菜、菇類湯、非糯穀物各替換一餐；只回查一個明確的高糖點心。追蹤：餐後困重、腹脹、排便與舌苔。若乾燥、疲憊或不適增加，停止加強此方向並重新判讀。`
