# 食譜模板、餐盤建構與烹調方向

第二冊的價值不在逐字照做，而在讓食療能被「替換」：同一餐的穀物、菜、蛋白、湯、油脂、醬料可隨病勢與耐受調整。

## 五個可替換組件

| 組件 | 原書食譜群 | 可調整的方向 |
|---|---|---|
| 餐前／開胃 | 開胃拼盤、湯、味噌沾醬等 | 食慾、胃氣、餐的進入速度與少量宣動 |
| 主食基底 | 米、小米、玉米、蕎麥、雙粒小麥等 | 補益／滋潤、可消化的體積、個別耐受 |
| 蔬菜與豆類 | 綠葉菜、根莖、菇、豆類、發酵蔬菜 | 升降、清瀉／補益、纖維與腸道耐受 |
| 蛋白與脂質 | 魚、豆腐、雞、紅肉、蛋與油脂 | 溫養、建構、飽足與消化負荷的平衡 |
| 湯、醬料與香料 | 高湯、醬汁、香料、調味 | 以少量修正滋潤、溫度、方向與可口性 |

## 廚房原則

- 先決定餐的目標，再挑食材；不要以單一「超級食物」承擔所有工作。
- 烹調法本身改變食物傾向：蒸、燉、湯、烤、快炒、生食等都要納入判讀。
- 食譜可適用於餐廳點餐／外賣，但仍需保留份量、時間、溫度與個別反應的記錄。
- 甜點、零食與早餐也屬全日餐序，不以「健康名稱」排除其對糖、飢飽與睡眠的影響。
