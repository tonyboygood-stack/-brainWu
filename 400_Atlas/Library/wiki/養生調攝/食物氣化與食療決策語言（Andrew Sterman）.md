# 食物氣化與食療決策語言

## 食物不是單一屬性

原書用下列座標描述食物與烹調的可能傾向；它們是選餐與調整的語言，不是食材的永久醫囑。

| 座標           | 問的問題               | 例：怎樣用在決策                  |
| ------------ | ------------------ | ------------------------- |
| 補益／清瀉        | 此刻需建構媒介，還是需協助清除？   | 資源不足不能把長期清瀉當作基線           |
| 溫熱／寒涼        | 此人的熱與寒何者為病理、何者為反應？ | 食物溫度與食材內在傾向皆要看            |
| 滋潤／燥濕        | 津液、胃陰與黏膜是否足夠？      | 不能把喝水等同補水；烹調與脂質也影響媒介      |
| 升／降／守中／宣表／收澀 | 氣機、排泄與容邪需要往哪個方向？   | 先判升降是否失衡，再選根莖、芽菜、種子等方向性線索 |
| 五味／臟腑連結      | 味覺與食物如何提示其功能傾向？    | 用來微調餐盤，不用來憑味道診臟腑          |

## 與病生理總圖的翻譯

`病勢 → 媒介餘量 → 消化能力 → 食物／烹調方向 → 舌脈與日常回饋`

食療的首要貢獻通常是**重建媒介、保護資源、減少誘因與支持可行的排邪**。若身體正在以濕固攝熱或以補充經絡維持伏邪，食療不應以「去除表面現象」取代病勢判讀。

## 原書的三氣接口

- 營氣：食物先需被消化、轉化、吸收；中焦是最常見的起點。
- 元氣：先天體質、腎與深層資源決定可承擔的調整強度。
- 衛氣：防禦與排邪需氣、津液與適當的向外／向下出口。

這三者直接接到 [[古典舌診 MOC（Ann Cecil-Sterman）]] 的苔／舌體／舌下三層，以及 [[古典脈診 MOC（Ann Cecil-Sterman）]] 的深度與媒介判讀。
