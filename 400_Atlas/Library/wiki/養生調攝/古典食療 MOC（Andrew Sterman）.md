# 古典食療整合入口

> 食療不是「病名 → 食材」，而是**病勢／媒介／消化能力 → 食物性質與烹調 → 日常回饋**。第一冊定義判讀語言，第二冊提供可變動的餐桌模板。

**先看這三張可直接用的卡**：[[病勢—媒介—食物與烹調矩陣（Andrew Sterman）]]（由病勢選方向）、[[食療食材群索引（Andrew Sterman）]]（看到實際食物）、[[食療衛教建議單模板（Andrew Sterman）]]（輸出個案衛教）。

## 食療決策順序

1. 是否有急性、嚴重、營養風險或既有疾病／藥物問題，需先由合格醫療專業處理？
2. 現在的瓶頸是誘因暴露、消化能力、津液／血／氣、排泄出口，還是深層資源？
3. 病勢是排邪中、維持伏邪、容量超載、病邪顯露，或入臟腑風險？
4. 食物需偏向補益或清瀉、溫或涼、滋潤或燥、升／降／守中／宣表／收澀的哪一個方向？
5. 以烹調、份量、搭配與餐序把方向落地，不以一個「超級食物」取代餐盤。
6. 與舌、脈、症狀、二便、睡眠和耐受度一起追蹤；無改善或惡化即回到診斷／轉介。

## 禁止捷徑

- 不把食物性質當成絕對營養／醫療事實。
- 不在無苔、脫水、嚴重疲勞或排泄不通時，將「清瀉／排毒」視為預設。
- 不因厚苔、濕或體重變化就預設祛濕；先查熱、媒介與脈象。
- 不讓食療取代急性醫療、疾病管理、過敏評估或合格營養照護。
