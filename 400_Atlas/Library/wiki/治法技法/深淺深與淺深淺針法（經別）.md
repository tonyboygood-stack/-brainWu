> Sterman 對經別的針法分兩大方向：**DSD（深—淺—深，Deep-Superficial-Deep）**把病邪重新導回伏邪狀態（適用於病理正在演變、伏邪能力尚存時）；**SDS（淺—深—淺，Superficial-Deep-Superficial）**把已顯露、依循行路線可辨識的病邪（多為肌肉骨骼病症）排出體外。兩者用穴幾乎相同，差別在意圖、順序與是否用井穴。

## 治療意圖的分野
- **DSD**：目的是把病邪帶回伏邪狀態並建立媒介，而非釋放病邪——**不使用井穴**。
- **SDS**：目的是把已經顯露的病邪透過經筋排出——固定用**井穴**收尾。

## DSD 進針順序
1. 交會穴（會穴）——通常依交會情況由上至下進針，不使用交叉穴
2. 開放穴——可雙側進針，或於第一針同側單側進針
3. 循行穴位——依個別診斷選取

**DSD 拔針順序**（與進針相反）：
1. 標準方案外額外加入的元氣層次穴位（先拔）
2. 循行穴位
3. 開放穴
4. 上合口／會穴，下合口／會穴

## SDS 進針順序（經別環）
1. 刮痧皮部或緊繃區域
2. 交會穴（會穴）——以「環」的方式針刺：先刺一側下交會穴，再刺同側上交會穴，接著對側上交會穴，最後對側下交會穴，中間以任脈或督脈上的**交叉穴**（GV-20 效果佳）連接兩側，讓病邪轉移到力量較強、能徹底排出的那一側
3. 開放穴——依環路側別雙側，或第一針同側單側
4. 循行穴位——從首針同側最遠端穴位開始沿該側向上針，交叉至對側再向下針
5. 井穴——與最後交會穴同側收尾

**經別環方向怎麼決定**（依受傷起源側判斷，黃金法則：井穴留在受傷起源那一側）：
- **情境 1**：傷始於左、痛現於右 → 左側已「填滿」伏邪容量、痛「溢出」到右側 → 環從右側起針，井穴留左側
- **情境 2**：傷在右、左側無顯現病史 → 右側尚未「填滿」，仍有力量推出 → 環從左側起針，井穴留右側
- **情境 3**：極長期、斷續、單側表現 → 很可能起於對側（目前無痛側），已耗盡容量後溢流至現痛側 → 環從現痛側起，井穴留對側

**SDS 拔針順序**：
1. 標準方案外額外加入的元氣層次穴位（先拔）
2. 循行穴位
3. 開放穴（若非交會穴）
4. 未配井穴那一側的交會穴、交叉穴，最後拔配井穴那一側的交會穴
5. 井穴

## 井穴功能
井穴不屬於經別循行路線的一部分。在 SDS 治療中，井穴的功能是**激活經筋**，為表層的病邪提供現成的排邪通道。DSD 治療中不使用井穴，除非出現好轉反應。

## 治療前準備：滯塞的釋放
經別治療成敗往往取決於滯塞的釋放——常見於頸部、骨盆、夾脊肌群、肩胛骨、胸鎖乳突肌、肩膀、斜方肌、腹直肌、乳房周圍、季肋、肋骨架上下、臀肌、腓腸肌（武術稱「五柱」）。刮痧（瓷湯匙或動物角刮痧板）至出痧、局部鬆開為止，SDS、DSD 皆適用——移動衛氣之前必須先解放滯塞。治療前給患者飲用常溫白開水：向身體傳遞「有足夠津液可供轉化」的訊號。

## 六合的合口選擇原則（如何依脈象/病情挑合口）
1. **脈細澀弱** → 該合口媒介不足，考慮換其他合口
2. **表層脈緊** → 身體正嘗試把病理推向經筋，適合 SDS
3. **臟腑強弱**：如患者血虛但脾強，可用脾經別支援肝經別備用
4. **媒介匱乏導致無法維持伏邪**：如患者津液極虛而脾弱，先用心／小腸經別建構前一層次的媒介（胃／脾），再處理胃／脾經別
5. **慢性、單側、間歇性病灶部位**：如慢性間歇 LI-15 疼痛，用大腸經別
6. 脈浮數而全部脈位皆然 → 陰不足以用前四合，改用三焦與心包經別
7. 脈弱或細的合口盡量不用；若必須用，DSD 加原穴

## 精油輔助
僅在交會穴塗抹**極微量**精油（牙籤沾取瓶口邊緣的量即可）——過量會使神經感受器過載而失效，且 BL-1 附近過量精油有移行入眼的風險。

| 經別 | SDS | DSD |
|---|---|---|
| BL/KI（膀胱／腎） | 茉莉(B)、松針(T) | 芹菜籽(M)、羅勒(T) |
| GB/LR（膽／肝） | 德國洋甘菊(M)、香檸檬(T) | 歐當歸籽(B)、冷杉(M) |
| ST/SP（胃／脾） | 芫荽籽(M)、丁香(T) | 胡蘿蔔籽(M)、絲柏(B) |
| SI/HT（小腸／心） | 沒藥(B)、橘(T) | 葛縷子(M)、松針(T) |
| TH/PC（三焦／心包） | 乳香(B)、薄荷(T) | 甘松(B) |
| LI/LU（大腸／肺） | 欖香脂(B)、薄荷(T) | 肉桂皮(B)、安息香(B) |

> T=前調、M=中調、B=後調。SDS 較高香調比例是較低香調的兩倍；DSD 相反。

## 區域經別治療（急性、多部位病症）
把同一區域對應的兩個經別連結治療，慣性病症用「五行經別治療」（即依六合逐一治療），**急性病症**（尤其多部位）用「區域經別治療」：
- 太陽：膀胱與小腸經別
- 少陽：膽與三焦經別
- 陽明：胃與大腸經別
- 太陰：脾與肺經別
- 少陰：心與腎經別
- 厥陰：肝與心包經別

操作要點：(a) 刮痧或走罐釋放對應皮部；(b) 務必含交會穴／會穴；(c) 用於釋放肌肉骨骼或皮膚科病症。經別理論中，病程少於三週大致算急性，仍需依個案臨床判斷。

## 經別皮部（區域治療用）
範圍較窄、比歷史上廣義皮部更複雜，是區域配對經別（BL/SI、GB/TH、ST/LI、SP/LU、HT/KI、LR/PC）在衛氣層面的連結，用於刮痧／走罐（患者坐姿刮出最多痧）：
- **太陽皮部**（胸部環帶）：GB-22 → CV-17、BL-44、BL-15、GV-11 繞胸一圈回 GB-22
- **少陽皮部**：a. 乳突（GB-12、TH-16 周圍，或延伸至 TH-18/19）；b. 季肋（LR-13、GB-25）；c. GB-25 至 CV-2、CV-3 帶狀區
- **陽明皮部**（衣領環帶）：GV-14 → GB-21 → SI-12、ST-12、CV-22 → 回 GV-14
- **太陰皮部**（喉部環帶）：包圍 ST-9、LI-18、SI-16

## 好轉反應與疑難排解
- **好轉反應**：療效顯現後，先前被壓制、未解決或潛伏的疾病重新顯現，是剝離能量滯塞的正常過程。
- **SDS 後疼痛僵硬仍在**：確認是否刮過皮部；是否食用寒涼生冷食物（沙拉、綠拿鐵、冰水、果汁、冰淇淋）；是否用冰敷（禁忌——冰敷限制衛氣流動，易致晚年關節痹阻）。
- **DSD 治療中突發疼痛**：定位痛處，衛氣層次進針、朝遠離前正中線方向旋轉 180 度後立即拔針、保持針孔開放；若疼痛仍在，針刺對應經筋的井穴，不留針。
- **針感無法在淺深層間接引**：可能是針材質或針柄類型不對。
- **治療失敗**：可能需刮痧釋放胸鎖乳突肌、膈肌、髂腰肌、腹肌、夾脊肌群、臀肌、胸骨、骶骨等伏邪易積聚處。
- **患者服用類固醇**：類固醇損害陽氣，降低身體維持媒介在原位的能力，會形成「身體嘗試排邪→類固醇阻撓→加量類固醇→更損陽氣」的惡性循環。
- **血檢示免疫亢進但血中未見病邪**：經別仍適用——身體可能在對抗一種能量狀態（如寒邪），或病邪幾乎完全處於伏邪狀態。
- **連續治療三天休息三天的用意**：連日治療是督促身體不要習慣把病邪留在體內或習慣失敗的排邪嘗試；休息三天讓身體整合訊息，天天治療反而可能被身體忽略。
