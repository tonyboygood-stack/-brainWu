## 定義與學派背景

> 🟢 「在溫病學中，以**陸懋修、惲樹珏、章巨膺、祝味菊**等為代表的醫家**強烈抨擊葉桂、吳瑭的四時溫病學說**，主張用《傷寒論》六經理法辨治溫病。對於溫病初起證，他們**堅決反對用葉氏的辛涼輕清疏透法**，極力推崇劉完素的防風通聖散、雙解散等『相和通解表裡』之方。」

**核心主張**：麻黃配石膏、辛溫辛寒並舉，才是「辛涼解表」治溫病表熱證的重要手法。發汗非麻黃不可，麻黃辛溫、用石膏調和其溫性。

> 🟢 「其代表方防風通聖散、雙解散、三黃石膏湯用於溫病表鬱證**具有銀翹散、桑菊飲等辛涼疏透方難以替代的療效**，用其治療雜病火熱鬱證更有理想的療效。」

## ★★ 本章與第一章是對立的兩條路線

| | 第一章 [[辛涼疏透法（張文選）]] | 第四章 本法 |
|---|---|---|
| 代表 | 葉桂、吳瑭 | 劉完素 |
| 方 | 銀翹散、桑菊飲 | 防風通聖散、雙解散、三黃石膏湯 |
| 手法 | 薄荷、牛蒡、銀花、連翹為主體的**輕清疏透** | **麻黃配石膏**，辛溫寒涼雜用 |
| 力度 | 輕 | 重（表裡上下同治） |
| 反對者 | 陸懋修、惲樹珏、章巨膺、祝味菊 | 遵葉吳學說者謂其「未真正脫卻傷寒」 |

> 🟢 **張文選的立場（不選邊）**：「臨床上**既要重視吳瑭銀翹散、桑菊飲所代表的辛涼法，也要重視劉完素防風通聖散、雙解散所代表的辛涼法**。雖然兩法的制方思路完全不同，但各有特點，**不可偏執一方**。在目前人們風行應用銀翹散、桑菊飲等方辛涼疏表的形勢下，**應更加重視防風通聖散、雙解散的臨床應用**。」

## 劉完素的理論根基

- **「六氣皆能化火」**（發揮《內經》病機十九條）
- **「傷寒即是熱病」**（本《內經》「今夫熱病者，皆傷寒之類也」）
- 由此推出：外感熱病表證**不得用麻黃湯、桂枝湯辛溫發汗**；初起多是怫熱鬱結，惟辛涼甘寒解表才是正治

> 🟢 劉完素自述：「餘自制雙解、通聖辛涼之劑，**不遵仲景法桂枝、麻黃髮表之藥**，非餘自銜，理在其中矣。故此一時彼一時，奈五運六氣有所更，世態居民有所變……故不可峻用辛溫大熱之劑。」（《素問病機氣宜保命集》）

**歷史地位**：「傷寒宗仲景，熱病主河間」。葉桂本人亦推崇：「後賢劉完素創議，迥出諸家，謂溫熱時邪，當分三焦，投藥以苦辛寒為主；若拘六經分證，仍是傷寒治法，致誤多矣。」（《幼科要略》）

## ★★★ 本章最重要的臨床發現：鬱火生風

這是張文選在本書中**原創性最強的一節**，也是最直接可用的一條。

### 現象

> 🟢 「我在臨床上發現：五志過極、飲食失節等原因導致鬱火內生，發為**心煩急躁、口渴欲飲、口舌生瘡、口唇紅腫疼痛起泡起皮、大便乾燥、小便短赤**等症時，**患者多有惡風、怕冷或惡寒的感覺，而且鬱火愈甚，惡風愈明顯**。凡遇到這一組特殊的證，用防風通聖散有**立竿見影**之效。」

### 理論根據（劉完素）

> 「**風本生於熱**，以熱為本，以風為標；凡言風者，熱也，**熱則風動**。」（《素問玄機原病式·熱類》）
> 「風火皆屬陽，多為兼化。」（《素問玄機原病式·五運主病》）

> 🟢 **張文選的推進**：「人們習慣於將火熱所生之風，與熱極動風、或火熱引起中風證聯繫起來……但是，**人們忽視了火熱也能產生類似於外感風邪襲表的『風』**，如鬱火證的惡風、怕冷，內生火毒引起的皮膚瘡瘍疹癬的風癢等。」

### ★★ 火鬱生風的四方分流表（可直接臨床用）

> 🟢 「對於火鬱生風而惡風怕冷，或上、下肢，背、腹部冰冷的辨治，**多數醫生沒有經驗，或無膽識，只知道用黃芪劑補氣，或附子劑溫陽，結果越治越重**。對此，如能撥開雲霧，辨識火鬱，**率用寒涼直瀉鬱火，多可取立竿見影之效**。」

| 兼見 | 選方 |
|---|---|
| 大便乾、便秘、裡實 | **防風通聖散**（本章正方） |
| 口乾或渴、汗出、脈滑數 | **白虎湯／白虎加人參湯**（第五章） |
| 舌赤苔黃、口苦口臭、煩躁易怒、大便乾燥 | **三黃瀉心湯類方**（第六章） |
| **胃脘、腹部惡風發涼** | **葛根芩連湯、黃連黃芩湯**（第六章） |
| 三焦火熱而**裡不實、無便結、或便溏** | **三黃石膏湯**（本章） |

> ⚠️ **這張表跨了本書四章**，是全書少數幾條橫向線索之一。相關醫案張文選散在各章：白虎湯章「唇風：王某，女，20歲」、瀉心湯章「大腿發涼：韓某某，男，50歲」「臀以下冰冷：董某某，男，65歲」、黃連黃芩湯章「胃痛腹瀉：賈某某，男，25歲」。**待第五、六章整理時回填連結。**

## 兩個方證的分工

| | [[防風通聖散方證（張文選）]] | [[三黃石膏湯方證（張文選）]] |
|---|---|---|
| 特徵性證 | 心煩急躁，**便秘尿阻**，口舌生瘡，皮膚斑疹 | 心煩急躁，口乾口苦，舌紅苔黃 |
| 有無硝黃 | **有大黃、芒硝**（含通下） | 無（可加） |
| 疏表力 | **較強** | 較弱 |
| 清熱力 | 較弱 | **較強**（芩連柏梔膏） |
| 適用 | 火鬱**裡實便秘**者 | 火鬱三焦、**裡不實、無便結或便溏**者 |

> 🟢 「特別是一派鬱火而見有**葛根芩連湯證**者，用三黃石膏湯或再合入葛根芩連湯有獨特的療效。」

## 本法在總框架中的位置

- **邪氣層**：火熱（六氣皆能化火）；火鬱生風、生溼
- **氣機通道層**：**表裡三焦俱鬱**——熱鬱營衛（表）＋熱盛三焦（裡）同時存在
- **策略層**：**表裡雙解、上下分消**（汪昂：「上下分消，表裡交治，而能散瀉之中，猶寓溫養之意，所以汗不傷表，下不傷裡」）
- **手段執行層**：辛溫發散組＋寒涼瀉火組**捆綁使用**——單用任一組都不成立
