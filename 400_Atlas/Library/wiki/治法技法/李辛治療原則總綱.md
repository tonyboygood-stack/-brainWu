## 操作說明

### 總綱五訣

> 🟢「**定其神、審其勢、利其行、⚠️□其度、顧其本。**」（原文行 848）

- **定其神** — 首先要穩定病人的神，神定則氣機穩定
- **審其勢** — 明晰邪正鬥爭的發展趨勢
- **利其行** — 協助「第一個醫生」完成邪正鬥爭，順應原本的方向（開或闔、向表或裡）以排除病邪
- **□其度** — 減緩邪正的反應強度，使之在患者可承受的範圍
- **顧其本** — 時刻留意本氣（中氣、元氣）之有無

> ⚠️ **OCR 損壞字的處理**：原文行 848 第四項首字為 `[?]`。
> **書內互證推定為「握」**——同書〈再論病機〉（原文行 655）列出處理慢性病復發的四原則：
> 🟢「第一，**得其機**……第二，**順其勢**……第三，**握其度**……第四，**顧其本**。」
> 兩份清單共有「其度」與「顧其本」，且釋義一致（皆為調控反應強度）。
> 標為**推定**，非原文確認。原書 336 頁，可覆核紙本。

### 四原則（處理慢性病復發，原文完整無損）

| 原則 | 內容 |
|---|---|
| **得其機** | 🟢「**是最重要的**，要抓住這次真氣提升的機會，利用新的邪正鬥爭，幫助鬥爭完成充分，祛除病根」 |
| **順其勢** | 因勢利導：汗法宣暢皮表膜理＝開上焦；導通大便、下降腑氣＝運通中焦；淡滲、化瘀＝通洩下焦水道或血分 |
| **握其度** | 🟢「調控身體的反應不至過強過猛，以免傷精破氣……**如同小火熬粥，火太大，粥溢而鍋損；火太小，氣冷而米僵**」 |
| **顧其本** | 根據資源水平與當下邪正反應強度，斟酌補充中下焦，以助病勢由陰轉陽 |

## 適應症

### 十條具體治則

| 治則 | 內容 |
|---|---|
| **通因通用** | 身體反應方向想要開通，就順應「通」。如中焦邪熱或瘀阻所致腹瀉，「向下通」是正常排邪反應，可用大黃順應之 |
| **塞因塞用** | 因中氣虛或下焦精氣不足導致的阻塞（如便秘），此時身體需要「闔」，用補益藥幫助完成——蓮子、肉蓯蓉、人參 |
| **其在表者，汗而發之** | 邪在表，氣機正常方向向外開，順應之，可以汗法驅邪 |
| **其在裡者，攻而下之** | 病機在裡，氣機方向向下，用有「降、洩」力量的藥 |
| **急則治標，緩則治本** | 大小便不利而病勢緊急，需先治之；等二便正常、病勢緩和，再治其本病 |
| **表解裡自和** | 表裡同病，若裡氣尚足，大方向是開表，裡也自解 |
| **裡和表自解** | 表裡同病但病機已入裡為甚，當先和其裡，表氣自開 |
| **釜底抽薪** | 壺裡乾燒沒有足夠的水，就把木柴移開。如食滯、溼熱所致腸道阻塞而高燒，可通便瀉下 |
| **胃不和則臥不安** | 中焦不和，神與睡眠易受影響 |
| **引熱下行** | ⚠️ 內有鬱熱阻滯時，**不能過於開表**（辛味風藥），否則加劇熱象（**風火相煽**），可通利二便引熱下行 |

> 🟢「**選擇正確的方向是療效的關鍵！**……治療中，面對種種症狀，**不能點對點思維、對症用藥**，調整氣機的大方向更為重要。」

## 禁忌/注意事項

### 不是壓症狀，是控制反應強度

> 🟢「我們需要做的，**不是去抑制機體的反應**，不能只是著眼於消除或掩蓋眼前的症狀——這是**錯誤的治療方向**，會干擾疾病發展自然的『勢』，錯失轉化的『機』。」
> 🟢「我們所能做的，是**控制身體的反應強度在可接受的範圍**（比如若發熱嚴重，可用滑石和石膏這一類甘寒藥，或微苦平涼藥），這樣病人不會太痛苦……真氣主導的抗病修復反應能夠繼續下去。」

### 主動創造機會（第四階段慢性病）

> 🟢「對於長期衰弱、處於第四階段的慢性病人，『內在的醫生』已經無力抗爭，因此需要**主動『創造機會』**，可謹慎選用一些溫補或『開』的藥，適度幫助氣機格局『由陰轉陽』。這個過程中**原來的症狀可能會明顯，甚至加重**。」

思路：**守中央、通四方、顧下焦**。

古法對應：中醫外科的「**陰證轉陽**」——治陰證瘡瘍用附子、黃芪、黨參、麻黃託舉陽氣。

> ⚠️ 🟢「在疾病發展過程中『抓住時機』和『創造機會』**並不容易**，要求醫生有非常敏銳的直覺和對疾病發展過程、邪正鬥爭層次足夠的經驗。」
