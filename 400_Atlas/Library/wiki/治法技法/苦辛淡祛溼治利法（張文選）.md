## 定義

> 🟢 「這一類方所形成的治法可稱為『苦辛淡祛溼治法』，此法以**藿香梗、厚朴、陳皮、茯苓**為基本用藥，或者合白蔻、滑石、豬苓、通草，或者合黃芩、白芍等藥組方，具有**芳化滲溼、升清降濁、開暢中焦氣機**的作用，用於治療**溼熱阻滯中焦**所引起的便溏、下利等病證。」

這一類方可稱為**加減正氣散類方證**。

## 源流：葉桂變通藿香正氣散

藿香正氣散出自《太平惠民和劑局方》，組成為大腹皮、白芷、紫蘇、茯苓、半夏曲、白朮、陳皮、厚朴、苦桔梗、藿香、甘草，主治傷寒頭疼、憎寒壯熱、心腹冷痛、氣瀉霍亂等，重在**解表化溼**。

> 🟢 「葉桂取藿香正氣散中藿香、厚朴、陳皮、茯苓4藥為基礎方，巧妙加味，形成了一系列變通正氣散法，用以治療溼、暑溼、洩瀉、痢疾等病證。」

吳瑭整理葉案，制定出**五個加減正氣散**（見 [[一加減正氣散方證（張文選）]] 內「加減變方」）以及**滑石藿香湯**、**四苓合芩芍湯**（原名四苓合蒼朮湯）——**《溫病條辨》實際上有七個加減正氣散方**。

## 葉桂用藿香正氣散的加減規律（本章核心）

以**藿香、厚朴、廣皮、茯苓皮（或茯苓）**為最基本四味，隨證加味：

| 兼證 | 加味 |
|---|---|
| 溼重 | 合四苓散法，加豬苓、澤瀉 |
| 暑熱較重 | 合六一散法，加滑石、通草 |
| 兼寒溼 | 加草果 |
| **溼熱在經絡，身體疼痛** | 合加減木防己湯法，加大豆黃卷、木防己、川通草、苡仁（見第九章 [[加減木防己湯方證（張文選）]]） |
| 溼熱痢疾，滯下重墜 | 合黃芩湯法加黃芩、白芍；或合香連丸法加黃連、木香 |
| 兼上焦溼 | 加白蔻仁、杏仁 |
| 暑溼腹瀉 | 多加木瓜 |

> ⭐ 五個加減正氣散中，一、二、三加減證**溼重熱微**（一加減用茵陳、二加減用通草豆卷苡仁、三加減用滑石，皆稍佐清熱）；四、五加減證**純屬寒溼**（四加減用草果、五加減用蒼朮，皆溫燥為主）。詳見 [[一加減正氣散方證（張文選）]]。

## 本法在總框架中的位置

- **邪氣層**：溼熱阻滯中焦（溼重熱微為主流，亦有純寒溼一支）
- **氣機通道層**：脾胃升降失司，三焦氣機不宣
- **策略層**：芳化＋苦溫燥溼＋淡滲，三法並用分消三焦之溼
- **手段執行層**：藿樸陳苓基礎方＋隨證加味（見上表）
