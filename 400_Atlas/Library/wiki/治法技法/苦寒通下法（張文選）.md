## 定義

> 🟢 「苦寒通下是指以**大黃為主藥**組方所形成的治法，具有**通下胃腸熱結、瀉火解毒**的作用，用於治療陽明腑實證。大承氣湯、小承氣湯、調胃承氣湯為其代表方。」

## ★ 明清溫病學家的「加減承氣湯」譜系

> 🟢 「明清溫病學家在此基礎上，創立了一系列**療效卓著的變通承氣湯**……從而發展了仲景的苦寒通下學說，**極大豐富了下法的內容和方法**。」

| 醫家 | 方 | 加了什麼 |
|---|---|---|
| **吳有性** | **承氣養榮湯** | ＋滋陰養血（知母、當歸、芍藥、生地） |
| **楊璿** | **解毒承氣湯** | ＋瀉火解毒（黃連解毒湯＋升降散） |
| **吳瑭** | **增液承氣湯** | ＋滋陰（增液湯） |
| | **牛黃承氣湯** | ＋開竅（第十章） |
| | **宣白承氣湯** | ＋清肺 |
| | **導赤承氣湯** | ＋涼血通小腸 |
| **俞根初** | **犀連承氣湯**（今名西連承氣湯） | ＋涼血散血 |
| | **枳實導滯湯** | ＋導滯 |
| | **俞氏解毒承氣湯** | ＋瀉火解毒（銀翹、金汁、綠豆、蚯蚓） |

> 「這些方劑**不僅可以治療外感陽明病，而且可以廣泛地應用於各科雜病的胃腸熱結證**。」這一類方證可稱為**加減承氣湯類方證**。

⚠️ **本章僅選最具代表性的三方介紹**：增液承氣湯、導赤承氣湯、楊氏解毒承氣湯。

## ★★ 承氣類方治雜病的共同機制：生地／玄參＋大黃

本章反覆出現的一個組合：

> 🟢 「生地甘苦寒，能**清熱涼血，養陰生津，通經逐血痺**；玄參味苦鹹微寒，也善入營血分，能**涼營生津，散結解毒**；大黃苦寒，除瀉下攻積外，更可**瀉火解毒、涼血祛瘀**。這三味藥配合，就使該方具有了**涼血祛瘀、瀉火解毒、滋陰生津**的新功效。」
>
> **因此，本方不僅可以滋陰通下用於陰津虧竭的大便秘結，而且可用於以血分火毒鬱結為病機的諸多疑難病證。**

> ⭐ **這句話是本章能治雜病的總開關**——中風、頭面腫脹疼痛、痤瘡粉刺、瘡瘍癢疹、出血、精神分裂症、月經不調，都是走「血分火毒鬱結」這條路，而不是走「便秘」。

## 本法在總框架中的位置

- **邪氣層**：胃腸熱結；血分火毒鬱結
- **氣機通道層**：腑不通則氣不降；「**無水舟停**」（津液不足致腑不通）
- **策略層**：釜底抽薪、通腑瀉熱；但**溫病的下法多兼顧陰液**（不同於傷寒的純攻）
- **手段執行層**：大黃為軸，據兼證掛滋陰／涼血／解毒／開竅／清肺
