## 定義

> 🟢 「甘寒滋陰生津法是指**沙參、麥冬、玉竹、生地等甘寒藥**組方所形成的治法，具有**生津增液、滋陰潤燥**的作用。」

**源流鏈**：《金匱要略》麥門冬湯（重用麥冬）→ 葉桂變通 → 吳瑭立方（沙參麥冬湯、益胃湯、玉竹麥門冬湯、增液湯）。

> 🟢 「這些方證的建立，不僅**發展了仲景之學**，而且**創新了李杲的脾胃學說**；不僅為溫病邪熱損傷肺胃陰津確立了有效的治法，而且為**雜病火熱內傷肺胃陰津**的治療提供了思路和方法。」

張文選稱這一族為「**沙參麥冬湯類方證**」。

## ★★ 本章的思想骨幹：葉桂「脾與胃分治」

這一章表面是四首滋陰方，底層是一套**脾胃觀的改寫**。張文選把它講得最清楚的一段是東垣與葉桂的對照：

|      | 李杲（東垣）            | 葉桂                |
| ---- | ----------------- | ----------------- |
| 脾胃關係 | **合論而治**          | **分別論治**          |
| 重心   | **詳於治脾而略於治胃**     | **重點強調胃病治法**      |
| 所治之證 | 勞倦飲食內傷，脾胃**陽氣虛損** | 分胃陰虛／胃陽虛，**兩者皆治** |
| 治法   | 補氣、昇陽、除溼、瀉火       | **治胃陰力主甘寒滋陰生津**   |

葉桂原話：

> 「**九竅不和，都屬胃病**，陽土喜柔，偏惡剛燥，若四君、異功等，竟是治脾之藥。**腑宜通即是補**，甘濡潤，胃氣下行，則有效驗。」
> 「納食主胃，運化主脾。**脾宜升則健，胃宜降則和**。」
> 「**太陰溼土，得陽始運；陽明陽土，得陰自安**」——脾喜剛燥，胃喜柔潤。
> 「仲景急下存津，其治在胃；東垣大昇陽氣，其治在脾。」（華岫雲按語評為「實超出千古」）

> ⭐⭐ **臨床上最要緊的一句是吳瑭的解釋**：胃陰虧為什麼反而**不食、痞脹、胃痛**，而不是消谷善飢？
>
> 🟢 「此由中焦**胃用之陰不降，胃體之陽獨亢**，故於甘潤法**救胃用，配胃體**，則自然飲食，**斷不可與俗套開胃健食之辛燥藥，致令燥咳成癆也。**」（《溫病條辨》下焦篇 35 條自注）
> 🟢 「蓋十二經皆稟氣於胃，**胃陰復而氣降得食**，則十二經之陰皆可復也。」（中焦篇 12 條自注）
>
> 這兩句是本章**全部四方能治「不食」的唯一理由**，也是張文選自述「拍案叫絕」「多年疑問渙然冰釋」的出處（見 [[醫案_張父_肺炎後不食胃痛（張文選）]]）。

## ★ 葉氏通補胃陰法（本章的基礎方）

> 🟢 「我根據此方的結構特點，將之稱為『**通補胃陰法**』。」

**基本四味：沙參、麥冬、白扁豆、甘草。**

- 沙參、麥冬——甘寒滋胃陰（以**甘寒之沙參代甘溫之人參**）
- 甘草——甘緩益氣，**「甘守津還」**
- 白扁豆（微溫）——養胃健中祛溼，**代替半夏、粳米、大棗**，滋中兼通運

> ⭐ 關鍵在於：**「滋胃生津而並非純用滋膩，脫出於麥門冬湯而又不悖麥門冬湯的立法。」**

### 葉氏加減法（張文選整理，六條）

| 情況 | 加 |
|---|---|
| 胃津損傷明顯 | 玉竹／天花粉／蔗汁、梨皮、梨汁 |
| **胃氣不通明顯** | 生扁豆外再加茯苓／薏苡仁／大麥仁／新會皮一味——**「不守滋而通滋，不守補而通補」** |
| 肺熱咳嗽為主 | **桑葉**，或再加杏仁 |
| 咳嗽痰多不利 | 仿葦莖湯加薏苡仁 |
| 咽痛、失聲、音啞 | 仿《金匱》苦酒湯加**雞子白** |
| 陰傷汗出明顯 | **糯稻根鬚** |

### ⭐ 對照：葉氏通補胃陽法（本章的反面）

胃虛不只有陰虛。葉氏以《金匱》**大半夏湯**（半夏、人參、白蜜）為底，**去守補之白蜜**，加茯苓之淡滲、生薑或薑汁之辛通，成通補胃陽基本方：**人參、半夏、生薑、茯苓**。

> 「胃虛益氣而用人參，**非半夏之辛，茯苓之淡，非通劑矣**。」
> 「佐茯苓通胃陽。」
> 胃陽虛甚者取附子粳米湯意加附子——「**少少用附子以理胃陽，粳米以理胃陰**」。

胃陽虛的辨識語：「食谷不化，胃無火也」「胃陽衰微，開合之機已廢」。症亦為嘔吐、呃逆、不納食、胃脘痛、脘痞脹滿——**與胃陰虛同症而異機，分野在舌**。

> ⚠️ **這是本章最容易誤治的地方**：同樣的「不食、痞脹、胃痛」，舌紅赤少苔無苔走本章，舌淡胖走大半夏湯。

## 四方的分工

| 方證 | 滋的部位 | 特徵性證 | 方的性格 |
|---|---|---|---|
| [[沙參麥冬湯方證（張文選）]] | **肺胃同滋，偏上焦氣分** | 舌紅少苔或無苔，咳嗽，胃痛不食，孔竅乾燥 | 加桑葉透、加扁豆運 |
| [[益胃湯方證（張文選）]] | **純滋胃陰，兼入血分** | 舌**深紅**少苔無苔，口舌乾燥，胃痛，不飢不食 | 加生地涼血 |
| [[增液湯方證（張文選）]] | **上中下三焦兼滋，入營血分** | 舌赤或絳、少苔無苔，**大便乾燥** | 鹹寒為君，**寓瀉於補** |
| [[薛氏四汁四香湯方證（張文選）]] | 胃津 ＋ **疏肝理氣** | 舌紅無苔，口渴，乾嘔，胃脘灼熱痛，脈細數 | **性味相反兩組藥合用** |

### ★ 沙參麥冬湯 vs 益胃湯（張文選專列一節）

| | 沙參麥冬湯 | 益胃湯 |
|---|---|---|
| 滋 | **肺胃同滋**，偏上焦氣分 | 偏滋胃陰，**並能入血分涼血生津而散血** |
| 證的重心 | **燥咳、咽喉燥痛、鼻燥、眼乾**、胃燥灼熱疼痛 | **胃燥疼痛、胃燥不思食、肌膚枯燥**、陰虧小便溺管痛 |

### ★★ 增液湯的定位（本章最有結構感的一句）

> 🟢 「如果說沙參麥冬湯以滋**氣分中上焦肺胃津**為特點，加減復脈湯以滋**下焦肝腎之陰**為特點的話，增液湯則是一首**界於沙參麥冬湯與加減復脈湯之間**的甘寒與鹹寒相兼的滋陰名方。」

```
沙參麥冬湯 ── 增液湯 ── 加減復脈湯
（氣分上中焦） （跨三焦、入營血） （下焦肝腎，→第十五章）
```

## 本法在總框架中的位置

- **邪氣層**：火熱已去或未盡，**陰津虧損**為病變主體（溫病傷陰、雜病鬱火傷陰、藥物毒副作用傷陰三源）
- **氣機通道層**：**胃氣不降**（胃用之陰不降，胃體之陽獨亢）——故症為不食痞脹而非善飢
- **策略層**：甘寒滋陰生津，**滋中必兼通**（扁豆、茯苓、薑汁、四香）
- **手段執行層**：沙參麥冬玉竹為軸，按部位掛桑葉（上）／生地（血分）／玄參（下焦與通腑）／四香（氣滯）
