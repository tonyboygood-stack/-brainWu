## 中醫觀點

鬱證是指情志抑鬱不暢而引起的疾病。朱丹溪認為：氣血沖和，萬病不生，一有怫鬱，諸病生焉。這就說明怫鬱是諸病之始，鬱不除，氣血不能沖和，疾病乃生。朱氏提出了六鬱化火，影響髒腑經絡，可以出現很多不同證候的觀點。筆者認為：鬱乃萬病之始，鬱不解，髒腑功能失調，氣血不暢，必然生病。有鬱就應調順，但如何調順，應當仔細研究。不是說，凡鬱皆當理氣，皆當辛散，皆當活瘀，皆當芳化，必須看清鬱之本質，然後根據情況，分別論治。

- **憂思喜怒，肝氣鬱結，胸陽不展**：胸脅滿悶，氣滯不伸，口淡無味，舌苔白膩，脈象弦勁 → [[鬱證一法_疏調氣機以暢胸陽]]
- **病久深入血分，絡脈瘀阻不暢**：脅痛日久，痛有定處，舌紅口幹，脈象沉澀 → [[鬱證二法_活血化血通絡緩痛]]
- **痰濕鬱阻不化，胸陽不得舒展**：胸脘痞滿，咳嗽痰多，痰白而黏，周身酸沉，舌苔白膩，兩脈濡滑略沉 → [[鬱證三法_理氣機以開其鬱化痰濕而暢胸陽]]
- **火邪蘊鬱不化**：頭暈，心煩夢多，甚則目赤口瘡，小便赤熱，大便幹結 → [[鬱證四法_火鬱發之熱者清之實者瀉之調其氣機]]
- **濕鬱則肺氣不宣，三焦不得通暢**：胸滿悶而脘腹作脹，胃納不甘，腰背酸楚，一身乏力，苔白膩，脈濡緩 → [[鬱證五法_芳香宣化苦溫燥濕少佐淡滲]]
- **情志不遂，運化失調，消化欠佳**：飲食積滯不除，中脘悶滿且脹，舌苔厚膩，脈象弦滑 → [[鬱證六法_疏氣導滯以開其鬱]]
- **惱怒之後，胸脅刺痛**：脘悶噯氣，胃納不甘 → [[鬱證七法_疏肝理氣以緩脅痛]]
- **肝鬱日久，邪已化熱**：口苦脅脹，中脘堵滿，溲黃便幹，脈象弦滑略數 → [[鬱證八法_清泄肝熱理氣緩痛]]
- **肝氣鬱結，氣鬱化火**：兩目紅赤，心煩口苦，唇角幹裂，大便幹結，舌紅口幹，脈象弦滑而數 → [[鬱證九法_泄肝火清膽熱兼以通便]]
- **肝鬱日久，陰分受灼，肝陽上亢**：頭痛較重，面赤心煩，舌紅起刺，脈弦極而力弱 → [[鬱證十法_泄其肝熱潛其亢陽以定眩暈]]
- **久病體弱，陰血大虧，絡脈失其濡養**：脅肋時痛，按之則舒，心煩多夢，甚則四肢抽搐 → [[鬱證十一法_滋養肝腎以定抽搐]]
