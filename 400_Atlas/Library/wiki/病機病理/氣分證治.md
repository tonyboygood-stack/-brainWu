## 中醫觀點

溫病證治——溫熱病，邪傳氣分階段的治法。氣分證涵蓋範圍極廣，趙紹琴列出二十六法，包括肺熱、腑實、暑熱、余熱未清等多種氣分病機的分型論治。

- **溫熱邪氣內壅於肺**：身熱惡熱，汗出口渴，咳喘氣急，甚則鼻翼煽動，胸脅滿悶，痰白黏稠或黃，舌紅苔黃，脈象滑數 → [[氣分一法_清宣肺熱化痰平喘]]
- **風熱外襲，痰熱內結，熱鬱於肺，發為肺癰**：吐膿血臭痰，喘息胸痛，舌苔黃膩，脈象滑數 → [[氣分二法_清肺滌痰逐瘀排膿以定喘咳]]
- **燥熱傷肺**：發熱頭痛，幹咳無痰，或痰少而燥，甚則痰中帶血絲，喘息氣急，鼻燥咽幹 → [[氣分三法_清肺熱兼以潤燥肅喘咳而止痰紅]]
- **暑熱犯肺**：身熱頭暈，咳喘少痰，胸脅悶痛，心煩口渴，苔薄黃，脈數，兩寸有力 → [[氣分四法_宣肺清暑兼止咳喘]]
- **熱鬱於胸膈氣分，余邪鬱於胸膈**：身微熱，心煩懊，坐臥不安，胸悶欲吐，苔薄而略黃，寸脈較大 → [[氣分五法_宣鬱折熱以暢胸陽]]
- **氣分熱邪，壅於胸膈，化火灼津，微兼腑實**：身熱惡熱，煩躁不安，胸膈灼熱如焚，唇焦咽燥，口渴，咽喉腫痛，大便秘結 → [[氣分六法_涼膈泄熱兼以通腑]]
- **熱邪蘊鬱，與痰水相結於胸中**：身熱惡熱，頭暈面赤，胸脘痞滿，按之作痛，渴欲冷飲，飲不解渴，得水則嘔，便秘溲短，舌苔黃膩而滑 → [[氣分七法_清痰熱以消痞滿寬胸陽以散其結]]
- **手太陰肺與足陽明胃無形熱邪彌漫**：高熱惡熱，面赤心煩，或喘息氣急，大渴飲冷，蒸蒸汗出，舌苔黃燥，脈洪大而數 → [[氣分八法_清熱生津達熱出表]]
- **暑傷津氣**：氣短似喘，倦怠神疲，身熱汗出，口渴心煩，尿少而黃，舌紅少苔，脈虛細無力 → [[氣分九法_清滌暑熱益氣生津]]
- **氣分高熱，傷津耗氣，導致正氣欲脫**：身熱驟退，大汗不止，少氣不足以息，脈微欲絕 → [[氣分十法_補氣生津斂陰固脫]]
- **溫熱邪氣內踞氣分，燥熱傷津，陽明腑實**：大便秘結，或下利清水，腹滿痛拒按，日晡潮熱，神昏譫語 → [[氣分十一法_攻熱結以通其便祛腑實而解神昏]]
- **素體陰虧，津液內乏，又患溫病，陰分更傷**：身熱，口燥咽幹，大便幹結，舌苔焦黑，脈沉細弦 → [[氣分十二法_增陰液以潤其燥苦鹹寒而通其腑]]
- **溫熱內結陽明，應下失下，氣陰大傷**：身熱腹滿，口燥咽幹唇裂，倦怠乏力，精神萎靡，舌苔黃燥或焦燥，脈沉細無力 → [[氣分十三法_滋陰液兼益其氣祛腑實以解熱結]]
- **溫熱夾痰內壅於肺，下灼大腸，表裏同病**：喘息胸悶，潮熱便秘，痰涎壅盛，舌苔黃厚而膩 → [[氣分十四法_攻下熱結宣肺化痰以定其喘]]
- **痰熱壅滯胸脘，燥屎踞結大腸**：痰涎壅盛，胸脘痞滿，身熱口渴，腹滿便秘，舌苔黃燥 → [[氣分十五法_清化痰熱以暢胸陽攻下熱結而通腑氣]]
- **陽明溫病，下之不通，大腸熱結又兼膀胱熱甚**：身熱煩渴，腹滿便秘，小便赤少，澀滯熱痛 → [[氣分十六法_清泄膀胱以利小便攻下熱結而通大腸]]
- **溫熱內迫大腸**：瀉利頻繁，肛門灼熱，苔黃脈數 → [[氣分十七法_苦寒堅陰清熱止利]]
- **溫病氣分熱盛，並見手足、頸項強直，甚則角弓反張**：高熱汗出，口渴飲冷，舌苔黃燥，脈沉實弦數，日晡潮熱，大便秘結 → [[氣分十八法_清熱生津攻下熱結佐用涼肝以熄其風]]
- **陽明溫病，熱鬱膽經**：身熱心煩，幹嘔口苦，兩脅作痛 → [[氣分十九法_清宣膽熱疏理氣機以緩脅痛]]
- **燥熱化火，上攻清竅**：氣血壅滯，耳鳴目赤，齒齦腫痛，咽喉腫疼，口鼻幹燥 → [[氣分二十法_宣燥熱以清肺胃泄其火而利清竅]]
- **溫瘧，邪熱壅盛於裏，阻滯經絡**：但熱不寒，骨節煩疼，苔黃脈數 → [[氣分二十一法_清透熱邪以解溫瘧]]
- **大頭瘟或痄腮**：初起惡寒發熱，繼則寒罷熱增，頭面紅腫熱痛，甚則目不能開，咽喉紅腫且痛 → [[氣分二十二法_疏風清熱以暢氣血解毒消腫而定其痛]]
- **爛喉痧，熱毒壅滯氣分，竄擾營分**：高熱口渴，煩躁不安，肌膚潮紅密布細痧點，咽部紅腫疼痛 → [[氣分二十三法_清氣熱以解溫毒涼營血而透痧]]
- **氣分證後期，高熱雖退，但余熱未清，氣陰兩虛**：低熱口幹，心煩胸悶，納穀不香，氣短神疲，舌紅少苔 → [[氣分二十四法_清熱生津益氣和胃以退低熱]]
- **氣分證後期，邪熱已退，肺胃陰傷，津液虧乏**：低熱不退，口燥，咽幹，或見幹咳，舌紅少苔 → [[氣分二十五法_滋潤肺胃兼以益氣退其低熱]]
- **氣分證後期，邪熱已退，氣陰兩傷**：夜寐不安，氣短乏力，胃不思納，脈濡弱而按之細弦 → [[氣分二十六法_益其氣兼以育陰培後天求其納穀]]

## 理論闡述（溫病縱橫）

《溫病縱橫》對氣分證治的分類與《臨證400法》二十六法逐條對應（歸為「熱在肺／熱在胸膈／痰熱結胸／肺胃熱熾／津氣欲脫／陽明熱熾兼津傷／暑傷津氣／熱在腸（腑實九種兼證）／氣熱動風／熱鬱膽經／燥犯清竅／溫瘧／溫毒氣分／余熱未清」十四大類），並逐條標明具體方名與《溫病條辨》等原文出處，補上了《臨證400法》未明寫的方名對照：

一法麻杏石甘湯｜二法葦莖湯合桔梗湯｜三法清燥救肺湯｜四法雷氏清宣金髒法｜五法梔子豉湯｜六法涼膈散｜七法小陷胸加枳實湯｜八法白虎湯／白虎加人參湯｜九法王氏清暑益氣湯｜十法生脈散｜十一法大／小／調胃承氣湯｜十二法增液承氣湯｜十三法新加黃龍湯｜十四法宣白承氣湯｜十五法陷胸承氣湯（《重訂通俗傷寒論》）｜十六法導赤承氣湯｜十七法葛根黃芩黃連湯｜十八法白虎湯或調胃承氣湯加羚羊角鉤藤菊花僵蠶｜十九法黃連黃芩湯｜二十法翹荷湯｜二十一法白虎加桂枝湯｜二十二法普濟消毒飲｜二十三法余氏清心涼膈散｜二十四法竹葉石膏湯｜二十五法沙參麥冬湯｜二十六法三才湯。

⚠️ 另有兩個《臨證400法》二十六法未單獨列出的證型，屬《溫病縱橫》新增：

- **火鬱三焦**（憎寒壯熱、一身盡痛、四肢厥冷、煩躁譫語、發斑發疹吐衄——多因初起過用寒涼、火鬱於內寒遏於外所致）→ 治宣泄鬱火，方用 [[升降散]]
- **火鬱上焦，衛氣同病**（溫病初起憎寒壯熱、體痛頭痛、胸腹滿悶、斑疹隱現，脈浮數有力）→ 治宣鬱透邪、清熱泄火，方用神解散（《傷寒溫疫條辨》）

上述兼有「便秘」的九種腑實變證（原方調胃承氣湯／增液承氣湯／新加黃龍湯／護胃承氣湯／宣白承氣湯／陷胸承氣湯／導赤承氣湯／解毒承氣湯／葛根芩連湯，對應熱結兼陰傷、氣陰兩虛、痰熱壅肺、痰熱結胸、小便赤痛、三焦火熱、單純下利等九種兼證）已與 [[增液承氣湯方證（張文選）]][[導赤承氣湯方證（張文選）]][[楊氏解毒承氣湯方證（張文選）]] 等既有方證頁重疊，完整病機分析、《溫病條辨》原文考據與趙紹琴按語見《溫病縱橫》原書，不在此重複摘引。
