## 補充經絡是什麼
補充經絡（Complement Channels）是 Sterman 對正經以外的整套經絡系統之統稱：**經筋、絡脈、經別、奇經八脈**。她認為這四層並非正經的附屬，而是身體用來把病邪維持在「伏邪（latency）」狀態、爭取時間避免病邪深入臟腑的完整防線體系——這是她整套臨床系統的核心命題，四層各自有獨立的診斷邏輯（脈象／循行指徵／衛氣指徵）與治療方案，但共用同一套「維持伏邪 vs. 病邪顯露」的病機語言。

## 經別為何形成：正經治療失敗後的下一道防線
理解經別形成的一種方式：正經未能處理病邪。古典上正經被視為水道，其陽性功能在遇到病邪時是「發汗以驅邪」。若形成了經別，代表正經已被病邪壓制，無法透過發汗排邪。

例如：太陽膀胱經未能透過發汗排出病邪，且病邪停滯在膝關節附近，就會沿著膀胱經筋進入膝膕橫紋處的 BL-40（膀胱經別的第一個穴位）。此時，病邪的處理便交由衛氣觸發元氣層次的介入，被帶入伏邪儲存的部位，因為衛氣缺乏將病邪完全排出體外的能量。**我們發現 BL-40（委中） 是經別系統中最早建立的穴位。**

經別把病邪帶入伏邪的另一種方式，是被用來作為「儲存庫」。伏邪儲存庫的經別系統之間有連結。舉例來說……（原文此處續論其他儲存庫連結方式，⚠️ 待後續拆解補齊）。

## 六合：一條漸進耗損的病程軸線
六合（六對經別）不是六個平行、獨立的選項，而是**依身體維持伏邪能力遞減排列的一條病程軸線**——從第一合到第六合，代表身體用來扣留病邪的「媒介」逐層耗竭：

| 合 | 經別配對 | 媒介 | 病機摘要 |
|---|---|---|---|
| 第一合 | [[膀胱經別]]／[[腎經別]] | 腎精 | 在最深表部（骨與關節）為病邪尋伏邪之所；只要活著就有腎精可用，身體會在腎精耗盡前主動轉移到下一合以保護腎精 |
| 第二合 | [[膽經別]]／[[肝經別]] | 血 | 「血能養精」——用血固定病邪於募穴 |
| 第三合 | [[胃經別]]／[[脾經別]] | 津（外分泌液） | 津液移動以支持血分；此階段患者常表現為極度口渴 |
| 第四合 | [[小腸經別]]／[[心經別]] | 液（內分泌液） | 動員內分泌液支持外分泌液，衛氣內收至胸部再入腦，開始出現神經病變與萎縮，身體正在失去維持伏邪的能力 |
| 第五合 | [[三焦經別]]／[[心包經別]] | 氣 | 生理津液已耗竭，改動員濕邪（病理性體液）容納病理；伏邪的喪失已告完成，氣是維持伏邪的最後手段 |
| 第六合 | [[大腸經別]]／[[肺經別]] | 陽氣（末期） | 陽氣幾乎耗盡，病邪顯露且失去控制，此為疾病終期 |

**這條軸線也是選擇合口的依據**：不是「哪個經別對應哪個症狀」的靜態查表，而是「病人目前還剩下什麼媒介可用」的動態判斷——脈象細澀弱代表某層媒介已顯不足，見〈[[深淺深與淺深淺針法（經別）]]〉的合口選擇七原則。

## 補充經絡的組織版圖：三個能量層次
每套系統作用在哪個層次，決定它能處理什麼樣的病邪：

| 系統 | 衛氣層次 | 營分層次 | 元氣層次 |

| 正經 | | ✓ | ✓ |

| 經別 | | ✓ | ✓ |
| 奇經八脈 | | | ✓ |

- **衛氣層次**（防禦之氣）：對抗外感病邪的第一線
- **營分層次**（血與津液）：病邪已進入體液層面
- **元氣層次**（先天之氣）：病邪已觸及最深層的儲備，關乎體質、遺傳、慢性/終身性問題

## 病邪的完整遷移路徑（跨四層總覽）
這是把經筋、絡脈、經別、奇經八脈四層真正串成一套系統的核心敘事——病邪不是「選一層治」，是**依序逃竄**，每層防禦失敗就退到下一層：

1. 經筋是第一線，靠噴嚏、汗、咳、嘔、瀉、頻尿釋放病邪；失敗則轉入經別或絡脈
2. 太陽經筋防禦失敗且絡脈未接住 → 病邪循膀胱正經合穴入關節，進入經別序列
3. 絡脈因營分（血/津液）不足而超載 → 轉入經別
4. 經筋因陽氣不足失守 → 病邪入關節，隨腎精衰退而顯露為關節炎
5. 營分因熱邪受損、腎精出面用寒性制邪；腎精維持伏邪的能力耗盡時，熱邪與病邪一同釋放，三焦脈浮起，病邪可能因此入臟腑
6. 絡脈溢滿、找不到鄰近絡脈可容納 → 排空至元氣層次
7. 絡脈也可排空至對應正經或鄰近絡脈
8. 絡脈可通向奇經八脈：膽絡末端在 ST-42（衝陽） 接衝脈；肝絡末端在 CV-2（曲骨） 接任脈，進入先天體質
9. 先天體質把病邪交給帶脈（主要儲存庫）；帶脈滿溢又無法排瀉時，改用腎經別擴充伏邪範圍
10. 病邪進入經別後沿六合序列移動，直到最後一合（大腸／肺經別）
11. 經別序列終點：病邪可在 ST-12（缺盆） 進入正經，但身體會試圖把它推向 GB-22（大包，也是脾之大絡）
12. 脾之大絡填滿時，可經膽正經或胞脈下溢至帶脈
13. 或在 GB-8（率谷） 進入督脈
14. 體內維持伏邪的容量全部耗盡 → 病邪轉入臟腑，疾病進入晚期

## 新手上路：兩種簡化策略
Sterman 建議臨床頭一年先限制選擇範圍，兩種做法擇一：
- **依主訴類型分工**：經筋治急性病症、絡脈治情緒主訴、經別治慢性/單側/間歇性主訴與自體免疫問題、奇經八脈治童年起病或元氣層次問題
- **依時段輪替專攻**：一段時間只用一種系統治療所有病人（例如一個月只用經別，下個月只用絡脈），較快培養診斷手感

## 各系統治療頻率、療程與針刺側別
| 系統 | 治療頻率 | 療程時間 | 單/雙側 |
|---|---|---|---|
| 經筋 | 每日一次，連續3-5天 | 不超過10天，不留針 | 患側單側 |
| 絡脈 | 每隔一天，連續21天（共11次） | 鋒針/調血針不留針 | 刺血對側絡穴，其餘雙側 |
| 正經 | 每隔一天至每五天不等（依臟腑），共30天 | 補法20分鐘少針；瀉法40分鐘多針 | 單或雙側 |
| 經別 | 連續3天休3天，循環18天 | SDS 20分鐘；DSD 40分鐘 | 交會穴雙側，井穴單側 |
| 奇經八脈 | 每週一次，共12週（進展快可縮減至1/2/3/4/6/8/12週） | 標誌穴進針後40分鐘 | 單側（女右男左取開穴，任督相反） |

> 現代臨床患者多每週回診一次，不符合上述古典頻率也無妨——重點是理解其脈絡與儀式感，實務上每週一次同樣能有顯著效果。
