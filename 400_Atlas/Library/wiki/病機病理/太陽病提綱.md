## 中醫觀點

### 提綱條文

太陽病的辨證總則：脈浮，頭項強痛而惡寒。

- **中風**：發熱、汗出、惡風、脈緩
- **傷寒**：或已發熱或未發熱，必惡寒、體痛、嘔逆，脈陰陽俱緊
- **溫病**：發熱而渴、不惡寒；若誤發其汗、身灼熱，則轉為風溫（風溫脈陰陽俱浮、自汗出、身重、多眠睡、鼻息必鼾、語言難出——誤下、誤火皆有變證，是誤治的警示條文而非正治法）

### 傳與不傳的判斷

- 脈若靜——不傳
- 頗欲吐、躁煩、脈數急——為傳
- 二三日陽明少陽證不見——不傳

### 陰陽發病與病程

病有發熱惡寒者，發於陽；無熱惡寒者，發於陰。發於陽七日愈，發於陰六日愈（陽數七、陰數六）。太陽病頭痛至七日以上自癒者，以行其經盡故也；若欲作再經者，針足陽明使經不傳。

太陽病欲解時，從巳至未上（09:00–15:00）。

### 表寒與裡寒的鑑別

身大熱反欲得衣者，熱在皮膚、寒在骨髓；身大寒反不欲近衣者，寒在皮膚、熱在骨髓——不可單憑體表寒熱判斷，需看病人對衣物覆蓋的反應。

### 不可發汗清單

太陽病以發汗為正治法，但下列體質誤汗必生壞證，需先辨明再決定能否發汗：

| 條件 | 誤汗後果 |
|---|---|
| 咽喉乾燥者 | 不可發汗 |
| 淋家 | 便血 |
| 瘡家（雖身疼痛） | 痙 |
| 衄家 | 額上陷、脈急緊、直視不得眠 |
| 亡血家 | 寒栗而振 |
| 汗家（重發汗） | 恍惚心亂、小便已陰疼（與禹餘糧丸） |

### 表裡緩急先後

汗法雖是太陽病本治，但遇到裡證同時存在時，先後順序需視緩急而定：

| 情況 | 處置 |
|---|---|
| 下利清穀不止、身疼痛 | **急當救裡**，宜四逆湯 |
| 身疼痛、清便自調 | **急當救表**，宜桂枝湯 |
| 病痼疾加以卒病 | **當先治其卒病，後乃治其痼疾** |
| 大下後復發汗、心下痞、惡寒（表未解） | **不可攻痞，當先解表，後攻其痞** |

## 臨床意義

這是六經辨證的入口：**脈浮、頭項強痛、惡寒**三者是太陽病的共同標誌，中風與傷寒的鑑別關鍵在**汗出與否、脈緩或緊**。此提綱之下分出桂枝湯（中風，見 [[桂枝湯]]）與麻黃湯（傷寒，見 [[麻黃湯]]）兩大方向，後續變證、壞病、合病並病皆從此展開。
