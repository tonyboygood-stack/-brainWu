## 中醫觀點

溫病證治——濕熱病，邪在中焦階段的治法，依濕熱輕重分三型：一、濕重於熱（八法）；二、濕熱並重（四法）；三、熱重於濕（四法）。

### 一、濕重於熱（八法）
- **濕邪夾食滯鬱阻中焦，脾胃升降失司**：脘腹脹滿，納呆嘔惡，大便溏滯不爽，舌苔白膩，脈象濡滑 → [[中焦濕熱一之一法_香以開鬱苦燥其濕少佐消導疏調氣機]]
- **濕邪鬱阻，內困脾胃，外鬱肌膚經絡**：脘腹脹滿，大便溏薄；周身沉重疼痛 → [[中焦濕熱一之二法_宣通表裏以化濕鬱疏調氣機而退滿脹]]
- **濕阻中焦，脾胃升降失司，氣機不暢，陽氣鬱遏，久則釀熱**：小溲短赤，舌苔黃膩，脈象濡軟 → [[中焦濕熱一之三法_芳香以化濕鬱甘淡滲濕利尿分消以暢氣機]]
- **中焦濕熱鬱蒸，外達肌表**：發熱身痛，汗出不解，表情淡漠，胸脘痞悶，嘔惡便溏，胸腹部發出白，舌苔黃膩，脈濡 → [[中焦濕熱一之四法_清宣濕熱以透白淡滲利濕兼暢三焦]]
- **濕熱蘊蓄中焦，壅滯筋脈，成動風**：牙關緊急，四肢抽搐，頸項強直，甚則角弓反張，神識昏蒙，舌苔黃膩，脈濡 → [[中焦濕熱一之五法_祛濕清熱通絡熄風]]
- **濕熱疫癘之邪伏於募原**：憎寒發熱，繼則但發熱而不憎寒，日晡益甚，頭身疼痛，胸悶脘痞，時作嘔惡，苔白膩而中如積粉，脈弦數 → [[中焦濕熱一之六法_苦辛溫開鬱燥濕調募原行氣破滯]]
- **中焦濕熱減而未清，脾胃功能不複**：胸脘痞悶，知饑不食，食不甘味，精神倦怠，舌苔白膩，脈象濡緩 → [[中焦濕熱一之七法_疏化升和瘥後調理]]
- **濕熱病後期，濕遏傷陽，溫化失權，心陽衰微，火不制水**：心悸頭暈，肢冷身腫，舌胖嫩苔水滑，脈沉弱或沉遲 → [[中焦濕熱一之八法_溫陽以化氣利水而消腫]]

### 二、濕熱並重（四法）
- **濕熱並重，鬱阻中焦，升降失和**：身熱心煩，胸脘痞悶，惡心嘔吐，大便溏瀉，色黃味臭，舌苔黃膩，甚則糙垢，脈象濡數，或濡滑 → [[中焦濕熱二之一法_苦以泄熱燥以祛濕宣通三焦]]
- **濕熱並重，彌漫三焦，邪無出路**：潮熱汗出，心煩口渴，胸脘痞悶，嘔惡便溏，小便黃少，舌紅苔灰白且垢，脈象濡數互見 → [[中焦濕熱二之二法_清其鬱熱化其濕邪通利三焦而退潮熱]]
- **濕熱之邪鬱阻三焦，氣機滯塞**：寒熱交作，頭暈目弦，脘痞腹脹，泛惡作嘔，舌苔黃膩，脈象濡滑 → [[中焦濕熱二之三法_分消濕熱以祛其邪宣展氣機而退寒熱]]
- **濕熱之邪鬱阻骨節經絡之間，濕熱痹痛**：壯熱寒戰，骨節腫痛，面色晦暗不華，舌苔灰膩或黃膩，兩脈多屬濡數 → [[中焦濕熱二之四法_清濕熱通血脈宣痹止痛]]

### 三、熱重於濕（四法）
- **中焦陽明胃熱熾盛，又兼太陰脾濕**：高熱汗出，煩渴飲冷，脘悶身重，舌苔黃膩而幹，脈象洪大，按之略濡 → [[中焦濕熱三之一法_清胃熱以泄陽明燥脾濕兼解太陰]]
- **暑熱夾濕，彌漫三焦，升降失常**：身熱面赤，頭暈耳聾，汗出口渴，小溲黃少，胸脘痞悶，惡心嘔吐，大便溏臭，舌苔黃膩，脈象滑數 → [[中焦濕熱三之二法_清泄濕熱以暢三焦通暢氣機而利清竅]]
- **中焦濕熱不解，鬱阻足少陽膽經，熱重於濕**：惡寒發熱，其狀如瘧，發熱重而惡寒輕，午後熱甚，心煩口渴，胸脘痞悶，口苦嘔惡 → [[中焦濕熱三之三法_清透少陽分消濕濁以利樞機]]
- **脾胃濕熱不解，熱重於濕，鬱於肝膽，發為陽黃**：周身面目黃染，鮮明如橘子色，但頭汗出，腹滿脅痛，食少泛惡，口渴，小便不利，苔黃滑膩 → [[中焦濕熱三之四法_清熱利濕以退黃疸]]
