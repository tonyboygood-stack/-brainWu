# 李辛 — 思路檔案

> ⚠️ **樣本範圍**：本庫目前僅收《回到本源》第一部分（人體觀＋四步診斷＋病機論）與第二部分的氣味章、臨床案例。
> **針刺、靜坐氣功、方劑分類、附錄本草尚未匯入**，故本頁看不到他的針法思路與完整方劑座標系。
>
> **透鏡類型：論述型**——此書幾乎全是說理，以下第 1–7 段大量使用 🟢 原文直引，非從方藥反推。
>
> 🟢 原文直述／統計實證　🟡 本庫歸納　🔴 外部知識（不可作臨床依據）

## 1. 他怎麼看人體 🟢

**四大層次：精、氣、形、神。** 形承載精氣神；精化生氣，氣化生神；**神的統攝又反過來影響精與氣**。

**真氣＝下焦元氣（先天）＋ 中焦中氣（食物）＋ 上焦清氣（自然）。**

財富比喻：下焦元氣＝**原始資本**；中焦中氣＝**現金流**。中氣不足 → 被迫提取資本（元氣）→ 久之精也虧。

**氣機＝真氣的正常運行，基本方向是升、降、開、闔。**

> 🟢「這個開與闔的氣機方向是**診斷的基礎**。」

⚠️ **他明確不走臟腑辨證**：
> 🟢「**關注臟腑功能的辨證思路是近代發展出來的，更接近於物質化肉體的『西式』觀點。**」
> 只抓**元氣與中氣**兩大源泉做虛實、陰陽、邪正、進退的大方向判斷，「化繁為簡」。

詳見 [[真氣與氣機（李辛人體觀）]]。

## 2. 他怎麼定義病 🟢

> 🟢「**常，即是氣機；變（失常），即是病機。**」

病機有兩種來源：**本氣自病**（真氣自身不足）／**邪正鬥爭**（與外邪或七情鬥爭）。

⭐ **關鍵轉向**：
> 🟢「**病機源自失常後的修復抗病反應**，即邪正鬥爭。」

**病機不是壞事本身，是身體在處理壞事的過程。** 這一句決定了他後面所有的治療態度。

> 🟢「古代醫者關心的是『**常**』，現代中醫關心的是『**病**』，這兩者的著眼點大有不同。」

## 3. 醫者站在哪裡 🟢

> 🟢「如果把能量的正常運行狀態（氣機）作為『**第一個醫生**』……我們中醫作為『**第二個醫生**』，就可以更好地順應、激發『第一個醫生』發揮作用。**如果治療忽略了人體自身，只針對疾病，『第二個醫生』就可能會越俎代庖，導致治療方向的偏離。**」

**戲劇比喻**（他用來說明為何不能盯著症狀看）：

| 戲劇 | 人體 |
|---|---|
| 舞臺 | 形 |
| 兩位主角 | 真氣與邪氣 |
| 情節、表演 | 症狀 |
| 故事線索 | **病機** |
| 作者的意圖 | **第一個醫生** |
| 結局 | 預後 |

> 🟢「如果只盯著舞臺上的每一個症狀，會很容易**錯失整個演出的故事線索和作者的意圖**。」

## 4. 診斷推理鏈 ★核心 🟢

### 執行前：先取整體意象

> 🟢「在開始問診和觸診等執行細節診療之前，**最重要的是對病人有一個完整的直觀感受和意象**……醫生需要保持安靜、專注和放鬆。」

四步的作用是**澄清、確認**這個意象，不是取代它。

### 序列（每步的答案如何決定下一步）

| 步 | 問什麼 | 看什麼 | **→ 如何決定下一步** |
|---|---|---|---|
| **一・資源** | 他還有多少本錢？ | 下焦元氣、中焦中氣（各五維度：症狀／神／觸診／舌／脈） | **設定力度上限**。🟢「如果精不足（脈緊、細、弱），用藥時**不能猛烈地開表**」 |
| **二・三焦氣機** | 它此刻想往哪走？ | 開闔升降方向、邪正在哪層、**汗／便／尿**三渠道 | 定出的是**方向**不是藥。方向清晰單純＝資源尚足 → **順勢而為**；方向不清 → 需**激發**病機 |
| **三・神與陰陽** | 神定不定？ | 睡眠三型（入睡困難／早醒／多夢） | 神不定則氣機不穩，前兩步判斷都不牢 |
| **四・八綱病機** | 這場仗打成什麼樣？ | 虛實 > 表裡 > 陰陽 > **寒熱最不重要** | ⚠️ **閉環回第一步** |

### 三個貫穿全程的硬規則

1. **虛實判斷有絕對優先權**
   > 🟢「只要下焦元氣或中焦胃氣不足，**不管病人有任何症狀或檢查結果，都屬於虛證**。」

2. **病因不重要**
   > 🟢「關於表證和裡證的鑑別，**病因並不重要**……重要的是**當下或最近病情的病機呈現**。」

3. **禁止點對點**（全書出現至少四次）
   > 🟢「一定要避免『點對點』、由症狀推導結論的錯誤思路。」
   > 🟢「書本上常說：白天出汗叫自汗是陽氣虛，夜間出汗叫盜汗是陰血虛。**事實上……對於任何一個單一的症狀，都不能就此簡單推理出某個診斷結果。**」

### 序列圖

```
        整體直觀意象（先於一切）
                 ↓
   ┌──→ 一・資源（元氣／中氣）── 設定力度上限
   │            ↓
   │     二・三焦氣機 ── 定出開/闔方向 ＋ 選哪個渠道
   │            ↓
   │     三・神與陰陽 ── 氣機穩不穩得住
   │            ↓
   └──── 四・八綱病機（虛實為核心）
              閉環回第一步
```

詳見 [[李辛四步診斷法]]。

## 5. 從診斷到處方的橋 ★核心 🟢

**這是他的「底層邏輯」本體。** 診斷定出的是方向與層次，處方要靠三個轉換完成：

```
症狀 → 病機 → 方向 → 氣味／取氣或取味 → 具體藥＋劑量＋煎法
```

### 轉換一：方向 → 渠道 → 味

| 渠道 | 對應焦 | 不暢時的入手味 |
|---|---|---|
| 出汗 | 上焦 | **辛** |
| 大便 | 中焦 | **苦**（降氣導滯） |
| 小便 | 下焦 | **淡滲** |

> 🟢「在臨床中，**從哪一層打開，要取決於『第一個醫生』所需的方向**。」

### 轉換二：層次 → 取氣 or 取味

| | **取其氣**（陽） | **取其味**（陰） |
|---|---|---|
| 作用層次 | 氣分、三焦、經脈 | 血分、下焦深部 |
| 藥形 | 薄而輕，辛甘淡 | 色深形厚質重，酸苦鹹，多根莖 |
| **劑量** | **小** | **大** |
| **煎煮** | **短** | **長**，湯汁濃稠 |
| 藥例 | 薄荷、紫蘇葉、菊花、防風、荊芥、陳皮、佛手 | 熟地黃、肉蓯蓉、巴戟天／黃連、大黃、芒硝 |

⚠️ **同一味藥，煎法決定它是氣還是味**——大黃黃連瀉心湯以麻沸湯浸漬取其「輕清之氣」，避免久煎取厚味而傷中焦。

### 轉換三：資源 → 力度

| 體質 | 開表用藥 |
|---|---|
| 強健 | 麻黃、細辛 |
| 一般 | 防風、荊芥 |
| 虛弱 | 紫蘇葉、藿香、香薷 |

### ⭐ 完整實例：從「睡不好」走到具體藥

| 問診所得 | 病機判讀 | 需要的方向 | 氣味／類別 | 具體藥 |
|---|---|---|---|---|
| **入睡困難** | 陽氣／神氣不能入於陰血 → **闔降不足** | 闔、降 | 礦物類／陰味 | 牡蠣、滑石、生石膏、磁石／女貞子、墨旱蓮、五味子、山茱萸 |
| **早醒** | 內心有長期無出路的問題 → **氣鬱**（源自神機鬱滯） | 舒緩流通 | 淡、微甘、微酸 | 淡竹葉、竹茹、烏梅 |
| **多夢** | **神氣浮越不寧** | 收、鎮 | 石類／苦味／收斂 | 生龍骨、紫石英、代赭石 |

**五格連通，每格都能追問為什麼。** 這就是「底層邏輯」的實體樣子。

詳見 [[三焦層次用藥法則（李辛）]]、[[李辛神與陰陽平衡評估]]。

## 6. 選藥規則 🟢

### 《素問・陰陽應象大論》四法則（他的用藥憲法）

| 法則 | 應用 |
|---|---|
| **形不足者，溫之以氣** | 小劑量 5～15 克，煎煮不長。例：補中益氣湯 |
| **精不足者，補之以味** | 質厚重，根類／動物類／種子類，色深或黑 |
| **陽化氣，陰成形** | 「氣」推動化生；「味」保持聚闔形體 |
| ⚠️ **味傷氣，氣傷精** | 過用厚味傷氣；**過用辛甘發散溫通 → 陽極傷陰甚而傷精** |

### 微而非強

> 🟢「用『**微**』而非『**強**』……否則會**藥過其位、過於開洩而傷正氣**。」

### 配的是藥勢，不是藥名

> 🟢「**具有相近氣味的中藥可以替換使用。**」
> 🟡 推論：他的處方本質是配「藥勢」。這解釋了為何同一治則在他醫案中可用不同藥組達成。

### 從藥湯味道就能驗方

> 🟢「當患者向醫生描述他曾經吃過的方劑的味道，**即使不看具體的組方成分，我們也可以大致瞭解其補瀉和方向是否得當**。」

## 7. 禁忌與硬規則 🟢

| 規則 | 內容 |
|---|---|
| **精不足不可猛開表** | 左尺脈緊、細、弱者，強開表會進一步耗傷元氣（醫案有違反實例，見第 8 段） |
| **鬱熱不可過開表** | 🟢「內有鬱熱阻滯時，**不能過於開表**（辛味風藥），否則會加劇熱象（**風火相煽**）」，應通利二便引熱下行 |
| **下焦主闔，靜才是真養** | 溫陽化氣之藥可補一時之不濟，但**不宜久服**，否則傷精耗氣 |
| **不可壓症狀** | 🟢「**不是去抑制機體的反應**……這是**錯誤的治療方向**，會干擾疾病發展自然的『勢』，錯失轉化的『機』」。能做的只是**控制反應強度**在可承受範圍 |
| **握其度** | 🟢「**如同小火熬粥，火太大，粥溢而鍋損；火太小，氣冷而米僵。**」 |
| **第四階段的假性緩解要警覺** | 真氣已虛、邪氣不盛時症狀隱去，🟢「會讓醫生和病人以為『病好了』，其實這正是**邪氣留駐深入，病勢漸漸加重**的階段」 |

### 總綱五訣

> 🟢「**定其神、審其勢、利其行、⚠️□其度、顧其本。**」
> ⚠️ 第四項首字 OCR 損壞，經書內互證推定為「握」（詳見 [[李辛治療原則總綱]]）。

## 8. 判讀範例：走完全程 ★ 🟢

**A 先生，口腔潰瘍 4 年 ＋ 下肢慢性潰瘍近 10 年。** 完整病程見 [[醫案_A先生_口腔潰瘍四年（李辛）]]。

### 四步怎麼跑

| 步 | 答案 | 決定了什麼 |
|---|---|---|
| 一・資源 | 中下焦皆不足，服苦寒 2 年致脾胃更虛 | 🟢「**不能用『掄棍子』的方法**……過去的診療過程也證明此路不通」 |
| 二・氣機 | 小便不暢、足寒、舌厚膩；虛陽上浮＝方向逆 | 選**從小便開**（阻力最小），暫不強開表 |
| 三・神 | 壓力大、失眠多夢、未表達的情感創傷 | 針取上星清降神氣；後期特意選**病人可休假、神氣舒緩**時進補 |
| 四・八綱 | 虛實夾雜、邪入血分＝**第三階段** | 補中下焦 ＋ 保持渠道通暢給邪出路 |

### ⭐ 最有價值的一段：他記錄了自己的誤判

6/18 加麻黃 6g、升麻 12g 開上焦表氣：

> 🟢「**但不是合適的時機，開早了**，他的口腔潰瘍加重，入睡也困難了。左脈再次拘緊不舒。此為精虛，陽氣上浮之象。」
> 🟢「可見，**下焦精虛是其根本原因**。但此時中焦尚弱，熱毒之勢尚熾，**目前還沒有條件濡養陰精**。」
> 🟢「但這次『開』的好處是，**表氣已通，為未來的進一步治療打好了基礎**。」

**他違反了自己在第 7 段立下的硬規則，並記錄了後果。**

💡 這揭示了一件單看理論看不到的事：**「機」不只是方向對不對，還有時候對不對。** 方向正確（表確實需要開）、規則已知（精不足不可猛開）、仍然做錯——因為**中焦與熱勢還沒到能承受的階段，而且時值夏季天地之氣開洩**。

### 推進次序（資源恢復到哪，力度才推到哪）

```
運通中焦（輕宣疏透，苦味劑量壓到最小）→ 中氣復
   ↓ ⚠️ 6/18 開表過早 → 退回
闔補下焦（黃柏、生地黃）→ 精氣復
   ↓ 脾胃改善「我可以用更苦、涼一些的藥」
推進血分（味厚：青蒿鱉甲、玄參、何首烏）
   ↓
固中（四君子加酸甘）→ 攻血分（大黃芒硝 → 三物小白散）
   ↓ 「大開之後，需要再『固』」
收尾（小劑量味苦通絡）
```

**追蹤指標**：左脈 緊滯→柔和→沉而柔緩→平順｜舌苔 深黃厚膩→略厚→乾淨｜**腳汗 十多年無→首次有汗**

## 10. 對應老吳的框架 🟡

> ⚠️ 以下為對照 [[病生理診斷治療總框架 MOC]] 的比對，**李辛是該框架的骨架來源之一**，非事後套用。

| 老吳總框架 | 回到本源原文 |
|---|---|
| 「先決條件：我們是第二醫生」 | 🟢「氣機作為『第一個醫生』……我們中醫作為『第二個醫生』」 |
| **L0 資源** | 第一步：資源評估（下焦元氣／中焦中氣） |
| **L1 氣機格局** | 第二步：三焦氣機，「升降開闔四個基本方向」 |
| 總開關「升降開闔是目標，寒熱補瀉是手段」 | 🟢「選擇正確的方向是療效的關鍵……調整氣機的大方向更為重要」 |
| 力度分級「微而非強」 | 🟢「用『微』而非『強』……**藥過其位**、過於開洩而傷正氣」 |
| 「病機方向清晰且單純 → 順勢而為」 | 🟢「若病機方向清晰且單純……醫生只需要順勢而為，保護和推動原本的氣機進程」 |

### ⚠️ 框架缺口候選：缺一個「順序層／時機層」

本庫目前有**三個獨立來源**指向同一個缺口：

1. [[趙紹琴]]（引《內經》「火鬱發之」）：**熱不能直接清，要先開鬱**
2. [[揚達vsIdaRolf_姿勢代償的處理順序]]：解除抑制優先於啟動；穩定平面優先於旋轉負荷
3. **李辛（本頁）**：得其機、順其勢 — 且醫案證明**同一個正確方向，早做會出事**

前兩者講的是**順序**（A 沒解決前不能做 B）；李辛多加一層——**時機**（A 解決到什麼程度、外在天時如何，才輪到 B）。

> 建議：總框架 L1 增設「順序與時機」規則。**待老吳裁決，未自動改寫 MOC。**

## 11. 盲區與不談的事 🟡

**本庫目前樣本（第一部分＋氣味章＋醫案）中：**

| 主題 | 狀態 |
|---|---|
| 臟腑辨證 | ⚠️ **主動迴避**，非盲區——他明說那是「近代發展出來的、更接近西式觀點」 |
| 具體病名的治法 | 全書幾乎不以病名組織。找「某病怎麼治」不能問李辛 |
| 經方條文考據 | 引《傷寒論》但取其藥勢思路，不做條文訓詁 |
| 針刺、火罐、按摩 | ⏳ 第三部分，**未匯入**（非盲區） |
| 靜坐氣功 | ⏳ 第四部分，**未匯入**（他視為與用藥同等的治療） |
| 方劑座標系統 | ⏳ 第二部分主體，**未匯入** |

> ⚠️ 「未匯入」與「盲區」必須分清。本頁目前只有第一列是真正的取向性選擇，其餘是本庫尚未涵蓋。
