# 趙紹琴 — 思路檔案

> ⚠️ **本指紋僅基於《臨證400法》一書（本庫 522 頁）**，不代表其一生思路全貌。
> 該書為內科雜病證治，故本頁看不到他的溫病專論、醫案實錄與教學論述。
>
> **萃取層級標示**：🟢 原文直述／統計實證　🟡 從本庫已拆解頁面歸納　🔴 外部公開知識，非本庫文獻

## 一句話核心命題 🟡

**病多是氣機被鬱阻、津液被壅滯的結果；治療重在「化」開它，而不是攻掉它、或補住它。**

依據：190 個方劑頁的「方義」區塊中，治法動詞以**化 84 次**居首，其後為清 52、溫 50、散 34、疏 33、泄 32、補 32、宣 28；
而**攻 4、固 3、澀 2** 幾乎不出現。他極少把病當成「有個東西要打掉」或「有個洞要塞住」來處理。

---

## 慣用切入點 🟡

**診斷順序：脈為主、舌為輔，兩者並重。**

| 依據        | 出現於幾方（共 190） |  佔比 |     |
| --------- | -----------: | --: | --- |
| 主治提到**脈** |          160 | 84% |     |
| 主治提到**舌** |          131 | 69% |     |
| **脈舌兼提**  |          128 | 67% |     |
| 脈舌皆不提     |           27 | 14% |     |

- 脈的出現率高於舌，且脈舌兼提佔三分之二——**他不是靠單一指標下判斷**
- 27 方（14%）脈舌皆不提，多為病位病因已極明確者

**辨證順序：先分虛實，再分病程階段，同一病拆成多法。**

一病多法是這本書的骨架：痰飲九法、痢疾九法、嘔吐九法、咳嗽八法、泄瀉八法、水腫八法。
最少的是奔豚氣、濁病（1–2 法）。**他不給「一病一方」，給的是一組分岔路。**

## 手段光譜與力度偏好 🟢

| 分組                                 | 出現次數 |   佔全部方劑 |
| ---------------------------------- | ---: | ------: |
| **輕清宣透**（防風32、杏仁26、蘇葉19、前胡16、薄荷6…） |  110 | **58%** |
| 溫陽（肉桂20、乾薑18、附子14、吳茱萸10…）          |   68 |     36% |
| 峻補（黃芪21、熟地黃10、人參5、阿膠4）             |   40 |     21% |
| **峻下**（大黃11、芒硝2、元明粉1、牽牛子1、商陸1）     |   16 |  **8%** |

**力度偏「微」而非「強」——而且是用劑量做到的，不只是選藥：**

- 大黃：190 方中只有 11 方用到，劑量 1–8 克，**中位僅 3 克**
- 人參：只用於 5 方，1–10 克，**中位 3 克**
- 全庫劑量中位數 10 克，四分位 6／12 克

> 這一條直接對應總框架的「**力度分級**」規則：能行氣導滯解決的，不動用攻下。

**⚠️ 但不要簡化成「他只會輕」**：溫陽藥出現率 36%，附子中位 10 克、熟地黃中位 15 克、黃芪最高 60 克。
輕的是**攻邪**，該補該溫的時候他不手軟。

## 分期與動態辨證習慣 🟡

**加減法是這本書的主體，不是附錄：**

- **189/190 方附加減法**，合計 417 條，每方中位 2 條、最多 6 條
- 加減條件多為脈舌變化與兼證出現，而非病名

**依病程分階段論治**（至少 10 個病機頁採此結構）：
[[肺癰]]（四階段）、[[腸癰]]（初起／成膿／潰後）、[[積聚]]（六法依病程虛實遞進）、
[[感冒]]、[[痢疾]]、[[水腫]]、[[消渴]]、[[臌脹]]、[[反胃]]、[[耳鳴耳聾]]

**禁忌意識**：43/190 方（23%）明寫「不可／忌／慎用／切忌」。
典型如 [[便秘一法_泄熱通便以祛腑實]]：「若舌苔滑潤者，攻下藥不可急用，去硝、黃」——
**同一張方，看到舌象不對就先撤攻下藥。**

## 在總框架上的位置 🟡

> ⚠️ 以下為對照 [[病生理診斷治療總框架 MOC]] 的**推論**，待老吳校正。

| 框架層 | 他的落點 |
|---|---|
| **L1 氣機格局** | 偏「**開**」向（輕清宣透 58%）；方義中降 17、升 11 相對少 |
| **總開關：目標 vs 手段** | 他下的幾乎都是**手段**（化、清、溫、疏），升降開闔是被達成的結果 |
| **力度分級** | 明確偏「微」；攻下 8% 且劑量壓到中位 3 克 |
| **L4 治法** | 主要貢獻在此層——一病多法 ＋ 每法附加減，是一整套可執行的手段庫 |

**可能的框架缺口（待驗證）**：

[[腸癰]] 頁：「乃取《內經》『火鬱發之』之意，火熱鬱結**必先**疏風宣透，鬱開則火熱自散，
**若單純清熱則鬱不能開**」——這講的是**順序**：熱不能直接清，要先開。

⚠️ 注意 attribution：這條原則趙紹琴自己標明是取自**《內經》「火鬱發之」**，
不是他的原創，而是他繼承並反覆運用的古典規則——這反而讓它更值得納入框架。

總框架目前有「先辨虛實」「力度分級」，但**沒有「開闔優先於寒熱」這條順序規則**。
若成立，這是 L1 該補的一條。
