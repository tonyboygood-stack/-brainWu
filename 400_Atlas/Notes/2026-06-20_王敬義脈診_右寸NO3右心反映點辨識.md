# 王敬義脈診：右寸 NO3 右心反映點辨識

> 右寸第三層（NO3）為**右心反映點**。
> 把到異常脈感時，須鑑別心肌炎與三尖瓣 / 右心器質性病變。

---

## 一、病毒性心肌炎

**脈象：** 右寸 NO3 搏動有力 ＋ 跳動紊亂

**症狀提示：** 心悸、心累、面色蒼白、倦怠乏力、胸悶氣緊、呼吸困難

### 方藥（抗病毒 ＋ 抗過敏 ＋ 保護心肌）

| 層次 | 藥物 |
|---|---|
| 風寒 | 蜂房、秦艽、大棗 |
| 風熱 | 丹皮、紫草、生地、赤芍 |
| 心陽虛（脈緩慢） | 桂枝、附子 |
| 心陰血不足 | 麥冬、天冬、太子參、柏子仁 |
| 氣短 | 黨參、黃耆、白朮、西洋蔘 |
| 心悸 | 酸棗仁、遠志、茯苓、茯神 |

---

## 二、三尖瓣受損 / 右心房室病理性擴大

**脈象：** 右寸 NO3 搏動有力 ＋ 細如實心橡皮筋，或粗大堅韌短促

**症狀提示：** 心悸、心累、面色蒼白、倦怠乏力、胸悶氣緊、呼吸困難（同上）

**方藥：** 在心肌炎治療基礎上，加入：
- 軟堅散結、活血化瘀
- 瀉肺平喘（減少右心負荷）

---

## 臨床辨識陷阱

> **右寸 NO3 有力 ≠ 一定是肺實火**

過去見右寸 NO3 有力直覺歸肺實火，用清熱瀉肺；但若病人**無肺熱症狀**，反而出現心悸、喘、面色蒼白——這是心臟器質性病變的訊號，不可只從肺論治。

**鑑別要點：**
- 有咳嗽、黃痰、咽紅、口渴 → 肺實火方向
- 有心悸、喘、面蒼白、倦怠、按到實心脈感 → 右心 / 三尖瓣方向，建議西醫檢查確認
