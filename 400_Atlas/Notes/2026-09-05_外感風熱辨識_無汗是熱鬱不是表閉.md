# 外感風熱的辨識——無汗是熱鬱，不是表閉

## says（核心觀點）

風熱在衛的辨識靠口微渴、咽紅且痛、舌邊尖紅、脈浮數兩寸獨大；無汗不是風寒表閉，而是熱邪鬱阻肺衛致宣降不利——這一步認錯就會誤用辛溫。

## 辨識要點

| 徵候 | 意義 |
|:--|:--|
| 口微渴、咽紅且痛、舌邊尖紅 | 上焦熱向外透的表現，是風熱的核心指標 |
| **無汗或汗出不暢** | **熱邪鬱阻肺衛、宣暢不利**，不是風寒的表閉。認錯這一點就會用辛溫發散 |
| 脈浮數；或不緩不緊而動數，兩寸獨大 | 《溫病條辨》語，見 [[文魁脈學]] |
| 苔薄白 | 仍在衛分初起 |
| 苔薄白**略乾** | 津液已經輕度受傷 |
| 咳嗽 | 肺也被鬱熱影響，不只在衛 |

## 為什麼「無汗」最容易誤導

風寒表閉與風熱鬱肺都可以無汗，但機轉相反：

- 風寒：寒主收引，腠理閉塞 → 要辛溫開表
- 風熱：熱邪壅滯肺氣，宣降失司 → 要**辛涼疏透**，讓熱有外達之路

用錯方向的後果見 [[2026-09-05_外感四證鑑別_風熱風寒伏氣春溫濕溫]] 與辛溫誤治的變證。

## 定位與病性

定位：上焦肺與衛　　病性：鬱熱，且已開始傷津
