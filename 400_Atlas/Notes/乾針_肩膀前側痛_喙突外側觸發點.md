# 乾針｜肩膀前側痛：喙突外側觸發點

## 核心發現

肩膀前側痛 + 抬手受限，**從喙突往外摸，可誘發 trigger point**。

乾針處理前三角肌 + 二頭長頭肌腱處 → **當場緩解**。

## 解剖定位

```
喙突 → 往外側摸 → 二頭肌長頭腱溝區域 / 前三角肌
```

- **喙突**（coracoid process）：肩胛骨前突，是短頭二頭肌、喙肱肌、胸小肌的附著點
- **往外**：沿二頭肌長頭腱（bicipital groove，結節間溝）方向
- **前三角肌**：覆蓋此區，也常有 trigger point

## 臨床特徵

| 症狀 | 細節 |
|---|---|
| 主訴 | 肩膀前側痛 |
| 誘發動作 | 抬手明顯 |
| 觸診 | 喙突往外按壓可重現疼痛（trigger point 誘發）|

## 乾針處置

- **位置**：前三角肌 + 二頭長頭肌腱處
- **效果**：當場緩解

## 臨床記憶點

> 遇到肩膀前側痛、抬手受限 → 先從喙突往外摸，找 trigger point，確認後乾針直取。

## 延伸思考

- 乾針治療肌筋膜 trigger point 的即效機制（局部抽搐反應 → 肌纖維放鬆）
- 此位置與旋轉肌袖（rotator cuff）問題的鑑別：旋轉肌袖損傷多在外展弧，trigger point 多在特定位置可重現
