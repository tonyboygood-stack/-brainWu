# 經筋治療成功的四個資源點

經筋治療有效的前提，是身體底層四個資源充足。治療前可先用脈象確認，不足者先補再治經筋。

---

## 四大資源

| 資源 | 脈象指標 | 補充方法 |
| ---- | -------- | -------- |
| **腎陽** | 尺脈12層有力 | 艾灸太溪、命門 |
| **津液** | 右關中層足夠寬 | 喝水 + 衝陽、中脘 |
| **肝氣** | 左關不弦，肝氣舒暢 | 期門、章門、膈俞 |
| **肺氣** | 右寸肺脈能升至浮位 | 列缺 |

---

## 臨床意涵

- 腎陽不足 → 經筋得不到溫煦，難以鬆解
- 津液不足 → 筋失濡養，治療後易反彈
- 肝氣鬱滯 → 筋膜張力高，手法難以入深
- 肺氣不升 → 衛氣不能布散至體表經筋
