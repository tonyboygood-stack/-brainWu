# 沉脈辨證思路：先分虛實

## says（核心觀點）

把到沉脈，第一刀切虛實。虛者細查夾邪；實者再辨有形無形；且實者需反問：是否正虛導致邪陷，治療需有次第。

---

## 沉脈四大類型

| 類型 | 機制 | 特徵 |
|------|------|------|
| 1. 正氣虛而沉 | 氣血不足，無力鼓動脈氣外達 | 沉而無力，常兼細弱 |
| 2. 正虛邪陷（類型1延伸） | 正虛後邪氣乘虛入裏，陷而不出 | 沉而兼夾邪象（滑、澀、弦等）；詳見 [[2026-05-07_正虛邪陷與三瀉心湯]] |
| 3. 氣鬱在裏 | 氣機鬱滯，脈氣不得外達 | 沉弦頂手，以雙關最常見；詳見 [[2026-05-14_沉脈：氣鬱在裏（雙關沉弦）]] |
| 4. 邪氣鬱阻在裏（純實） | 有形實邪鬱阻，脈氣被壓沉 | 沉而有力，兼具邪象（滑、澀、緊等） |

---

## 臨床辨證流程

```
把到沉脈
    │
    ├─ 虛？（沉而無力）
    │       │
    │       └─ 細查夾邪
    │               ├─ 夾濕（沉滑或沉緩）
    │               └─ 夾瘀（沉澀）
    │
    └─ 實？（沉而有力）
            │
            ├─ 無形邪：氣鬱
            │       └─ 沉弦頂手 → 柴胡類方
            │
            ├─ 有形邪：瘀血／痰濕／水飲／燥結
            │       └─ 依兼脈辨別（澀、滑、緊、結代等）
            │
            └─ ⚠️ 反問：此「實」是否為正虛邪陷？
                    └─ 若是：先補後攻，或攻補兼施，治療有次第
```

---

## 臨床要點

- 虛實不是二元對立，常常虛中夾實、以虛致實
- **正虛邪陷**是最容易誤判的類型：表面看似實證，根底是虛，若單純攻邪反傷正氣
- 把到沉脈，「有力 vs 無力」是第一手感，但需配合整體脈氣、兼脈及症狀綜合判斷
