# 胃脘痛診治思路（趙紹琴）

## says（核心觀點）

胃脘痛從氣滯起，依次演變為化熱、夾濕、食積、肝胃不和、入血分、熱傷胃陰、久痛入絡；每一層有其脈舌指徵，層層遞進，用藥隨之調整。

---

## 病機演變與對應治法

### 一、初起氣滯（單純，少見）
**脈象：** 脈弦

**治法：** 解鬱行氣

| 藥物 | 劑量 |
|------|------|
| 紫蘇 | 6g |
| 蘇梗 | 6g |
| 香附 | 10g |
| 陳皮 | 6g |
| 半夏 | 10g |

---

### 二、氣鬱化熱
**脈象：** 脈轉弦滑　**舌象：** 舌尖紅起刺

**加藥：**
- 川楝子 6g　延胡索 3g

---

### 三、夾濕
**舌象：** 苔白膩

**加藥（溫化）：**
- 肉桂 1.5g　炮薑 1.5g

**苔白脈沉、濕郁氣機：**
- 蘇梗 6g　藿香 6g　佛手 6g

---

### 四、食積
**舌象：** 苔黃厚　**症狀：** 腹脹

**加藥：**
- 焦麥芽 10g　香稻芽 10g　六神曲 10g　雞內金 10g

---

### 五、肝胃不和（肝火犯胃）
**脈象：** 弦數　**症狀：** 心煩易怒、口甘苦

**治法：** 辛開苦降

- 吳茱萸 1g　黃連 10g

---

### 六、入血分
**加藥：**
- 蒲黃 10g　五靈脂 10g

---

### 七、久病熱傷胃陰、陽亢
**治法：** 滋陰活血緩痛

| 藥物 | 劑量 |
|------|------|
| 沙參 | 12g |
| 麥冬 | 10g |
| 白芍 | 12g |
| 川楝子 | 12g |
| 延胡索 | 適量 |
| 蒲黃 | 10g |
| 五靈脂 | 10g |
| 香附 | 10g |
| 吳茱萸 | 1g |
| 黃連 | 10g |

---

### 八、久痛入絡
**脈象：** 脈沉澀　**舌象：** 舌質暗、有瘀斑
**症狀：** 痛有定處、痛如針刺、面色滯暗

**治法：** 活血化瘀通絡

| 藥物 | 劑量 |
|------|------|
| 五靈脂 | 10g |
| 生蒲黃 | 10g |
| 茜草 | 10g |
| 川楝子 | 10g |
| 白芍 | 10g |
| 當歸 | 10g |

> 視情況可配合氣血雙補
