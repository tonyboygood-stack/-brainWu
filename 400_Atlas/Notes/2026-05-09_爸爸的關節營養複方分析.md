# 爸爸的關節營養複方分析

## 複方組成

| 成分 | 作用機制 |
|------|----------|
| **UCII**（非變性二型膠原蛋白） | 腸道免疫耐受，阻斷自體免疫攻擊 |
| **II型膠原蛋白**（一般） | 提供建築原料，補充軟骨基質 |
| **軟骨素** | 補充關節滑液成分，維持軟骨彈性 |
| **檸檬馬鞭草** | 號稱活血，促進局部循環 |
| **薑黃** | 抗發炎（Curcumin 抑制 NF-κB 等發炎路徑） |

## 用中醫複方角度解讀

整體設計邏輯對應四個策略：

1. **阻斷誤攻**：UCII → 免疫耐受，讓身體停止攻擊自己的軟骨（治本）
2. **補陰填精**：II型膠原蛋白 + 軟骨素 → 提供原料，修復已損耗的軟骨結構（補虛）
3. **活血通絡**：檸檬馬鞭草 → 改善局部循環，讓原料得以輸送（通道）
4. **清熱消炎**：薑黃 → 壓制急性發炎反應（治標）

> 中醫複方思路：先通（活血）、再補（填精）、同時清（消炎）、根本斷（免疫調控）。
> 這個配方設計者明顯考慮了「障礙賽」問題——加入活血成分，試圖改善循環來提高原料到達關節的機會。

## 值得注意的問題

- **UCII vs 一般膠原蛋白**：兩者同時存在的必要性？UCII 走免疫路徑，一般膠原蛋白走材料路徑，理論上互補，但若一般膠原蛋白在腸道也被辨識，是否干擾 UCII 的耐受機制？（待查）
- **軟骨素的實際到達率**：仍受制於關卡二（無血管、滲透障礙）→ 見 [[2026-05-09_營養補充品走入關節的障礙賽]]
- **薑黃的吸收率問題**：薑黃素本身生物利用率極低，需搭配黑胡椒素（Piperine）或脂質包覆才有效——此複方有無考慮？
