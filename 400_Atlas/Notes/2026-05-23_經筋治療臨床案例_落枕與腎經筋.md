# 經筋治療臨床案例：落枕與腎經筋

## 落枕案例

**主訴：** 頸部僵痛，無法低頭、左右旋轉受限

**辨經筋：**
- 左右旋轉障礙 → 三焦經筋（少陽）
- 俯仰（低頭抬頭）障礙 → 小腸經筋（太陽）

**治療流程：**
1. 井穴 + 匯合穴（三焦、小腸各經）
2. 局部鑿刺排風
3. 三焦經處理 → 左右旋轉即時改善
4. 小腸經處理 → 低頭抬頭疼痛改善
5. 干針：提肩胛肌局部（病人痛感明顯，待檢討）

**臨床心得：**
- 動作方向是辨經筋的關鍵：旋轉 = 少陽，俯仰 = 太陽
- 提肩胛干針痛感大，需複習進針技術或評估替代穴位

## 腎經筋案例

**主訴：** 翹腳穿襪子動作無法完成（屈髖、外旋）

**辨經筋：** 腎經筋（此動作涉及腎經筋循行區域）

**待複習：** 腎經井穴（湧泉）在經筋治療的用法 → 見 [[腎經井穴在經筋治療的用法]]

**狀態：** 回家複習後補充

---

## 辨經筋動作辨位法（初步整理）

| 動作障礙 | 對應經筋 |
| -------- | -------- |
| 頸部左右旋轉 | 三焦經筋（少陽） |
| 頸部俯仰 | 小腸經筋（太陽） |
| 翹腳 / 屈髖外旋 | 腎經筋 |
