# 正虛邪陷：中氣受損後的痰飲上逆

## 與純虛型的區別

| | 純虛型（大氣下陷） | 正虛邪陷型 |
| --- | --- | --- |
| 體質背景 | 純氣虛，無明顯痰飲 | 素有水飲痰濁，中氣偏弱 |
| 發作誘因 | 長期消耗 | 勞累、飲食不節即可觸發 |
| 邪氣表現 | 不明顯 | 痰飲上衝、腸鳴下利、寒熱錯雜 |
| 現代常見度 | 較少 | **多數** |

## 病機核心

- 現代飲食習慣（煎炸、冷飲）→ 痰飲水濕積存
- 中氣一傷，無力運化 → **痰飲水濕馬上顯露加重**
- 客氣（邪氣）趁虛上逆 → 心下痞、嘔、腸鳴、下利

## 典型臨床表現

- 講話多或勞累後 → 喉嚨生痰、頭暈冷汗、痰濁上衝
- 吃冷腹瀉，吃熱上火（**中焦虛而邪氣阻滯的典型矛盾**）
- 吃煎炸油膩後腸胃無法運化 → 上火或腹瀉

## 進程：從實瀉到虛瀉

```
飲食不節（煎炸油膩＋飲冷）
         ↓
實瀉期：葛根芩連湯（清熱止利，邪實為主）
         ↓ 若下利不止，中氣受損
虛瀉期：甘草瀉心湯（補中降逆，中虛客氣上逆）
```

> 中氣越虛，客氣上逆越明顯——這也能理解部分冠心病患者可從瀉心湯、理中湯角度治療。

## 條文依據（甘草瀉心湯）

> 「傷寒中風，醫反下之，其人下利日數十行，穀不化，腹中雷鳴，心下痞鞕而滿，乾嘔，心煩不得安，醫見心下痞，謂病不盡，復下之，其痞益甚，此非結熱，但以胃中虛，客氣上逆，故使鞕也，甘草瀉心湯主之。」（158條）

### 病機與主症比較

| | 半夏瀉心湯 | 生薑瀉心湯 | 甘草瀉心湯 |
| --- | --- | --- | --- |
| **核心病機** | 寒熱錯雜，胃氣不降 | 寒熱錯雜＋**食積水飲** | 寒熱錯雜＋**中氣大虛** |
| **特徵症狀** | 嘔、下利、心下痞（滿而不痛） | 噫氣食臭、脅下水氣、腸鳴 | 下利日十行、心煩、心下痞硬 |
| **辨識關鍵** | 標準痞證基礎方 | 有**食臭噯氣**（食積氣味） | **中虛最重**，下利頻次多 |
| **邪氣側重** | 寒熱錯雜均衡 | 水飲食積偏重 | 客氣上逆最明顯 |

### 臨床辨識口訣

- **嘔而痞**，無特殊 → **半夏瀉心湯**
- **噯氣食臭**，有水飲 → **生薑瀉心湯**（加生薑散水，減乾薑防燥）
- **下利頻頻**，中氣大傷 → **甘草瀉心湯**（重甘草補中）
