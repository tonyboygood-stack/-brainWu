# MET 操作校正：PIR 與 RI 的起始角度差異

> 以「二頭肌放鬆」為例說明。

---

## 核心差異一句話

| | PIR | RI |
|---|---|---|
| 目的 | 活化**目標肌**的腱器官（GTO） | 活化**拮抗肌**，神經性斷電目標肌 |
| 起始角度 | 目標肌伸張**極限**（邊界） | 拮抗肌**最佳發力角度**（退回中間段） |
| 發力者 | 目標肌（二頭肌）輕度屈曲 | 拮抗肌（三頭肌）輕度伸直 |
| 機制 | GTO 腱器官 → 反射性放鬆 | 脊髓交互抑制迴路 → 強制斷電 |

---

## PIR 正確操作（以二頭肌為例）

**起始位置：** 手肘延伸到二頭肌「感覺緊繃、再過去就拉扯痛」的極限（約 160–170°）

**發力：** 請病人用二頭肌做屈曲（往 90° 方向），治療師給阻力擋住

**力量：⚠️ 僅 5–10%，不可因為「在極限感覺安全」就用力過大**
- 太大力會觸發牽張反射，反而讓肌肉更緊
- 目的是只活化 GTO，不是真的要彎手肘

**放鬆後：** 配合吐氣，治療師被動帶向新邊界，重複 3–5 次

---

## RI 正確操作（以二頭肌為例）

> **關鍵：RI 不能在手肘最直的位置操作**
> 關節快卡死的終點角度，三頭肌幾乎沒有收縮空間，RI 訊號極弱。

### 方式 A：等長 RI（最推薦）

**起始位置：** 退回 130–150°（三頭肌有充足收縮空間）

**操作：**
1. 請病人用三頭肌發力，試圖把手肘推直
2. 治療師的手給阻力擋住（維持等長）
3. 三頭肌在此角度出力效率最高 → 脊髓對二頭肌發出強烈抑制訊號
4. 放鬆後，治療師被動把手肘帶向完全伸直 → 通常輕易到位

### 方式 B：動態 RI（向心抗阻）

**起始位置：** 約 130–140°（更多屈曲，出力空間更充足）

**操作：**
- 請病人主動用三頭肌對抗治療師阻力，**沿路慢慢把手肘推直**
- 整段動作中三頭肌持續收縮 → 二頭肌沿路被神經性放鬆
- 神經效益比靜態 RI 更持續，適合頑固緊繃

---

## PIR + RI 搭配順序

```
PIR（在伸張極限）
    → 目標肌初步鬆弛，邊界推進到 170°
    ↓
切換 RI（退回 150°，三頭肌發力）
    → 神經性斷電，深化放鬆
    ↓
治療師被動帶向完全伸直
    → 通常輕易到達 180°
```
