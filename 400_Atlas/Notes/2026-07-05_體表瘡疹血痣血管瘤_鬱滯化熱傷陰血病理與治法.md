# 體表瘡疹血痣血管瘤——鬱滯化熱傷陰血病理與治法

## 一、病理：鬱滯 → 陽氣鬱而化熱 → 傷陰血

體表出現的瘡、血痣、櫻桃血管瘤、紅疹等，病理常常是血循過程受到鬱滯或阻礙，影響陽氣疏布——可能因**寒凝、氣滯、血瘀、濕阻**等。

陽氣鬱而化熱而生；熱鬱也傷陰血。

## 二、治法：養陰、清熱活血 + 解表

| 治法 | 用藥 |
|------|------|
| 解表 | 荊芥、石菖蒲、薄荷、連翹 |
| 養陰 | 生地 |
| 清熱活血 | 丹參、夏枯草 |
