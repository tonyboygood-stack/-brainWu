# 瓜蔞薤白——振奮心陽與肺痰熱累心模型

## 一、瓜蔞薤白白酒湯：振奮心陽、驅散陰邪

心臟不適（胸悶、渾身涼、疲倦、不出汗）很多時候是**動能不足＋體表不通**：陽氣被鬱閉在裡，像烏雲罩頂。

臨床觀察：喝點感冒藥、身體微微出汗，心臟反而舒服——就是體表一通，陽氣打開，烏雲散掉。

瓜蔞薤白白酒湯正是**振奮心陽、驅散陰邪**的經典方，白酒辛散升提、薤白辛溫通陽，兩者相合開胸中陽氣。

## 二、瓜蔞的性味定位

- 瓜蔞皮：清熱化痰、利氣寬胸
- 瓜蔞仁：潤肺化痰，兼滑腸通便

## 三、病理模型：肺痰熱累心（慢性心衰／心肌肥大的路徑）

**傳變邏輯：**

中焦堵塞不通 → 熱浮於上 → 肺熱灼津為痰 → 痰熱蘊肺 → 心臟送血入肺變得吃力（心之熱本可散肺之寒，今肺氣道不通，心臟負荷加重）→ 久之慢性心衰竭、心肌肥大

**治療思路：** 治心先治肺——把肺處理好，心臟壓力自然減輕。

| 藥物 | 作用 |
|------|------|
| 瓜蔞 | 清肺熱、化痰，寬胸利氣 |
| 半夏 | 降氣和胃化痰，助右脈降下 |
| 薤白 | 振奮心陽 |

三藥合用（瓜蔞薤白半夏湯方向），讓右脈降下，心臟壓力減輕，同時振奮心陽——對「肺有黏痰、心臟不適」這組病理模型效果顯著。

**對應脈象：** 右脈上越、右寸關夾滑，左寸不足。
