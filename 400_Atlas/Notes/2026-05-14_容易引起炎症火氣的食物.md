# 容易引起炎症火氣的食物

## says（核心觀點）

這類食物助陽生熱，長期食用會加重體內炎症反應；對濕邪體質者，麩質與乳製品更會同時加重濕熱，需雙重限制。

---

## 主要引火食物

| 食物 | 說明 |
|------|------|
| 大蒜、洋蔥 | 辛溫走竄，助火上行 |
| 辛辣香料 | 直接刺激胃火，助熱 |
| 酒 | 濕熱俱生，最易引發全身火氣 |
| 咖啡 | 興奮心火，加重上焦熱 |
| 巧克力 | 同上，心火刺激物 |

## 對部分人有影響（個體差異）

| 食物 | 機制 |
|------|------|
| 麩質（小麥製品）| 引發腸道炎症，間接生熱 |
| 牛奶、起司 | 乳製品生痰助濕，濕鬱化熱 |

---

## 臨床應用

- 火氣旺、易上火者 → 優先戒酒、咖啡、辛辣
- 舌苔厚膩兼有熱象者 → 同時限制麩質＋乳製品
- 衛教重點：**不需要全戒，但急性期或症狀明顯時暫時迴避**
