# 大柴胡湯：中焦氣結辨治框架

**原方：** 柴胡、黃芩、芍藥、半夏、生薑、枳實、大棗、大黃

---

## 典型脈象

- 關脈鬱而獨大
- 輕取：氣弦
- 重按：滑有力

---

## 核心病理

**中焦氣結 → 實邪阻滯**

實邪無法從表走，**二便才是出口**，大黃是通道的關鍵。

與血府逐瘀湯對比：
| | 中焦氣結後的走向 |
|---|---|
| 大柴胡湯 | → 痰熱（或其他實邪）滯留 |
| 血府逐瘀湯 | → 血瘀滯留 |

---

## 加減法：氣弦脈下藏著什麼？

| 病理 | 脈/舌提示 | 加減方向 |
|------|---------|---------|
| 痰熱 | 重按滑數 | 黃芩 + 半夏（原方）/ 小陷胸 |
| 寒濕 | 白膩苔 | 蒼朮、改生薑→乾薑 |
| 食積 | | 保和丸加減 |
| 寒凝 | 關脈緊硬 | 吳茱萸、乾薑 |
| 血瘀 | 尺澀 | 當歸、桃仁、茜草 |
| 痰濁 | 沉取滑 | 二陳湯 + 決明子、小量大黃 |

> 氣弦 = 氣機鬱結（四逆散底層）
> 氣弦下細看：重按藏什麼，就補什麼邪出路

---

## 案例三要點（寒實重案）

雙關大緊硬而實、尺沉細澀，主訴小腹痛、小便細不暢、大便乾：
- 緊硬 → 寒邪阻滯，寒飲結中焦
- 尺細澀 → 血虛血瘀夾熱
- 治法：乾薑 + 吳茱萸（針對寒實） + 升降散（開散結聚） + 四逆散 + 大黃（給邪出口） + 四物 + 丹皮（血虛血瘀）

---

## 老吳的臨床思考

臨床常用小柴胡湯（少陽病、感冒內陷），大柴胡湯讓思路更深一層：

> **中焦氣結之後，發生了什麼？**

氣弦脈是共同點，差別在氣弦下的病理：細查舌脈，順著疏散鬱結，選對應邪氣的出口。

**值得嘗試：大柴胡湯 + 越麴丸隨證加減**

越麴丸（蒼朮 9g、香附 9g、川芎 9g、神麴 9g、梔子 9g）—— 本身就是治各類中焦阻滯（氣、血、痰、火、食、濕六鬱），與大柴胡框架邏輯相通。
