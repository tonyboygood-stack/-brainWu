# 大氣下陷脈象與升陷湯

## 脈象特徵

- **整體沉弱**，寸關前（左寸）更明顯
- 屬純虛無邪的氣虛類型
- 生理上寸脈應能上浮至三菽（肺氣能宣的基準）；整體沉本就代表虛不能升

## 外候（症狀）

| 機理 | 症狀 |
| ---- | ---- |
| 氣虛無法上達 | 短氣、喘、胸滿悶 |
| 水分送不上去 | 咽乾口渴 |
| 清陽不升 | 腹瀉便溏 |
| 嚴重時 | 神昏健忘 |

## 舌象注意

- 不要以為氣虛必然舌淡
- 氣虛下陷日久 → 鬱熱（身體代償之熱） → **可見舌紅**
- 這也是升陷湯加知母的原因

## 老吳的思考

- 大氣下陷典型是沉弱寸更明顯，但也有**整體沉弱差不多**的情況
- 關鍵在於：1. 寸脈能否上浮三菽　2. 搭配外候：胸悶、喘、消耗加重、口乾、便溏
- **基本上不會只有肺氣虛**：通常是脾虛不升在前，肺自然無以宣發，所以右關也不會好

## 升陷湯（張錫純《醫學衷中參西錄》）

**原方組成：**

| 藥 | 量 |
| --- | --- |
| 生黃芪 | 18g |
| 知母 | 9g |
| 柴胡 | 4.5g |
| 桔梗 | 4.5g |
| 升麻 | 3g |

**藥義：**
- 黃芪：大補宗氣，為主藥
- 柴胡、升麻、桔梗：升提氣機，使大氣復位
- 知母：制黃芪溫燥，兼清鬱熱

**主治：** 大氣下陷，氣短不足以息，努力呼吸，脈沉遲微弱（左寸尤甚）

## 書中案例（《圖解脈診》）

**患者**：男，36歲，反覆咳嗽

- 前醫用止嗽散無效
- 走路時咳嗽加重（消耗加重）
- 嚴重口乾、大便溏稀
- 脈：整體沉，左細右弱，舌底偏紅

**辨證**：大氣下陷＋脾虛不升＋鬱熱

**處方（升陷湯加減）：**

柴胡 15g、桂枝 6g、桔梗 10g、黃芪 20g、升麻 6g、葛根 30g、當歸 12g、黨參 25g、白術 20g、炙甘草 10g、桑寄生 30g、知母 10g、澤瀉 15g、生地黃 20g

**盡劑而愈**

> 作者自評：生地黃為畫蛇添足，此處舌紅屬鬱熱，知母已足。
