# 經筋治療：同名經互用策略

## 核心概念

手經筋的問題會反映到足經筋（同名經），治療效果不佳時，**考慮檢查並鬆開同名經的對應經筋**。

---

## 同名經對應表

| 手經筋 | 足經筋 | 同名 |
| ------ | ------ | ---- |
| 手太陽小腸經 | 足太陽膀胱經 | 太陽 |
| 手陽明大腸經 | 足陽明胃經 | 陽明 |
| 手少陽三焦經 | 足少陽膽經 | 少陽 |
| 手太陰肺經 | 足太陰脾經 | 太陰 |
| 手少陰心經 | 足少陰腎經 | 少陰 |
| 手厥陰心包經 | 足厥陰肝經 | 厥陰 |

---

## 臨床應用

**例：治療小腸經效果不佳 → 檢查並鬆開膀胱經**

當主治經筋反應不理想，沿同名的手/足另一條經筋尋找緊繃或壓痛點，先鬆解後再回頭治療原經筋。
