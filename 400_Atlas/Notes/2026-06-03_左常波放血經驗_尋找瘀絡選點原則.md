# 左常波放血經驗——尋找瘀絡選點原則

> 核心邏輯：依**病灶位置**選策略，再在對應區望診找瘀絡（青紅紫色小血管）。
> ⚠️ **評估原則：有反應徵象才治療**——無壓痛、無瘀絡就不做。

---

## 一、病灶在四肢

**策略：循經在上下望診，找瘀絡（遠近皆可）**

- 沿病灶所在的經脈，往近端或遠端延伸找異常血管
- 見到靜脈在分叉處分向兩指時，可兩根各自放血

**應象系統（手指對應）：**

| 手指 | 對應部位 |
| ---- | -------- |
| 拇指 + 食指 | 拇指、食指及上肢遠端 |
| 食指、無名指 | 上肢（食指優先，因病位在食指，且往往放了食指拇指也緩解）|

**臨床案例：**
- 拇食指（1、2指）麻木，夜間加重晨起緩解 → 血瘀指徵 → 在拇食指對應線找到瘀絡放血 → 手指麻木快速緩解，效果立竿見影
- 拇指背側痛無法下壓 → 拇指背側找到瘀絡放血 → 馬上緩解

---

## 二、病灶在頭面五官或內臟

### 局部刺血
在病灶附近或臟腑體表投影區找瘀絡

**案例：** 深呼吸脅肋痛 → 期門附近找到瘀絡放血拔罐 → 整體緩解

### 手膝關節附近與下肢反應區

| 臟腑問題 | 對應放血區 |
| -------- | ---------- |
| 肝膽 | 腿外側膽經找瘀絡 |
| 心臟不適 | 手肘（可再找心前區或背俞穴，先拔罐找出痧點再放血）|
| 臟腑通用 | 小腿內側分上中下找瘀絡 |

### 應象微絡刺血（手掌部）

**大拇指全段對應地圖：**

| 區段 | 對應部位 |
| ---- | -------- |
| 遠端指節 | 頭面 |
| 近端指節 | 頸部 |
| 大魚際上 1/3 | 上焦（心肺） |
| 大魚際中 1/3 | 中焦（脾胃） |
| 大魚際下 1/3 | 下焦（肝腎、下腹） |

**其他手指：**

| 手指 | 對應部位 |
| ---- | -------- |
| 中指指頭 | 頭面 |

找紫紅色小血管刺入。

---

## 三、血管太細看不清時

1. **酒精擦拭** → 找紅點刺血拔罐
2. **先拔罐** → 再針對最明顯出痧點放血拔罐
