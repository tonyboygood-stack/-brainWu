# 丹參——養心陰血、活血涼血與丹桂湯

## 一、丹參的定位：功同四物湯

丹參活血、也能養陰血、涼血，古有「一味丹參飲，功同四物湯」之說。

## 二、現代人的病理：陰血虛→熱→瘀

現代人熬夜、睡眠不足，陰血耗傷，心臟跳動產生的熱無法順利送出，久而形成血熱。

- 脈見**細數**：陰血虛＋熱
- 熱久更傷氣陰，容易**氣陰兩虛、虛火上冒**
- 症狀：渾身沒勁、手麻、咽喉不適、鼻冒熱氣、上火，**舌尖紅**

## 三、心臟三味用藥對應

| 需求 | 用藥 |
|------|------|
| 補心氣 | 紅參 |
| 補心陽 | 桂枝 |
| 補心陰血、活血涼血 | 丹參（脈細、舌尖紅、有瘀者可用到 30-50g） |

## 四、驗方：丹桂湯

**組成：** 丹參20g、桂枝10g、生薑20g、大棗5枚、炙甘草8g

**方義：** 養陰血，助推動而溫通＋活血化瘀

**適應：** 對血瘀效果佳
