# 現代人的誤下——中焦陽傷的現代病因

## 核心觀點

傷寒論大量描述「誤下」後中氣虛損的變證（痞證、下利、嘔逆等），看似是古代醫療失誤才有的情況，但**現代人傷中氣的機會其實更多**，只是換了形式。

## 現代版的「誤下」

| 現代行為 | 傷中機理 |
| --- | --- |
| 飲食生冷（冷飲、冰淇淋） | 寒邪直中中焦，損脾陽 |
| 大量螃蟹 | 性寒質膩，傷脾滯中 |
| 大量蔬食瓜果 | 多性涼，生食尤傷脾陽 |
| 綠拿鐵（生蔬菜汁） | 寒涼生冷，與誤服寒藥無異 |
| 濫用瀉藥（排便不暢自行用藥） | **最直接**，與傷寒論「誤下」幾乎等同 |

## 臨床意義

- 見到心下痞、腸鳴下利、寒熱錯雜的症狀群，**不要只從感染、腸躁症思考**
- 先問：近期有沒有大量生冷？有沒有自行服用瀉藥或清腸食物？
- 這一問往往就能定位病因，直接對應瀉心湯類方

## 與傷寒論的對應

```
古代：誤下（苦寒瀉藥）→ 中氣受損 → 痞證/下利
現代：生冷飲食／濫用瀉藥 → 中氣受損 → 同樣的痞證/下利
```

傷寒論的條文不是在講古代，是在講病機——**病機不變，只是病因換了包裝**。
