# 以脈測症，脈證合參

## 一、察整體資源

### 1. 氣是否充足
- 沉取力度弱，不耐重按 → **氣虛**：疲憊、少氣懶言、四肢無力、虛汗、易感冒
- 沉取無力＋脈搏緩慢（甚至 <60）→ **陽虛**：長期怕冷、手足冰冷

### 2. 津液是否充足
- 整體脈偏細＋左尺不足 → **津液虧虛**：眼乾澀、多夢易醒、口乾汗少、皮膚乾燥、脫髮、經血量少

### 3. 腎精是否充足
- 察雙尺，沉弱空虛 → **精虧**：不耐勞、腰痠腿軟、抵抗力差、恢復力差、虛汗，嚴重則影響生殖發育（參 [[2026-06-30_左尺沉取腎陰_腎陰是臟腑陰質的根源]]）

### 4. 觸診補一手（李辛老師）
- **踝內側、大魚際小魚際虛軟凹陷、小腹虛冷** → 下焦資源不足（參 [[2026-08-15_李辛下焦資源評估_元氣不足與精虛的分層]]）
- **肌肉鬆弛無力** → 中焦資源不足（參 [[2026-08-15_李辛中焦資源評估_虛則闔補實則通運]]）
- 下焦虛還要再分深淺：元氣不足（陽動，甘溫辛熱）vs 精虛（陰靜，酸鹹沉降），治療方向相反

## 二、察通道

> ⚠️ 待補

## 三、察脈勢

脈勢反映能量分布狀態：
- **甲字脈**：能量在上，下虛（參 [[2026-07-02_決明子_降膽助肝火下降滋水涵木]]、[[2026-07-02_夏枯草貓爪草_清熱散結治肝膽痰結]]、[[2026-07-02_懷牛膝川牛膝_左右路降法與補肝腎]]）
- **申字脈**：能量卡在中焦
- **由字脈**：能量卡在下，上虛
- **凸脈**：能量浮在表，內在空虛
- **凹字脈**：能量沉在裡，表層空虛（參 [[2026-06-25_凹字脈_風藥升陽開表法]]）

## 四、察獨處

- 獨處分**獨強、獨弱**
- 臨床症狀多出現在**獨弱**處
- 獨弱常見於寸、尺；**關脈獨弱則陰陽離絕**，臨床較少見

## 五、辨別邪氣

- 脈粗大濡滑，皮膚黏、大便黏、身體困重乏力 → **痰濕**（參 [[2026-07-05_絲瓜絡_通三焦排痰濕主藥]]、[[2026-05-23_理中湯脈象與脾虛病理鏈（圖解脈診）]]）
- 左寸不足、右關與關下鬱大 → **腸積**：大便色深、不規律，肩胛區不適、胃脹、心前區不適
- 脈滑數燥 → **內熱**：怕熱喜冷飲
- 脈弦緊 → **寒凝**：多痛、喜溫惡寒
- 整體脈弦，左關鬱大 → **氣滯**：情志不暢、善太息、胸脅苦滿（參 [[2026-05-14_沉脈：氣鬱在裏（雙關沉弦）]]、[[2026-05-23_大柴胡湯_中焦氣結辨治框架]]）
- 脈滯澀 → **血瘀**：定點刺痛、下肢皮膚乾燥、血塊、經色暗（參 [[2026-05-30_放血療法的使用與診斷基礎]]）
