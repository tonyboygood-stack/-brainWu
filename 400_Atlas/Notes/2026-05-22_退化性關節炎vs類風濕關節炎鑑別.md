# 退化性關節炎 vs 類風濕關節炎鑑別

## 鑑別表

| 鑑別點 | 退化性關節炎（OA） | 類風濕關節炎（RA）|
|---|---|---|
| **好發關節** | DIP（遠端第一指節）、PIP | MCP（掌指）、PIP（近端第二指節）|
| **分佈型態** | 不對稱 | **對稱** |
| **晨僵時間** | < 30 分鐘 | **> 1 小時** |
| **疼痛特性** | 活動後加重，休息改善 | 休息後反而僵，動了才鬆 |
| **全身症狀** | 無 | 疲倦、低燒、體重減輕 |
| **抽血** | 正常 | RF(+)、anti-CCP(+)、ESR↑、CRP↑ |
| **X 光** | 骨刺、關節間隙狹窄 | 骨侵蝕（erosion）、骨質疏鬆 |
| **中醫對應** | 腎虛骨退、氣滯血瘀 | 熱痹、風濕熱痹、或久病入絡 |

## 記憶點

- **Heberden 結節** = DIP 骨性突起 → OA 特徵
- **Bouchard 結節** = PIP 骨性突起 → OA（RA 在 PIP 是軟組織腫，非骨性）
- RA 可有關節外表現：類風濕結節、肺間質病變、鞏膜炎

## 臨床鑑別四問

看到手指關節痛，依序問：
1. **遠端還是近端？**（DIP → OA；MCP/PIP → 考慮 RA）
2. **活動後加重還是緩解？**（加重 → OA；活動後鬆開 → RA）
3. **對稱嗎？**（不對稱 → OA；對稱 → RA）
4. **有無全身免疫症狀？**（疲倦、低燒、乾燥、皮疹 → RA / 其他自體免疫）
