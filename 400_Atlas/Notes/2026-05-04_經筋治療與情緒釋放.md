# 經筋治療與情緒釋放

## 核心概念

經筋依附於骨骼，穿過筋膜、韌帶。當創傷發生而未被心理妥善處理時，衝擊力會被**儲存在經筋**中，屬於「衛分」層面的潛意識。

治療經筋時，可能觸發儲存的情緒，患者出現**情緒低落或恐懼**是正常的釋放反應。

---

## 臨床操作要點

### 建立有意識連結
治療時主動詢問創傷當下的細節：
- 車上有誰？
- 當時的狀態、感受？

幫助身體從潛意識層面「有意識地重新連結」創傷記憶，促進整合。

### 情緒強烈時：絡脈放血
根據表現的情緒，選對應絡穴放血協助疏散：

| 情緒 | 絡穴 |
| ---- | ---- |
| 恐懼 | 膀胱絡穴（飛揚 BL58） |
| 憂鬱 / 憤怒 | 肝膽經絡穴 |
| 過度思考 | 胃絡穴（豐隆 ST40） |

---

## 外分泌釋放是清理的訊號

情緒釋放必然伴隨「外分泌釋放」：

- **出汗**
- **流淚**

經筋（衛分）與液體有關，汗與淚是身體清理情緒的自然管道，出現時代表治療有在深層作用。
