# 滋陰消斑湯

> 來源：《婦科方藥臨證心得十五講》→ [[婦科方藥臨證心得十五講]]

## 組成

| 藥物 | 劑量 |
| ---- | ---- |
| 熟地黃 | 10g |
| 山藥 | 10g |
| 山茱萸 | 10g |
| 茯苓 | 10g |
| 澤瀉 | 10g |
| 牡丹皮 | 10g |
| 丹參 | 10g |
| 赤芍 | 10g |
| 五靈脂 | 10g |
| 玄參 | 10g |
| 懷牛膝 | 10g |

> 六味地黃丸六味各 10g 為底

## 主治 / 適應症

- 更年期婦女黃褐斑（主症）
- 同病機延伸：婦科病、盆腔炎

## 病機分析

**陰虛火旺**夾**血瘀**（或夾痰濕）

→ 治則：滋陰降火，活血化瘀

## 方義解析

- **六味地黃丸**（熟地、山藥、山茱萸、茯苓、澤瀉、丹皮）：滋補腎陰，清虛火
- **丹參、赤芍、五靈脂**：活血化瘀消斑
- **玄參**：清熱滋陰
- **懷牛膝**：補肝腎，引血下行（引火歸元）

## 臨床加減

| 症狀 | 操作 |
| ---- | ---- |
| 腹脹痛、便稀軟 | 去玄參、熟地；加木香、白朮、陳皮 |
| 經前 | 可配合補陽：杜仲、續斷 |
| 合方選項 | 血府逐瘀湯 |

## 使用注意

- ❌ 脾胃虛弱便溏 → 不宜
- ❌ 行經期間 → 不宜（尤其量少腹痛者）
- ✅ 經後服較佳
- ⏳ 用藥需耐心，效果緩慢
