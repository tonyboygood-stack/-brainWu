
## 經筋治療：第一部分 —— 臨床操作與疼痛管理

### 問題一：如何減輕經筋治療的痛感？（Daniel 提問）

**Daniel 提問：** 部分患者覺得這種技術太痛。除了改用「鑚法」（Chiseling technique）外，還有什麼方法可以減少不適感？

- **Ann 的回答：**
    
    - **患者的容忍度：** 如果治療能產生顯著的療效，患者通常會原諒治療中的不適。
        
    
    - **鑚法（Chiseling technique）：** 這是一種較溫和的手法，動作來自**肩膀**，而不是手腕或手指。雖然溫和，但可能需要更多操作才能解決問題。
        
    
    - **撚轉法（Twisting technique）：** 針刺入後旋轉，抓住組織（皮肉會隨之牽拉）。這在損傷部位非常疼痛，但療效驚人。
        
    
    - **關鍵技術細節：** 使用**進針管**時，請**用力按壓**。這會拉緊皮膚（像繃緊的鼓皮），針頭刺入時會變得非常輕快，患者痛感大幅降低。
        
    
    - **正確診斷：** 疼痛減輕最好的方法是「找對經絡」。不要只治療痛點，要透過**動作評估**（哪種動作最受限）來決定治療哪條經筋。
        

- **Cody 的補充：**
    
    - **拔罐輔助：** 在面積較大（如背部）或組織太緊的地方，我會先**拔罐**以鬆開組織，減少針刺時的拉扯感，然後再針對特定點進行經筋手法。

## 古針案例: 經筋與情緒：隱藏在「衛分」中的創傷

### 經筋治療會引發情緒釋放嗎？（Amanda 的案例）

**Amanda 分享：** 一位女性患者曾被車撞過（右側）。治療時，Ann 發現她的右側背部反應極度敏感，甚至手掌懸空在其上方，肌肉都會抽搐。治療後，患者經歷了前所未有的「黑暗情緒」並大哭一場，隨後感覺煥然一新。

- **Ann 的分析：**
    
    - **潛意識的儲存庫：** 經筋依附於骨骼，穿過筋膜、韌帶。當創傷發生而未被心理妥善處理時，衝擊力會被儲存在經筋中（屬於「衛分」層面的潛意識）。
        
    
    - **修復危機（Healing Crisis）：** 治療將深藏的能量帶到表層。患者在情緒釋放過程中，可能會經歷短暫的情緒低落或恐懼。
        
    
    - **整合治療：** * **溝通：** 在治療時詢問細節（如當時車上還有誰？燈號是什麼？），幫助身體有意識地連結創傷並解鎖。
        
        - **絡脈（Luo Channels）放血：** 如果情緒過於強烈或無法消散，應配合**絡穴放血**（Luò point bleeding）。
            
        
        - **五志對應：** 根據表現出的情緒選擇絡穴：恐懼（膀胱 58）、憂鬱/憤怒（肝膽經絡穴）、過度思考（胃 40）。

> **重點筆記：** 情緒的釋放必然伴隨著「外分泌釋放」，如**出汗**或**流淚**。經筋（衛分）與液體有關，汗與淚是清理情緒的管道。

## 多經絡治療的順序與效率

### 問題三：如何在 60 分鐘內治療多條經筋？（Alexander 提問）

**Alexander 提問：** 如果患者同時顯示多條經筋（如太陽、少陽、陽明、少陰）的問題，該如何安排順序？

- **Ann 的操作策略：**
    
    1. **由內而外（From Interior to Exterior）：** 必須從最內層的經筋開始，例如**少陰（Shaoyin）**，以防止將邪氣推向更深層。
        
    
    2. **單側 vs. 雙側：** 先治療患側。通常處理完內層經筋後，外層的疼痛會自行消失。
        
    
    3. **高效率尋找「阻力點」：** 不需要針對每一寸皮膚操作。沿著經筋走向快速按壓，尋找明顯「反彈」或硬結的點，在那裡進針即可。
        
    
    4. **區域連結：** 如果是手經筋的問題（如心經筋），通常會反應到足經筋（如腎經筋）。如果上肢治療效果不佳，必須檢查並鬆開下肢的相對經筋。

## 確保經筋治療成功的四大支柱

Ann 強調，如果以下四個要素（參數）不在狀態，經筋治療將會失敗：

|                           |                       |                                                     |
| ------------------------- | --------------------- | --------------------------------------------------- |
| **要素**                    | **評估方式（脈診/表現）**       | **處理方案**                                            |
| **1. 津液（Hydration）**      | 胃脈（中層）過細，顯示津液不足。      | 給患者喝水，針刺**胃 42**、**中脘（Ren 12）或消濼（SJ 10）**。          |
| **2. 腎陽（Kidney Yang）**    | 腎脈（深層 12 豆以下）無力。      | 在**太溪（KI 3）施以艾灸**。腎陽是經筋運行的動力。                       |
| **3. 肝氣（Liver Flow）**     | 肝脈（左關中層）顯現「弦脈」（Wiry）。 | 針刺**期門（LIV 14）**、**章門（LIV 13）**或**膈俞（BL 17）**以疏通氣機。 |
| **4. 肺氣（Lung Diffusion）** | 肺脈無法隨手指抬起而浮現於表層。      | 針刺**列缺（LUN 7）**，幫助衛氣宣發至體表。                          |

## 結語與醫囑建議

- **72 小時原則：** 經筋治療需要 72 小時（三天）才能完成一個完整的衛氣循環。在診療床上，我們只追求「顯著改善」；完整的修復請叮囑患者在 72 小時後再評估。
    

- **醫病信任：** 告訴患者這是一個「時間彈簧」，能讓他們帶著期待與放鬆離開診間，而非帶著審判與焦慮。
