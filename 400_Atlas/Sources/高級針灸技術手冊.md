# 高級針灸技術手冊

> 來源節錄：經別（Divergent Channels）章節

---

## 經別基本理論

經別可以成功地用於治療多種慢性退行性疾病。身體為了預防更嚴重的疾病而創造一種緩慢進展的疾病或較輕的慢性疾病，這是一種自然的反應。我們稱之為**疾病剋星理論**。經別是這個過程中的關鍵參與者。**經別只在存在病理的情況下才存在。**在沒有病理的情況下，它們沒有被調動的必要。

經別的功能是將致病因素從臟腑中轉移開，因為在臟腑中致病因素可能是致命的，並將其送往關節（外部解剖學的最深層）以保持潛伏（隱藏）。因此，**經別在衛氣層和原氣層之間進行溝通**，衛氣層是致病因素進入的層次，而原氣層是身體遏制致病因素並使其保持靜止的層次。

---

## 案例研究（胃/脾經別）

一名 46 歲女性，「過勞且睡眠不足」，嚴重關節疼痛（左髖、左肘、左拇指），消化問題逐漸惡化（胃食道逆流、胃炎）。

- 約十年前曾臥床數日「腸胃型感冒」，嘔吐排出綠色液體
- 兩側關脈中層明顯細弱；脈無浮象；舌乾燥，中線裂紋

**診斷**：胃津不足，衛氣困於關節導致痹阻
**病因**：病毒感染在胃部被經別截斷，轉移至主要關節（髖、肩）。患者從感冒中恢復但未完全清除病原體。十年後資源耗盡，經別無法再維持潛伏，病原體返回臟腑引起胃部問題。

**治療**：ST/SP 會合點 DSD。連續治療三天休息，第四天症狀消失（已導回關節），出現腰痛和鼻竇感染（病原體進入第一會合點），膀胱/腎經別完成清除。

---

## 致病因素的定義

致病因素可以是：氣候因素（風、寒、濕）、飲食因素、生態因素（污染、病毒、細菌、真菌、寄生蟲）、毒素（石棉、重金屬）或情緒。

潛伏狀態的維持完全取決於精氣。隨著精氣耗損，身體按以下順序調用其他資源：
**精氣 → 血液 → 津液（外分泌液）→ 液（內分泌液）→ 氣 → 陽氣**

---

## 六個經別會合點

共有十二條經別，分為六對會合點（每對共享四個穴位）。配對順序即疾病進展順序，逆轉時為疾病解決順序。

| 會合點 | 配對經別 | 媒介 | 上會合點 | 下會合點 |
|---|---|---|---|---|
| 第一 | 膀胱 / 腎 | 精氣 | BL-10 天柱 | BL-40 委中 |
| 第二 | 膽 / 肝 | 血液 | GB-1 童子髎 | CV-2 曲骨 |
| 第三 | 胃 / 脾 | 津液 | BL-1 睛明 | ST-30 氣衝 |
| 第四 | 小腸 / 心 | 厚液 | BL-1 睛明 | GB-22 淵腋 |
| 第五 | 三焦 / 心包 | 氣 | SJ-16 天牖 | CV-12 中脘 |
| 第六 | 大腸 / 肺 | 陽氣 | LI-18 扶突 | ST-12 缺盆 |

> 第五、第六會合點通常用於以犧牲氣（第五）和陽（第六）為代價來實現潛伏——資源已嚴重耗竭。

## 針刺手法

### DSD（深-淺-深）— 鞏固、使病原體潛伏

目標：將病原體帶到關節保持潛伏，或將致病因素從衛氣層/臟腑向外到關節。

**手法**：
a. 深刺入穴位（原氣層），小提插或震顫
b. 將針拖至衛氣層，提插或圓形手法
c. 將針推回深處，再次提插（動作要**慢**）

> DSD 不針刺井穴（目的是潛伏，不是釋放）

---

### SDS（淺-深-淺）— 釋放、將病原體排出

目標：將致病因素從原氣層移回體表排出。

**手法**：
a. 敲入衛氣層（針管深度），提插引動氣
b. 深刺入原氣層，提插或震顫
c. 將針拖回衛氣層，提插（動作要**快**）
d. 針留在衛氣層，幾乎懸空

> SDS 必須針刺井穴（提供病原體出口），否則可能導致病情惡化

---

## 適應症

**適用**：慢性、間歇性、單側症狀，或兩側交替出現的症狀。

**禁忌**：脈象細弱或澀滯時，不可使用 SDS（可能導致自身中毒）。若不確定，使用 DSD 建立媒介。

---

## 治療工具包（七種工具）

1. **會合點**：每對四穴，必須針刺，以 SDS 或 DSD 手法
2. **交會點**：中線單穴（通常 GV-20），僅用於 SDS，針尖指向有井穴的一側
3. **開啟點**：區分配對中兩條經別（膀胱和胃經別的開啟點=下會合點）
4. **循行點**：選擇性使用，針越少效果越強
5. **局部點（阿是穴）**：針後先觸診，很多時候疼痛已消失
6. **井穴**：僅 SDS 使用，激活經筋提供出口；不加井穴可能導致病原體倒流
7. **皮部**：刮痧釋放衛氣（SDS/DSD 皆可）

## 經別脈診

### 伏脈操作
施加壓力至骨骼（15「綠豆」壓力）→ 輕微放鬆（14「綠豆」）→ 若 14 有脈但 15 無脈，即為**經別脈**（病原體可維持潛伏）

### 脈位對應
| 脈位 | 對應經別 |
|---|---|
| 左寸 | 小腸/心 |
| 左關 | 膽/肝 |
| 左尺 | 膀胱/腎 |
| 右寸 | 大腸/肺 |
| 右關 | 胃/脾 |
| 右尺 | 三焦/心包 |

### 選擇會合點的依據（依序考量）
1. 脈的中層寬度（代表媒介資源）
2. 脈浮緊（身體試圖推出）→ SDS
3. 特定臟腑的強度
4. 媒介作用缺乏程度
5. 慢性單側間歇性問題的位置
6. 病情進展的層次
7. 症狀和體徵

## 六個會合點的媒介與關鍵短語

| 經別 | 關鍵短語 |
|---|---|
| BL（膀胱）| 在骨骼和關節中為致病因素尋找潛伏處，精氣衰退時顯現 |
| KI（腎）| 陽氣活動由陰轉化；腎經別是帶脈的緩衝區 |
| GB（膽）| 運化氣以使致病因素潛伏，需要血液運載氣 |
| LR（肝）| 利用血液支持精氣；安靜、深層的補血者 |
| ST（胃）| 稀液（外分泌液）移動以支持血液 |
| SP（脾）| 風動因稀液耗竭而起 |
| SI（小腸）| 厚液（內分泌液）被調動以支持稀液，衛氣內化到胸部 |
| HT（心）| 厚液流失導致潛伏狀態喪失；陽氣無法固守腰背 |
| TH（三焦）| 潛伏狀態完全喪失，氣正在流失 |
| PC（心包）| 津液和血液嚴重流失 |
| LI（大腸）| 末期，陽氣幾乎喪失 |
| LU（肺）| 引導衛氣與經脈和臟腑匯合；病理在 LU-1 處進入臟腑 |

## 療程安排

**治療時長**：
- DSD：從所有會合點進針時算起 40 分鐘
- SDS：從井穴進針時算起 20 分鐘

**療程節奏**：三天治療、三天休息，共三個週期（18 天）再評估
> 若不遵循此節奏，身體可能忽略訊息。每週一次時，可讓患者按摩或使用精油在會合點維持療效。

---

## 進針順序

### DSD 進針順序
1. 上會合點 / 下會合點（兩個上 → 兩個下）
2. 開啟點
3. 循行點
（不用交會點，不針井穴）

### SDS 進針順序（環路針刺）
1. 刮痧皮部
2. 會合點（環路：左下→左上→交會點→右上→右下）
3. 開啟點
4. 循行點
5. 井穴

### 出針順序（兩種手法皆同）
原氣層附加穴 → 循行點 → 開啟點 → 上/下會合點 → 井穴（SDS）

## 故障排除

| 問題 | 原因 |
|---|---|
| SDS 後疼痛仍存在 | 未刮痧皮部；患者食生冷；患者使用冰敷（禁忌） |
| DSD 期間突然疼痛 | 針刺衛氣層，向遠離中線 180° 轉後立即出針，針孔保持開放 |
| 患者服用類固醇進展緩慢 | 類固醇損害陽氣，降低媒介維持能力 |
| 免疫系統過度活躍 | 適用：病原體幾乎完全潛伏，或身體對抗能量狀態（如寒） |

---

## 注意事項

- 治療前讓患者飲用常溫白開水（向身體傳達津液充足的訊息）
- 若腸道功能受損（便秘），加 ST-25 天樞確保排泄通暢
- 疤痕阻礙衛氣流動，治療前應先處理疤痕
- 使用冰敷禁忌（使衛氣和炎症壓入關節，導致晚年關節炎）
