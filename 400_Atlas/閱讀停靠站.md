# 閱讀停靠站

> 這不是待辦清單，也不是閱讀筆記。它只回答一件事：**我現在有哪些來源正在讀，下一次從哪裡繼續？**
> 可以同時保留 1–3 個閱讀來源；超過時先回學習佇列，不讓正在閱讀區變成壓力清單。

## 正在閱讀

```query
tag:#閱讀中
```

## 在來源頁怎麼停靠

1. 在要開始的來源頁任一處加上 `#閱讀中`。
2. 要暫停時，在該頁最後寫一行：`停在：……｜下次：……`。
3. 閱讀時只標 `#我的收穫` 或 `#我的疑問`；靈感與待辦分別用 `#靈感發想`、`#行動與待辦`。
4. 讀完或暫時不讀時，移除 `#閱讀中`；它仍留在 Library／Sources 原位，不需要搬檔。

## 你可以直接對我說

- `開始讀：[[來源頁]]`：我幫你標為閱讀中，必要時補一行停靠欄位。
- `停靠：[[來源頁]]｜下次……`：只更新這篇的停靠點，不做收成。
- `收成這一篇：[[來源頁]]`：只處理該篇尚未收成的標記。
- `加入學習佇列：標題＋連結`：先放進待讀清單，不強迫建立來源卡。
