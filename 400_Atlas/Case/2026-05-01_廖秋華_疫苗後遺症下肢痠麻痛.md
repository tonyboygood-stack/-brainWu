## 2026-05-20 重評（卡關）

### 今日脈症
- **脈**：沉弦滑有力，左寸不足
- **症**：麻刺痛 + 下肢沉重感 + 走路無力

### 出入點分析
| | 5/1 | 5/20 |
|---|---|---|
| 脈象 | 六脈沉弦滑數 | 沉弦滑有力，左寸不足 |
| 症狀 | 下肢痠麻痛、影響睡眠 | 麻刺痛 + 沉重感 + 走路無力 |

- **左寸不足（新發現）**：痰瘀阻絡心氣無法上達？或心氣本身不足？
- **麻 + 刺痛並存**：血虛不養筋（麻）＋血瘀阻絡（刺）→ 核心矛盾：純補則滯，純通則傷正
- **沉重感**：濕痰流注下肢
- **走路無力**：腎陽不足 / 脾氣下陷 / 痿證（肝腎虧虛），三者待辨

### 待查方向（三選一或合用）

**A. 轉督脈**
走路無力 + 下肢沉重 → 督脈失養。衝脈無效，督脈值得試。
參考取穴：大椎、命門、腰陽關、承山、崑崙。

**B. 心腎不交切入**
左寸不足 + 整體脈有力 → 上下不通，心火不下、腎水不上，下肢失溫失養。
參考取穴：神門、通里、太溪、照海。

**C. 痰瘀並治**
滑弦並見 + 麻刺痛 = 痰瘀互結阻絡。換工具：刺絡（委中/承山）+ 開痰通瘀方向。

> 老吳查完回來確認後，更新治療方向。
