# 病案：疲勞眠差（丁立夫 #15743）

## 主訴

疲勞、睡眠差、多夢、易醒。

## 脈象

沉無力數。

**辨證方向：虛中夾熱，寒熱虛實錯雜，難以單純補或清。**

## 舌象

舌苔白黃厚乾。

> 白黃厚苔 → 有積滯或濕熱；乾 → 津液不足或熱耗津；與脈沉無力並見 → 虛實夾雜

## 治療紀錄

| 日期       | 處置                         | 效果         |
| ---------- | ---------------------------- | ------------ |
| 2026-05-04 | 回診評估，補清均效果不明顯   | 待深究       |

## 治療反思

- 過去或補或清，效果均不明顯
- 可能原因：
  1. **虛實夾雜**：單補則助熱，單清則傷正，需攻補兼施
  2. **氣機問題**：沉脈主裡，是否有氣機鬱滯阻礙？補藥補不進去
  3. **中焦問題**：苔厚 → 中焦有積，脾胃運化障礙，藥物吸收差
  4. **疲勞的根源**：是氣虛、血虛、陰虛、還是陽虛？需再細分

## 追蹤方向

- 釐清疲勞性質：是懶得動（氣虛）、頭腦不清（清陽不升）、還是睡再多也累（陰虛）？
- 眠差多夢易醒：屬心？肝？膽？
- 苔厚乾是否有口苦、大便黏滯等中焦積滯佐證？
