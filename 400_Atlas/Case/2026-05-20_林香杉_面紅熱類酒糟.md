# 病案：林香杉（#14484）—— 面紅熱 / 類酒糟

## 主訴

面紅熱，類酒糟樣表現。

## 脈象

- **右脈**：上越不降（肺胃氣機上亢，熱不透出）
- **左關**：少陽鬱熱不升（樞機卡住，熱出不去）

## 舌象

> ⚠️ 待補：舌色、苔色厚薄、舌邊、有無裂紋

## 辨證思路

兩個核心病機：
1. **少陽樞機不利**：左關少陽鬱熱，熱鬱於內無法疏泄
2. **肺胃氣機上越不降**：熱往上衝，沒有出路，積於面部

類酒糟另有**血熱**成分，赤芍涼血對應。

## 治療紀錄

| 日期 | 處方 | 效果 |
| ---- | ---- | ---- |
| 上次 | 清上防風湯 | 效果有限 |
| 2026-05-20 | 小柴胡湯 + 葛根、白芷、薄荷、石膏、梔子、赤芍、枇杷葉 | 待追蹤 |

## 處方分析（2026-05-20）

| 藥組 | 藥物 | 對應病機 |
|---|---|---|
| 少陽樞機 | 小柴胡湯 + 薄荷 | 左關少陽鬱熱，打開樞機 |
| 肺胃透熱 | 石膏 | 右脈上越，從表向外泄熱（辛散） |
| 肺氣下降 | 枇杷葉 | 右脈不降，降肺氣 |
| 引熱下行 | 梔子 | 三焦清熱，往下走 |
| 涼血 | 赤芍 | 類酒糟血熱成分，涼血活血 |
| 陽明臉部引經 | 葛根 + 白芷 | 引藥上臉，走陽明肌肉層 |

**設計邏輯**：石膏（外透）+ 梔子（向下）+ 枇杷葉（降肺）同時開三個出口，解決清上防風湯只散不降的問題。

**清上防風湯沒效原因**：方中防風、荊芥、薄荷、白芷升散藥多，右脈本就上越，等於火上加油；且未動少陽樞機，繞過了核心病機。
