# 病案：蔡如茜（#10235）—— 心悸恐慌 / 氣血虛夾水飲

## 主訴

容易心悸、恐慌。

## 脈象

- **左脈**：弦細
- **左寸**：偶不足

## 辨證關鍵（2026-05-20 突破點）

**弦脈兩個來源，之前誤判方向：**

| 弦的來源 | 機制 | 治法 |
|---|---|---|
| 血不養筋 | 血虛脈道失養 | 補血柔脈 |
| **正弦（水飲）** | 水飲停滯，脈道受壓 | 溫陽化飲 ← 今日確認 |

- 左脈弦是**正弦**，夾有水飲
- 細脈 + 左寸偶不足 → 仍有氣血虛底
- 核心：**虛實夾雜，氣血虛 + 水飲並存**

## 治療紀錄

| 日期 | 處方 | 效果 |
| ---- | ---- | ---- |
| 過去 | 炙甘草湯 / 八珍 / 養心湯（純補氣血方向） | 效果有限 |
| 2026-05-20 | 養心湯 + 苓桂朮甘湯 | 待追蹤 |

## 換方思路（2026-05-20）

**之前沒效原因**：甘藥滋膩，水飲是實邪，純補不但去不掉水，反而助濕。

**今日方向**：虛實並治

| 方 | 對應病機 |
|---|---|
| 養心湯 | 氣血虛（細脈、左寸偶不足）|
| 苓桂朮甘湯 | 正弦水飲（桂枝溫心陽、茯苓導水下行）|

## 左寸候心三要素分析（2026-07-05）

見 [[2026-07-05_左寸候心三要素_心陽心氣陰血與右尺互參]] 框架，套用本案：

- **心陽不足**：明確（左寸沉細）
- **大氣下陷**：不確定（右寸未見凹陷，證據不足）
- **陰血不足**：明確（脈細＋舌淡白嫩齒痕＝氣血虛）
- **右脈弦**：主氣滯＋水飲，水飲基底仍為陽虛停水

**治療方向**：溫陽化水＋補命門火＋補心火＋補心氣＋補陰血並行，不可單靠活血或補氣——下次回診應更關注恢復右手脾腎陽，以提供心臟動能。

## 追蹤重點

- [ ] 心悸頻率是否下降
- [ ] 恐慌發作是否減少
- [ ] 左脈弦是否軟化（最直接指標）
- [ ] 有無「氣上衝」感或「起身頭暈」消失（苓桂朮甘湯有效的典型訊號）
