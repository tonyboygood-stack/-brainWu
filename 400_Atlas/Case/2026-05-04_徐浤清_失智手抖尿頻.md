# 病案：失智手抖尿頻（徐浤清 #15848）

## 主訴

- 漸漸開始失智症狀
- 手抖
- 白天尿頻急，程度嚴重

## 脈象

整體滑大，痰濕為主。

## 舌象

舌苔白黃膩。

**辨證：痰濕盛，蒙蔽清竅（失智）、阻滯經絡（手抖）、下注膀胱（尿頻急）。**

## 治療紀錄

| 日期       | 處置                             | 效果   |
| ---------- | -------------------------------- | ------ |
| 過去       | 脾胃經別治療                     | 待評估 |
| 2026-05-04 | 首次嘗試衝脈治療                 | 待觀察 |
| 2026-05-12 | 回診：精神不佳，腿部出現大水泡，警示天皰瘡（自體免疫大皰症），中止針灸，建議轉診皮膚科確認 | 等待皮膚科回報 |
| 2026-06-08 | 天皰瘡已沒事（皮膚科處理完畢），回診繼續治療。現症：痰濕水飲多、疲倦、頭暈、無力。推測與前段抗生素治療有關（傷脾胃正氣）。 | 繼續治療中 |

## 治療思路

- **過去：脾胃經別** → 從中焦化痰濕，治本
- **今日：衝脈** → 衝脈主血海，滲灌諸陽；痰濕之根在腎，衝脈通腎，或能從更深層處理
- 三症（失智、手抖、尿頻）同源於痰濕，以衝脈統治可能更有效率

## 追蹤方向

- **天皰瘡已排除，恢復針灸治療**
- 現階段主要矛盾：抗生素後傷正 → 痰濕水飲更盛，氣虛不運
  - 疲倦、頭暈、無力 → 可能脾氣虛 + 水飲蒙清竅
  - 考慮：衝脈繼續 + 加強健脾益氣（參苓白朮散方向）
- 觀察指標：痰濕症狀（疲倦、頭暈、無力）改善、尿頻急變化、手抖幅度
- 家屬觀察失智症狀進展

## 治療假設

衝脈第一條路線可引腎助脾，同時清理下焦濕熱痰，對膀胱尿頻急應有直接幫助。
此次嘗試若尿頻改善，可作為衝脈處理下焦痰濕的佐證案例。
