# 2026-06-16 老吳本人 — 感冒虛勞辨治

## 主訴
感冒。初起喉嚨痛（持續一天，非腫痛）→ 鼻涕黃稠、倒流黏涕、咽喉癢

## 診斷
**虛勞底 + 風寒外感，鼻翹化熱**

- 平時基礎脈：雙關郁，左關浮亢按弦，右關浮弦大按之稍空，雙寸容易不足
- 感冒後脈：左寸浮細緊，右寸浮數邊微微緊而空
- 最終辨證：右關浮弦大亢按之空（虛勞大脈）+ 右寸浮緣微緊（風寒在鼻）

## 處方（治療歷程三階段）

**第一階段（初起喉痛）**
- 辨證：風熱 + 虛火上炎
- 用藥：銀翹散 + 黃連、板藍根（治標）
- 結果：1.5天後咽痛消 ✓

**第二階段（鼻涕黃稠）**
- 辨證：參考黃元御四聖心源，脾濕阻中焦→胃不降→肺鬱化熱
- 用藥：玄參3 石膏3 桔梗3 杏仁3 茯苓3 半夏3 生薑3 五味子1
- 結果：效果普通，鼻涕仍黃稠
- **反思：落入套方窠臼**——此方適用時機為右關緩滑痰濕 + 右寸浮亢（右脈上越為實），本案右關按之空為虛，不符合使用條件

**第三階段（重新辨證後）**
- 辨證：虛勞 + 風寒，右脈上越為虛而非實
- 用藥：桂枝湯6、龍骨1、牡蠣1、黃耆1、白芷1、麻黃0.5、石膏1、丹皮1
- 方義：
  - 桂枝龍牡湯：補虛勞，收斂右脈
  - 黃耆：補脾肺氣
  - 麻黃、白芷：祛鼻部風寒（針對脈緣微緊）
  - 石膏、丹皮：清鼻翹化熱（針對黃稠涕）
- 結果：整體舒適，鼻通暢，鼻涕止，無倒流 ✓
- 但：下腹微脹，排便不順

## 追蹤重點
- 目前脈：右寸關浮弦亢數按之稍空，右尺浮弦；上越感稍緩
- 右尺仍浮弦 → 腎虛火未歸根，桂枝+麻黃白芷黃耆整體偏升散，下焦更虛而脹
- 研議合入**封髓丹**收斂下焦，繼續觀察
