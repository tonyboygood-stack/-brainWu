# /case-image-sort — 整理病歷圖片

## 觸發條件

使用者說「整理病歷圖片」。

---

## 執行步驟（依序完成）

### 1. 同步確認

```
git fetch origin && git pull origin main
```

確保病案檔是最新版本。

---

### 2. 掃描來源資料夾

來源路徑：`G:\我的雲端硬碟\我的AI同步資料夾\病例圖片\`

列出所有圖片檔案（`.jpg`、`.jpeg`、`.png`、`.heic`）。

若資料夾為空或不存在，回報「來源資料夾無圖片」後結束。

---

### 3. 逐張解析

對每張圖片：

**Step A：識別病人**

1. 優先解析**檔名**，提取病歷號（`#XXXXX` 或純數字）或患者姓名
2. 若檔名無法識別，用 Read 工具**視覺讀取圖片**，從畫面上的文字辨識病歷號或姓名
3. 若仍無法確認，列出圖片請老吳手動指定

**Step B：比對病案**

掃描 `400_Atlas/Case/` 所有 `.md` 檔案的 frontmatter `patient:` 欄位，規則：
- 含病歷號：比對 `#XXXXX` 是否出現在 `patient:` 值中
- 含姓名：比對姓名是否出現在 `patient:` 值中
- 多筆符合：列出讓老吳選擇

**Step C：複製圖片進 vault**

目標路徑：`400_Atlas/Case/attachments/`

命名格式：`YYYY-MM-DD_患者姓名_舌象.jpg`（YYYY-MM-DD 用今天日期）

若同名檔已存在，加後綴 `_2`、`_3` 避免覆蓋。

**Step D：讀取圖片，分析舌象**

用 Read 工具視覺分析圖片，填入以下項目（若無法判斷則填「不清晰」）：
- 舌色（淡白 / 淡紅 / 紅 / 絳 / 紫暗 / 青紫）
- 苔色（白 / 黃 / 灰黑）+ 苔質（薄 / 厚 / 膩 / 燥 / 剝落）
- 舌體（胖大 / 齒痕 / 瘦薄 / 正常）
- 舌邊（有無紅點、瘀斑）
- 裂紋（有 / 無，位置）

**Step E：更新病案舌象區塊**

找到病案 `## 舌象` 區塊：
- 若只有 `> ⚠️ 待補` → **替換**整個區塊
- 若已有內容 → 在最下方**追加**（保留舊紀錄）

更新格式：

```markdown
## 舌象

> 更新：YYYY-MM-DD

![[YYYY-MM-DD_患者姓名_舌象.jpg]]

| 項目 | 觀察 |
|---|---|
| 舌色 | （填入）|
| 苔色 / 苔質 | （填入）|
| 舌體 | （填入）|
| 舌邊 | （填入）|
| 裂紋 | （填入）|
```

---

### Step F：補充武器庫（搜尋相關筆記）

舌象更新後，依據病案的**辨證方向、脈象、舌象**，掃描 `400_Atlas/Notes/` 找出相關筆記，補入 `## 🗡️ 武器庫` 區塊：

- 用關鍵詞 grep 搜尋筆記標題（如辨證主題、脈象特徵、舌象特徵）
- 格式：`- [[筆記檔名]] — 與本案關聯說明`
- 只加入**已存在**的筆記，找不到則武器庫留空

---

### 4. 完成報告

列出處理結果：

```
━━ 整理完成 ━━
✅ 林香杉（#14484）→ 舌象已更新
✅ 張瓊文（#15761）→ 舌象已更新
⚠️  IMG_0003.jpg → 無法識別病人，請手動指定
```

---

### 5. 自動清空來源資料夾

完成報告後，**自動刪除**來源資料夾中已成功處理的圖片（不詢問）。

規則：
- ✅ 成功比對並更新病案的圖片 → 刪除
- ⚠️ 無法識別病人的圖片 → **保留不動**，在報告中提示老吳手動處理

刪除後回報：「已清空 N 張已處理圖片，X 張無法識別的保留在來源資料夾。」

---

## 注意事項

- 病案比對必須精確，若有歧義（同名患者）一定要詢問確認
- 圖片為醫療資料，不得上傳至任何外部服務（只在本地操作）
- HEIC 格式：若 Read 工具無法讀取，提示老吳先轉成 JPG
- 完成後 commit：`git add 400_Atlas/Case/ && git commit -m "整理病歷舌象圖片：YYYY-MM-DD"`
