# 文獻庫 Skill — LLM Wiki 模式

## 關於這個知識庫

這是老吳的「醫學文獻庫」，涵蓋**中醫與現代醫學**（不限中醫），任務是把古籍原文、教材、論文、課程資料、還沒讀完的資料，整理成一套彼此連結、好查找的筆記，讓老吳可以用提問的方式吸收知識。

**這裡放的是「文獻怎麼說」，不是「老吳自己怎麼想」**——老吳自己的觀點、臨床心得另外存在 `400_Atlas/Notes/`（見 [[note-capture]] skill）。兩者要分清楚。

---

## 資料夾與文件功能說明

- **史料**（`400_Atlas/Library/raw/`）：放原始的文獻全文/古籍/教材/論文掃描。AI 只能讀取，不能修改這裡的內容。
- **文獻庫**（`400_Atlas/Library/wiki/`）：由 AI 建立、更新、整理，採扁平式資料夾結構（靠「目錄.md」和 `[[雙向連結]]` 組織）。**分類不限中醫**，中西醫、結構治療等內容都收，用頁面內的 `discipline` 欄位標記學派/系統（見下方範本）。

### 目前 10 個分類

| 資料夾 | 收什麼 |
|---|---|
| `/典籍` | 原文書/教材整理頁（中醫古籍、西醫教材、療法專書都收，一本書一頁，內容龐大可依篇章拆頁） |
| `/醫家` | **思路檔案**（不是生平簡介，見下方範本）；`/醫家/指紋/` 放腳本產生的用藥指紋頁 |
| `/病機病理` | 疾病成因與機轉，中醫病機與西醫病理生理可並存同一頁——這是跨系統整合最重要的節點 |
| `/治法技法` | 治療方法與操作技術：針法、手法治療、徒手技術（MET/PIR/SCS/乾針等）、復健運動 |
| `/方劑` | 中藥複方 |
| `/藥物本草` | 單味中藥、西藥、營養補充品（含劑量、交互作用） |
| `/穴位經絡` | 穴位定位、經絡循行、奇經八脈 |
| `/解剖生理` | 現代解剖學、生理學、肌動力學、生物力學 |
| `/診斷評估` | 脈診、舌診、理學檢查、功能性評估測試 |
| `/辨析` | 跨典籍、跨學派、跨中西醫的比較與整合分析 |

### AI 提議新分類的規則

- 整理時若累積 **≥3 頁**內容明顯不屬於以上任何一類、硬塞很牽強，在整理摘要中提議新分類名稱與理由
- **新增頂層分類要問老吳確認**，不能自動建立資料夾——這跟新增單一頁面不同，是結構性變動
- 確認後：在 `wiki/` 下建新資料夾，並在 `wiki/index.md` 加上對應的 `##` 區塊

- **目錄.md**（`400_Atlas/Library/wiki/index.md`）：文獻庫的目錄大綱，列出所有頁面，方便 AI 檢索
  - 每個項目：`[[頁面]] — 一句話說明`
  - 範例：`[[傷寒論_太陽篇]] — 太陽病提綱與桂枝湯、麻黃湯證治辨析`
- **日誌.md**（`400_Atlas/Library/log.md`）：每次整理動作都記一行
  - 格式：`## [日期] 動作 | 說明`
  - 範例：`[2026-07-19] 匯入文獻 | 傷寒論太陽篇全文`
  - 原始資料匯入後，詳細登記每個匯入文件的名稱，避免日後重複匯入

## 資料匯入與整理規則（觸發：「整理文獻庫」）

1. 先讀取 `raw/` 查看是否有需要匯入的新資料
2. 讀取 `wiki/index.md`，了解目前已有哪些頁面
   - 新資料屬於已存在的頁面主題 → 更新原本頁面，**不重複建立**
   - 新資料出現新的重要主題 → 才建立新頁，套用對應分類的範本
   - 新資料明顯不屬於任何既有分類（且已累積 ≥3 頁類似情況）→ 提議新分類，問老吳確認
3. **每頁必填 `醫家:`（list）與 `attribution:`**——不確定就填 `待判定` 並標 ⚠️，不可自行猜測
   - `attribution` 四值：`原創`（該醫家自己的方/論）、`化裁`（本於前人方而改）、`收錄`（共用節點，如本草/穴位）、`待判定`
   - 匯入完成後跑 `scripts/backfill_attribution.py` 檢查有無漏標
4. 每個新頁面至少 `[[雙向連結]]` 一個相關頁面，避免孤立筆記
4. **撰寫風格：保留原始術語（中醫術語或西醫學名皆同）**，不要為了通順而改寫成白話簡化詞彙——醫學術語的精確性比可讀性重要。可在術語後面加括號白話註解方便快速理解，但不能取代原文用詞
5. **每頁標記 `discipline`**（中醫／西醫／結構治療／營養／疼痛科學／跨學科），方便之後依學派篩選或比較
6. **不確定的地方要標註**：原文語意有爭議、版本不同、翻譯不確定、或 AI 判斷信心較低時，用「⚠️待確認」標記，不要自行下定論
7. **整個過程不逐一詢問老吳確認**（新分類提議除外）——整理完才輸出一份「這次新增/更新了什麼」的摘要，附上「⚠️待確認」條目清單供老吳抽查
8. 整理完成後，必須：
   - 更新 `wiki/index.md` 反映最新內容
   - 在 `log.md` 加一筆記錄

```yaml
  - "[[相關頁面]]"
created: YYYY-MM-DD
---

（依原文脈絡整理，保留關鍵原文用字）
## 待確認
（列出語意不確定或版本有爭議之處，無則省略此區塊）
```

### 醫家（思路檔案）

> **這一頁就是該醫家的「透鏡」**——問「某某會怎麼看」時，AI 載入這頁 ＋ 篩 `醫家: 某某` 的頁面作答。
> 不是生平簡介。生平放最後，且必標 🔴。
> 範例見 [[趙紹琴]]。

```yaml
---
title: 醫家姓名
source_type: 醫家
discipline: 中醫
醫家:
  - 醫家姓名
attribution: 原創
朝代:
本庫樣本:          # 誠實標明指紋涵蓋哪些書
本庫頁數:
tags:
  - 思路檔案
related:
  - "[[代表著作]]"
created / updated: YYYY-MM-DD
---
```

**必備區塊（每段標萃取層級，不可省略）：**

| 區塊 | 內容 |
|---|---|
| 頁首聲明 | 樣本範圍 ＋「不代表其一生思路全貌」 |
| 一句話核心命題 | 他認為病怎麼來、該怎麼解 |
| 慣用切入點 | 診斷順序：先看脈？舌？氣機？（附出現率統計） |
| 手段光譜與力度偏好 | 各類手段佔比 ＋ 峻藥實際劑量 |
| 用藥指紋 | 連到 `[[XXX_用藥指紋]]`，摘要核心圈 |
| 分期與動態辨證習慣 | 是否分階段、加減法密度、禁忌意識 |
| 在總框架上的位置 | 對照 [[病生理診斷治療總框架 MOC]]，標明是推論待校正 |
| 盲區與不談的事 | 用「本庫 0 頁」這種可驗證的方式陳述 |
| 生平與學派標籤 | 🔴 區，明寫不可作臨床依據 |
| 本庫索引 | 各分類頁數 ＋ 檢索方式 |

**萃取層級標記（強制）：**

- 🟢 **原文直述／統計實證** — 文獻原文，或腳本從本庫算出來的
- 🟡 **本庫歸納** — 從已拆解頁面推論出來的
- 🔴 **外部公開知識** — 非本庫文獻，**不可作為臨床依據**

盲區與切入點這類敘述，一律用可驗證的數字表達（「本庫 522 頁中針灸 0 頁」），
不要寫「他似乎不重視針灸」這種無法查證的話。

## 回答提問的要點（觸發：「查文獻庫的 XXX」或直接提問文獻內容）

### 證據誠實規則（最高優先，不可違反）

- **只能用本庫實際存在的內容作答**，逐條標明來源頁
- 庫裡沒有 → **直說「本庫無此內容」**。可補充背景知識，但**必須標 🔴** 並明講「這不是從你的文獻庫來的」
- **嚴禁**用 AI 背景知識填補庫裡的空缺後當成文獻結論
- 老吳問的書若尚未匯入 `raw/` → 主動提示「這本還沒進庫」，而不是用背景知識硬答
- **回答必須標明是哪位醫家的主張**，不可講成中醫通論
  （本庫 96% 內容來自趙紹琴一人，講成通論等於把一家之言當共識）

### 檢索步驟

1. 先讀 `wiki/index.md` 找相關頁面，根據頁面內容回答；若目錄裡沒有對應頁面，才回頭讀 `raw/` 原文
2. 問「某醫家會怎麼看」時：先載入 `醫家/<姓名>.md` 思路檔案，再篩 `醫家: <姓名>` 的頁面作答，**其他醫家的內容不得混入**
3. 回覆中清楚標明引用了哪些頁面（`[[頁面名稱]]`），讓老吳知道答案依據
3. 問答中若產生老吳自己的觀點、或值得保留的臨床啟發，**先問老吳要不要存到 `400_Atlas/Notes/`**（走 [[note-capture]] 完整流程），不要直接寫回文獻庫

## 歸納：把散落的線索收攏成一頁（觸發：「歸納 <醫家> 的 <治法/概念>」）

> **為什麼需要**：拆解時，一個醫家的核心手法會被打散進各頁的「方義」欄位。
> 例：「輕清／宣透」全庫只有 6 頁提及、4 個句子，散在腸癰、瘖啞頁裡，
> 沒有任何一頁專門講它——問「趙老的輕透上焦」根本撈不出東西。

1. 篩 `醫家: <該醫家>` 的全部頁面，撈出相關方義、加減法、病機論述
2. **評估證據量**是否足以立頁
3. 足夠 → 建 `wiki/治法技法/<治法>（<醫家>）.md`，標 `attribution` ＋ 🟡本庫歸納，**逐條附來源頁連結**
4. **不足 → 明確回報「本庫證據僅 N 條，不足以立頁」，並指出缺哪本書**，不可用背景知識補完
5. 歸納出的治法頁回答的是「**該醫家怎麼做**」，還不是老吳的東西——
   老吳自己的理解與框架解構走 [[note-capture]] 存 `400_Atlas/Notes/`

## 醫家對照：碰撞層（觸發：「醫家對照 <A> vs <B> 的 <主題>」）

輸出到 `wiki/辨析/`，沿用 [[神經學派vs生物力學派]] 的 `比較對象／異同分析／延伸提問` 骨架。

**固定對照欄位（掛在總框架上，這是碰撞能有結論的關鍵）：**

| 欄位 | 說明 |
|---|---|
| 病機定位 | 各家在 L1（升降開闔方向）／L2（臟腑生克）的落點 |
| 目標 vs 手段 | 各家下的是「升降開闔」還是「寒熱補瀉」（總開關規則） |
| 力度分級 | 微／中／峻，可引用各家用藥指紋的實際劑量佐證 |
| 診斷依據 | 各家憑什麼判斷（脈／舌／證／腹診），可引用出現率統計 |
| 分歧點與可能原因 | 時代、地域、病人族群、學派立場 |
| 框架缺口 | 某家思路本框架解釋不了 → 回寫總框架 MOC 文末「框架缺口」 |

> ❌ **不合格的產出**：兩段各說各話的摘要並排。
> ✅ **合格的產出**：同一個問題底下的分岔表，老吳看完知道「什麼情況找誰」。

**邊界**：對照中若產生老吳自己的取捨或觀點 → 先問要不要走 [[note-capture]] 存 `400_Atlas/Notes/`，
**不直接寫回文獻庫**。文獻庫只放「文獻怎麼說」。

## 更新用藥指紋（觸發：「更新用藥指紋」）

跑 `scripts/herb_fingerprint.py --write`，重算全部醫家的指紋頁。
每次新醫家匯入、或方劑頁有增修後執行。輸出屬 🟢 層級。

指紋頁文末的兩張 ⚠️ 待裁決表（非單味藥條目、同藥異名候選）要主動提給老吳確認，
**不可自動合併**——炮薑與乾薑是否算同一味，屬專業判斷。

## Hub 頁的醫家分區規則（第二位醫家匯入時觸發）

- **預設**：`病機病理/` 單頁內以 `## <醫家A>視角` / `## <醫家B>視角` 分區，**絕不合併敘述**
- **切分門檻**：單一醫家區塊超過約 150 行 → 拆成 `<病名>（<醫家>）`，原 hub 頁轉為導覽 ＋ 辨析
- 方劑頁不需改名（`咳嗽一法_...` 已由 `醫家:` 欄位區分）；兩家同名法時才加後綴
- `醫家:` 是 list，混合頁掛兩人；AI 引用時**引到區塊而非整頁**

## 文獻庫維護檢查（觸發：「文獻庫維護」）

- 檢查是否有失效的 `[[雙向連結]]`
- 檢查是否有孤立頁面（沒有被其他頁面連結到）
- 檢查是否有重複或高度相似的頁面，提出合併建議
- 檢查頁面之間是否有內容矛盾或不一致
- 檢查是否有分類累積內容明顯該獨立成新分類（依上方「AI 提議新分類的規則」）
- **檢查是否有頁面漏標 `醫家:` / `attribution:`**（跑 `scripts/backfill_attribution.py` dry-run）
- **檢查 `attribution: 待判定` 的頁面**是否已可判定
- **檢查醫家思路檔案的 🔴 區塊**是否已能由新匯入的文獻降級為 🟡／🟢
- 任務完成後輸出一份簡短報告
