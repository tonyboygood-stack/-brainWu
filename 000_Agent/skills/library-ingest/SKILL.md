# 文獻庫 Skill — LLM Wiki 模式

## 關於這個知識庫

這是老吳的「醫學文獻庫」，涵蓋**中醫與現代醫學**（不限中醫），任務是把古籍原文、教材、論文、課程資料、還沒讀完的資料，整理成一套彼此連結、好查找的筆記，讓老吳可以用提問的方式吸收知識。

**這裡放的是「文獻怎麼說」，不是「老吳自己怎麼想」**——老吳自己的觀點、臨床心得另外存在 `400_Atlas/Notes/`（見 [[note-capture]] skill）。兩者要分清楚。

---

## 資料夾與文件功能說明

- **史料**（`400_Atlas/Library/raw/`）：放原始的文獻全文/古籍/教材/論文掃描。AI 只能讀取，不能修改這裡的內容。
- **文獻庫**（`400_Atlas/Library/wiki/`）：由 AI 建立、更新、整理，採扁平式資料夾結構（靠「目錄.md」和 `[[雙向連結]]` 組織）。**分類不限中醫**，中西醫、結構治療等內容都收，用頁面內的 `discipline` 欄位標記學派/系統（見下方範本）。

### 目前 12 個分類

| 資料夾 | 收什麼 |
|---|---|
| `/典籍` | 原文書/教材整理頁（中醫古籍、西醫教材、療法專書都收，一本書一頁，內容龐大可依篇章拆頁） |
| `/醫家` | **思路檔案**（不是生平簡介，見下方範本）；`/醫家/指紋/` 放腳本產生的用藥指紋頁 |
| `/病機病理` | 疾病成因與機轉，中醫病機與西醫病理生理可並存同一頁——這是跨系統整合最重要的節點 |
| `/治法技法` | 治療方法與操作技術：針法、手法治療、徒手技術（MET/PIR/SCS/乾針等）、復健運動 |
| `/方劑` | 中藥複方 |
| `/藥物本草` | 單味中藥、西藥、營養補充品（含劑量、交互作用） |
| `/穴位經絡` | 穴位定位、經絡循行、奇經八脈 |
| `/解剖生理` | 現代解剖學、生理學、肌動力學、生物力學 |
| `/診斷評估` | 脈診、舌診、理學檢查、功能性評估測試 |
| `/辨析` | 跨典籍、跨學派、跨中西醫的比較與整合分析 |
| `/醫案` | **文獻中的**醫案。與 `400_Atlas/Case/`（老吳自己的病案）分層——這裡收的是「文獻裡的醫者怎麼推理」 |
| `/養生調攝` | 靜坐、氣功、飲食、作息、環境等**非治療手段**的干預 |

### AI 提議新分類的規則

- 整理時若累積 **≥3 頁**內容明顯不屬於以上任何一類、硬塞很牽強，在整理摘要中提議新分類名稱與理由
- **新增頂層分類要問老吳確認**，不能自動建立資料夾——這跟新增單一頁面不同，是結構性變動
- 確認後：在 `wiki/` 下建新資料夾，並在 `wiki/index.md` 加上對應的 `##` 區塊

- **目錄.md**（`400_Atlas/Library/wiki/index.md`）：文獻庫的目錄大綱，列出所有頁面，方便 AI 檢索
  - 每個項目：`[[頁面]] — 一句話說明`
  - 範例：`[[傷寒論_太陽篇]] — 太陽病提綱與桂枝湯、麻黃湯證治辨析`
- **日誌.md**（`400_Atlas/Library/log.md`）：每次整理動作都記一行
  - 格式：`## [日期] 動作 | 說明`
  - 範例：`[2026-07-19] 匯入文獻 | 傷寒論太陽篇全文`
  - 原始資料匯入後，詳細登記每個匯入文件的名稱，避免日後重複匯入

## 資料匯入與整理規則（觸發：「整理文獻庫」）

1. 先讀取 `raw/` 查看是否有需要匯入的新資料
2. 讀取 `wiki/index.md`，了解目前已有哪些頁面
   - 新資料屬於已存在的頁面主題 → 更新原本頁面，**不重複建立**
   - 新資料出現新的重要主題 → 才建立新頁，套用對應分類的範本
   - 新資料明顯不屬於任何既有分類（且已累積 ≥3 頁類似情況）→ 提議新分類，問老吳確認
3. **每頁必填 `醫家:`（list）與 `attribution:`**——不確定就填 `待判定` 並標 ⚠️，不可自行猜測
   - `attribution` 四值：`原創`（該醫家自己的方/論）、`化裁`（本於前人方而改）、`收錄`（共用節點，如本草/穴位）、`待判定`
   - 匯入完成後跑 `scripts/backfill_attribution.py` 檢查有無漏標
4. 每個新頁面至少 `[[雙向連結]]` 一個相關頁面，避免孤立筆記
4. **撰寫風格：保留原始術語（中醫術語或西醫學名皆同）**，不要為了通順而改寫成白話簡化詞彙——醫學術語的精確性比可讀性重要。可在術語後面加括號白話註解方便快速理解，但不能取代原文用詞
5. **每頁標記 `discipline`**（中醫／西醫／結構治療／營養／疼痛科學／跨學科），方便之後依學派篩選或比較
6. **不確定的地方要標註**：原文語意有爭議、版本不同、翻譯不確定、或 AI 判斷信心較低時，用「⚠️待確認」標記，不要自行下定論
7. **整個過程不逐一詢問老吳確認**（新分類提議除外）——整理完才輸出一份「這次新增/更新了什麼」的摘要，附上「⚠️待確認」條目清單供老吳抽查
8. 整理完成後，必須：
   - 更新 `wiki/index.md` 反映最新內容
   - 在 `log.md` 加一筆記錄

## 座標欄位（跨醫家的共用比較軸）

> **為什麼需要**：有些醫家（如 [[李辛]]）的組織軸不是病證，而是「三焦層 × 開闔 × 氣血分 × 氣味」的座標系。
> 照病證拆會把座標打散。實例：《回到本源》的桂枝湯原文標明「亦見於本章『中焦層：補益中焦』」——**同一方掛兩個座標**。

方劑、藥物本草、治法技法頁**在能判定時**加註以下欄位（判不定就省略，不要猜）：

```yaml
部位: [上焦, 中焦]      # list——可同時掛多處。上焦/中焦/下焦/三焦
方向: 開                # 開 / 闔 / 升 / 降
層次: 氣分              # 氣分 / 血分 / 血中氣分
補瀉: 補                # 補 / 瀉
氣味: 甘辛、微酸，溫     # 原文有標示才填
力度: 柔                # 輕柔 / 中 / 峻（原文用語如「輕可去實」「柔開」「緩開」）
```

- 這組欄位讓座標系**可用查詢重建**，不必新增資料夾
- **同時是跨醫家碰撞的共用軸**——不同醫家的方掛在同一張格子上才比得出結論
- 趙紹琴的 190 方尚未回填此組欄位（⏳ 待辦）

### ⭐ 典籍自身的座標系（如傷寒論六經）——2026-08-22 定案，尚未執行

> **為什麼需要**：老吳計畫學習《傷寒論》，但傷寒論的核心難題跟李辛不同——
> **同一部典籍會被歷代多位醫家（成無己／柯琴／胡希恕……）分別作注**，
> 不是「一個醫家一本書」，是「一本書、多個醫家的觀點疊在同一條原文上」。
> 六經（太陽/陽明/少陽/太陰/少陰/厥陰）的**傳變順序本身就是內容**，
> 跟三焦座標一樣不能拆散，但六經還多一層「多家注解疊加」的需求。
>
> **老吳的框架 MOC 已預留接口**（`病生理診斷治療總框架 MOC.md`「框架缺口」）：
> 「傷寒六經辨證——規劃為**平行座標系**，用『開闔樞』作接口
> （太陽開／陽明闔／少陽樞），另建對照表」。**本規則就是那個接口的文獻庫端**。
>
> ⚠️ **老吳 2026-08-22 決定：先不接回框架**。傷寒論在文獻庫裡自己累積，
> 等他讀熟、確定某條規則要用在臨床，才個別走 note-capture 搬進
> `400_Atlas/Notes/`——跟趙紹琴、李辛的處理原則一致。

**六經是座標欄位，不是六個資料夾／六個 MOC 檔案**：

```yaml
六經: 太陽病        # 太陽病/陽明病/少陽病/太陰病/少陰病/厥陰病，可 list（合病/並病時掛多經）
開闔樞: 開           # 太陽開／陽明闔／少陽樞／太陰開／少陰樞／厥陰闔
條文: [12, 13, 95]  # 本頁涵蓋原書第幾條，方便對照原書
```

**理由**：跟三焦不開資料夾同一個道理——避免「六個 MOC 檔案」變成要單獨維護的六份清單，
且合病並病（同一條同時橫跨兩經）用 list 就能處理，資料夾做不到。

**基本單位用「方證」，不用逐條條文**：傷寒論 397 條、方僅 113 首，很多條文是
同一方的正證/變證/禁忌/加減。**逐條建頁會變成上百張碎頁**，跟《臨證400法》
按「法」而非逐句拆解是同一道理——臨床想到的是「桂枝湯證」，不是「第12條」。
條文編號**不丟**，寫進 frontmatter `條文:` 欄位方便回查原書。

**⭐ 加減變方併入母方頁面，不另開新頁**（老吳 2026-08-23 定案）。判準：

- **名稱是「母方名＋加／去＋藥味」，且組成確為母方增減** → 併入母方頁的
  「加減變方」區塊（如桂枝加葛根湯、白虎加人參湯、葛根加半夏湯併入桂枝湯／白虎湯／葛根湯）
- **同一段語境下的救逆/後續方**，即使名稱不含母方名，也可併入（如甘草乾薑湯、
  芍藥甘草湯是桂枝湯誤治段落的救逆方，併入桂枝湯頁的「誤治救逆方」區塊）
- **組成獨立、非母方加減者，仍individually 建頁**（如苓桂朮甘湯、奔豚湯、
  真武湯、吳茱萸湯——這些雖與某方同段出現，但方義與組成自成一格）

實際做法：母方頁內加一段 `## 加減變方（同頁收錄，不另開新頁）`，
每個變方用 `###` 子標題，簡述組成差異與主治，**不建獨立 frontmatter**。
這樣一頁能看到母方衍生的全部變化，查閱時不必在十幾個檔案間跳轉。

**三層對應現有分類（跟趙紹琴那套完全平行）**：

| 傷寒論內容 | 對應分類 | 範例 |
|---|---|---|
| 六經提綱、傳變規律、合病並病 | `病機病理/` | 太陽病提綱、六經傳變次序 |
| 每個方證（含全部相關條文） | `方劑/` | 桂枝湯證（含第12、13、95…條全部收在一頁） |
| 藥味 | `藥物本草/`（共用節點，本來就有，不用新建） | 桂枝、麻黃 |

### 方證頁的「集注體」格式（多醫家疊加同一條原文）

> 這不是新發明——跟藥物本草頁的「各家用藥經驗」是同一套邏輯（見下方藥物本草範本），
> 只是這裡疊的是**注解**不是**用法**。這是中國傳統注疏的標準做法（如十三經注疏）：
> 一段原文，底下多位注家各自一段。

```yaml
---
title: 桂枝湯證
source_type: 方劑
六經: 太陽病
開闔樞: 開
條文: [12, 13, 95]
醫家:
  - 張仲景
  - 成無己
  - 柯琴
attribution: 收錄
組成: 桂枝、芍藥、甘草、生薑、大棗
related:
  - "[[桂枝]]"
  - "[[太陽病提綱]]"
created: YYYY-MM-DD
---

## 原文（張仲景）
太陽中風，陽浮而陰弱……（第12條）
太陽病，頭痛發熱，汗出惡風……（第13條）

## 歷代注解

### 成無己
……

### 柯琴
……

## 辨析（醫家之間的異同，可選）
```

**匯入操作（觸發：老吳丟入新醫家對某方證的注解）**：

- **不新建頁面**——找到對應的方證頁，在「歷代注解」底下**新增一個 `### 醫家姓名` 區塊**
- 該頁 frontmatter 的 `醫家:` list 隨匯入次數增長
- 每疊加一位注家，順手檢查這條是否已有 2 位以上注家在解讀同一件事——
  夠了就可以觸發「醫家對照」，直接在**同一條**底下產出異同分析，
  這是碰撞層最精準的素材（單位夠小，不用跨頁比對）

**每位注家仍可有自己的思路檔案**：成無己、柯琴這類注家的內容雖然散在
許多方證頁的子區塊裡，仍可比照趙紹琴、李辛建立 `醫家/成無己.md` 透鏡頁——
篩 `醫家: 成無己` 收攏散落的注解，寫成「他解傷寒論慣用什麼切入角度」。
機制與現有醫家頁完全相同，見上方「⭐ 透鏡分型」。

### 醫家（思路檔案）

> **這一頁就是該醫家的「透鏡」**——問「某某會怎麼看」時，AI 載入這頁 ＋ 篩 `醫家: 某某` 的頁面作答。
> 不是生平簡介。生平放最後，且必標 🔴。
> 範例見 [[趙紹琴]]。

```yaml
---
title: 醫家姓名
source_type: 醫家
discipline: 中醫
醫家:
  - 醫家姓名
attribution: 原創
朝代:
本庫樣本:          # 誠實標明指紋涵蓋哪些書
本庫頁數:
tags:
  - 思路檔案
related:
  - "[[代表著作]]"
created / updated: YYYY-MM-DD
---
```

### ⭐ 透鏡分型（先判型，再決定怎麼寫）

| 來源性質 | 代表 | 透鏡主體 | frontmatter |
|---|---|---|---|
| **論述型**（原書有明確說理） | [[李辛]]《回到本源》 | **推理鏈**，大量 🟢 原文直引 | `透鏡類型: 論述型` |
| **方書型**（原書只有條目） | [[趙紹琴]]《臨證400法》 | 🟡 從結構反推推理鏈 ＋ 🟢 統計 | `透鏡類型: 方書型` |

⚠️ 方書型的推理鏈是**反推**的，**該醫家本人並未這樣明說**——必須在頁首聲明中講清楚，全段標 🟡。

### 必備區塊（11 段，層層遞進，每段標萃取層級）

```
【世界觀層】
0. 頁首聲明          樣本範圍 ＋ 透鏡類型 ＋「不代表一生思路全貌」
1. 他怎麼看人體
2. 他怎麼定義病
3. 醫者站在哪裡
   ↓
【推理層】★ 核心，老吳最重視這兩段
4. 診斷推理鏈        每一步：問什麼 → 看什麼 → 【答案如何決定下一步】
5. 從診斷到處方的橋  診斷結論怎麼轉成用藥（方向→氣味→藥→劑量→煎法）
6. 選藥規則
7. 禁忌與硬規則      if-then 形式的界線
   ↓
【驗證層】
8. 判讀範例 ★        用醫案完整走一遍 1→7；無醫案則留白並說明
9. 用藥指紋          統計降為輔助，不是主角
10. 對應老吳框架／缺口
11. 盲區與不談的事    ⚠️ 必須區分「盲區」與「本庫尚未匯入」
```

**第 4、5、8 段是透鏡有沒有用的判準。**

- 第 4 段每一步都要能回答「**答案如何決定下一步**」，只列步驟名稱＝不合格
- 第 5 段必須走到**具體藥名**，停在「宜清熱」＝不合格
- 第 8 段沒有醫案就**留白並說明原因**，不可虛構

### 自我測試

寫完後問一次：「這位醫家會怎麼看一個〔具體症狀組〕的病人？」
回答應**照他的推理順序展開**，而非直接給方。給不出推理過程 → 透鏡沒寫好，回去補第 4、5 段。

**萃取層級標記（強制）：**

- 🟢 **原文直述／統計實證** — 文獻原文，或腳本從本庫算出來的
- 🟡 **本庫歸納** — 從已拆解頁面推論出來的
- 🔴 **外部公開知識** — 非本庫文獻，**不可作為臨床依據**

盲區與切入點這類敘述，一律用可驗證的數字表達（「本庫 522 頁中針灸 0 頁」），
不要寫「他似乎不重視針灸」這種無法查證的話。

### ⭐⭐ 醫家頁必須是「概念層 MOC」，不是說明書＋一個示範例子（2026-08-22 定案）

> **背景**：老吳發現趙紹琴頁的「診斷推理鏈」只示範了咳嗽一個病當例子，
> 其餘 35 種病完全看不到，要逐頁點開病機病理資料夾才看得到全貌——
> 這不是 MOC，是「說明書＋一個案例」。老吳要的是「看這一頁就能掌握全貌」。

**不是**把該醫家全部 519 張子頁（36病機＋190方劑＋293本草）逐一列出——
那樣列表本身會變成另一份看不完的目錄，跟現在的問題一樣，只是換了一種亂法。

**而是**：在「診斷推理鏈」段落，把**每一個概念單位**（通常是「病」這個層級，
不是每一個方、每一味藥）壓縮成一行，全部列完，讓一頁就能掃過全貌：

```
| 病 | 法數 | 分岔軸（一句話壓縮決策樹形狀） |
|---|---:|---|
| [[咳嗽]] | 8 | 外感三法（寒→熱→化火）／內傷五法（陰虛漸深） |
| [[痰飲]] | 9 | 痰五法／飲四法（懸溢支痰） |
| ……36 種病全部列完…… |
```

**方劑（190）與本草（293）這種執行層不需要枚舉**——那本來就該用查詢找
（`醫家: 趙紹琴` ＋ 關鍵詞），不是在總覽頁塞 483 行。**只有概念層（病、
核心命題、治法通則）需要 MOC 化**，執行層維持現在的分類統計即可。

**這張總表同時是給 AI 用的檢索捷徑**：回答跨病比較的問題時
（例如「趙紹琴治感冒跟咳嗽的分法有什麼共通點」），先看這張總表
掌握全部 36 種病的分岔軸，不必逐頁重新推理一次。

### 「歸納」動作完成後，要回頭更新透鏡頁（銜接規則）

> 現有的「歸納」動作（見下方「歸納：把散落的線索收攏成一頁」）只會**新建一個
> 獨立頁**，沒有接回醫家頁的概念層總表——這是漏掉的一步。

歸納完成、新頁建好之後，**必須回頭檢查**：這個新概念是否該補進醫家頁的
概念層總表（多一行），或是否該更新「診斷推理鏈」「從診斷到處方的橋」等
段落的既有內容。不要讓醫家頁停在建立當下的樣子，永遠不再更新。

### 兩條線分清楚，不要混淆（老吳 2026-08-22 提問後定案）

老吳提問「趙紹琴的觀點是……」，我整合文獻庫多頁回答後，這份整合**可以**
回填進醫家頁讓它越來越完整——但要分清楚填去哪裡、屬性是什麼：

| 產出 | 去哪 | 屬性 |
|---|---|---|
| 整合文獻庫多頁回答「該醫家怎麼看 X」 | **醫家透鏡頁本身**（概念層總表或推理鏈段落） | 🟡 本庫歸納，仍是「文獻怎麼說」 |
| 老吳聽完後自己的臨床判斷／取捨 | **`400_Atlas/Notes/`** | 走 [[note-capture]]，是「老吳決定要用的」 |

**前者不需要每次都問老吳確認**（跟其他歸納動作一樣，整理完出摘要即可）；
**後者永遠要先問老吳要不要存**（既有規則不變）。兩者都可能在同一次問答中
被觸發，不要因為做了前者就忘記問後者，也不要把前者誤當成後者直接存進 Notes。

  - 診次: 二診
    日期: YYYY-MM-DD

> `診次:` 是給 Dataview 查詢用的結構化摘要，每一診的病機、治則都不同就各自成一筆，不可以把全案病機寫成一個籠統值。西醫診斷若原文完全沒提（多數古典醫案如此），`西醫診斷: []` 留空，不可用現代病名反推臆測；若原文本身有西醫檢查/住院診斷（如醫院會診案），才據實填入。

**必備區塊**：

| 區塊 | 重點 |
|---|---|
| 病人與背景 | 含生活、工作、情志——醫者若提到就要收 |
| 治療史 | 前醫用過什麼、為何無效（常是本次決策的關鍵約束） |
| 各診次 | 四診所見 → 病機 → 治則 → 處方 → 反應。**逐診記錄，不要合併摘要**；每診的病機/治則要與 frontmatter `診次:` 對應的那一筆一致 |
| ⭐ 醫者自述的判斷理由 | 🟢 直引。這是醫案最有價值的部分 |
| ⭐ 誤判與修正 | **若醫者記錄了自己的失誤，一定要保留並突出**——這是全書最有教學價值處 |
| 推理過程重建 | 對照該醫家的診斷框架，逐步列表；標 🟡（這是我們重建的） |
| 追蹤指標 | 醫者用什麼指標判斷進展（脈、舌、症狀、二便…）的變化軌跡 |
