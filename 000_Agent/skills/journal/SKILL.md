# Learning Journal Skill — 老吳版

## 目的與資料邊界

日記是把一天過成有脈絡的敘事，不是專案任務的唯一來源。

- 專案任務、完成狀態仍以各專案的原始任務為準。
- 白天的閱讀心得、生活片段與反思留在當日筆記。
- `daily-capture` 對任務更新或完成所留下的「今日活動紀錄」，是日記辨識今天發生什麼的收據；它不取代原始任務。
- 無法立即歸位的行動才暫存 `500_Inbox/inbox.md` 的「行動收件匣」。

日記必須**保留**當日既有內容，只新增或更新 `## 晚間回顧`，絕不可覆寫白天已記下的閱讀、反思與活動紀錄。舊日記維持原樣，不做批次改寫。

## 漏寫是正常情況

預設目標日期為今天。若使用者說「補寫昨天／某天」，依指定日期處理；若該日沒有足夠記錄，直接說明素材有限，不虛構一天的內容。

若使用者在 00:00–04:00 說「寫日記」或「快速日記」，而今天尚無捕捉素材、昨天已有筆記或本段對話明顯是昨天的活動，預設目標日期為昨天，並在開頭明確說明「現在過午夜，以下回顧 YYYY-MM-DD」。使用者說「寫今天」時才改為今天。

不要把連續記錄當成前提：

- 近期脈絡讀取目標日前最近的最多 3 份可用日記，而非死守昨天、前天、三天前。
- 跳過日記不影響已直接更新的專案任務；它只留下敘事空白。
- 若發現多日未回顧，先給一個簡短的「重新接上」摘要（最近未處理 Inbox 數、最近專案活動），再照常開始，不要求補寫每一天。

## 對話開頭閉環檢查

每次新對話開始時，查看昨天的日記是否有 `## 明天待辦` 與 `## 明天的期待`；有才簡短提醒。若昨天缺日記，靜默略過，不以更早日記冒充昨天的承諾。

## 寫日記流程

### 步驟 0 — 蒐集今日素材並保留原文

先確認目標日期，建立或讀取 `300_Journal/YYYY-MM/YYYY-MM-DD.md`。依序蒐集：

1. 目前對話中使用者提到的今日工作、學習、生活與想法。
2. 當日筆記的「此刻」「閱讀／臨床線索」「靈感發想」「留給下次的我」。
3. 當日筆記的 `## 今日活動紀錄`。
4. Inbox「行動收件匣」中以目標日期開頭、尚未路由的項目；若無日期，列為未定日素材，不假定它屬於今天。

先顯示精簡清單：

```
根據今天的捕捉與對話，你今天留下了這些：
- …

有漏掉的嗎？可以補充，或直接說「沒有」繼續。
```

使用者補充後，合併為今日活動素材，直接進入「今天做得不錯的事」。日記整理可改寫語句使通順，但不得把推測寫成已發生的事。

### 問題 1 — 今天做得不錯的事

從今日素材舉 1–2 個具體例子，詢問還有什麼值得記錄。讀取最近最多 3 份可用日記後，給真實、具體的近期脈絡，不過度稱讚。

### 問題 2 — 今天的幸運與支持

詢問今天感到幸運或被幫助的事。讀取近期日記，指出可見的支持脈絡即可，不套固定讚美。

### 問題 3 — 卡住／想改善

詢問今日卡點或想改善之處，並用近期日記協助判斷它是偶發事件還是反覆模式。共同定出 1–2 個可執行行動；只有使用者確認後，才放入 `## 明天待辦`。

### 問題 4 — 今天為哪個未來投票

讀 `200_Reference/vision.md` 的正向願景，從今日素材挑最相關的具體畫面詢問。沒有對應也可以略過，不硬湊願景。

### 問題 5 — 明天的待辦與期待

詢問明天最想完成的 1–3 件事，以及一件值得期待或有挑戰的事。這是明天早安可讀取的候選材料，不等同已確認的「今日要事」。

### 問題 6 — 今日狀態

詢問一句話或一個詞形容今天的狀態。

### 人物側寫

依今日 QA 與 `vision.md`，用第三人稱寫 300 字內、有細節且不浮誇的段落。困境與努力並存；沒有足夠素材時寧可簡短。

## 晚間回顧格式與寫入

先完整顯示草稿供確認。確認後，僅新增或替換當日筆記的 `## 晚間回顧` 區塊：

```markdown
## 晚間回顧

### 今天做了什麼

### 今天做得不錯的事

### 今天的幸運與支持

### 卡住／想改善

#### 具體改善行動
- [ ] …

### 今天為哪個未來投票

### 明天待辦
- [ ] …

### 明天的期待
- …

### 今日狀態
> …

### 人物側寫

*記錄於 HH:MM*
```

若 `## 今日活動紀錄` 不存在，建立空區塊於「晚間回顧」之前；不得移動或刪除既有白天區塊。完成後告知檔案位置與明天會從「明天待辦」帶出候選。

## 快速日記

使用者說「快速日記」時，讀取同樣的今日素材與活動紀錄，但只問兩題：今天最值得記下的是什麼？明天最重要的一件事是什麼？依既有素材補一段 100 字內的人物側寫，將結果寫入精簡的 `## 晚間回顧`。這是疲累時的保底模式，不要求補齊完整提問；之後可照常使用完整日記。
