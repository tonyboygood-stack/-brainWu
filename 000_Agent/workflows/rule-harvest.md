# 規則候選批次收成（相容流程）

> [!warning] 日常閱讀已改走 [[clinical-knowledge-harvest]]：以 `#我的觀點`、`#我的疑問` 建立個人臨床知識卡。此流程只保留給舊標記，或已具明確 if–then 條文、想直接檢驗的規則候選。

使用者說「整理新的規則候選」、「整理新的臨床疑問」或「收成今天的閱讀標記」時執行。本流程的目標是：不打斷閱讀，將已標記的個人判斷與疑問批次整理為**待覆核**的規則卡或問題卡；不可自動宣告為正式或正確規則。若使用者指定某一頁或說「收成這一篇」，只掃描該頁內的新標記。

## 使用者在閱讀時唯一需要做的事

在任何來源頁、課程筆記、病案或既有規則卡寫下：

```md
> [!tip]+ 規則候選 #規則候選
> 一句自己的判斷。
```

如果是在既有規則卡閱讀後出現新想法，寫：

```md
> [!example]+ 規則延伸 #規則延伸
> 一句可獨立檢驗的新想法。
```

不可要求使用者在閱讀當下填編號、層次、證據強度、關係類型或完整表格。

如果閱讀時出現疑問，寫：

```md
> [!question]+ 臨床疑問 #臨床疑問
> 問題：一句具體的疑問。
> 初步推測：（選填）我目前怎麼想。
```

問題不必先寫成規則。`#臨床疑問` 代表「先查資料、找不同解釋、由老吳覆核後才決定能否變成規則」。

若已有一張問題卡，你只需直接在卡內補：

```md
來源：書名／頁碼／影片時間／照片說明（知道多少寫多少）
摘錄或摘要：…… #資料補充

我的暫定判斷：…… #暫定結論
```

然後說「補灌 [[問題卡]]」或「校準 [[問題卡]] 的暫定結論」。不必先另建藥物卡、來源卡或規則卡。若補充是可辨識來源的本草、方劑或原文資料，AI 應同步併入既有的 Library 詞條，並在問題卡留下回連；若沒有可靠來源，才暫留問題卡等待核對。

暫定結論有三個落點：

- `#暫定結論`：只更新問題卡，暫存個人判斷。
- `#準規則`：建立 `P-XXX` 準規則卡，納入臨床規則手札 MOC 與框架編排；不要求先有完整反證。
- `#規則候選`：建立或更新 `R-XXX` 待覆核規則卡；應盡量寫成可檢驗的 if–then 條文。

## 快速模式與範圍

1. 先用全文標記搜尋找出含 `#規則候選`、`#準規則`、`#規則延伸`、`#臨床疑問` 的檔案；此步只列檔名與標記行，不重讀 Vault。
2. 只讀取**尚未標示** `<!-- rule-harvested: ... -->` 或 `<!-- question-harvested: ... -->` 的區塊、其所在標題及必要的前後脈絡。
3. 先從該頁的 `related`、`source`、`work`、作品總覽與相關 MOC 找材料，再以關鍵詞搜尋 Library；只開啟真正命中的少量頁面。
4. 不預設重讀整部作品或整個 Library。若現有命中資料不足，明確標記「需擴大查核」，由使用者決定是否進行深度檢索。
5. 預設單次收成以 5 個未處理標記為上限，確保每張卡都有來源與反證檢查；使用者說「全部收成」時才處理所有未處理標記。

## 執行流程

1. 搜尋 Vault 中含 `#規則候選`、`#準規則`、`#規則延伸` 或 `#臨床疑問` 的區塊，略過已標示收成註記的區塊。
2. 讀取每個區塊的原文、所在檔案、所在章節及必要的前後脈絡；來源檔案就是第一層出處。
3. 若為 `#臨床疑問`，先搜尋 `400_Atlas/Questions/`、相關 MOC 與 Library，建立或更新問題卡：
   - 新卡使用 `200_Reference/templates/臨床疑問卡模板.md`，位置為 `400_Atlas/Questions/`。只有原始提問、尚未查資料者為 `🟤 種子`；完成至少一輪來源與 Library 補充後改為 `🟢 澆水中`，`research_status` 仍為 `🟡 待覆核`；
   - 保留原始問題與初步假說，補上支持材料、其他解釋、資料缺口；
   - 僅在已能形成可檢驗 if–then 條文時，提議或建立一張 `🟡 待覆核` 規則卡並相互連結；
   - 在原區塊後加入 `已收成：[[問題卡]] <!-- question-harvested: YYYY-MM-DD -->`。
5. 若既有問題卡出現 `#資料補充` 或 `#暫定結論`，只更新該問題卡：
   - `#資料補充`：記錄來源與摘錄；有可靠出處的領域資料同步更新既有 Library 詞條並回連，補做增量檢索，更新「檢索紀錄與範圍」；不可重跑整個 Library。
   - `#暫定結論`：檢查是否已有明確適用條件、可觀察結果、至少一個反例／替代解釋與來源連結。資料不足時維持問題卡，將 `conclusion_status` 設為 `🔵 暫定結論`、`application_status` 最多為 `🔵 可作輔助觀察`。
   - 只有條文已形成可檢驗的 if–then 判斷，並可寫出適用邊界與反證，才建立或提議建立 `🟡 待覆核` 規則卡；「規則」表示結構成熟，不表示已被證實正確。
6. 若為 `#準規則`：建立或更新 `400_Atlas/Notes/Rules/` 下的 `P-XXX` 準規則卡，標記 `🟠 準規則`，連到原問題、來源與相關規則；在 [[臨床規則手札 MOC]] 的「準規則網絡」列出它。它只需保留個人結論、至少一個起點來源與未知處，不可假裝成已驗證規則。
4. 若為規則候選或規則延伸，搜尋 `400_Atlas/Notes/Rules/`、相關 MOC、Questions 與 Library，判斷它是：
   - 新規則候選；
   - 既有規則的條件補充；
   - 可獨立驗證的子規則；
   - 衝突／反例；或
   - 尚不足以成規則的問題。
5. 對每個規則候選建立或更新規則卡。新卡使用 `200_Reference/templates/臨床規則卡模板.md`，位置為 `400_Atlas/Notes/Rules/`，初始狀態一律為 `🟡 待覆核`。
6. 規則卡必須保留「我的原始判斷」，並補上：暫定條文、支持來源、可能鑑別／反證、框架接口、待補證據與版本紀錄。
7. 規則卡的 `sources` 必須連回來源頁。Library 中同一本書拆出的多頁屬同一來源脈絡，不可誤報為多份獨立證據。
8. 將新卡加入 [[臨床規則手札 MOC]] 的「待覆核」或對應主題；MOC 只放連結與一句摘要。
9. 在原候選區塊後加入 `已收成：[[規則卡]] <!-- rule-harvested: R-XXX -->`，保留原文不改寫，以避免重複收成。
10. 回報精簡的覆核清單：新卡／更新卡、最重要的支持、最大的疑點或衝突，以及需要使用者決定的地方。

## 覆核原則

- 將「可以判斷」優先改寫為「優先考慮」，除非來源與反證邊界足以支持絕對表述。
- 診斷線索、鑑別線索、策略與具體手段盡量拆開，避免一張卡同時承擔過多可分別驗證的主張。
- L0–L5 是診斷提問座標；衛氣營血、六經、病程快慢等是另一組座標。兩者交叉記錄，不強行互相取代。
- 規則衝突時保留兩側條文與來源，建立 `contradicts` 關係或新增 Question；不得以新卡覆蓋舊卡。
- 沒有清楚來源位置的外部書籍／課程候選，先建立最小 Source（書名、章節／頁碼或影片時間碼）或標為「待補來源」，不可假裝已可追溯。
